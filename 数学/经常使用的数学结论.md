#### 二阶线性常系数非齐次方程的特解

主要是利用待定系数法，看等式右边的不含 y 的  f(x)  项

**如果是  $P_n(x)e^{\alpha x}$ **

i  \alpha  不是特征根，则特解待定为 $H_n(x) e^{\alpha x}$

ii  \alpha  是一重特征根，则特解待定为  xH_n(x) e^{\alpha x} 

iii  \alpha  是二重特征根，则特解待定为  x^2H_n(x) e^{\alpha x} 

这种关键就是记住  H_n(x)  和  \alpha  这两个特征

**如果是  e^{\alpha x}[P_n(x)\sin \beta x+ Q_m(x) \cos \beta x] **

i 如果  \alpha \pm i\beta  不是特征根，则特解为： e^{\alpha x}[R_l(x) \cos \beta x + S_l(x) \sin \beta x] 

ii 如果  \alpha \pm i\beta  是特征根，则特解为： xe^{\alpha x}[R_l(x) \cos \beta x + S_l(x) \sin \beta x] 

这里的 l 是 n, m 两者取大， P_n(x)  表示 n 次多项式，这里记忆的化直接将这整个大式子记住

这里记忆采用三步法

第一步，写出等式右边的函数的一般形式，然后观察一般形式中改取哪些值

第二步，根据根的关系写出特解满足的一般形式，然后确定特解中的值

第三步，代入方程求解

注意  e^{\alpha x}  跟通解中的  e^{\lambda x}  不是一个东西，别弄混了

## 一些曲线几何公式

### 曲率和曲率半径公式

曲率是 K，曲率半径是 1/K

K 的两个公式如下：

曲率 K 的公式：

**参数方程：**
$$
K = \frac{|x^{'}(t)y^{''}(t) - x^{''}(t)y^{'}(t)|}{[x^{'}(t)^2 + y^{'}(t)^2]^{\frac{3}{2}}}
$$
也就是分子是两个式子一阶导和二阶导乘积的差值，分母是两者一阶导平方和开 3/2 次方

**一般方程：**

这是知道了 y (x) 的公式，这里可以将 x 看作参数，所以公式变成：
$$
K = \frac{|y^{''}(x)|}{[1 + y^{'}(x)^2]^{\frac{3}{2}}}
$$
曲率取个倒数就是曲率半径，注意曲率圆的半径是 K 的倒数，而如果题中给出了曲率圆的方程，其常数项其实是曲率半径的平方，别傻乎乎的直接将这个平方数代入了当作半径

### 弧长公式

弧微分 ds 为（参数方程下）：
$$
ds = \sqrt{x'(t)^2 + y'(t)^2} dt
$$
跟前面的曲率一样，x 看成参数得到普通的弧微分：
$$
ds = \sqrt{1 + y'(x)^2}dx
$$

## 多元函数积分学

### 利用定义法来判断对称性

利用定义法理解对称性的本质是考察对称的两个小块上的函数值的关系

比如如果图形是关于 x 对称的，而 f (x, y) 又是关于 x 的奇函数，那么：

（1）我们取一边的点 (x, y)，关于 x 对称的点为 (-x, y)

（2）代入 f (x, y) 观察函数值，可以发现一边是 f (x, y)，另一边是 f (-x, y) = -f (x, y)

（3）而根据二重积分的定义，其实是函数值乘一小块面积，然后相加，这样相加刚好等于零，所以关于 x 对称的区域并且 f (x, y) 关于 x 是奇函数的二重积分结果就是 0 了

这种判断方式用于图形关于 x = a 对称，关于 y = a 对称，都非常好用

### 行列式的逆序数计算方式

一个 n 阶的行列式其实是 n! 项的和

对于其中的一项，其实是 n 个元素的乘积，每个元素依次按顺序取自这 n 行，但是列是不同的

并乘这些元素的-1 的逆序数次幂，这里以 3 阶为例来说明，比如下面一个三阶的行列式：

<img src="https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/image-20241121161529453.png" alt="image-20241121161529453" style="zoom:33%;" />

其中一项是三个元素的乘积

假如第一个元素取第一行第一列，就是 a 11

那么第二个元素取第二行，由于第一列被取过，因此就只有两种取法，只能在第 2 列和第 3 列中取，假设我们取 a 23

那么第三个元素取第三行，就只能取第二列的元素 a 32 了

因此这一行的乘积就是 a 11 * a 23 * a 32

再乘以-1 的逆序对数次幂，这里的逆序对是 a 11 a 23 a 32 这三个元素，任意两个如果列号大的在前面那就是一个逆序对，比如 a 23 a 32 第三列反而排在 a 32 前面这就是一个逆序对，而这个排列中只有这一个逆序对，因此需要乘 ￥(-1)^1￥

因此这一项就是：
￥￥
(-1)^{1}a_{11} a_{23} a_{32}
￥￥
当然这只是其中的一项

第一个元素可以取第一行的 n 列中一共 n 个不同的元素

第一行取了之后第二行只能取 n - 1 列了

第三行只能取 n - 2 列了

因此一共有 n! 中取法，也就有 n! 项乘积，每个乘积项都要乘自己的-1 的逆序数幂，然后将这 n! 项加起来就是行列式的值了

<img src="https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/image-20241121162651099.png" alt="image-20241121162651099" style="zoom:50%;" />

反正只需要记住有 n! 项

每一项元素按顺序取自 1，2，3。。。n 行，并且保证这些元素不再同一列

再乘逆序数幂，逆序数是这一项乘积元素的列排列中逆序对数

### 三阶矩阵特征多项式的韦达定理

三阶矩阵的特征多项式就是：
￥￥
|A - \lambda E| = 0 = \lambda^3 + a \lambda^2 + b\lambda + c = 0 
￥￥
我们可以得到：

（1）特征值的乘积，就是行列式，就是常数项的相反数：
￥￥
\lambda_1 \lambda_2 \lambda_3 = -c = |A|
￥￥
（2）特征值的和，就是矩阵的迹，就是二次型的相反数：
￥￥
\lambda_1  + \lambda_2 + \lambda_3 = -a = tr(A)
￥￥
（3）特征值的交叉项和，就是伴随矩阵的迹，就是一次项：
￥￥
\lambda_1 \lambda_2 + \lambda_1 \lambda_3 +\lambda_2 \lambda_3 = b = tr(A^*)
￥￥
> 这个比较容易证，因为伴随矩阵的特征值就是 ￥\frac{|A|}{\lambda_1},\frac{|A|}{\lambda_2},\frac{|A|}{\lambda_3}￥，代入|A| = ￥\lambda_1 \lambda_2 \lambda_3￥ 就是了

### 矩阵 A 的特征值的性质

注意不管矩阵 A 的特征值是否是复数，下面两条性质是始终成立的：

（1）特征值的乘积是矩阵的行列式

## 矩阵的秩

### 向量组等价的充要条件

证明向量组 A 和 B 等价，就是证明：
￥￥
r(A) = r(B) = r(A|B)，单独的秩等于拼在一起的秩
￥￥
注意向量组等价与矩阵等价是两个不同的概念，向量组等价描述的是线性表示关系，而矩阵等价则是描述初等变换关系

矩阵等价的充要条件是秩相等

但是向量组等价的充要条件就是上面，三秩相等

### AB = 0 的秩的性质

根据 AB = 0 应该立刻反应出下面两个性质：

（1）r (A) + r (B) <= n，这里的 n 是 A 的列数，B 的行数

（2）B 的每一列都是 Ax = 0 的解向量

### 矩阵乘法的秩的性质

矩阵乘法之后其秩一定是越乘越小的：
￥￥
r(AB) \le r(A)且r(AB) \le r(B)
￥￥
### 矩阵加法的秩的性质
￥￥
r(A) + r(B) \ge r(A\pm B)
￥￥
### ￥A^{2} = A￥ 的三种处理方式

（1）矩阵 A 满足这个多项式，因此矩阵 A 的特征值也满足这个多项式，所以特征值有 ￥\lambda^{2} = \lambda￥

（2）将 A 看作一系列的向量，那么 A 中不为零的向量一定是 A 的属于特征值 1 的特征向量

（3）移相得到 ￥A(A - E) = 0￥，可以得到 A 的特征值的秩的关系 ￥r(A) + r(A - E) = n￥

> [!NOTE]
> 这是因为根据矩阵乘法为零的秩的性质有 ￥r(A) + r(A - E) \le n￥，根据矩阵秩加减的性质有 ￥r (A) + r(A - E) \ge r(A-(A - E) = E) = n￥，因此有上面的性质

### A 的伴随和 A 的秩的关系

 如果 ￥r(A) = n￥，则 ￥r(A^*) = n￥

如果 ￥r(A) = n - 1￥，则 ￥r(A^*) = 1￥

如果 ￥r(A) <= n - 2￥，则 ￥r(A^*) = 0￥
## 二次型与合同

### 矩阵合同的性质

矩阵 A 和 B 合同，也就是存在一个可逆矩阵 C 使得 ￥C^T A C = B￥

因此合同之后：
（1）矩阵 A 和矩阵 B 等价
（2）矩阵 A 和矩阵 B 具有完全相同的秩

### 判断矩阵合同以及求矩阵合同的方法

==**判断两个矩阵合同的方法：**==

（1）根据矩阵合同的充要条件：

**两个实对称矩阵合同的充要条件就是他们的正，负特征值个数都相等，即正，负惯性指数都相等**，所以可以直接通过求两个对称矩阵的特征值来判断是否合同，**所以实对称矩阵相似是一定合同的**

（2）只有实对称矩阵才有矩阵合同的概念：

实对称矩阵才能合同实对称矩阵，非实对称矩阵只能合同非实对称矩阵，一般而言矩阵合同仅仅是实对称矩阵之间的概念

==**求合同矩阵的方法（当然前提是知道了两个矩阵合同）：**==

先写出两个矩阵对应的二次型

（1）**通法是利用规范型作为桥梁**

通过 X = Q 1 Z，Y = Q 2 Z，X，Y 这两个二次型都通过线性变换变成了规范型 Z，利用 Z 这个桥梁构造 X 和 Y 的关系

（2）将两个二次型分别化成标准型，然后观察配凑

这种方式一般需要比较强的观察能力

（3）对两个二次型的矩阵强行进行配凑

强行通过观察凑出 ￥Q^T A Q = B￥，这种方法一般在选填的二阶矩阵中使用，超过三阶之后就非常难用了

### 实对称矩阵的性质

（1）**实对称矩阵的非零特征值的个数就是其秩**

> [!NOTE]
> 这是因为实对称矩阵一定可以相似对角化为一个对角矩阵，对角矩阵对角线上的元素就是这个实对称矩阵的特征值，也是这个对角矩阵的特征值，因此非零特征值的个数就是这个对角矩阵的秩，同时也是这个实对称矩阵的秩

（2）**实对称矩阵属于不同特征值的特征向量之间互相正交**

> [!NOTE]
>  **这个性质尤其可以用于 3 阶实对称矩阵中，只要剩下一个特征值的特征向量，我们立刻可以通过已知的特征值的特征向量通过正交得到剩下的一个特征值的特征向量**
>  
>  这里进行简单证明
> 
>  对于一个实对称矩阵 A，假设其有两个不同的特征值 ￥\lambda_1, \lambda_2￥，属于这两个特征值的不同的特征向量是 ￥\eta_1, \eta_2￥，因此有：
>  ￥￥
>  A\eta_1 = \lambda_1\eta_1;A\eta_2 = \lambda_2\eta_2
>  ￥￥
>  我们在 ￥A\eta_1 = \lambda_1\eta_1￥ 上左乘一个 ￥\eta_2^T￥，并且由于 A 是一个对称矩阵，于是得到：
>  ￥￥
>  \eta_2^TA \eta_1 = (A\eta_2)^T \eta_1= \lambda_2 \eta_2^T\eta_1 = \lambda_1 \eta_2^T\eta_1
>  ￥￥
>  由于两个特征值不一样，所以这两个特征向量的乘积一定是 0

**（3）实对称矩阵一定可以相似对角化为一个对角矩阵，并且实对称矩阵与这个对角矩阵相似又合同** 
**（4）实对称矩阵的充要条件就是有 n 个互相正交的特征向量**

> [!NOTE]
>  从左到右，显然成立，这是实对称矩阵的性质
>  
> 从右到左，有 n 个互相正交的特征向量，说明有 n 个互相线性无关的特征向量（因为正交矩阵的行列式不为零，所以 n 个正交向量组成的方阵行列式不为零），因此存在正交阵 Q 有 ￥Q^{-1}AQ = \wedge￥，这里的 Q 是由这 n 个正交向量每个单位化组成的，这里 Q 相比原来的 n 个正交向量组构成的方阵多了个系数，不过乘起来消掉了，对角矩阵没变
> 
> 因此有 ￥A = Q^{-1} \wedge Q \Rightarrow A^T = A￥

### 正交矩阵的性质 + 正交向量组 + 标准正交向量组


==**正交矩阵：**==

（1）正交矩阵的转置等于逆矩阵，这个是正交矩阵的定义：￥Q^TQ = QQ^T = E￥，正交矩阵的行向量组和列向量组都是标准正交向量组

（2）正交矩阵的每个列向量都正交，即点乘为零

（3）正交矩阵的每个列向量的模都是 1

（4）A 是正交矩阵，那么其转置，伴随，逆矩阵都是正交矩阵，并且两个正交矩阵的乘积仍然是正交矩阵

==**正交向量组：**==

两两正交不含零向量的向量组

==**标准（规范）正交向量组：**==

两两正交且向量的模是 1 的向量组

### 可逆线性变换的三种等价关系

二次型 `f(X)` 经过线性变换得到二次型 `g(Y)`，那么下面三种关系是等价的：

**（1）`f(X) = g(Y)`**

这是因为 f (X) 本质上是做了一个换元处理，很显然就是不改变二次型整体的大小

**（2）二次型的变量有：￥X = PY￥**

**（3）若 A 是 f (X) 的矩阵，B 是 g (Y) 的矩阵，那么有：￥P^T A P = B￥**

上面三个关系有一就有剩下两个

### 二次型的最值问题

**（1）一个结论**

对于一个二次型 f (X)，对于矩阵 A，其一定可以找到一个正交矩阵 Q，使得标准化的对角矩阵对角线元素是 A 的特征值，即对 X 做线性变换 X = QY，将 QY 代入 f (X) 得到：
￥￥
f(X) = x^T A x = y^T Q^TAQy = \lambda_1y_1^2 + \lambda_2y_2^2 + \lambda_3y_3^2
￥￥
对于这些特征值不妨设：
￥￥
\lambda_1 \le \lambda_2 \le \lambda_3
￥￥
所以可以直接对 f (X) 进行放缩：
￥￥
\lambda_1 y^Ty \le \lambda_1y_1^2 + \lambda_2y_2^2 + \lambda_3y_3^2 \le \lambda_3 y^T y
￥￥
这样我们就得到了 f (X) 的一个范围

由于 Q 是正交矩阵，而 X 进行正交变换是不改变向量模的大小的，即：
￥￥
x^T x  = (Qy)^T (Qy) = y^Ty
￥￥
所以我们可以直接得到：
￥￥
\lambda_1 x^T x \le \lambda_1y_1^2 + \lambda_2y_2^2 + \lambda_3y_3^2 = f(X) \le \lambda_3 x^Tx
￥￥
上面是一个结论需要直接记住，而题目中经常给出的是 ￥x^Tx￥ 的约束关系，这样我们就得到了 f (X) 的最大值和最小值了

对于这道题，我们只要求出 A 的特征值就可以了

**（2）用拉格朗日乘数法做**

不过还是得进行一次正交变换，X = QY，Q 是正交矩阵，因此有：
￥￥
f(X) = x^T A x = y^T Q^TAQy = \lambda_1y_1^2 + \lambda_2y_2^2 + \lambda_3y_3^2
  
由于正交变换模不变，上述三个特征值已知，因此约束就是： y_1^2 + y_2^2 + y_3^3 = 1 ，一般这个约束是题目中给的，因此可以在这个约束条件下求上面的式子的最值问题

### 正定 + 正定的充要条件和必要条件

正定就是一个二次型 f (X) 中的 X 不管咋取，f (X) 的结果都大于零，此时 f 就是一个正定二次型

**判断正定的充要条件：**

（1）按定义

> [!NOTE]
> **正定的定义的使用：**
> 
> 正定的定义是：
> ￥￥
> x \ne 0，那么二次型f = x^T Ax > 0，那么f就是一个正定二次型
> ￥￥
> 因此如果我们能证明  f \ge 0  并且只有 x = 0 的时候 f 才等于零，那么这个二次型就是正定的
>  f \ge 0  可以根据题目中的条件观察出来，而 x = 0 的时候 f = 0，可以与齐次方程组联系起来


（2）二次型的矩阵 A 的特征值全大于零；A 的规范型的系数全是 1；f 的正惯性系数 p = n；这三条是一种判定方式

（3）A 的全部顺序主子式均大于零；顺序主子式如下图所示，就是下图框起来的行列式：

![image-20241025112220872](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/image-20241025112220872.png)

（4）存在可逆矩阵 D 使得  A = D^T D 

（5）A 与单位阵 E 合同

> （4）（5）其实是一样的，（4）可以看作  A = D^T E D ；这两条如果要证明的话就是，A 如果正定，其规范型的系数一定全是 1，A 合同于一个单位阵；
>
> 即存在一个可逆矩阵 C 有  C^T A C = E ，于是  C^{-1}  就是 D 矩阵

**正定的必要条件：**

（1）A 的主对角线元素全部大于零

（2）A 的行列式大于零

（3）A 是正定矩阵； A^*，A^{-1}  也是正定矩阵

> A 是正交矩阵，A 的伴随和逆也是正交矩阵

（4）A 是正定，则一定有  A = B^2 

> 这是因为 A 一定可以通过正交变换写作  A = Q \wedge Q^{-1} ，中间的对角矩阵的对角线上的元素都是正的，因此这个对角矩阵可以写成一个矩阵的平方，比如  P^2 = \wedge ，那么 A 可以写作： (Q P Q^{-1}) (Q P Q^{-1}) ，所以  B = Q P Q^{-1} ，这里  Q^T = Q^{-1}
