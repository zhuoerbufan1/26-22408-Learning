
### 1 利用定义来求偏导数

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250610103937.png)

其实求偏导数就是求一元函数的导数

这道题首先求 fx' (0, 0) 和 fy' (0, 0)

fx' (0, 0) 就是在 y = 0 的情况下求 f (x, 0) 对 x 的导数，所以对于原式当 y = 0 的时候写出函数式：
$$
\begin{matrix}
f(x, 0) = 0,x\neq  0  \\
f(x, 0) = 0, x = 0
\end{matrix}
$$
对这个一元分段函数在 x = 0 处用定义，显然 fx' (0, 0) = 0

同理得到 fy' (0, 0)  = 0

当然也可以直接按照偏导数的定义求，其实都是一样的

然后是 0，0 处的二阶偏导

先求出 fx' (x, y) 和 fy' (x, y) 的函数式子，以 fx' (x, y) 为例：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250610105015.png)
fx' (0, 0) = 0


要求 fxy'' (0, 0) 其实就是求 fx' (0, y) 在 y = 0 处的导数

所以直接 x  = 0 代入 fx' (x, y) 得到 fx' (0, y) = 1 (y != 0)；fx' (0, y) = 0 (y = 0)

直接按照一元导数定义求导，结果不存在

同理 fyx'' (0, 0) 也是这样求
