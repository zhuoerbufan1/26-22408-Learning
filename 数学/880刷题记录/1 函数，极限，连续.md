==证明单调的方法==

作差，作除，将递推关系抽象成一个函数，根据函数的单调性
由 $x_{n + 1} = \sqrt{ a + x_{n} }$，抽象出来函数 f (x) = $\sqrt{ a + x }$

这个函数是单调增的，所以原来的数列一定单调，若 x 2 > x 1，则单增，若 x 2 < x 1，则单调减

但是如果这个函数是单调减的，则原来的数列一定不单调

上面两句话的证明方法都是根据 x 2 > x 1，两边取 f ()，得到 f (x 2) > f (x 1)，再根据递推关系，得到 x 3 > x 2，然后再取 f ()，得到 f (x 3) > f (x 2) 得到 x 4 > x 3，就这样递推下去，所以 xn > xn -1，所以本题数列单增


==证明有界性的通法==

用数学归纳法证明

我们事前已经在草稿纸上求出了极限 A，即设 $A = \frac{1 + \sqrt{ 1 + 4a }}{2}$ 那么这个极限 A 一定满足：

$$
A = \sqrt{ a + A }
$$
然后用数归

首先 a 1 < A

然后，假设 an-1 < A

那么 $a_{n} = \sqrt{ a + a_{n-1} } < \sqrt{ a + A } = A$

即证
