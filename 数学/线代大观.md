# 模拟题线代题目汇总

## 线代铜专题

### 代数余子式

#### 1

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20251202110503.png)

这道题可以得到 r (A) = 3，因此 $r(A^{*} ) = 1$

下面有两个角度可以思考

**（1）从 A 和 $A^{*}$ 的特征向量和特征值的角度**

这里假设 A 的特征值是 0, $\lambda_{1}, \lambda_{2}, \lambda_{3}$
那么 $A^{*}$ 的特征值就是 $\lambda_{1}\lambda_{2}\lambda_{3}, 0, 0, 0$

所以这里 $(1, -2, -2, 1)^{T}$ 就是 $A^{*}$ 的属于特征值 $\lambda_{1}\lambda_{2}\lambda_{3} = \eta$ 的特征向量

于是得到：

$$
A^{*}(1, -2 ,-2, 1)^{T} = \eta(1 ,-2 ,-2, 1)^{T}
$$
