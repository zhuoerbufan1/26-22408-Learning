### 易错点：反三角变换

对于 arcsin x 来说其图像为：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250513114537.png)

它的定义域一定是 `[-1, 1]`，值域一定是 $\left[ -\frac{\pi}{2}, \frac{\pi}{2} \right]$

所以对于 y = sin x，我们如果**想要用 y 来表示 x**，即去掉 sin 符号，进行反三角运算，那么就需要注意 x 的范围

如果 x 在 $\left[ -\frac{\pi}{2}, \frac{\pi}{2} \right]$ 中，那没问题，直接进行互逆运算，两边 arcsin 运算得到 $\arcsin y = \arcsin(\sin x) = x$，非常正确，符合反三角的定义域和值域

但是如果 x 不在 $\left[ -\frac{\pi}{2}, \frac{\pi}{2} \right]$ 中，比如 x 的范围是 $\left[ \frac{\pi}{2}, \frac{3\pi}{2} \right]$

那么对于 y = sin x，两边进行反三角运算：arcsin y = arcsin (sin x)，就不能直接等于 x，因为这样就不符合 arcsin y 的值域

这里必须用诱导公式对 x 进行变换，将其定义域变换到 $\left[ -\frac{\pi}{2}, \frac{\pi}{2} \right]$ 中，即 $y = sin x = sin (\pi - x)$

然后再两边取反三角：

$$
\arcsin y = \arcsin (\sin x )= \arcsin (\sin(\pi - x)) = \pi - x
$$
此时 $\pi -x$ 在反三角 arcsin y 的值域中，这时才成立，即对于 $\sin x = y$，当 x 的范围是 $\left[ \frac{\pi}{2}, \frac{3\pi}{2} \right]$ 的时候 $x = \pi - \arcsin y$
### 易错点：基本不等式取等

在得到一个式子的时候，比如 $f (x, y) = x  y + \frac{x}{y}x + \frac{y}{x}y$，x, y 均大于零

这里对后半部分使用基本不等式得到 $f (x, y) >= xy + 2\sqrt{ xy }$，这是正确的，因为后半部分取得最小的条件是 x = y，前半部分不变，当然有 $f (x, y) >= xy + 2\sqrt{ xy }$


并且取等的条件就是 x  = y，即当 x = y 的时候有 $f (x, y) = x  y + \frac{x}{y}x + \frac{y}{x}y = xy + 2\sqrt{ xy }$


但是这里只能认为 x = y 的时候能取到等号，不能认为 x = y 的时候取到最小值！即不能认为 $\frac{x}{y}x + \frac{y}{x}y \geq 2\sqrt{ xy }$，代入 x = y 得到 $\frac{x}{y}x + \frac{y}{x}y \geq 2x$，更不能认为 x = y 之后有 $f(x, y) \geq x^2 + 2x$


因为利用基本不等式放缩，本质上是两个函数的大小，即 $f (x, y) = x  y + \frac{x}{y}x + \frac{y}{x}y \geq xy + 2\sqrt{ xy } = g(x, y)$，等号成立的条件是 x = y

这个的含义是在 x = y 的时候 f (x, y) 和 g (x, y) 相切，并且在 x != y 的时候 f (x, y) 图像始终在 g (x, y) 图像的上方；但是不能认为 x = y 的时候这个条件就是 f (x, y) 或者 g (x, y) 的最小值！，所以不能将 x = y 的条件代入 f (x, y) 认为 f (x,  y) >= x^2 + 2 x !!!


就像 $(x - 1)^2 + x >=0 + x$ 取等条件是 x = 1；但是不能认为 x = 1 就是 (x - 1)^2 + x 的最小值，而只能认为 x = 1 的时候 (x - 1)^2 + x 与 x 这两个函数取同一个值，并且在 x != 1 的时候 (x - 1)^2 + x > x，这两个函数图像如下：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250612100159.png)


这也是为什么基本不等式放缩到一个常数的时候才认为取这个条件是最小值；这里其实省略了一步

比如有 ab = 4，那么 $a + b \geq 2\sqrt{ ab } = 4$，当 a = b = 2 的时候 a + b 取得最小值 4

这里的实际含义是当 a = b 的时候 a + b 与 4 相等，当 a != b 的时候 a + b > 4，所以此时 4 才是 a + b 的最小值，这里只是因为 4 是一个常数，在 a = b 的时候 a + b 取到 4，a != b 的时候 a + b > 4 才认为 4 是 a + b 的最小值；而不是 a = b 的时候就认为此情况下 a + b 取到最小值，如果题目没说 ab = 4，那么根据 $a + b \geq 2\sqrt{ ab }$，取等条件是 a = b 只能认为 a + b = 2 sqrt{ab}，而不能认为 a = b 的时候 a + b 取最小 a  + b  = 2 a 最小，这是错的

### 函数极限乘除运算的易错点，已知项非零

在计算 $\lim_{ x \to x_{0} } f(x)g(x), \lim_{ x \to x_{0}} \frac{f(x)}{g(x)}$ 的时候，如果 g (x) 的极限已知 = A，一般只有 A $\ne 0$ 的时候才能拆成 $A * \lim_{ x \to x_{0} } f(x), \lim_{ x \to x_{0}} \frac{f(x)}{A}$ ，通过计算 f (x) 的极限来做

而当 A = 0 的时候则考虑不能拆开来做，这是因为：

(1) 当计算乘积的时候，如果 f (x) 的极限是无穷，则无法拆成 0 * 无穷来计算整体乘积极限
(2) 当计算除法的时候，如果 A = 0，那就更不能拆开分别计算了
(3) 当然如果 f (x) 极限是有界量，那乘积提前计算结果其实就是 0，但是除法不能拆开


### 易错点：洛一次之后与导数的连续性，不能直接代入结果
其定义如下：

![image.png|684x341](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250415083902.png)


注意只要是 f (x) 和 g (x) 在 a 的一个空心领域中可导就可以洛一次，即：$lim \frac{f(x)}{g(x)} = lim \frac{f’(x)}{g’(x)}$，洛必达是通过结果反推的，如果可洛，洛完之后可以计算出极限 A，则原来的极限就是 A；但是如果洛完之后发现算不出，此时不能说明原来的极限不存在，需要换方法进行计算

但是计算 $lim \frac{f’(x)}{g’(x)}$ 不能直接代入 f’(x) 或 g’(x)，因为只有 f’(x) 和 g’(x) 在 a 点连续的时候才能代入

如果是抽象函数，题目没有说 f’(x) 和 g’(x) 在 a 点连续那就不能使用洛必达，因为洛出来的结果未知得不到 $lim \frac{f’(x)}{g’(x)}$ 是否等于 A，所以上面洛一次就是错误的，不能使用洛必达

但是如果是具体函数，可以用定义算出 a 点的 f (x) 和 g (x) 的导函数，即可以算出 $lim \frac{f’(x)}{g’(x)} = A$，那洛必达就是有效的

所以只要能求出 $lim \frac{f’(x)}{g’(x)} = A$ 即，$lim \frac{f’(x)}{g’(x)}$ 存在或者是无穷，那洛必达就是可用的，至于导数连不连续则是在代入极限需要做的事情，一般而言如果 n 阶导数存在并且连续，那么就可以洛到 n 阶，但是如果 n 阶导数只是存在没有说连续，则此时计算有关 n 阶导有关的东西时就需要凑导数的定义，而不是直接代入 n 阶导在趋于 a 处的值

### 易错点：不能根据原函数的极限来得到导函数的极限，洛必达不能反用

在满足了洛必达的，0 比 0，邻域可导，且 g' (x) != 0 的条件下，不能根据原函数的比值极限值而得到导函数的极限值

一个反例就是 $f(x) = x^2 \sin\left( \frac{1}{x} \right)$ 和 $g(x) = x$

考察在 x = 0 处的 $\frac{f(x)}{g(x)}$ 的情况，两者都是 0 比 0，并且都可导，并且 g (x)' != 0

原来的比值极限很容易得到是 0

但是导函数的比值极限分子中会出现一个 cos 1/x，这样会出现震荡的，极限不存在

因此洛必达的条件不能反用，只能在未知原比值极限的条件下导一次得到导函数的比值极限从而得到原函数的比值极限；不能在知道原函数的比值极限的条件下得到导函数的比值极限

### 易错点：无穷小运算的等号更像是属于，而不是相等

对于无穷小加减运算来说，低阶无穷小会吸收高阶无穷小：

$$
o(x^2) \pm o(x^3) = o(x^2)
$$

这里的等号更像是左边集合属于右边的集合，并不意味着左右两边的幂相等

比如 $x^2 - \sin x^2 = o(x^2)$，左边的式子在相减之后与 x^6 同阶，但是仍然属于 o (x^2)，所以无穷小的运算中的等号其实是一个很粗略的信息，应该是左边包含于右边的意思

一般如果知道了式子 $f(x)$ 的具体阶数 k 的话，可以直接将其替换成 $Cx^k + o(x^k)$ 放到式子中，这样不容易犯错

比如上面 $\sin x^2$ 其实是 $x^2 - \frac{1}{6} x^6 + o(x^6)$，那么这个式子其实真实等价于 $x^2 - x^2 + \frac{1}{6}x^6 + o(x^6)$，可以看到其是一个与 x^6 同阶的无穷小

###  易错点：函数如果不连续则不能直接代入极限

极限研究的是趋近性，而不是这个点的实际值，比如：

$$
\lim_{ x \to 0 } \frac{f(x)}{x} = 1
$$

这里只能得到 $\lim_{ x \to 0 } f(x) = 0$，只有说了 f (x) 连续，才有 f (0) = 0，否则 f (x) 在 x = 0 的实际具体值是不知道的

所以我们直接代值到极限观察趋近也是因为 f (x) 连续才能直接代值观察的

比如 $\frac{x}{\sin x}(x\to 0)$，这是一个零比 0 的极限，这里说的 0 比 0 是趋近的意思，这是因为 x 和 sinx 都是连续函数，所以我们可以通过其在 x = 0 的具体的值来得到趋近的值（就是 0），当然最后的极限结果是 1

同理对于：

$$
\lim_{ x \to 0 } \frac{e^{x\ln(x + 1)} - 1}{x^2}
$$
因为 xln (x + 1) 在 x = 0 是连续的，所以我们可以知道 xln (x + 1) 在 x 趋近 0 的时候也是趋近 0 的，所以可以进行等价替换：

$$
\frac{e^{x\ln(x + 1)} - 1}{x^2} = \frac{x\ln(x + 1)}{x^2}(x\to 0)
$$

再看一个易错的例子：
![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250604110640.png)

这道题目可以洛两次：

$$
\lim_{ x \to 0 } \frac{f''(x)}{2}
$$
但是，这里不能代入 f'' (0) = 2，因为 f'' (x) 不一定是连续的，题目中只说了二阶可导，即二阶导函数存在，但是 x = 0 处不一定连续，所以上式无法得到结果

正确的做法是洛一次：

$$
\lim_{ x \to 0 } \frac{f'(x) - 1}{2x}
$$

然后凑导数的定义：

$$
\lim_{ x \to 0 } \frac{f'(x) - 1}{2x} = \frac{f'(x)-f'(0)}{2(x - 0) } = \frac{1}{2}f''(0) = 1
$$

### 泰勒展开系数对应的易错点（利用泰勒公式求 n 阶导的方法）

一般这种问题就是直接求函数的 n 阶导不好求，需要利用常见的泰勒带具体系数的展开，来得到 an 和系数的关系，从而得到 n 阶导

题中给定一个常见的函数我们可以明确知道其泰勒带具体系数展开，比如 $x^2\ln(x + 1)$，这时题目要求这个函数在 x 0 处的 n 阶导，为了不出错，应该遵循下面的步骤

（1）写出 f (x) 在 x 0 处的带未知系数的展开（幂级数）：
$$
x^2 \ln(x + 1) = a_{0} + a_{1}(x - x_{0}) + a_{2}(x - x_{0})^2 + \dots \dots +a_{n}(x - x_{0})^n + o((x - x_{0})^n)
$$
（2）写出 $f(x)$ 的具体的系数的泰勒展开（一般是常用函数的泰勒展开）：
$$
x^2 \ln(x + 1) = (x - x_{0})^3 - \frac{1}{2}(x - x_{0})^4 + \frac{1}{3} (x - x_{0})^5 + \dots\dots \frac{(-1)^n}{n + 1}(x - x_{0})^{n + 3}
$$
（3）根据具体的通项泰勒**展开的次数**判断其对应带未知系数展开的哪一项，比如这里具体通项中是 n + 3 次，所以应该对应带未知系数展开中的第 n + 3 项，即 a (n + 3)，而不是 an

（4）写出带未知系数展开中的第 n 项对应的具体泰勒展开通项，这里就是 $a_{n}(x - x_{0})^n = \frac{(-1)^{n-3}}{n -2}(x - x_{0})^{n}$

然后根据 $a_{n} = \frac{f^{(n)}(x_{0})}{n!}$，从而得到 f (x) 在 x 0 处的 n 阶导

主要根据就是三点：

（1）带未知系数的这种泰勒展开是所有函数的通法，即 $\sum a_{i}(x-x_{0})^i$ 这种，它这里的系数有一个公式就是 $a_{i} = \frac{f^{(i)}(x_{0})}{i!}$，这是第 i 项的系数

（2）一个常见函数我们可以直接凑出具体的泰勒展开，我们同样可以得到第 i 项的系数，并且这个系数是具体的可知的

（3）根据具体的泰勒展开和带未知系数的泰勒展开的次数对应关系来得到 ai 的表达式，而 $a_{i} = \frac{f^{(i)}(x_{0})}{i!}$，这样就可以求出 i 阶导数了


==在 x  非零处泰勒展开的处理==

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250719100531.png)

这里需要求的是 f (x) 在 x = 1 处的泰勒展开，但是你 ln (1 + x) 中的 x 是趋于 1 的，所以不能用常见的泰勒公式直接展开成具体系数的形式

这里的处理措施是将 ln (1 + x) 中凑成 ln (1 + A)，其中 A 是 x - 1 的形式，这样 x = 1 的时候 A = 0 于是就可以将 A 看作一个整体进行泰勒展开了：

$$
f(x) = (x - 1)^2\ln(2 + x - 1 ) = (x - 1)^2 \ln\left( \frac{2 + x - 1}{2} * 2\right ) = (x - 1)^2\ln 2 + (x - 1)^2\ln(1 + \frac{x-1}{2})
$$

也就是 $f(x) = (x - 1)^2\ln 2 + (x - 1)^2\ln(1 + \frac{x-1}{2}) = (x - 1)^2\ln 2 + g(x)$

这个函数的的 2025 阶导是和 g (x) 的 2025 阶导是一样的，所以我们只用求 g (x) 在 x = 1 处的 2025 阶导即可

$$
g(x) =  (x - 1)^2\ln(1 + \frac{x-1}{2})
$$

那就是求这个函数在 x = 1 处的泰勒展开了

理论带未知系数的形式是：

$$
g(x) = a_{0}  + a_{1}(x - 1) + a_{2}(x - 1)^2 + \dots \dots +a_{n}(x - 1)^n + o((x - 1)^n)
$$

然后就是利用常见的公式写出带具体系数的泰勒展开，你这里将 x-1/2 看作一个整体，对这个整体在 0 处的展开为：

$$
g(x) = (x - 1)^2\left[ \frac{x-1}{2}  - \frac{1}{2} \left( \frac{x-1}{2} \right)^2 + \dots (-1)^{n - 1} \frac{1}{n} \left( \frac{x-1}{2} \right)^n \dots\right]
$$

它的通项就是：

$$
(-1)^{n-1}  \frac{1}{n} \frac{1}{2^n}(x - 1)^{n + 2}
$$

你这里，虽然是对 x-1/2 整体在 0 处的展开，但是写成的形式是关于 x-1 的多项式，所以对于 g (x) 来说就是在 x = 1 处的展开

根据 x - 1 的次数关系，所以有：

$$
a_{n + 2} = \frac{g^{(n  + 2)}(1)}{(n + 2)!} = (-1)^{n - 1} \frac{1}{n} \frac{1}{2^n}(x - 1)^{n + 2}
$$


因此 $g^{(n + 2)}(1) = (-1)^{n - 1} \frac{1}{n} \frac{1}{2^n}(n + 2)!$


n = 2023 就是结果了




### 易错点：单调性和导数正负互相推导


如果说了函数可导：

（1）只有 $f'(x) \ge 0$ 且等号在有限个点成立，函数才严格单增，如果没说有限个点 = 0，则只能说明函数广义单增

（2）函数严格单增，只能说明 $f'(x) \ge 0$，但是无法说明 $f'(x) >0$，比如 x^3

如果没说函数可导：

那么由函数单增无法推出导数的正负，甚至无法得到函数是否连续，以及导数是否存在

也就是两个易错点：

（1）没说函数可导，无法通过单调性推出导数信息
（2）函数可导，f' (x) 只有在有限个点处等于 0，才能根据其正负推出严格单调，否则就只是广义单调

### 易错点：凹凸性与函数二阶导的关系

（1）只有 $f''(x) \geq 0$ 并且等号在有限个点成立，函数才是凹的，如果没有有限个点取等 0，则不能说函数是凹的

（2）反过来，如果一个函数是凹的，也只能推出 $f''(x) \geq 0$，不能得到 $f''(x)$ 严格大于 0，比如 x^4



### 易错点：某点可导与领域连续和领域单调的关系

如果知道 $f'(x_{0})$ 在某点可导，并且 $f'(x_{0}) >0$，则在一个领域 $(x_{0} - \delta, x_{0} + \delta)$ 中：

（1）**无法得到函数的单调性**，这个不多说，一个说烂的例子是：

（2）**无法得到函数的连续性**，比如 $f(x) = x^2 D(x)$，D (x) 是迪利克雷函数，x 取有理数的时候是 1，无理数的时候是 0，x^2 D (x) 在 x = 0 连续并且可导，但是不存在一个领域这个函数连续

反正就是由一点可导，无法推出区间的性质

### 易错点：某点连续不能推出领域存在或者连续

函数 f (x) 在 x 0 点连续，无法推出存在一个领域使得 f (x) 在这个领域中连续，也无法推出存在一个领域使得 f (x) 在这个领域内有定义

一个典型的例子就是类似迪利克雷函数

f (x) = 0，x 是有理数才成立

那么在 x = 0 点处，根据连续的定义：

(1) x = 0 有定义，这个确实，就是 f (0) = 0
(2) 在 x -> 0 的时候 f (x) 极限趋近于 0，这个也确实，根据极限的定义，对于任意的 $\epsilon > 0$，存在一个 $\delta$，当 x 在这个领域中的时候（取有理数），即 $|x - 0| < \delta$，有 $|f(x) -f(0)| = 0 <\epsilon$，因此 f (x) 在 x = 0 处连续

所以 f (x) 是在 x = 0 连续的，并且其实 f (x) 在它的定义域，任意一个有理数都连续

但是存在一个 0 的领域使得 f (x) 有定义吗？当然不是，因为任意一个领域都包含了无理数，f (x) 当然没有定义，既然没有一个领域使得 f (x) 有定义，那当然也就不存在一个领域使得 f (x) 连续了


### 易错点：极值点和驻点，可导，连续的关系

x 0 是 f (x) 的极值点，则 f (x) 在 x 0 处不一定是驻点，也不一定可导，也不一定连续

极值点与这三者没有任何必然联系

只有说了 f (x) 在 x 0 可导之后，如果此时 x 0 是极值点，这时这个极值点才是驻点，也可导，同样也连续；但是驻点还是不一定是极值点，比如常函数，比如 x^3 在 x = 0 处


### 易错点：极值点和最值联系

（1）极值点是某一点范围的概念，因此**极值只能在区间内部取得**，最值可以在区间得端点取得

（2）**除了常函数**，根据极值和最值的定义，如果最值 f (x 0) 在区间内部取得，那 x 0 也是极值点；

（3）**如果 f (x) 在开区间可导，并且 x 0 是区间内部**的唯一极值小（大）点，则这个 f (x 0) 是最小（大）值

这里可以用反证法证明

假如 x 0 是 (a, b) 内部的唯一极小值，并且它不是最小值，还有一个 x 1 在区间内部使得 f (x 1) 更小，那么考虑闭区间[x 0, x 1]，在这个闭区间中 f (x) 由于是可导的，所以一定会取得最大值，并且最大值不会在端点处取得，一定会在[x 0, x 1]区间内部取得一个 x 2 是最大值， f (x 2) 在区间内部取得，那 x 2 也是极值点，并且是极大值点，与 x 0 是唯一的极小值点矛盾，所以 f (x 0) 就是最小值



（4）常函数认为每一点既是最大值也是最小值，但是不认为这一点是极值，这是一个特殊情况，剔除即可
