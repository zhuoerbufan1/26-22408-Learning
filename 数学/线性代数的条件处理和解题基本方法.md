## 矩阵

### 条件处理： $A = - A^T$ 

也就是 A 是一个反对称矩阵的性质

（1）反对称矩阵的对称线上的元素全为 0

（2）奇数阶的反对称矩阵的行列式为 0

（3）对于任意的向量 x，有 $xAx^{T} = 0$ 

$xAx^{T}$ 其实是一个数字，它取转置有：

$$
(xAx^{T})^{T} = xA^{T}x^{T} = -xAx^{T} = xAx^{T} \implies xAx^{T} = 0
$$


### 条件处理： $a_{ij} = -A_{ij}$ 与 $a_{ij} = A_{ij}$，A 是 3 阶非 0矩阵

这个条件可以得到：

（1）$A^{T} = -A^{*}$（最重要）
（2）|A| = -1
（3）r (A) = 3
（4）A 为正交矩阵


后面（2）（3）（4）都是由第一条推导出来的

对于第一条，首先得出|A| = ai 1 + Ai 1 + ai 2 + Ai 2 + ai 3 + Ai 3 是一个平方和的结构，推出 A 的行列式不为 0

然后两边取行列式得到 |A| = -1




==对于 $a_{ij} = A_{ij}$ ==

这个条件可以得到：

（1）$A^{T} = A^{*}$
（2）|A| = 1
（3）r (A) = 3
（4）A 为正交矩阵

### 条件处理：n 阶矩阵A 可逆的 4 个等价条件

（1）A 的行列式 != 0
（2）r (A) = n
（3）A 的列向量组线性无关
（4）A 没有 0 特征值

### 判断矩阵可逆的三个方法

（1 ）行列式不等于 0

（2）矩阵的秩= n

（3）特征值全部非零


### 条件处理：AB = A + B

（1）将所有的项移动到等号左边，写成 (A - E) (B - E) = E 的形式，说明 A-E 和 B -E 互为逆矩阵

（2）根据第一条，(B - E) (A - E) = E，所以 BA = A + B = AB，即 AB = BA

$$

### 条件处理：$E + k\alpha\beta^{T}$

这里 $\alpha$ 和 $\beta$ 是列向量，所以 $\alpha \beta^{T}$ 是一个 r= 1 的矩阵

这个条件的处理方法是，令 $A = E + k\alpha\beta^{T}$，然后有：

$$
k\alpha \beta^{T} = E - A \implies (k\alpha \beta^{T})^{2}  = (E - A)^{2} = k^{2} l \alpha \beta^{T} = k^{2} l \frac{A - E}{k} = kl(A - E) = (A - E)^{2}
$$

这样转换成一个关于 A - E 的式子，这里的 l 是 $l = \beta^{T} \alpha$ 是一个常数

==看一道例题：==

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250729143441.png)

这里就说明了 A 的特征值是 a，特征向量就是一个全 1 的向量

现在思考怎样才能根据这个特征值与特征向量联系伴随矩阵相关的东西

我们想到伴随矩阵与 A 矩阵的特征值和特征向量的联系：

$$
\lambda_{A^*} = \frac{|A|}{\lambda_{A}}, \eta_{A^*} = \eta_{A}
$$

所以 A 伴随的特征值就是 1/a，并且全 1 向量也是 A 伴随的特征向量，所以 A 伴随的每一行之和就是 1/a

而题目的刚好就是 A 伴随的第一行元素，所以结果就是 1/a

### 条件处理：$P=(\alpha, A\alpha, A^2\alpha)$ 可逆

这个条件一般就要写成 $AP = P\wedge$ 或者 $AP = PB$ 的形式，然后通过 P 可逆得到：

$P^{-1}AP = \wedge$ 或者 $P^{-1}AP = B$ 从而得到 A 的相似关系
