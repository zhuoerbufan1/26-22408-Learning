### 2 关于极限的 3 条结论

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20251204120133.png)

这道题按照 $f_{n+1}(x_{n + 1}) = k$，$f_{n}(x_{n}) = k$ 可以得到 xn 是递减的（按照某一年的数列极限真题来做），并且 x 有下界，因此极限一定存在，又根据 $x^{n}+nx = k$ 因此等式左边 n 取极限之后结果就是 k

因此 xn 的极限必须是 0，如果不是 0，那必然是一个>0 的数，这样 $x_{n}^{n} + nx_{n} = k$ 等式左侧趋近无穷了，而 k 是一个固定的值，显然不成立

所以 xn 的极限就是 0

所以题目中的式子可以写成：

$$
\lim_{ n \to \infty } (1 + x_{n})^{1/x_{n}} n*x_{n} = e^{\lim_{ n \to \infty } n * x_{n}}
$$

由题意：

$$
x_{n}^{n} + nx_{n} = k \implies nx_{n} = k - x_{n}^{n}
$$

因此可以得到：

$$
\lim_{ n \to \infty } (1 + x_{n})^{1/x_{n}} n*x_{n} = e^{\lim_{ n \to \infty } k - x_{n}^{n}}
$$

由于 n 趋于无穷的时候 xn -> 0 所以结果当然就是 e^k 了

### 4 用拉格朗日来判断正负或者 0 的情况

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20251204145534.png)


举一个特值，直接排除 AC

对于 B 来说是积分极限，因此构造数值不等式：

$$
F(x) = 4\int_{0}^{x}tf(t)dt - 3x \int_{0}^{x}f(t)dt
$$

这里求一次导得到：

$$
F'(x) = xf(x)-3\int_{0}^{x}f(t)dt
$$

显然，需要再求一次导，得到：

$$
F''(x) = xf'(x) - 2f(x)
$$


还是无法得到什么结果，所以继续求导：

$$
F'''(x) = xf''(x) - f'(x)
$$

还是无法得到什么结果，但是不能继续求导了，因为题目只说了二阶可导，这里用一次拉格朗日：

$$
F'''(x) = xf''(x) - (f'(x) - f'(0)) = xf''(x) -f''(\xi)x = x(f''(x )-f''(\xi)),\xi \in(0, x)
$$

所以 F''' (x) > 0 因此得到 F''(x) 递增，因此F'' (x) > 0 因此 F' (x) 递增，因此 F' (x) > 0，因此 F (x) 递增，又 F (0) = 0，所以 F (x) > 0，所以 B 正确
