这道题的处理思路是根据 f (0) = 0，可以得到 f' (0) 必然为 0，然后将这个极限拆开：

$$
\lim_{ x \to 0 } \frac{f(x)-f(0)}{x} + \lim_{ x \to 0 } \frac{f'(x)-f'(0)}{x} = 1 \implies \lim_{ x \to 0 } \frac{f'(x)-f'(0)}{x} = 1\implies f''(0) = 1
$$

这里只能得到一点处的二阶导的正负，二阶导没有说连续，因此无法得知领域的二阶导情况，所以凹还是凸无法确定

但是根据 $\lim_{ x \to 0 } \frac{f' (x)-f' (0)}{x} = 1$ 可以得到 0 的右领域 f' (x) > f' (0) = 0，所以递增，0 的左领域 f' (x) < f' (0) = 0，所以递减

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250418115328.png)

这道题跟上面类似，一阶导 > 0，但是一阶导是否连续未知，无法得到领域的一阶导信息，但是按照 0 处的定义：

$$
\lim_{ x \to 0 } \frac{f(x)-f(0)}{x} > 0
$$

可以得到在右领域 f (x) > f (0)，左领域 f (x) < f (0)

因此 C 正确

假如这里第一问改成 f'' (x) 连续，则可以得到 lim f'' (x) (x -> 0) = 1，此时可以得到 0 附近一个领域是>0，可以得到是凹函数，但是这里只得到 f'' (0) = 1，没说连续，因此无法得到二阶导的极限信息，无法使用二阶导的极限的保号性，当然也就无法得到领域的二阶导信息了

### 2 微分方程法构造函数

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20251129151000.png)

这道题移向求导展开之后得到：

$$
f(x) + xf'(x) + kf(x) \leq 0
$$

按照微分方程法构造函数得到：

$$
F(x) = x^{k + 1}f(x)
$$

因此 F' (x) <= 0，F (x) 是一个递减的函数

因此代入 x = 2 得到：

$$
2^{k + 1}f(2) = 2^{k + 1}\geq x^{k + 1}f(x)
$$

也就是说，当 x 逼近无穷的时候 $F(x) = x^{k + 1}f(x)$ 大于 0，并且小于一个有界量 $2^{k+ 1}$

而 $x^{k + 1}$ 在 x 逼近无穷的时候是无穷，所以只有 f (x) 逼近 0 才能满足

所以 A 正确

但是如果想要推导的话根据题目条件可以得到 B = AC，C 这里已知

$$
A^{-1} + B^{-1} = A^{-1} + C^{-1}A^{-1} = A^{-1}(C^{-1} + E)
$$

$$
(A^{-1}+B^{-1})^{*} = (C^{-1}+E)^{*}(A^{-1})^{*}
$$

这个两边再取行列式计算就可以了

但是对于这类的 $A^{-1} + B^{-1}$ 的处理的通法是：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20251129162107.png)
