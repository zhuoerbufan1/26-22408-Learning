这道题判断极值得用到定义法，将这个式子写成关于 x 的式子，这里 y 不可能为 0，否则原式就不成立，所以可以放心除过去：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20251106115303.png)

观察 x = 0 处的 y 的值，可以发现 x= 0 的时候 y = 1，那么 x 在 0 的左右摇摆的时候|x|始终是 >= 0 的，因此 $\frac{e -e^{y}}{y} \geq 0$，观察这个式子，只有 y <= 1 的时候 $\frac{e -e^{y}}{y} \geq 0$ 才能成立，所以 x 在 0 的左右摇摆的时候 y <= 1，因此 y = 1 当然就是极大值

关于可不可导，这里得用到定义法

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20251106115711.png)

这里虽然 y 是和 x 的绝对值满足这个方程，但是对于 y 和 x 本身而言在 x = 0 的领域左右都是可导的，所以可以直接用洛必达得到：

$$
y'_{+}(0) = \lim_{ x \to 0^{+} } y'
$$

右导数就是 x > 0 的时候 y'在 0 处的右极限，所以对于原来的式子，当 x > 0 时有 xy + e^y = e，两边对 x 求导得到：

$$
y + xy' + e^{y}y' = 0 \implies y' = -\frac{y}{x + e^{y}}
$$
当 x -> 0+的时候，由于 $x = \frac{e -e^{y}}{y}，x > 0$，x 在 0 处连续，所以 y 本身肯定也是在 x = 0 连续的（连续函数的反函数也是连续函数），所以直接代入 y = 1 x = 0 到上面的式子中可以得到 y' = -1/e，即右导数是 -1/e

同理可以得到左导数，从而发现左导数和右导数不一样，因此不可导

### 3 用泰勒展开处理高阶导数

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20251106162645.png)


这道题应该是 2025 阶导，而不是 2024 阶

$\frac{1}{1  + t}$ 的泰勒通项，第 n 项是 $(-1)^{n} t^{n}$

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20251106164006.png)


因此 $\frac{t^{2023}}{1 + t}$ 的通项就是 $(-1)^{n}t^{n + 2023}$

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20251106164040.png)


所以 $\int_{0}^{x} \frac{t^{2023}}{1 + t} dt$ 的通项就是：

$$
(-1)^{n} \frac{1}{n + 2024} x^{n + 2024}
$$

n 从 0 开始：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20251106164100.png)


所以 f (x) 可以写成：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20251106164154.png)

这里只有 $x * \frac{x^{2024}}{2024}$ 这一项求 2025 阶导然后代入 0 还有系数存在，所以结果就是 C 正确

或者换种思路，$f^{(2025)}(0)$ 按照 f (x) 的泰勒展开是 x^2025 次方的系数：

$$
\frac{f(0)^{2025}}{2025!}x^{2025}
$$



这是第 2025 项的含高阶导的通项，它的系数与下方 f (x) 的第 2025 次方具体通项系数应该是相同的：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20251106165102.png)

所以有：

$$
\frac{1}{2024} = \frac{f(0)^{2025}}{2025!}
$$

因此 C 正确

这道题无法根据 f (x) = xln (x + 1) 这种简单的函数直接求出 x = 0 处展开的 f (x) 的具体通项，然后与含有 n 阶导的通项进行系数对比求出 n 阶导（即无法求出 $f^{(n)}(0)$）

### 4 变限积分的定义域问题

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20251106165403.png)


![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20251106165956.png)

对于 y = f (x)，比如 y = 1/x-1，只要能保证 y 是存在的，那么在 y 存在的情况下的 x 的范围就是定义域，这里也是这样，保证 y = $\int_{0}^{x}$ 存在的 x 的范围就是定义域

变限积分存在和积分存在是等价的，只要保证[0, x]中积分存在（可积），那这个 x 的范围就是定义域，所以只要[0, x]中没有发散的瑕点，这个积分都是存在的，因此 y 就存在

所以就转化为处理反常积分的问题了，看看选项中的一些选项是否包含发散的点

显然首先应该观察 pi/2 这个点处的敛散性

这个积分可以变换为：

$$
\int_{0}^{x} \frac{\left( \frac{\pi}{2} - t \right)^{4/3}}{(1-\sin t)(\sin ^{2}t + \sin t + 1)}

$$

它在 pi/2 处的敛散性就与 $\int_{0}^{x} \frac{\left ( \frac{\pi}{2} - t \right)^{4/3}}{(1-\sin t)}dt$ 在 pi/2 处的敛散性相同

在 pi/2 处，对这个积分进行换元，令 $\frac{\pi}{2}- t = u$ ，转换为 u 在 0 点处的敛散性，可以得到是收敛的

所以它在 pi/2 一定是收敛的，所以 pi/2 可以包含在定义域中，是收敛的瑕点，所以 C 错误

A，B 中其实都没有包含发散的瑕点，但是 A 的范围更大，显然更正确一些，所以 A 正确，注意这里 x 并没有取到 5 pi/2 或者-3 pi/2，所以整个积分中一定没有发散的瑕点，所以一定可积，所以 y 一定存在

D 是显然错误的，D 的 x 可以取极大，那么这里面肯定有瑕点，所以不对
