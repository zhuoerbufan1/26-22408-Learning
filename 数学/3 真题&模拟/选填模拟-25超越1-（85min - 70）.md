### 2

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20251015111925.png)

这道题直接利用分部积分可以得到一个式子：

$$
\lim_{ x \to +\infty } x - \frac{2}{\sqrt{ \pi }}x \int_{0}^{x}e^{-t^{2}}dt + \frac{1}{\sqrt{ \pi }}
$$

左边的积分是一个反常伽马积分，它的值就是 $\frac{\sqrt{ \pi }}{2}$，所以左边极限的值就是 0，这里算极限的时候可以用：

$$
\lim_{ x \to \infty } \frac{\left( 1 - \frac{2}{\sqrt{ \pi }}\int_{0}^{x}e^{-t^{2}}dt \right)}{\frac{1}{x}}
$$
这是一个 0 比 0 的形式极限，可以用洛必达，结果就是 0

因此结果就是 $\frac{1}{\sqrt{ \pi }}$
