### 2 判断可微问题

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20251121180343.png)

这里写出 F (x, y) 可微的定义式：

$$
\lim_{ x \to 0, y\to 0} \frac{|x-y|f(x ,y) - 0 -F_{x}'(0,0)x - F'(0, 0)y}{\sqrt{ x^{2}  +y^{2} }}
$$

首先应该观察偏导的信息，这里写出 F (x, y) 在 (0, 0) 对 x 的偏导：

$$
\lim_{ x \to 0 } \frac{F(x,0)-F(0,0)}{x} = \frac{|x|f(x,0)}{x}
$$

当 f (0, 0) 是 0 的时候，很显然可以得到 $F'_{x}(0,0) = 0$ ，同理 $F_{y}'(0,0) = 0$，即偏导存在，那么可微定义式变成：

$$
\lim_{ x \to 0, y\to 0} \frac{|x-y|f(x ,y) }{\sqrt{ x^{2}  +y^{2} }} = \frac{|x-y|}{\sqrt{ x^{2} + y^{2} }}f(x, y)
$$

对于 $\frac{|x-y|}{\sqrt{ x^{2} + y^{2} }}$ 这个式子来说，它是：

$$
0 \leq \frac{|x-y|}{\sqrt{ x^{2} + y^{2} }} \leq \frac{|x| + |y|}{\sqrt{ x^{2} + y^{2} }} \leq 2
$$
所以它是一个有界量，有界量乘一个 0，所以结果就是 0，因此可微

反过来，当可微的时候：

$$
\lim_{ x \to 0, y\to 0} \frac{|x-y|f(x ,y) - 0 -F_{x}'(0,0)x - F'(0, 0)y}{\sqrt{ x^{2}  +y^{2} }} = 0
$$

因此对 x 或者 y 在 (0, 0) 处的偏导一定存在，写出定义式：

$$
\lim_{ x \to 0 } \frac{F(x,0)-F(0,0)}{x} = \frac{|x|f(x,0)}{x}
$$

按照左极限等于右极限，可以得到 f (0, 0) = 0，所以反过来也成立

### 3 二重积分的中值定理

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20251121191641.png)

这道题关键就是写出这个方程的参数方程以及使用积分中值定理进行化简

使用一次积分中值定理可以得到：

$$
\lim_{ t \to 0 } \frac{\iint_{Dt}dxdt}{t^{2}}
$$

剩下的就是求这个区域的面积

这里不知道星型线没关系，可以简单描出大致图像，只用直到这个图像关于 x 轴和 y 轴对称，并且过点 (0, t)，(t, 0)，因此这里的面积就是 4 倍的第一象限的面积

即 $S = 4\int_{0}^{t}ydx$

这里显然不能硬算，得进行换元

所以必须想办法弄出这个参数方程

如果令 x = $\cos ^{3} \theta, y = \sin ^{3}\theta$ 会发现三角可以消掉，但是少了 t，因此可以令：

$$
x = t\cos ^{3}\theta, y = t\sin ^{3}\theta
$$

所以有 ：

$$
\lim_{ t \to 0 } \frac{\iint_{Dt}dxdt}{t^{2}} = \frac{\left( 4\int_{\frac{\pi}{2}}^{0} t * \sin ^{3}\theta *t * 3\cos ^{2} \theta(-\sin \theta) d\theta\right)}{t^{2}}
$$

这里的 t 刚好可以消掉，于是剩下一个三角积分
 
结果就是：C

### 8 思维题

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20251121210651.png)

求一次导可以得到一个微分方程，得到：

$$
y''(t) = y'(t) \implies y = C_{1} + C_{2}e^{x}
$$

根据 y (0) = 1，得到 C 1 + C 2 = 1

这里再对这个式子进行一次 0 到 1 的积分，可以得到：

$$
y(1) - y(0) = 2 \int_{0}^{1}y(t)dt
$$

将 y (t) 代入可以得到另一个方程，于是就得到 C 1 和 C 2 了

最后代入 1 即可

### 10 变限积分求极限中带有无穷的处理方法

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20251121211933.png)

这道题实际上考察的是收敛问题，这里可以写成：

$$
\frac{\left( \int_{+\infty}^{a} \frac{e^{-t}}{t}dt + \int_{a}^{x} \frac{e^{-t}}{t}dt \right)}{\ln x}
$$

这里分子的左侧式子在无穷的瑕点处是收敛的，所以可以直接洛，将其消掉，后续就容易处理了

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20251121212232.png)

这道题关键就是弄出 B 的特征值，$tr(A +B) = tr(A) + tr(B)$

这里可以尝试对题目中的等式右乘一个 A 的特征向量 $\alpha$

于是可以得到：

$$
B(E - A)\alpha = \lambda \alpha \implies (B - BA)\alpha = \lambda \alpha \implies B(1-\lambda)\alpha = \lambda \alpha \implies B = \frac{\lambda}{1-\lambda}\alpha
$$

 这就说明对于一个属于 A 的特征值，$\frac{\lambda}{1-\lambda}$ 就是属于 B 的特征值了

这样就得到结果了
