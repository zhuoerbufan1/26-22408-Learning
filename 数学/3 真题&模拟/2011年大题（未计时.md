### 1 对 $f_{x}'(x, y_{0})$ 和 $f'_{x}(x_{0}, y)$ 的理解

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20251118144112.png)

**（1）**

$f_{x}'(x, y_{0})$ 和 $f_{x}'(x_{0}, y)$ 分别是关于 x 的函数和关于 y 的函数，都可以先求出 $f_{x}'(x, y)$，然后代入 x 0 得到 $f_{x}'(x_{0},y)$ 或者代入 y 0 得到 $f_{x}'(x, y_{0})$

**（2）按照定义**

$f_{x}'(x, y_{0})$ 是 f (x, y) 在 y = y 0 的条件下在 x = x 0 处的导数，当 x 0 不断变化的时候，形成了 $f_{x}'(x, y_{0})$

即：

$$
\lim_{ x \to x_{0} } \frac{f(x, y_{0}) - f(x_{0},y_{0})}{x-x_{0}} = f'_{x}(x_{0},y_{0})
$$
这里当 x 0 不断变化的时候形成了 $f_{x}'(x, y_{0})$，按照这个定义，完全可以直接代入 y 0 到 f (x ,y) 得到 f (x, y 0)，然后这个式子直接对 x 求导就得到了 $f_{x}'(x, y_{0})$



$f_{x}'(x_{0},y)$ 按照定义，就是 y = y 的情况下，x 在 x 0 处的导数，别想太多，这里将 y 当作常数，就这样按照定义展开：

$$
\lim_{ x \to x_{0} } \frac{f(x,y)-f(x_{0},y)}{x-x_{0}} = f_{x}'(x_{0}, y)
$$

得到一个关于 y 的函数，就这样处理即可
