### 4 可导函数的导函数的间断点问题

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20251101192544.png)


如果一个函数可导，则它的导函数只可能有一种间断点，就是震荡的间断点

下面来利用导数定义挨个排除 ABC

假如有可去间断点，意思就是：

$$
f'(x_{0}) = B \neq \lim_{ x \to x_{0} } f'(x) = A
$$

那么对 f (x) 在 x 0 处使用定义（f(x) 在领域可导）：

$$
\lim_{ x \to x_{0} } \frac{f(x) - f(x_{0})}{x - x_{0}} =_{洛} \lim_{ x \to x_{0} } f'(x_{0}) =A
$$

由于 f (x) 在 x 0 处可导，所以它的左右导数应该相等，就等于它的导数 f'(x 0) 的值为 B，但是这与定义法做出来的矛盾，所以不可能是可去间断点

同理，如果是跳跃间断点，对 f (x) 使用导数的定义，会发现 f (x) 左右导数不一样，这与 f (x) 可导矛盾，所以不可能是跳跃间断点

如果是无穷间断点，同理对 f (x) 使用导数定义，发现 f (x) 导数不存在，同样出现矛盾

### 5 易错点：关于 x =1 的积分区域对称的处理方式

这个区域是关于 x 轴对称的，我们先观察变量 y：

对于函数 f (xy^2 - y^2) = g (x, y)，由于 g (x, -y) = f (xy^2 - y^2) = g (x, y)，所以它是关于 y 的偶函数

对于函数 f (yx^2 + y) = g (x ,y)，由于 g (x , -y) = f (-yx^2 - y) = -f (yx^2 + y)，所以它是关于 y 的奇函数

所以这个式子应该等于 $2\iint_{D_{1}}f(xy^{2} - y^{2})d\sigma$

但是对于函数 $f((x - 1)y^{2})$，对 D 1 进行左移一个单位，被积函数变成 $f(xy^{2})$，积分区域关于了 y 对称，所以最后结果应该是 0

### 8 lnx 相关的两个不等式

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20251102153424.png)

这道题显然是取对数，这里的指数部分就是：

$$
\ln\left( 1 + \frac{1}{n^{2}} \right) + \ln \left(  1 + \frac{2}{n^{2}} \right) +\dots \ln\left( 1 + \frac{n}{n^{2}} \right)
$$

根据 ln (1 + x ) <= x，可以放缩成：

$$
\ln\left( 1 + \frac{1}{n^{2}} \right) + \ln \left(  1 + \frac{2}{n^{2}} \right) +\dots \ln\left( 1 + \frac{n}{n^{2}} \right) \leq \frac{1}{n^{2}} + \frac{2}{n^{2}}+\dots \frac{n}{n^{2}} = \frac{1}{2} + \frac{1}{2n}
$$

当 n 趋于无穷的时候不等号右边趋于 1/2

根据 $\ln\left( 1 + \frac{1}{x} \right) \geq \frac{1}{x + 1}$，此时左边可以放缩成：

$$
\frac{1}{n^{2}  +1}  + \frac{2}{n^{2} + 2} + \dots \frac{n}{n^{2} + n} \leq \ln\left( 1 + \frac{1}{n^{2}} \right) + \ln \left(  1 + \frac{2}{n^{2}} \right) +\dots \ln\left( 1 + \frac{n}{n^{2}} \right)
$$

左边的这种结构可以进一步放缩，将分母部分的变化量全部放缩成 n：

$$
\frac{1}{n^{2}  + n} + \frac{2}{n^{2} + n} + \dots \frac{n}{n^{2} + n } <\frac{1}{n^{2}  +1}  + \frac{2}{n^{2} + 2} + \dots \frac{n}{n^{2} + n} \leq \ln\left( 1 + \frac{1}{n^{2}} \right) + \ln \left(  1 + \frac{2}{n^{2}} \right) +\dots \ln\left( 1 + \frac{n}{n^{2}} \right)
$$ 
n 取极限左边也趋近于 1/2

所以指数部分就是趋近 1/2，所以整个结果就是趋近 $\sqrt{ e }$ 了
