
### 1 导函数趋于无穷证明原函数趋于无穷的方法 + 逆用洛必达

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20251130151129.png)


令 $F(x) = e^{2x}f(x)$

题目中的条件是想说明：

$$
\lim_{ x \to \infty } \frac{F'(x)}{e^{2x} } = 1
$$
也就是说 F (x) 的导函数是趋于无穷的，那么 F (x) 本身也必然趋于无穷

这里的证明方式是利用拉格朗日，即存在一个 x 0，当 x > x 0 的时候有：

$$
F(x) - F(x_{0}) = F'(\xi)(x - x_{0}) \implies F(x) = F'(\xi)(x - x_{0}) + F(x_{0})
$$

显然，当 x 0 和 x 趋于无穷的时候 F' ($\xi$) 趋于无穷，那么此时 F (x) 必然趋于无穷


==逆用洛必达==


逆用洛必达是指，如果我们知道了 $\lim_{ x \to x_{0} } \frac{f'(x)}{g'(x)}$ 的值，于是可以构造 $\lim_{ x \to x_{0} } \frac{f(x)}{g(x)}$ 从而得到 $\frac{f(x)}{g(x)}$ 的极限的值

这里知道了 $\lim_{ x \to \infty } \frac{F'(x)}{e^{2x} } = 1$


因此对于 $\lim_{ x \to \infty } \frac{F(x)}{\frac{1}{2}e^{2x}}$ 就得到了是 1，也就是：

$$
\lim_{ x \to \infty } \frac{F(x)}{e^{2x}} = \frac{1}{2}
$$


即：

$$
\lim_{ x \to \infty } f(x) = \frac{1}{2}
$$
所以 $\lim_{ x \to \infty }f'(x) = 0$
