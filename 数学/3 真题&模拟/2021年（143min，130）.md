==第一题==

$df(x, y)$ 其实就是 f 对两个位置的全微分，可以写成 $df(x, y) = f_{1}'(x, y) dx + f_{2}'(x, y)dy$，这里的 x 和 y 其实含义都是第一个位置以及第 2 个位置的变量，当然，这里恰好第一个位置就是 x，第二个位置就是 y，所以可以写成 $df(x, y) = \frac{ \partial f(x, y)}{\partial x} dx + \frac{ \partial f(x, y)}{\partial y}dy$

那么对于 $f(x+ 1, e^{x})$ ，第一个位置变量就是 x + 1；第二个位置变量就是 $e^{x}$

那么 f 对 x 求导可以写成：

$$
\frac{df}{dx} = f_{1}'(x  + 1, e^{x}) \frac{d(x+1)}{dx} + f_{2}'(x+1, e^{x}) \frac{de^{x}}{dx} = \frac{d[x(x+1)^{2}]}{dx}
$$

这是根据求导法则来的 $f_{1}'$ 就表示对第一个位置的求导，上式代入 x = 0 得到一个 $f_{1}'(1, 1)和f_{2}'(1, 1)$ 的 方程

同理第二个式子也是直接对 x 求导按照位置写出式子，代入 x = 1 得到另一个方程

这样就可以将 $f_{1}'(1, 1)和f_{2}'(1, 1)$ 解出来了，于是得到了 df (1, 1)
