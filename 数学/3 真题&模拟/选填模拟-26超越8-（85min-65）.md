### 1 定积分定义处理数列极限

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20251121113109.png)


这道题很阴，得转两个弯才行

这里先利用对称性将题目变形为 $2\int_{0}^{\pi/2} \sin x dx$，然后再换元 $x = \pi t$ 得到：

$$
2 \pi\int_{0}^{1/2} \sin t dt
$$

然后在这个式子的基础上写出极限的定义形式，观察 C 选项它可以变换成：

$$
2\pi  *\frac{1}{2n}\sum_{i = 1}^{n}\sin \frac{(i-1)\pi}{2n}
$$

对于 $\frac{1}{2n}\sum_{i = 1}^{n}\sin \frac{(i-1)\pi}{2n}$ 来说，这里变换部分是 i-1/2 n，i 变换到 n 取极限，就是 1/2，所以上下限是 0 到 1/2，这里一共划分了 n 次，所以步长就是 1/2 n，因此这个式子就是 $\int_{0}^{1/2} \sin t dt$ 的极限定义形式

所以：
$$
2\pi  *\frac{1}{2n}\sum_{i = 1}^{n}\sin \frac{(i-1)\pi}{2n} = 2 \pi\int_{0}^{1/2} \sin t dt
$$

C 是正确的

### 2 利用导数定义，构造微分方程

**第一题**

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20251121113821.png)

直接写出导数定义：

$$
f'(x) = \lim_{ \Delta x \to 0 } \frac{f(x + \Delta x) - f(x)}{\Delta x} = \frac{f(x)+f(\Delta x)+g(x\Delta x)-f(x)}{\Delta x} = \frac{f(\Delta x)}{\Delta x} + \frac{g(x\Delta x)}{\Delta x} 
$$


所以可以得到：

$$
f'(x) = \frac{f(\Delta x)}{\Delta x} + \frac{g(x\Delta x)}{\Delta x} 
$$

等式右侧左边一项在 $\Delta x$ 趋于 0 的时候结果是 f' (0)，这里如果右边想用题目中的条件，那就得凑成题目中的 $\frac{g(x)}{x}$ 的形式，所以想到：
$$
f'(x) = \frac{f(\Delta x)}{\Delta x}  +\frac{g(x\Delta x)}{x\Delta x}x \implies f'(x) = f'(0) + x(\Delta x \to 0)
$$


所以 f'' (x) = 1，因此对于 0 来说，f (0) = 0，f' (0) = 0，f'' (0) = 1 > 0，所以是极小值点

**第二题**

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20251121114642.png)

直接写出导数定义：

$$
f'(x) = \lim_{ \Delta x \to 0 } \frac{f(x + \Delta x) - f(x)}{\Delta x}
$$
利用题目条件展开：

$$
f'(x) = \lim_{ \Delta x \to 0 } \frac{f(x + \Delta x) - f(x)}{\Delta x} = \frac{f(\Delta x)(1 + f^{2}(x))}{\Delta x(1 - f(x)f(\Delta x))}
$$
当 $\Delta x$ 趋于 0 的时候

可以得到：

$$
f'(x) = f'(0)(1 + f^{2}) \implies y' = f'(0)(1 + y^{2})
$$

后面就是处理微分方程了

**第三题**

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20251121114647.png)



这里直接写出函数的定义式子：

$$
f'(x) = \lim_{ \Delta x \to 0 } \frac{f(x + \Delta x) - f(x)}{\Delta x} 
$$

显然，要利用题目条件，那得对分子进行提公因式处理才行，这里提的是 x，这是因为提了 x 之后形成的是 $x\left( 1+\frac{\Delta x}{x} \right)$，这里的 $\frac{\Delta x}{x}$ 在 $\Delta x$ 趋于 0 的时候整体是趋于 0 的，后面可能会进行整体处理

所以得到：

$$
\frac{\left( xf\left( 1 + \frac{\Delta x}{x} \right)  +\left( 1 + \frac{\Delta x}{x} \right)f(x)-f(x)\right)}{\Delta x} = \frac{\left( xf\left( 1 + \frac{\Delta x}{x} \right) \right)}{\Delta x} + \frac{f(x)}{x } = \frac{f\left( 1 + \frac{\Delta x}{x} \right)}{\frac{\Delta x}{x}} + \frac{f(x)}{x} (\Delta x \to 0)= f'(x)
$$

按照题目意思，可以得到 f (1) = 0，所以当 $\Delta x$ 趋于 0 的时候可以得到：
$$
f'(1) + \frac{f(x)}{x }  = f'(x) = 2 + \frac{f(x)}{x}\implies \frac{dy}{dx} = 2 + \frac{y}{x}
$$


后面就容易处理了

**第二个思路，从秩的角度**

对于 $A^{T}B^{T}$ 与 $B^{T}$，$A^{T}$ 是列满秩矩阵，所以不改变 $B^{T}$ 的秩，所以有：

$$
r(A^{T}B^{T}) = r(B^{T})
$$

并且由于 $A^{T}B^{T}$ 的行向量是由 $B^{T}$ 的行向量线性表示的，所以 $r(B^{T}) = r\left( \frac{A^{T}B^{T}}{B^{T}} \right)$

所以：

$$
r(A^{T}B^{T})  = r(B^{T}) = r\left( \frac{A^{T}B^{T}}{B^{T}} \right)
$$

两个矩阵以及两个矩阵拼在一起增广的秩相等，所以 $A^{T}B^{T}$ 与 $B^{T}$ 是同解的


同样可以得到 $A^{T}B^{T}$ 和 $B^{T}$ 的行向量组等价
