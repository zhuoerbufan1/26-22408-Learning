==统一做法==

这里发现要求的式子中积分上下限的差值是 2

所以可以令：

$$
F(x) = \int_{x}^{x + 2} f(t)dt
$$

因此有：

$$
F'(x) = f(x + 2) - f(x) 
$$

对于第一题有 $F'(x) = \sin x$，所以 $F(x) = -\cos x + C$，根据 $\int_{0}^{2}f(x)dx = 0$，所以 $F(0) = 0$，所以得到 C = 1，因此得到：

$$
F(x) = \int_{x}^{x + 2}f(t)dt = -\cos + 1
$$

所以 $\int_{1}^{3}f(x)dx = F(1) = 1-\cos{1}$，所以 $\int_{2}^{4}f(x)dx = F(2) = 1-\cos 2$

所以 I 2 > I 1

这道真题也是这样处理的


真题有 $F'(x) = x$，所以 $F(x) = \frac{1}{2}x^{2} + C$，所以 C = 0，所以 F (x) = 1/2 x^2，

因此 $\int_{1}^{3}f(x)dx = F(1) = \frac{1}{2}$
