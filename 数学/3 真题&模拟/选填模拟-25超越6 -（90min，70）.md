
### 1 积分不等式的证明

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20251110164314.png)

这道题可以用特值 e^x 做出来

如果要严格证明的话，像这类积分不等式，就是利用变上限构造函数处理

比如对于 A 选项的前一对不等关系构造：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20251110165218.png)

求导之后得到：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20251110165229.png)

对于后面一项的积分用一次积分中值定理，再根据 f' (x) > 0，所以 F' (x) > 0 

所以 F (x) 递增，所以 A 选项的第一组不等式成立

对于后面一组不等式，其实还是构造函数

将 a + b/2 去掉，也就是要证：

$$
\int_a^{x}f(t)dt \leq (x-a) f\left( \frac{a +x}{2} \right)
$$

令 F (x) = $\int_a^{x}f(t)dt -(x -a) f\left( \frac{a +x}{2} \right)$

F (a) = 0

F' (x) = f (x) - $f\left( \frac{a +x}{2} \right)$ - $\frac{x-a}{2}$ f' ($\frac{a +x}{2}$)

对 f (x) - $f\left( \frac{a + x}{2} \right)$ 使用一次拉格朗日中值定理，得到：

$$
F'(x) = \frac{x-a}{2} f'(\xi) - \frac{x-a}{x}f'\left( \frac{a + x}{2} \right)
$$ 
这里的 $\xi$ 位于 x 和 $\frac{a + x}{2}$ 之间，由于 f' (x) 是递增的，并且由于 x > a，所以 x > $(a + x)/2$，所以 $\xi$ 是比 $\frac{a + x}{2}$ 大的

所以 F' (x) >= 0，所以 F (x) 递增，由于 F (a) = 0，所以 x > a 的时候 F (x) >= 0，所以 F (b) > = 0

所以可以得到：

$$
\int_a^{b}f(t)dt \leq (b-a) f\left( \frac{a +b}{2} \right)
$$

两边同时乘 $\frac{a + b}{2}$，就得到 A 选项的右边不等式组了

（2）

f (0, 0) = 0，这里按照偏导定义求解即可，偏导也是存在的，而且结果就是 0

（3）

可微这里按照定义实际上不是很好求，可以先看看偏导连续，如果能得到偏导连续，这是一个极强的条件那么就可以得到可微了

当然也可以直接求：

这里偏导数存在，所以就是验证：

$$
\frac{f(x, y)}{\sqrt{ x^{2} + y^{2} }} = \frac{(x^{4} + y^{4})^{1/3}}{(x^{2} + y^{2})^{1/2}}(x\to 0, y \to 0的时候结果是否为0)
$$

这里带分数幂不好看，直接上下 6 次幂得到：

$$
\frac{(x^{4}+y^{4})^{2}}{(x^{2} +y^{2})^{3}} = \frac{x^{8}}{(x^{2} + y^{2})^{3}} + \frac{y^{8}}{(x^{2} + y^{2})^{3}} + \frac{2x^{4}y^{4}}{(x^{2} + y^{2})^{3}}
$$

对于前两项，通过夹逼放缩结果就是 0，对于最后一项，它取绝对值并且在 x, y 逼近 0 的过程中有：

$$
|\frac{2x^{4}y^{4}}{(x^{2} + y^{2})^{3}} | \leq 2 | \frac{y^{4}}{x^{2}} | \leq 2|y^{4}|
$$

通过夹逼，结果还是 0

或者这里分数幂别乘 6，而是直接乘 3，分子变成 x^4 + y^4，这样更加简单，用夹逼更容易一些

（4）

这里 x 和 y 是对称的，所以研究 x 即可，对 x 求偏导：

$$
f_{x}'(x, y) = \frac{4}{3} \frac{x^{3}}{(x^{4} + y^{4})^{2/3}}
$$

如果这个偏导在 (0, 0) 处的极限是 0，那么偏导就是连续的

这里用夹逼来做：

$$
0 \leq |f_{x}'| = \frac{4}{3}|\frac{x^{3}}{(x^{4} + y^{4})^{2/3}}| \leq \frac{4}{3} | \frac{x^{3}}{(x^{4})^{2/3}} |
$$

当 x 逼近 0 的时候左右都逼近 0，所以这里偏导就是连续的

所以可微
