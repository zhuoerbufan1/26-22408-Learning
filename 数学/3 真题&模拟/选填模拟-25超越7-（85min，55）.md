这道题先观察 g (x) 在趋于 1 的左右情况的值，x->1+，g (x) -> 正无穷，x -> 1-，g (x) -> 0

A：
连续的话是很显然的，将 f (x) 的式子中的 x -1 单独领出来，1-g (x) / 1 + g (x)，无论趋于 1 正还是 1 负都是一个有界量，因此 x->1 的时候 f (x )->0，所以连续

B：
这里按照导数定义来做，注意这里是 1 处的导数的定义，因此导数定义式子化简就只剩下 1-g (x) / 1 + g (x)，这个式子在 x -> 1-和 x-> 1+的时候结果不一样，所以不可导

C，D：

这里用定义来做，在 x-> 1+的时候 (x - 1) > 0，(1 - g (x)) < 0，1 + g (x) > 0，所以整个式子 < 0；
在 x->1-的时候（x - 1）< 0，（ 1- g（x）） > 0，1 + g (x) > 0，所以整个式子 < 0
因此 0 就是极大值了

### 4 正交矩阵的性质

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20251112191435.png)

A 是正交矩阵，并且|A| < 0，所以得到|A| = -1

所以可以得到：

$$
A^{*}B = -E + A^{*}
$$

A 是正交矩阵，所以 $A^{*}$ 也是正交矩阵

所以对上式右乘 $(A^{*})^{T}$ 得到：

$$
A^{*} B (A^{*})^{T} = -(A^{*})^{T} + E
$$

所以 B 和矩阵 $-(A^{*})^{T} + E$ 是相似的，即 B 和 $-(A^{*})^{-1} + E$ 是相似的

-1 是属于 A 的单特征值，并且这个特征值的特征向量是 $\alpha_{1}$

根据 A 和 $A^{*}$ 的特征值关系，$A^{*}$ 的特征值是 $\frac{|A|}{-1}, \frac{|A|}{\lambda_{2}}, \frac{|A|}{\lambda_{3}}$，并且非零

由于-1 是单特征值，也就是说-1 与 $\lambda_{2},\lambda_{3}$ 都不相同，因此对于 $A^{*}$ 来说 $\frac{|A|}{-1}$ 也是一个单特征值，并且特征向量是对应的 $\alpha_{1}$

即 $\frac{|A|}{-1} = 1$ 也是 $A^{*}$ 的单特征值，特征向量是 $\alpha_{1}$，假设 $1, \eta_{2},\eta_{3}$ 是 $A^{*}$ 的特征值，那么根据 $A^{*}$ 和 $(A^{*})^{-1}$ 的特征值关系

所以 $(A^{*})^{-1}$ 的特征值就是 $1, \frac{1}{\eta_{2}}, \frac{1}{\eta_{3}}$，由于 1 和 $\eta_{3},\eta_{2}$ 不相同，所以 1 也是 $(A^{*})^{-1}$ 的单特征值，特征向量是 $\alpha_{1}$

同上，所以对于矩阵 $-(A^{*})^{-1} + E$ 来说，0 也是它的单特征值，特征向量就是 $\alpha_{1}$

B 与矩阵 $-(A^{*})^{-1} + E$ 相似，因此 0 同样是 B 的单特征值，但是由于 B = $(A^{*})^{T}[-(A^{*})^{-1} + E]A^{*}$，此时 B 对应的 0 的特征向量是 $(A^{*})^{T}\alpha_{1} = (A^{*})^{-1}\alpha_{1}$，而不能直接得到就是 $\alpha_{1}$

由于 $\alpha_{1}$ 也是 $(A^{*})^{-1}$ 的属于 1 的特征向量，所以 $(A^{*})^{T}\alpha_{1} = (A^{*})^{-1}\alpha_{1} = \alpha_{1}$

因此 $\alpha_{1}$ 也是属于 B 的关于单特征值 0 的特征向量，所以选项B 正确

**第一题**

这两个特解相减就是齐次的一个解：$e^{-x}\sin 2x$，说明二阶齐次的根是 $-1 \pm 2i$，所以二阶齐次的特征根方程就是：

$$
\lambda^{2} + 2\lambda + 1 = -4 \implies y'' + y' + 5y = 0是齐次方程
$$

代入 e^x 得到非齐次部分就是 7 e^x，所以结果就是：

$$
y'' + y' + 5y = 7e^{x}
$$

**第二题**

**第三题**

说明这个特征方程有一个根 1，以及一对根 $-\frac{1}{2}\pm \frac{\sqrt{ 3 }}{2}i$

根 1 可以确定一项 x - 1，一对虚根可以确定 $\left( x+\frac{1}{2} \right)^{2}+\frac{3}{4}$

所以特征方程就是：

$$
(x-1)\left[ \left( x+\frac{1}{2} \right)^{2} + \frac{3}{4} \right] = 0
$$
根据此确定方程即可
