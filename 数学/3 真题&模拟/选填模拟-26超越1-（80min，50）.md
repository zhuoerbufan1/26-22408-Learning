### 2 判断可微与重极限处理****

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20251115201551.png)

这里判断偏导数存不存在按照定义做即可，上文有分析

这里判断可微，就是判断：

$$
\lim_{ x \to 0,y\to 0} \frac{f(x, y)}{\sqrt{ x^{2} + y^{2} }}是否存在
$$

我们知道的条件是：

$$
\lim_{ x \to 0,y\to 0 }  \frac{f(x, y)}{|x| + |y|} = 0
$$


这里采用的方法就是凑出我们知道的 $\frac{f(x,y)}{|x| + |y|}$ 这个条件：

$$
\lim_{ x \to 0, y \to 0 } \frac{f(x, y)}{\sqrt{ x^{2} + y^{2} }} = \frac{f(x ,y)}{|x|+ |y|} * \frac{|x| + |y|}{\sqrt{ x^{2} + y^{2} }}
$$

对于式子 $\frac{|x| + |y|}{\sqrt{ x^{2} + y^{2} }}$ 来说，它可以拆成 $\frac{|x|}{\sqrt{ x^{2} + y^{2} }} + \frac{|y|}{\sqrt{ x^{2} + y^{2} }}$，这两项都是 < 1 的，因此上式右边是一个有界量，左边是一个 0，所以结果也一定是 0

### 3 积分敛散性判别

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20251117175516.png)

这道题有瑕点 0，无穷，和 1

对于瑕点 0 和无穷处的敛散性可以直接忽略分子的 lnx，观察：

$$
\frac{1}{(x^{a} - x^{b})^{1/3}}的敛散性
$$

对于瑕点 0 处，可以上下同除 $x^{b/3}$，分母就是：$(x^{a-b}-1)^{1/3}$，因此在瑕点 0 处这个分母可以直接忽略，整个式子就剩下了分子的：

$$
\frac{1}{x^{b/3}}
$$
他的在 0 处的敛散性，显然 b/3 < 1，即 b < 3

瑕点无穷处，分子的 ln x 直接忽略，分母取决于 x^a，所以可以替换为：

$$
\frac{1}{x^{a/3}}的敛散性
$$

在无穷处的敛散性，显然 a/3 > 1，即 a > 3

因此 A 正确

### 5 $AA^{T}$ 与 $A^{T}A$ 的特征值处理

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20251117193202.png)

这里根据四秩相等以及行列式的定义等等可以得到 $A^{T}A$ 有特征值 0，2，还剩下一个特征值

这里用定义法来进行处理，根据 $A^{T}A$ 的特征值为 2，可以得到：

$$
A^{T}A \alpha = 2\alpha
$$

这里 $A\alpha \neq 0$

**为了与题目靠拢**，可以在上式同时左乘一个矩阵 A，得到：

$$
AA^{T}A\alpha = 2A\alpha
$$

因此对于 $AA^{T}$ 来说，他就有一个特征值 2，再根据行列式为 1，可以得到 $AA^{T}$ 的特征值就是 1，2

同理再对 $AA^{T}$ 用一次定义：

$$
AA^{T}\alpha = \alpha
$$
同时左乘 A^T 凑出 A^TA 这样的矩阵，得到：

$$
A^{T}AA^{T} \alpha= A^{T}\alpha
$$

因此对于 $A^{T}A$ 他就还有一个特征值 1

所以 $A^{T}A$ 的特征值就是 1，2，0

所以 $A^{T}A + 2E$ 的特征值就是 3，4，2

因此结果就是 24

### 6 $f(x)\int_{0}^{x}f(t)dt$ 条件处理 + 区间再现公式

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20251117194824.png)

这道题可以变换为：

$$
f(x)\int_{0}^{x}f(t)dt = x\cos ^{4}x
$$

两边同时在 0 到 pi 上进行积分得到：

$$
\int_{0}^{\pi}\left(  \int_{0}^{x}f(t)dt d\left( \int_{0}^{x}f(t)dt \right) \right) = \int_{0}^{\pi}x\cos ^{4}x dx
$$

左边就是按照结论做
右边用区间再现公式：

$$
\int_{0}^{\pi}x\cos ^{4}x dx = \frac{\pi}{2} \int_{0}^{\pi}\cos ^{4} dx = \pi \int_{0}^{\pi/2}\cos ^{4}x dx
$$

所以剩下的结果就容易得到了
