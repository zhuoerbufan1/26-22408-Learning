
### 1 复杂的函数复合的泰勒展开

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20251123152440.png)

这道题涉及的是 $\frac{f(x)}{g(x)}$ 这种的除法形式的泰勒展开

这类题目的出法一般是令 $\frac{f(x)}{g(x)} = h(x)$，然后 h (x) 含有一些参数

处理方式是两边成 g (x) 转换成乘法的形式：

$$
f(x) = h(x) g(x)
$$

然后分别对 f (x) 和 g (x) 进行泰勒展开，系数对应相等来弄出系数

或者按照定义：

$$
\lim_{ x \to 0 } \frac{\left( \cot x - \frac{1 + ax^{2}}{x + bx^{3}} \right)}{x^{5}} = 0
$$

然后对这个分式进行上下同乘处理变成：

$$
\frac{\cos x(x + bx^{3})- (1 + ax^{2})\sin x}{x^{7} + bx^{9}} = 0(x \to 0)
$$

这样处理同样正确（实际上是一样的处理手段），对分子进行泰勒展开处理，此时分母是 7 阶，因此分子也要展开到 7 阶

这里分子的 x 7 次方之下的幂次的系数必须全部为 0，根据此来求出系数

这里分子中 x^3 的系数是：
$$
\left( -\frac{1}{2} + b + \frac{1}{6} + a \right)
$$

x^5 的系数是：

$$
\left( \frac{1}{4!} - \frac{1}{2}b - \frac{1}{5!} + \frac{1}{6}a \right)
$$
x^7 的系数是：

$$
-\frac{1}{6!} + \frac{1}{4!} b + \frac{1}{7!} - \frac{1}{5!}a
$$

利用 x^3 和 x^5两个系数 = 0 就可以将 a 和 b 解出来了

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20251123154105.png)

但是，此时 x^7 的系数不为 0，所以实际上这个题是一个错题，题目中不应该是 x^5 的无穷小，如果改成 o (x^3） 就正确了

如果改成 x^3，那么下式分母是：

$$
\frac{\cos x(x + bx^{3})- (1 + ax^{2})\sin x}{x^{5} + bx^{7}} = 0(x \to 0)
$$

这个时候只用分子展开到 5 次就可以了，这样做法就正确了

### 2 23 年真题改编，$f(x + 2) - f(x) = g(x)$ 的条件处理

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20251123154529.png)

==统一做法==

这里发现要求的式子中积分上下限的差值是 2

所以可以令：

$$
F(x) = \int_{x}^{x + 2} f(t)dt
$$

因此有：

$$
F'(x) = f(x + 2) - f(x) 
$$

对于第一题有 $F'(x) = \sin x$，所以 $F(x) = -\cos x + C$，根据 $\int_{0}^{2}f(x)dx = 0$，所以 $F(0) = 0$，所以得到 C = 1，因此得到：

$$
F(x) = \int_{x}^{x + 2}f(t)dt = -\cos + 1
$$

所以 $\int_{1}^{3}f(x)dx = F(1) = 1-\cos{1}$，所以 $\int_{2}^{4}f(x)dx = F(2) = 1-\cos 2$

所以 I 2 > I 1

这道真题也是这样处理的


真题有 $F'(x) = x$，所以 $F(x) = \frac{1}{2}x^{2} + C$，所以 C = 0，所以 F (x) = 1/2 x^2，

因此 $\int_{1}^{3}f(x)dx = F(1) = \frac{1}{2}$





==另一种做法==
核心是对 $\int_{1}^{3}f(x)dx$ 的处理

这里进行区间拆分：

$$
=\int_{1}^{0} f(x)dx + \int_{0}^{2}f(x)dx + \int_{2}^{3}f(x) dx = \int_{1}^{0}f(x)dx + \int_{0}^{1}f(x + 2)dx = \int_{1}^{0}f(x)dx + \int_{0}^{1}(f(x) + \sin x)dx = \int_{0}^{1}\sin xdx
$$

### 5 Ax = 0 的通解结构问题

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20251123174200.png)

这里显然 $\beta_{1}, \beta_{2}$ 都是 Ax = 0 的解

Ax = 0 的解的结构就是 k $\beta$，**k 任意，并且 $\beta$ 线性无关**，即它必须非零

因此只有 D 是非零的

一般而言，对于 Ax = 0 的 s个解，它的解形式是：

$$
k_{1}\alpha_{1} + k_{2}\alpha_{2} + \dots k_{s}\alpha_{s}
$$

必须满足：
（1）这些组合系数任意
（2）$\alpha_{1}, \alpha_{2},\alpha_{3}\dots \alpha_{s}$ 是 Ax = 0 的基础解系，即他们必须线性无关，即不能出现 0 向量！

### 7 分块矩阵的秩的结论

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20251123193904.png)

题目中的这个迹的条件 $ABXX^{T}$ 实际上是一个行向量 ABX 乘一个列向量 $X^{T}$ 形成的矩阵的迹，这是一个 r = 1 的矩阵的迹，所以它的迹实际上就是这两个向量的内积，所以可以改写成：

$$
X^{T}ABX= tr(ABXX^{T})
$$

同理第二个迹的条件也可以改写成：

$$
X^{T}ABX = tr(XX^{T}AB)
$$


所以这个条件就是说明：

$$
X^{T}ABX > 0
$$

这里 AB 不一定是实对称矩阵，所以这里跟二次型扯不上什么关系

只能往矩阵的迹上面靠拢

这里对于 ABX 这个列向量来说，一定有 $ABX \neq 0$

也就是说对于任意的非零列向量 X 都有 ABX != 0

也就是说 ABX = 0 没有非零解，所以 AB 就是一个满秩矩阵，所以：

$$
r(AB) = n \leq r(A), r(B) \implies r(A) = r(B) = n
$$

对于第一个矩阵

AB 可以经过行变换变成 B，所以第二行的 B 可以利用第一行消掉，因此它的秩 = r (B) + r (BC) = n + r (C)

对于第二个矩阵

这里 B 可逆，所以它的秩 = r (B) + r (AC) = n + r (C)

对于第三个矩阵

它的秩是 r (A) + r (AB) <= r <= 2 n

所以它的秩就是 2 n

因此 r 3 >= r 2 = r 1

所以 C 正确
