==第一题==

如果根的情况是两个相异的实根，根据根的辨别，$\Delta > 0$，得到 a 的范围是 a < -1 或 a > 2；此时要想保证积分收敛，e 的系数必须<0，即两个根必须小于 0，根据韦达定理，2 a < 0 且 a + 2 > 0，所以得到 -2 < a  <0；取交集，得到-2 < a < -1

如果根的情况是两个相等的实根，得到此时 a = 2 或者 a = -1，同样，要保证这个根必须小于 0，所以 a = -1

如果根的情况是一对虚根即 $\alpha \pm \beta i$，此时方程的解的形式是 $e^{\alpha x}(C_{1}\sin \beta x + C_{2}\cos \beta x)$，首先根据根的判别得到 -1 < a < 2；此时必须保证 $\alpha < 0$，按照伟大定理，x 1 + x 2 = 2 a  = 2 $\alpha$ < 0，所以 a < 0，取交集得到-1 < a < 0

以上三种情况哪种都可以，所以总的取并集，结果就是-2 < a < 0 了

==第二题==

在正无穷到负无穷有界，那么此时根的情况必须是一对虚跟了，解的形式是 $e^{\alpha x}(C_{1}\sin \beta x + C_{2}\cos \beta x)$，并且 $\alpha = 0$

按照判别式： $a^{2} - 4b < 0$

按照维达定理，必须保证 $\alpha = 0$，所以 x 1 + x 2 = a = 0，又因为 $a^{2} - 4b < 0$，所以 b > 0

==第三题==

所有的解都是 x 的周期函数，说明解的形式必须是 $e^{\alpha x}(C_{1}\sin \beta x + C_{2}\cos \beta x)$，并且 $\alpha = 0$

同第二题，a = 0 且 b > 0

这道题 QP 之间的万有引力公式是：

$$
\frac{G 1 * 1}{x^{2}  +1} = \frac{G}{x^{2}+1}
$$

P 沿水平从 (0, 0) 到 (l, 0)，那当然是万有引力沿着水平的分量对位移做功才对

所以：

$$
dW = \frac{G}{x^{2} + 1} \cos \theta dx
$$
这里按照微元分析法，认为 $\cos \theta$ 保持不变，即 $\cos \theta = \frac{x}{\sqrt{ x^{2} + 1} }$

所以：

$$
dW = \frac{Gx}{(x^{2} + 1)^{3/2}}dx

$$

因此 B 正确

当 f (0) > 0，那么一定有一个领域，使得在这个领域中 f (x) > 0，所以题目给出的条件的绝对值可以去掉，得到：

$$
\lim_{ x \to 0 } \frac{f(x) - f(0)}{x} 存在
$$
那这个式子其实就是 f (x) 的导数的定义，所以成立

当 f (0) = 0，题目的条件就变成了：

$$
\lim_{ x \to 0 } \frac{|f(x)|}{x} 存在
$$

这个条件可以推出 $| \frac{f(x)}{x}|$ 极限是存在的

在 x -> 0+的时候这个条件可以写成：

$$
\lim_{ x \to 0+ }  \frac{|f(x)|}{x}  = \lim_{ x \to 0+ } | \frac{f(x)}{x}|  =A，存在
$$

在 x -> 0-的时候这个条件可以写成：

$$
\lim_{ x \to 0- }  \frac{|f(x)|}{x}  = -\lim_{ x \to 0- } | \frac{f(x)}{x}|  =A，存在
$$

所以可以得到

$$
\lim_{ x \to 0 } | \frac{f(x)}{x}| = 0
$$

因此可以推出 $\lim_{ x \to 0 } \frac{f(x)}{x} = 0$ 存在，所以可导

因此第一个条件正确，同时可以得到第三个条件正确

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20251029190446.png)

这道题从左到右很好证明，用两次拉格朗日即可

下面来证明从右到左：

这里的思路是按照导数的定义来做

这里可以将 x 2 看作一个变量，对于 x 1 处的导数来说，我们让 x 2 从右侧趋近 x 1，这里之所以是右侧，是因为要保证在 x 2 在趋近的过程始终大于 x 1，保证上面的不等式成立

可以得到：（下式的右侧 x 2 取趋近于 x 1 的极限可以直接代入 x 1）

$$
\lim_{ x_{2} \to x_{1}^{+} } \frac{f(x_{2})-f(x_{1})}{x_{2} -x_{1}} =f'_{+}(x_{1})\leq \frac{f(x_{3})-f(x_{1})}{x_{3}-x_{1}} 
$$

同理，对于 x 3 处的导数，我们根据这个式子让 x 2 从左侧趋近于 x 3：

可以得到：

$$
\frac{f(x_{3})-f(x_{1})}{x_{3} - x_{1}} \leq f'_{-}(x_{3})
$$

根据 f (x) 可导，所以左右导数实际上就是导数本身，并且根据这个桥梁我们可以得到：

$$
f'(x_{1}) \leq f'(x_{3})
$$

可以得到不严格单调

这里如果想要得到严格单调需要再在 x 1 和 x 3 之间假如一个不动的点 x 0，然后在 x 1 和 x 0 之间有动点 s，x 0，x 3 之间有动点 t，即 x 1 < s < x 0 < t < x 3

按照上面的分析过程，对于 x 1 < s < x 0 这个区间，我们可以得到：(s 逼近于 x 1 取极限的过程)

$$
f'(x_{1}) \leq \frac{f(x_{0})- f(x_{1})}{x_{0}-x_{1}}
$$

对于 x 0 < t < x 3 这个区间我们可以得到：（t 逼近于 x 3 取极限的过程）

$$
\frac{f(x_{3})-f(x_{0})}{x_{3}-x_{0}} \leq f'(x_{3})
$$

然后对于 x 1 < x 0 < x 3 这个区间，我们根据题目的条件有（将 x 0 看作题目中的 x 2）：

$$
\frac{f(x_{0})- f(x_{1})}{x_{0}-x_{1}} <\frac{f(x_{3})-f(x_{0})}{x_{3}-x_{0}} 
$$

这样就有 f' (x 1) < f' (x 3) 严格小于了
