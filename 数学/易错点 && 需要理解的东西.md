### 互逆计算法则

$\arctan x = a$  这个东西如果不知道 x 或者 a，可以直接两边取 tan，得到  $x = \tan a$ 

tan 和 arctan 是互为逆运算

同样 ln 和 e 也是互逆运算

这里的互逆运算的应用就是通过等式左右同时一次运算可以消掉另外一个运算符号，比如上面的 x = tan a，左右同时进行 arctan 得到：
$$
\arctan x = a
$$
那右边就消掉了 tan

比如 lnx  = t，左右同时进行 e 运算：
$$
x = e^t
$$
那左边就消掉了 ln

### 反三角变换的易错点

对于 arcsin x 来说其图像为：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250513114537.png)

它的定义域一定是 `[-1, 1]`，值域一定是 $\left[ -\frac{\pi}{2}, \frac{\pi}{2} \right]$

所以对于 y = sin x，我们如果**想要用 y 来表示 x**，即去掉 sin 符号，那么就需要注意 x 的取值范围

如果 x 在 $\left[ -\frac{\pi}{2}, \frac{\pi}{2} \right]$ 中，那没问题，直接进行互逆运算，两边 arcsin 运算得到 $\arcsin y = \arcsin(\sin x) = x$，非常正确，符合反三角的定义域和值域

但是如果 x 不在 $\left[ -\frac{\pi}{2}, \frac{\pi}{2} \right]$ 中，比如 x 的范围是 $\left[ \frac{\pi}{2}, \frac{3\pi}{2} \right]$

那么对于 y = sin x，两边进行反三角运算：arcsin y = arcsin (sin x)，就不能直接等于 x，因为这样就不符合 arcsin y 的值域

这里必须用诱导公式对 x 进行变换，将其定义域变换到 $\left[ -\frac{\pi}{2}, \frac{\pi}{2} \right]$ 中，即 $y = sin x = sin (\pi - x)$

然后再两边取反三角：

$$
\arcsin y = \arcsin (\sin x )= \arcsin (\sin(\pi - x)) = \pi - x
$$
此时 $\pi -x$ 在反三角 arcsin y 的值域中，这时才成立

### 海涅定理及其两点使用

（1）对于 f (xn) 和 f (x)，如果 f (x) 在 x -> x 0 的时候极限存在，即  $\lim_{ x \to x_{0} } f (x) = a$ ，那么当 xn 收敛于 x 0 的时候，可以将 f (xn) 转化为求解 f (x)，即  $\lim_{ xn \to x_{0} } f (x_{n}) = \lim_{ x \to x_{0} } f (x) = a$ 

其用处在于可以==将一个复杂的数列极限表达式转化为函数极限的表达式==，用求函数极限的方法来求解，比如：

![image.png|411x204](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250414115619.png)

（2）xn 其实可以看作是 f (x) 的变量 x 的一个子列，根据数列收敛的性质，只有所有收敛于 x 0 的子列 xn 都有 f (xn) 极限为 a 的时候，才有 f (x) 的极限为 a

这个命题的用处在于其逆否命题，==用于说明函数极限不存在==，我们判断  $\lim_{ x \to x_{0} }f (x)$  ，的时候，只要找到趋于 x 0 的两个子列，这个两个子列代入 f () 之后的极限不相等，那么函数的极限就不存在

比如对于函数极限 $\lim_{ x \to 0 }\sin\frac{1}{x}$

取  $xn = \frac{1}{n\pi} ， bn = \frac{1}{n\pi + \frac{\pi}{2}}$ ，代入可以发现 f (xn) 与 f (bn) 的极限不一样，因此  $\lim_{ x \to x_{0} }f (x)$  的极限就不存在

### 计算函数极限 $x \to 0$ 的易错点，分正负零讨论

计算函数极限的时候，当 $x \to 0$，此时 $\frac{1}{x}, e^{\frac{1}{x}}, \arctan\frac{1}{x}$，这些式子在 0 负和 0 正的情况是不一样的

$\arctan {x}$，当 x 趋于正无穷的时候其趋近于 $\frac{\pi}{2}$，x 趋近于负无穷的时候其趋近于 $-\frac{\pi}{2}$

### 函数极限乘除运算的易错点，已知项非零

在计算 $\lim_{ x \to x_{0} } f(x)g(x), \lim_{ x \to x_{0}} \frac{f(x)}{g(x)}$ 的时候，如果 g (x) 的极限已知 = A，一般只有 A $\ne 0$ 的时候才能拆成 $A * \lim_{ x \to x_{0} } f(x), \lim_{ x \to x_{0}} \frac{f(x)}{A}$ ，通过计算 f (x) 的极限来做

而当 A = 0 的时候则考虑不能拆开来做，这是因为：

(1) 当计算乘积的时候，如果 f (x) 的极限是无穷，则无法拆成 0 * 无穷来计算整体乘积极限
(2) 当计算除法的时候，如果 A = 0，那就更不能拆开分别计算了
(3) 当然如果 f (x) 极限是有界量，那乘积提前计算结果其实就是 0，但是除法不能拆开


### 洛必达法则易错点，n 阶导连续

其定义如下：

![image.png|684x341](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250415083902.png)


注意只要是 f (x) 和 g (x) 在 a 的一个空心领域中可导就可以洛一次，即：$lim \frac{f(x)}{g(x)} = lim \frac{f’(x)}{g’(x)}$，洛必达是通过结果反推的，如果可洛，洛完之后可以计算出极限 A，则原来的极限就是 A；但是如果洛完之后发现算不出，此时不能说明原来的极限不存在，需要换方法进行计算

但是计算 $lim \frac{f’(x)}{g’(x)}$ 不能直接代入 f’(x) 或 g’(x)，因为只有 f’(x) 和 g’(x) 在 a 点连续的时候才能代入

如果是抽象函数，题目没有说 f’(x) 和 g’(x) 在 a 点连续那就不能使用洛必达，因为洛出来的结果未知得不到 $lim \frac{f’(x)}{g’(x)}$ 是否等于 A，所以上面洛一次就是错误的，不能使用洛必达

但是如果是具体函数，可以用定义算出 a 点的 f (x) 和 g (x) 的导函数，即可以算出 $lim \frac{f’(x)}{g’(x)} = A$，那洛必达就是有效的

所以只要能求出 $lim \frac{f’(x)}{g’(x)} = A$ 即，$lim \frac{f’(x)}{g’(x)}$ 存在或者是无穷，那洛必达就是可用的，至于导数连不连续则是在代入极限需要做的事情，一般而言如果 n 阶导数存在并且连续，那么就可以洛到 n 阶，但是如果 n 阶导数只是存在没有说连续，则此时计算有关 n 阶导有关的东西时就需要凑导数的定义，而不是直接代入 n 阶导在趋于 a 处的值

### 无穷小运算易错点，无穷小运算的等号更像是属于，而不是相等

对于无穷小加减运算来说，低阶无穷小会吸收高阶无穷小：

$$
o(x^2) \pm o(x^3) = o(x^2)
$$

这里的等号更像是左边集合属于右边的集合，并不意味着左右两边的次数相等

比如 $x^2 - \sin x^2 = o(x^2)$，左边的式子在相减之后与 x^6 同阶，但是仍然属于 o (x^2)，所以无穷小的运算中的等号其实是一个很粗略的信息，不能确定式子的具体阶数

一般如果知道了式子 $f(x)$ 的具体阶数 k的话，可以直接将其替换成 $Cx^k + o(x^k)$ 放到式子中，这样不容易犯错

比如上面 $\sin x^2$ 其实是 $x^2 - \frac{1}{6} x^6 + o(x^6)$，那么这个式子其实真实等价于 $x^2 - x^2 + \frac{1}{6}x^6 + o(x^6)$，可以看到其是一个与 x^6 同阶的无穷小

### 无穷大和无界的易错点，无穷大是无界，但是无界不一定是无穷大 + 0 * 无穷大的理解

无穷大的定义是 $\lim_{ x \to x_{0} } f(x) = \infty$（此时极限仍然不存在），而无界的定义是对任意的正数 M，存在 x 0 使得 |f (x 0)|>M

无界可能是震荡的，而无穷就是要求函数中所有未知数子列代入函数都是趋于无穷的

### 函数间断点，极值点，极值，最值，驻点，拐点的规范写法

## 一元函数微分学

### 可微的定义以及对线性主部和图像的理解

对于函数 `f(x)`，在 x 0 处（即固定 x 0）的函数增量有：$f(x0 + \Delta x) - f(x0) = \Delta y$

这里 Delta x 成变量，Delta y 成 Delta x 变化的时候的因变量

如果 $\Delta y$ 可以写成 $\Delta y = A(x_{0}) \Delta x+\alpha(\Delta x)$，其中 A (x 0) 是与 Delta x 无关的量，并且 $\alpha(\Delta x)$ 是当 $\Delta x$ 趋于 0 的时候的无穷小

那么此时可以称为 f (x) 在 x 0 处可微，此时的对于式子 $\Delta y = A(x_{0}) \Delta x+\alpha(\Delta x)$ 来说，$A(x_{0}) \Delta x$ 是其线性部分，称为线性主部，记作 $dy|_{x = x_{0}}$，并且规定 $\Delta x = dx$

于是我们根据求导数的公式可以发现 $A(x_{0}) = f'(x_{0})$，因此就有 $\frac{dy}{dx}|_{x_{0}} = f'(x_{0})$

**这里 x 0 固定，Delta y 可以看作是 Delta x 的函数**

如果可以写成 $\Delta y = A(x_{0}) \Delta x+\alpha(\Delta x)$ 的情况下，即可微的情况下，我们发现 A (x 0) 就是 f (x) 在 x 0 处的导数，于是可以将其在图像中表示出来：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250421090704.png)

注意上图中的 dy 并不是在 Deltax 趋于 0 的时候才有意义，dy 仅仅代表式子 $\Delta y = A(x_{0}) \Delta x+\alpha(\Delta x)$ 有可微下的线性主部，是一个与 dx 有关的量，而上图中 Delta y 和 dy 的差值才是一个 Dleta x 趋于零的时候的无穷小量

x 0 固定的时候，dx 的变化导致 dy 的变化，但是 dy 除以 dx 的结果就是导数，是在 x 0 处的导数，此时 dy 就是关于 dx 的一个一次函数；当 x 0 变化的时候 dy/dx 整体就是关于 x 0 的函数了，就是原函数的导函数，即 $\frac{dy}{dx}|_{x=x_{0}} = f'(x_{0})$

而在 $\Delta x$ 趋于 0 的时候的有关意义是，可以用 d y 代替 $\Delta y$，即在 $\Delta x$趋于零的时候就可以以直线代替曲线了

### 微分形式的不变性的理解

所谓微分形式不变性的意思就是，对于一个符合函数 $y = f[g(x)]= f(u)$，这里无论将 u 当作自变量对 y 求微分，得到 dy = f' (u) du，还是将 u 当作因变量，对 y 求微分 dy = f' (u) g' (x) dx，得到的 y 的微分形式始终是 dy = f' d 这种等式右边一个导数乘一个微元的形式，这个称为微分形式不变性

#### 拉格朗日余项和皮亚诺余项的区别在于

（1）形式不同
（2）条件不同，拉格朗日余项要求 n + 1 阶可导，但是皮亚诺余项只用 n 阶可导

#### 泰勒公式的通项与项数的对应关系

都是从第 0 项开始

对于带系数的展开式：$f(x) = a_{0} + a_{1}(x - x_{0}) + a_{2}(x - x_{0})^2 + \dots \dots +a_{n}(x - x_{0})^n + o((x - x_{0})^n)$

上图中的通项有的是带系数展开式第 n 项的通项，有的是带系数展开式第 n + 1 项的通项，比如 e^x 的通项就是带系数展开式第 n 项的通项；但是 ln (x + 1) 的通项就是带系数展开式第 n + 1 项的通项

分辨方式是看通项是否对得上展开式第 0 项的值即可，比如 e^x 的通项取 0，可以对的上带系数展开式的 a 0，那么 e^x 的通项的 n 就是展开式中的第 n 项

而 ln (x + 1) 的通项 n 取 0 对应的是带系数展开式的第 1 项，因此 ln (x+1) 的通项取 n 就对应带系数展开式的第 n + 1 项，也就是对应的是 n + 1 阶导

同理对于 $x^2\ln(x  + 1)$，其在 0 处展开的通项为：$x^3 - \frac{1}{2}x^4 + \frac{1}{3} x^5 + \dots\dots \frac{(-1)^n}{n + 1}x^{n + 3}$
写出 $x^2 \ln(x + 1)$ 的带系数展开式：$x^2 \ln(x + 1) = a_{0} + a_{1}(x - x_{0}) + a_{2}(x - x_{0})^2 + \dots \dots +a_{n}(x - x_{0})^n + o((x - x_{0})^n)$

在 x 0 = 0 处的带系数展开式为：
$$
x^2 \ln(x + 1) = a_{0} + a_{1}x  + a_{2}x^2 + a_{3}x^3 +\dots\dots a_{n}x^n
$$
可以发现 x^3 是第 0 项，对应带系数展开式中的第 3 项，所以通项 $\frac{(-1)^n}{n + 1}x^{n + 3}$ 就对应带系数展开式中的第 n + 3 项，因此带系数展开式的第 n 项的通项应该是 $\frac{(-1)^{n-3}}{n -2}x^{n}$

从而得到 $\frac{f^{(n)}(0)}{n!} = \frac{(-1)^{n-3}}{n -2}$，从而求出 $x^2\ln(x + 1)$ 在  0 处的 n 阶导

其实根据通项中 x 的次数就可以直接判断通项是对应带系数展开式的第几项


### 泰勒展开系数对应的易错点（利用泰勒公式求 n 阶导的方法）

一般题中给定一个常见的函数我们可以明确知道其泰勒展开，比如 $x^2\ln(x + 1)$，这时题目要求这个函数在 x 0 处的 n 阶导，为了不出错，应该遵循下面的步骤

（1）写出 f (x) 在 x 0 处的带系数的展开（幂级数）：
$$
x^2 \ln(x + 1) = a_{0} + a_{1}(x - x_{0}) + a_{2}(x - x_{0})^2 + \dots \dots +a_{n}(x - x_{0})^n + o((x - x_{0})^n)
$$
（2）写出 $f(x)$ 的具体的通项泰勒展开：

$$
x^2 \ln(x + 1) = (x - x_{0})^3 - \frac{1}{2}(x - x_{0})^4 + \frac{1}{3} (x - x_{0})^5 + \dots\dots \frac{(-1)^n}{n + 1}(x - x_{0})^{n + 3}
$$
（3）根据具体的通项泰勒展开的系数判断其对应带系数展开的哪一项，比如这里通项中是 n + 3 次，所以应该对应带系数展开中的第 n + 3 项

（4）写出带系数展开中的第 n 项对应的通项，这里就是 $a_{n}(x - x_{0})^n = \frac{(-1)^{n-3}}{n -2}(x - x_{0})^{n}$

然后根据 $a_{n} = \frac{f^{(n)}(x_{0})}{n!}$，从而得到 f (x) 在 x 0 处的 n 阶导

### 单调性和导数正负互相推导的易错点

如果说了函数可导：

（1）只有 $f'(x) \ge 0$ 且等号在有限个点成立，函数才严格单增，如果没说有限个点 = 0，则只能说明函数广义单增

（2）函数严格单增，只能说明 $f'(x) \ge 0$，但是无法说明 $f'(x) >0$，比如 x^3

如果没说函数可导：

那么由函数单增无法推出导数的正负，甚至无法得到函数是否连续，以及导数是否存在

也就是两个易错点：

（1）没说函数可导，无法通过单调性推出导数信息
（2）函数可导，f' (x) 只有在有限个点处等于 0，才能根据其正负推出严格单调，否则就只是广义单调
### 某点可导与领域连续和领域单调的关系

如果知道 $f'(x_{0})$ 在某点可导，并且 $f'(x_{0}) >0$，则在一个领域 $(x_{0} - \delta, x_{0} + \delta)$ 中：

（1）**无法得到函数的单调性**，这个不多说，一个说烂的例子是：
 ![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250423120144.png)

（2）**无法得到函数的连续性**，比如 $f(x) = x^2 D(x)$，D (x) 是迪利克雷函数，x 取有理数的时候是 1，无理数的时候是 0，x^2D (x) 在 x = 0 连续并且可导，但是不存在一个领域这个函数连续


### 极值点和驻点，可导，连续的关系

x 0 是 f (x) 的极值点，则 f (x) 在 x 0 处不一定是驻点，也不一定可导，也不一定连续

极值点与这三者没有任何必然联系

只有说了 f (x) 在 x 0 可导之后，如果此时 x 0 是极值点，这时这个极值点才是驻点，也可导，同样也连续


### 易错点：极值点和最值联系

（1）极值点是某一点范围的概念，因此**极值只能在区间内部取得**，最值可以在区间得端点取得

（2）**除了常函数**，根据极值和最值的定义，如果最值 f(x 0)在区间内部取得，那 x 0也是极值点；反过来，**如果 f(x) 在开区间可导，并且 x 0是区间内部**的唯一极值小（大）点，则这个 f(x 0)是最小（大）值，这里必须可导，如果不可导如下所示：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250425120740.png)

x 0 是唯一极小值点，但是不是最小值点

**即一个函数升降的分界点是极值点，但是极值点不一定是函数升降的分界点**


### 极值点和拐点和驻点的定义

==极值点的定义是：==

x 在 x 0 的一个邻域中 f (x) > f (x 0) 则 x 0 是极小值点，极大值点也是这样定义

**此处是严格小于，并且不要求 f (x) 在 x 0 处可导，也不要求 f (x) 在 x 0 处连续，只要有定义即可**

==拐点的定义：==

连接 f (x) 凹弧和凸弧的点，即 f (x) 一阶导单调性变化的点

**此处 f (x) 必须在拐点 (x 0, f (x 0)) 处连续，但是拐点处的一阶导可以不存在**

==驻点的定义：==

使得函数的一阶导 $f'(x) = 0$ 的点是驻点

**驻点不一定是极值点，极值点也不一定是驻点**
### 极值点和拐点的充分条件

==极值点的充分条件：==

**（1）f (x) 在 x 0 处连续，在 x 0 的去心领域可导，如果 x 0 左右的 f' (x) 变号，则 x 0 是极值点，如果同号，则不是极值点（教材原话）**

<font color="#2DC26B">第一充分条件使用的前提是 f (x) 在 x 0 处必须连续</font>，并且 f (x) 在 x 0 的去心领域可导，此时才能通过判断 x 0 左右两侧的导数符号来判断 x 0 是否是极值，以及是极大值还是极小值，如果不连续，则次判定条件失效：

如果函数不连续，则判断失效，比如下面：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250425114243.png)

此时这个点左侧函数大于零，右侧小于零，但是根据定义这个点不是极大值，这就是因为此处函数不连续

**（2）f (x) 在 x 0 二阶可导，在 x 0 处 f'' (x) != 0，则 x 0 是极值点**

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250504102308.png)


**（3）f (x) 在 x 0 n 阶可导，在 x 0 处 $f^{(n)} (x_{0}) \ne 0$，如果 n 是偶数，则 x 0 是极值点**

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250504102324.png)


==拐点的充分条件：==

**（1）连续函数 f (x)，在 x = x 0 两侧 f'' (x) 异号，则 (x 0, f (x 0)) 是 f (x) 的拐点，如果在 x = x 0 两侧 f''(x) 不异号，则不是拐点（数分教材原话）**


**（2）f (x) 在 x = x 0 的领域内三阶可导，且 f'' (x 0) = 0，f''' (x 0) != 0，则 (x 0, f (x 0)) 是 f (x) 的拐点**

**（3）f (x) 在 x 0 n 阶可导，在 x 0 处 $f^{(n)} (x_{0}) \ne 0$，如果 n 是奇数，则 (x 0, f (x 0)) 是 f (x) 的拐点**

### 极值点和拐点的必要条件

==极值点的必要条件==

f (x) 在 x 0 可导，并且在 x 0 处取得极值，则 f' (x 0) = 0

反过来不行，比如常函数

==拐点的必要条件：==

f (x) 在 x 0 有二阶导数，并且在（x 0, f(x 0)）处是拐点，则 f'' (x 0) = 0

反过来不行，比如常函数



### 极值点和拐点的计算方法和区别

==极值点的计算方法：==

极值只可能在驻点或者不可导点中取得，因此我们挨个考察驻点和不可导点，对这些点挨个使用充分条件，判断左右两侧符号，**如果异号则是极值点，如果同号，则不是极值点**

当然有可能三大充分条件全部失效 （一般题目不会出这样的）比如f(x) 在 x 0 处不连续，此时可以用定义来考察这个点

==拐点的计算方法：==

根据拐点的必要条件，拐点只可能在二阶导等于零和二阶不可导点中取得，因此我们挨个考察这些点两侧二阶导的符号，**如果异号则是拐点，如果同号则不是拐点**

当然有可能这个点不是 f (x) 的连续点，不连续那肯定就不是拐点（不满足定义）


### 极值点和拐点第一充分条件使用前提的区别和联系

（1）极值点要求 f (x) 在 x 0 处必须连续才能使用第一充分条件，如果不连续则应该用定义判断；拐点也要求在 x 0 处连续才能使用第一充分条件，如果不连续就不符合拐点定义，肯定不是拐点

（2）同时拐点第一充分条件的使用并不要求一阶导在 x 0 处连续，极值点的第一充分条件也不要求在 x 0 处连续

### 根据图像法判断极值点和拐点

==f(x) 原图像==

判断极值点：可以直接根据定义观察图像看出来

判断拐点：也可以直接根据定义观察图像看出来，连接凹凸两端图像的就是拐点，或者一阶导发生单调性变化的点就是拐点；**拐点必须是 f (x) 的连续点**

==f'(x) 图像==

判断极值点：观察图中一阶导曲线等于零和不存在的点，看两侧符号，两侧符号相同则不是极值点，两侧符号相异则是极值点

判断拐点：观察图中曲线单调性发生变化的点，看两侧曲线的单调性，两侧调性发生变化则是拐点，两侧单调性没有发生变化则不是拐点

==f''(x) 图像==

判断极值点：无法判断

判断拐点：观察图中曲线等于零和不存在的点，点两侧正负性发生变化则是拐点，正负性没有发生变化则不是拐点

**图像法其实就是考察一阶导和二阶导等于零以及不存在点两侧的符号，跟计算方法类似；而题目一般都会给出 f (x) 连续，如果不连续则判定极值点需要使用定义，判定拐点则可以直接判定不是拐点**
### 极值点和拐点的联系和区别

==拐点和极值点的联系和区别==

**（1）f (x) 在拐点处必须连续，但是 f (x) 在极值点处不一定连续**

**（2）拐点处的一阶导可以不存在，极值点处的一阶导也可以不存在**

**（3）一个函数的拐点和极值点可以同时取得，但是此处的导数一定不存在，这个函数的脑袋一定是尖尖的，对于函数的可导点，极值点和拐点无法同时取得**
![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250424084834.png)

（4）**拐点不能简单看作是一阶导的极值点，因为此处的导数可以不存在**，比如上面脑袋尖尖的函数；这是因为拐点本质上来说是原函数 f (x) 的性质，是连接一段凹一段凸的点，这个点处当然可能函数导数不存在

（5）判断极值点是找到一阶导等于零和不存在的点；判断拐点是找到二阶导等于零和不存在的点；判断方法都是观察两侧的一阶导和二阶导符号，变号则是极值点或者拐点，不变号则不是极值点或者拐点；区别在于当 f (x) 在 x 0 不连续，第一充分条件判定失效，判断极值点的时候需要用定义，而拐点可以直接判定 x 0 不是拐点

### 有理函数积分法


#### 一些基本的概念

有理函数的积分是类似与下面的式子：
$$
\int \frac{a_1x^{m_1} + a_2x^{m_2}+...a_nx^{m_n}}{b_1x^{t_1} + b_2x^{t_2}+...b_nx^{t_n}} dx
$$
一般来讲有理函数可以分为两类：

**（1）真分式，指分子的幂要小于分母的幂**，比如下面的式子：
$$
\frac{1}{x + 1}
$$

**（2）假分式，指分子的幂要大于等于分母的幂**，比如下面的式子：

$$
\frac{2x^2 + 1}{x^2 + 1}
$$

对于假分式来说，其一定可以拆成一个多项式与真分式的和，比如上面的式子可以拆成：
$$
\frac{2x^2 + 2 - 1}{x^2 + 1} = 2 - \frac{1}{x^2 + 1}
$$
#### 多项式除法
不过还有更一般的做法，可以直接用多项式除法来拆成一个多项式和真分式的和：

<img src="https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/image-20241115102419834.png" alt="image-20241115102419834" style="zoom:50%;" />

 这里的多项式除法只要余数是小于  x^2 + 1  的式子就好了，于是可以得到：
$$
 \frac{2(x^2 + 1) - 1}{x^2 + 1} = 2 - \frac{1}{x^2 + 1}
$$
再举一个多项式除法的例子：
$$
 \frac{x^3 - 12x^2 - 42}{x - 3}
$$

多项式除法如下所示：
<img src="https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/image-20241115110347393.png" alt="image-20241115110347393" style="zoom:50%;" />
因此将假分式化为多项式和真分式之和为：

$$
 \frac{(x - 3)(x^2 - 9x - 27) - 123}{x - 3} = x^2 - 9x - 27 - \frac{123}{x - 3}
$$

所以其实多项式除法就三个注意的步骤：

（1）被除式和除式都进行降幂排列，并且空缺的项的系数补零
（2）除法上系数的时候要保证被除式的最高幂可以被消掉
（3）一直到余数的幂小于除式，这时候除法终止

#### 处理的一般流程

##### （1）拆项，如果是假分式，拆成多项式与真分式的形式



##### （2）对真分式的分母进行因式分解，我们可以得到一个这样的真分式：
$$
\frac{P(x)}{Q(x)}
$$
其中 Q (x) 已经进行了因式分解

##### （3）对已经因式分解的真分式进行进一步的拆项，这一步有固定的套路：

i 如果分母中有 $(x - a)$，则拆出的项中有：$\frac{A}{x - a}$；如果分母中有 $(x - a)^2$，则拆出的项有 $\frac{A}{x - a} + \frac{B}{(x - a)^2}$；反正只要因式分解的一项是 $(x - a)^k$，那么其就会对拆分的项贡献出：$\frac{A}{x - a} + \frac{B}{(x - a)^2} + \frac{C}{(x - a)^3}....\frac{D}{(x-a)^k}$

ii 如果分母中有 $x^2 + px + q$，则拆出的项中就有：$\frac{Dx + E}{x^2 + px + q}$；同上，如果分母中有 $(x^2 + px + q)^k$，那么其就会对拆分的项贡献出：$\frac{D_1x + E_1}{x^2 + px +q} + \frac{D_2x + E_2}{(x^2 + px +q)^2} + ....\frac{D_kx + E_k}{(x^2 + px +q)^k}$；但是像这种二次的一般就只考到 k = 1，不会再多了

举个例子如下：
$$
\frac{3x + 6}{(x - 1)^2(x^2 + x + 1)} = \frac{A}{x - 1} + \frac{B}{(x - 1)^2} + \frac{Dx + E}{x^2 + x + 1}
$$
##### （4）确定拆项后的式子的系数：

也就是确定上面式子的 A，B，D，E，这里可以**用待定系数法**，对等式右边的式子进行通分，然后确定系数


##### （5）对拆分出来的式子进行积分：
$$
\int \frac{3x + 6}{(x - 1)^2(x^2 + x + 1)} dx = \int \frac{A}{x - 1} + \frac{B}{(x - 1)^2} + \frac{Dx + E}{x^2 + x + 1}dx =  \int \frac{-2}{x - 1} + \frac{3}{(x - 1)^2} + \frac{2x + 1}{x^2 + x + 1}dx
$$
上面的式子的前两项很简单，关键是后面的一项 $\int \frac{2x + 1}{x^2 + x + 1}dx$ 的处理

类似这种式子的处理其实有一个通用过程，就是将分子拆成分母的导数和一个常数：
$$
\int \frac{2x + 1}{x^2 + x + 1}dx = \int \frac{A(x^2 + x + 1)' + B}{x^2 + x + 1} dx= \int A \frac{(x^2 + x + 1)'}{x^2 + x + 1}dx + \int \frac{B}{x^2 + x + 1}dx
$$
这样做的逻辑有三个：

（1）分子是一定可以这样拆的，因为分子本来就是一个一次的式子，用 A 来控制一次项的系数，A 与导数的常数项作用得到常数，这时再加上 B 来控制常数项；所以一定可以通过 A 和 B 还原成原来的一次项

（2）拆成这样之后左边的项可以直接积分

（3）右边的项一定可以将分母写成平方式子所以我们可以得到：
$$
\int \frac{2x + 1}{x^2 + x + 1}dx = \int A \frac{(x^2 + x + 1)'}{x^2 + x + 1}dx + \int \frac{B}{x^2 + x + 1}dx = \int \frac{(x^2 + x + 1)'}{x^2 + x + 1}
$$
下面的积分就非常简单了
这里比较特殊，一般情况下，比如上式的分子如果是 2 的话可以拆成：
$$\int \frac{2x + 2}{x^2 + x + 1}dx  = \int \frac{(x^2 + x + 1)'}{x^2 + x + 1} + \int \frac{1}{x^2 + x + 1} dx
$$
进一步可以写成：
 
$$ \int \frac{2x + 2}{x^2 + x + 1}dx  = \int \frac{(x^2 + x + 1)'}{x^2 + x + 1} + \int \frac{1}{(x + \frac{1}{4})^2 + \frac{3}{4}} dx = \ln(x^2 + x + 1) + \frac{2}{\sqrt{3}} \arctan(\frac{x + \frac{1}{4}}{\frac{\sqrt{3}}{2}})
$$
上面的所有内容就是有理积分的一般处理流程


#### 留数法

将有理函数拆成多个积分式子确定其系数的时候不是很好做，计算量比较大，这里介绍一种留数法来快速处理

**留数法就是用来确定形如 $\frac{A_{k}}{(x - a)^k}$ 这种原来分母中的一次项拆开的项的系数的，但是对于二次项拆开的系数 $\frac{Ax+B}{x^2 + x + a}$ 留数法一般就失效了**

这里分别有几种情况来处理：

 ==i 类似分母一次幂形成的项的系数确定，分母的项无重根==

**等式两边同时乘分母中对应的项，然后代值**

 比如：$\frac{1}{(x - 1)(x - 2)} = \frac{A}{x-1} + \frac{B}{x - 2}$

 这里等式两边乘 (x - 1) 可以得到 $\frac{1}{x - 2} = A + \frac{(x - 1)B}{x -2}$，这也是一个恒成立的式子，于是我们直接取 x = 1 就得到了 A 了，同理等式两边同时乘 x - 2，然后 x 取 2 就得到 B 了

 ==ii 类似次数大于 2 的形式的项，即分母的项有重根==


 比如 $\frac{x - 3}{(x - 1)^2(x - 2)} = \frac{A}{x-1} +  \frac{B}{(x - 1)^2} + \frac{C}{x - 2}$

**对于确定分母中的单根项拆开项的系数，和重根项拆开的最高次项系数，等式两边同时乘分母中的项，然后代值即可**

这里先确定无重根的项 (x - 2) 的系数，等式两边同时乘 (x - 2) 然后代入 x = 2 得到 C = -1

接着对于 B 这种重根项最高次的，也可以采用两边同时乘 $(x - 1)^2$，然后代入 x = 1, 得到 B = 2

**对于确定分母中重根项拆开的低次方系数，还是通过同时乘分母中的重根项，但是需要求导将系数暴露出来，然后代值**

最后是参数 A，这里的做法是还是两边同时乘 $(x - 1)^2$，然后得到：$\frac{x - 3}{x - 2} = A(x - 1) + B + \frac{C}{x - 2}(x - 1)^2$，此时两边同时求导，并代入 x = 1，这样就可以消去 B，C 两项，同时将 A 暴露出来，于是就得到 A 了

再比如一个式子：$\frac{x - 3}{(x  - 1)^3(x + 1)} = \frac{A}{x - 1} + \frac{B}{(x - 1)^2} + \frac{C}{(x - 1)^3} + \frac{D}{x + 1}$

D的确定方法同上，两边同时乘 x + 1 然后代入 x = -1

C 对应有重根项的最高次系数，其的确定方法同上，两边同时乘最高项 (x - 3)^3，然后代入 x = 1 得到结果

B 的确定仍然是左右两边同时乘 (x-1)^3 得到：$\frac{x-3}{x + 1} = A(x - 1)^2 + B(x - 1) + C + \frac{D}{x + 1}(x - 1)^3$，然后，求一次导将 B 的系数暴露出来，同时代入 x = 1 将其他项的系数归零，得到结果

A 的确定仍然是左右两边同时乘 (x-1)^3 得到：$\frac{x-3}{x + 1} = A(x - 1)^2 + B(x - 1) + C + \frac{D}{x + 1}(x - 1)^3$，然后，求两次导将 A 的系数暴露出来，同时代入 x = 1 将其他项的系数归零，得到结果

这种同乘最高系数的重根项，然后求导，可以保证其他的系数要么在求导的过程中归零了，要么在求导后代入 x 的值归零了，可以将待求系数暴露出来


 再比如一个式子： $\frac{3x + 6}{(x - 1)^2(x^2 + x + 1)} = \frac{A}{x - 1} + \frac{B}{(x - 1)^2} + \frac{Dx + E}{x^2 + x + 1}$

这里可以用上面的方法快速确定系数 A 和 B，对于后面的 D 和 E，可以直接代值确定，比如得到了 A 和 B 之后直接代入 x = 0，就可以将 E 暴露出来，得到 E 之后再代入 x = 2 就可以得到 D 了

### 用定积分定义处理和式极限的做法

一般题目中给出的是一个 n 项和的极限，我们需要将这个 n 项和式极限写成定积分的形式来处理，转化成定积分的方式如下：

（1）凑出 $\frac{i}{n}$ 或者 2 i/n 或者 2 i - 1 / 2 n 这样的变化的项，这个是作为自变量，从而确定函数是什么

（2）观察 $\frac{i}{n}$ 或者 2 i/n 或者 2 i - 1 / 2 n 这样的项的变化范围，从而确定积分的上下限


如果 i/n 从 1/n 变化到 n/n，那么 n 取极限，那区间就是 0 到 1

如果我们凑出的是 2 i/n，那么这个变化范围就是 2/n 到 2 n/n，同样 n 取极限，那么区间就是 0 到 2

注意这里的变化范围不是根据 i 从 0 变化到 2 n 所以确定其范围是 0 到 2，而是变量变化的端点从 2/n 到 2 n/n， n 取极限之后，才得到区间是 0 到 2

（3）确定步长

主要就是观察 i 每增加一次增长了多少，比如是 i/n，i 每加 1 这个变量就是增长了 1/n 所以步长就是 1/n；如果是我们凑出的变量是 2 i - 1/ 2 n，i 每增加 1，这个变量就是增长了 1/n 所以步长还是 i/n；如果凑出的变量是 2 i - 1 / n，那么 i 每增加 1，这个变量增长了 2 / n，所以步长就是 2 / n

这里的步长是通过这个变化的项的增加 1 来算出来的，而与其和式多少项是无关的

（4）配出步长乘函数的形式

也就是配出  $\Sigma_{i = 1}^n \frac{1}{n}f\left( \frac{i}{n} \right)$ 或者 $\Sigma_{i = 1}^n \frac{2}{n}f\left( \frac{2i}{n} \right)$ 这样的步长乘一个函数值的形式

### 定积分的存在性（可积）与原函数存在的区别

一个函数 f (x) 的原函数存在与可积不是一个东西；

这两者的区别在于，定积分是一个数，而不定积分是一个函数族

如果 f (x) 有第一类间断点和无穷间断点，则 f (x) 原函数不存在；但是如果 f (x) 有界且有有限个间断点，则 f (x) 可积

**所以原函数存在不一定可积，同样可积也不一定原函数存在**

==可积的三个充分条件：==

在[a, b]上

（1）f (x) 连续必可积
（2）f (x) 单调必可积
（3）f (x) 有界且有有限个间断点（不包括无穷间断点），必可积

==可积的必要条件==

可积函数必有界

==原函数存在的三点：==

（1）连续函数必存在原函数
（2）含有第一类间断点，无穷间断点的区间上，函数必无原函数
（3）含有震荡间断点的区间上，可能有原函数
### 变上限积分（积分上限函数）的两个定理

（1）若 f (x) 在[a, b]上连续，则 $\phi(x)  = \int_{a}^x f(t)dt$ 在[a, b]上可导，并且 $\phi'(x) = f(x)$

（2）在（1）的情况下（ f(x) 连续 ），此时 $\phi(x)$ 是 f (x) 在[a, b]上的一个原函数，并且有 $\int f(x) dx = \int_{a}^x f(t)dt + C$，即此时 f (x) 的原函数就是变上限积分加上一个常数

### 三角换元的范围和单调性问题

第二换元法，即令 $x = g(t)$ 的使用其实有一个前提：$g(t)$ 单调可导并且 $g'(t) \ne 0$

所以在不定积分或者定积分计算的时候进行三角换元会涉及到范围的问题，比如：

$\sqrt{ a^2 - x^2 }$，这个换元一般是令 $x = \sin t$，$t \in (  -\frac{\pi}{2} , \frac{\pi}{2} )$

这样可以保证 ：

（1）sint 的取值可以取满 x 的范围（开闭无所谓，积分的值与某个点包不包含无关）
（2）sint 是单调的
（3）开方之后的 cost 是正的，不用加负号

所以不论是不定积分还是在定积分，在进行换元 x = g(t) 的时候其实只用考虑：

（1）t 的取值可以满足 x 的取值
（2）g (t) 单调

满足上述两点即可，至于开方之后的处理可以进行分区间讨论即可

### 极坐标与直角坐标

其实极坐标就是直角坐标 x, y 的参数方程，只不过 r 和 $\theta$ 在直角坐标中有实际意义

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250505083614.png)

任何一个直角坐标下的一个点 (x 0, y 0) ，比如上图中左上方的点，都可以用其与原点的距离 r 和这个距离的直线相对于 x 轴的夹角 $\theta$ 来表示即，即 A 可以表示为： $(r_{0}, \beta)$，并且有 $r_{0}\cos \beta = x_{0}, r_{0}\sin \beta = y_{0}$

所以极坐标和直角坐标的转换就是换元，写成参数方程的形式$$

$$ 与其他参数方程相比的特殊点在于，在直角坐标中 r 和 $\theta$ 具有实际意义，其表示点到原点的距离和与原点连线关于 x 轴的夹角

### 弧微分的推导和弧微分参与的积分的上下限问题

其实弧微分的本质是 $\sqrt{ (dx)^2 + (dy)^2 } = ds$，就是下面的图：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250505092133.png)

如果我们在根号中提取一个 dx 到根号外面，就可以得到：
$$
\sqrt{ 1 + ( \frac{dy}{dx} )^2 } dx = ds
$$

这样就得到 y = f (x) 的弧微分公式了：$\sqrt{ 1 + f'(x)^2 } dx = dx$

同理参数方程和极坐标方程都是看作换元利用 $\sqrt{ (dx)^2 + (dy)^2 } = ds$ 来推导的

另外在弧微分参与运算中如果涉及换元的问题，最好是先写出 y 和 x 的表达式，然后再按照换元的思想处理积分上下限，如果想直接套公式写出 $\int ds$，利用弧微分公式计算（有些情况只能套公式，不能先写出 y 和 x 然后换元），那么积分上下限一定是从小积到大

例如一个函数 $y = \sqrt{ 1 - x^2 }$ 中 $0 \le x \le$ 1 的弧长（这是一个 1/4 的圆）

正常情况下是 $\int_{0}^1 \sqrt{ 1 + y'(x)^2 }dx$，我们换元，令 $x = \cos t, y = \sin t$，积分上下限变成了 $\frac{\pi}{2} \le t \le 0$ 代入得到：

$$
\int_{\frac{\pi}{2}}^0 \sqrt{ 1 +  (\frac{\cos t}{\sin t})^2  } (-\sin t) dt
$$

将 $\sin t$ 放入根号中，它会自动调整成 $\int_0^{\frac{\pi}{2}} \sqrt{ \sin^2t + \cos^2 t }dt = \frac{\pi}{2}$

但是如果想要直接用 $ds  = \sqrt{ (y'(t)^2 +  x'(t)^2} dt$ 这个公式计算这一段的弧长，即 $\int ds = \int \sqrt{ (y'(t)^2 +  x'(t)^2} dt$

这个时候的积分上下限就不能根据换元的思想来确定了，因为这里不是换元的过程了而是直接套公式了，所以为了保证弧长最后的结果是正的，**这里的积分上下限必须是从小到大**

这两种做法的区别在于直接套公式是将 ds 看作了一个整体，即正的弧微分参与了运算，所以上下限必须要保证其是正的，因此一定是从小到大，而换元则是按照换元的原则进行处理，上下限也是按照换元的原则一一对应

另外弧长参与的面积运算也是这样的，如果按照换元，那么上下限的确定一定是按照换元的思想严格一一对应，但是如果直接套公式，那么上下限一般就是从小到大，如果最后分不清的话可以看结果是正还是负，反正面积一定是正的

### 变限积分在极限中的等价关系（积分的等价代换）


==被积函数的等价替换==
![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250506090901.png)

比如在 x -> 0 的时候 $\sin x \sim e^x - 1$，那么 x ->0 的时候就有 $\int_{0}^x \sin xdx \sim \int_{0}^x e^x - 1 dx$

这个结论有几点说明：

（1）**这里不要求 x -> 0 的时候 f (x) 和 g (x) 是无穷小**，只要满足两者的极限之比为 1 等价即可，比如 x->0 的时候 $\lim_{ x \to 0 } \frac{e^t}{\cos t} = 1$，那么 x->0 的时候同样有 $\int_{0}^x e^t dt \sim \int_{0}^x \cos t dt$
证明的方法是洛必达

（2）**这个等价可以广义化**为： $\int_{0}^{\phi(x)} f(t)dt \sim \int_{0}^{\phi(x)} g(t)dt$，要求是 $\phi(x)$ 在 x 的去心领域可导并且导数不为零（保证洛必达）

（3）**x 可以不一定趋于 0**，也可以趋于 a，我们可以研究在 x = 0 处的变限积分等价情况，也可以研究在 x = a 点的等价情况，于是上面的条件可以换成若 $\lim_{ x \to a } \frac{f(x)}{g(x)} = 1$，则当 x -> a 的时候有：$\int_{a}^x f(t) dt \sim \int_{a}^x g(t) dt$

（4）**进行积分等价替换的时候必须保证上下积分的被积函数中变量是同一个，具有相同的趋近性**

比如：$\frac{ \int_{0}^x f(t)dt}{\int_{0}^x g(t) dt}$，此时上下函数的 t 是同一个，当 t -> a 的时候 $f(t) \sim g(t)$，才能有 $\int_{a}^x f(t) dt \sim \int_{a}^x g(t) dt$

如果对分母进行了一次换元得到 $g(t) = h(u)$，此时哪怕 $h(a) \sim f(a)$，也不能进行积分代换，因为此时分母的 u 和分子的 t 无法同时取到 a，h(u) 中的 u 和 f(t) 中的 t 因为换元而产生关联，所以没有相同的趋近性，处理 $\lim_{ x \to a } \frac{h(x)}{f(x)}$ 是毫无意义的事情

这个结论的最好还是换成洛必达，洛一次同样可以得到结果，并且洛必达不会出错

### 反常积分处理方式

如果题目中是要求计算，则优先使用定义法，直接将被积函数积出来然后计算

如果题目中要求判断敛散性，则优先使用下面的审敛法，定性判断

#### **（1）基本思想**

首先反常积分其实有两种，积分到无穷的反常积分和函数无界的反常积分

**积分到无穷的的积分，即区间无限的反常积分：**
$$
\int_a^{\infty}f(x) dx
$$
这种积分的图像大致为：

<img src="https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/image-20241101164112566.png" alt="image-20241101164112566" style="zoom:67%;" />

显然，只有当 f (x) 是无穷小的时候这种积分才会收敛，并且 f (x) 的无穷小的阶数越高，其就越收敛

**函数无界的反常积分：**
$$
\int_a^bf(x)dx
$$
这种积分一般有端点导致 f (x) 无界，其图像大致为：

<img src="https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/image-20241101164350083.png" alt="image-20241101164350083" style="zoom:50%;" />

这种积分默认了 f (x) 在某个端点处就是无穷的，所以这一类积分想要收敛，那显然 f (x) 这个函数的无穷阶数越小越容易收敛

以上就是对两类积分的感性认识

#### **（2）记住两个特殊积分：**

对于区间无限的积分记住 p 积分：
$$
\int_a^{+\infty}\frac{1}{x^p}dx；(p \le 1发散；p >1收敛)
$$

> 显然 p 越大，趋于无穷的时候这个函数所形成的无穷小阶数越高，那显然就越容易收敛

对于函数无界积分记住 q 积分：
$$
\int_a^b\frac{1}{(x-a)^q}dx；(q \ge 1发散；q < 1收敛)
$$

> 显然 q 越大，趋于 a 的时候这个无穷大函数的阶数越高，那显然更容易发散

两个特殊积分取等号的时候都是发散的

#### **（3）解题的基本方法：**

**i 找出瑕点并划分区间**

这里的瑕点指的是可能导致积分发散得点，比如无穷点，以及上述 q 积分中得点 a 这个端点，比如  $\int _1^{+\infty} \frac{1}{x \ln x} dx$  中的  $1, +\infty$

这里的划分区间的意思是保证划分出来的区间中只有一个瑕点，这样通过分别判定两个不同区间的上的积分的敛散性来判断总体的敛散性，比如  $\int_0^2\frac{1}{\sqrt{x} (1 - \sqrt{x})} dx = \int_0^{\frac{1}{2}}\frac{1}{\sqrt{x} (1 - \sqrt{x})} dx + \int_{\frac{1}{2}}^2\frac{1}{\sqrt{x} (1 - \sqrt{x})} dx$ 

这样划分区间之后第一个区间只有 0 是瑕点，第二个区间中 1 是瑕点，这里的区间划分是随意的，并且只有所有区间的积分都收敛才能保证整体收敛

**ii 在每个瑕点对被积函数进行同阶替换，每个瑕点操作一次**

这里的同阶替换的意思是在 x 趋近于瑕点的时候被积函数整体的极限与同阶替换后的函数极限的比阶是一个常数，这样原函数与替换后的同阶函数在瑕点处具有相同的敛散性

比如 $1/sin x$ 与 $1/x，x = 0$ 显然是瑕点，这两个函数就可以同阶替换，这样  $\int_0^1 \frac{1}{\sin x}$  就与  $\int_0^1 \frac{1}{x}$  在 x = 0 处具有相同的敛散性

举一个例子： $\int_0^2\frac{1}{\sqrt{x} (1 - \sqrt{x})} dx$ 

有两个瑕点

x = 0 的时候进行同阶替换： $\frac{1}{\sqrt{x} (1 - \sqrt{x})} \sim \frac{1}{\sqrt{x}}$

x = 1 的时候进行同阶替换： $\frac{1}{\sqrt{x} (1 - \sqrt{x})} \sim \frac{1}{ (1 - \sqrt{x})} \sim \frac{1}{1 - \sqrt{x - 1  + 1}} \sim \frac{1}{x - 1}$  (注意这里是同阶替换，不是等价替换，可以直接省去系数）

然后直接分析同阶替换后的函数在瑕点处的积分敛散性即可

这里的同阶替换的意思是在瑕点处原被积函数和同阶函数在瑕点处具有相同的积分敛散性（比如上面例子  $\int_0^2\frac{1}{\sqrt{x} (1 - \sqrt{x})} dx$ ，原函数从一个正常点积分到 0 与  $\frac{1}{\sqrt{x}}$  积分到零具有相同的敛散性），所以我们在考虑敛散性的时候只用考虑同阶函数在瑕点的敛散性即可，当然多个瑕点积分区间还得划分一下，比如上面例子随便划分下区间：
$$
\int_0^2\frac{1}{\sqrt{x} (1 - \sqrt{x})} dx = \int_0^{\frac{1}{2}}\frac{1}{\sqrt{x} (1 - \sqrt{x})} dx + \int_{\frac{1}{2}}^2\frac{1}{\sqrt{x} (1 - \sqrt{x})} dx
$$
左边只用考虑在 0 处的敛散性，右边得考虑在 1 处的敛散性，分别做同阶替换，然后分别得到两个积分的敛散性，只要有一个发散，那两个的和就发散；当然 1 其实在区间里面，可以进一步划分左右趋近，不过可以简单一点
 
当然其实直接进行同阶替换然后考虑敛散性就行，区间划分其实无所谓

#### （4）注意事项

i 注意利用瑕点处的同阶替换的时候，如果这个瑕点是无穷，那一定是往 p 积分上凑，如果瑕点是一个数，那一定是往 q 积分上凑，然后根据 p 或者 q 的阶数来判断敛散性

ii 这里的同阶替换，只要保证趋于瑕点的时候是一个数即可，比如上面趋于瑕点 1 的替换： $\frac{1}{\sqrt{x} (1 - \sqrt{x})} \sim \frac{1}{ (1 - \sqrt{x})} \sim \frac{1}{1 - \sqrt{x - 1  + 1}} \sim \frac{1}{x - 1}$ 

其实做到  $\frac{1}{\sqrt{x} (1 - \sqrt{x})} \sim \frac{1}{ (1 - \sqrt{x})}$  这里的时候就可以将  \sqrt{x}  看作一个整体了，底下看作一个 q 积分了，因为我们通过趋于 1 的时候极限：
$$
\frac{1 - \sqrt{x}}{1 - x} = 常数
$$
趋于常数得到验证

#### **（5）对于积分式子中含有指数怎么处理**

如果积分式子中产生了指数，其实还是进行同阶替换

**根据反常积分的本质，对于趋于无穷的瑕点，当然是趋于零越快，越容易收敛**

**对于趋于趋于某个数的无界函数瑕点，当然是无穷大的阶数越小，越容易收敛**

所以指数反而变得更简单了，因为对于趋于无穷的瑕点，如果**因为指数导致了无穷大，那么指数的无穷大阶数一定大于任何幂函数**

**如果因为指数导致了 0，那么指数趋于零的速度也一定大于任何幂函数**

同理对于趋于某个具体的点处的瑕点也是这样

比如  $\frac{1}{e^x - 1}$ ，x 趋于无穷的时候其同阶就是  $\frac{1}{e^x}$ ，这个式子导致的无穷小的速度远远超过分子是幂函数时的无穷小，因此一定是收敛的

#### （6）对于积分式子中含有对数怎么处理

**无穷区间上的反常积分，其趋于零越快，越容易收敛**
**无界函数的反常积分，无穷阶数越小，越容易收敛**
**因此无论是无穷区间上的反常积分，还是无界函数的反常积分，一律是越小越容易收敛**

当 x 趋于 1 的时候 ln x 是一个无穷小处理很简单，直接同阶替换成幂函数即可，比较麻烦的是 ln x 趋于无穷大的情况，**需要注意的是 ln x 趋于无穷大的情况，无论是 x 趋于无穷的时候的无穷大，还是 x 趋于零的无穷大，其趋于无穷大的速度一定小于幂函数**

常见的有下面的几个处理方式：

（1）对于趋于 1 的反常积分，令 lnx 直接无穷小代换成 (x - 1)
（2）对于趋于无穷的反常积分，令 lnx = t 换元

上面两个处理之和再和一般的幂函数一样的过程判断敛散性


如果上面几个处理不行，那再进行下面的结论

**然后记住下面几个结论（一般同阶替换就往下面几种式子上取替换）：**

**i  $\int_2^{+\infty} \frac{1}{\ln^a x} dx$  一定是发散的**

 这是因为区间无穷的反常积分，其趋于无穷的时候越小越容易收敛，对于  $\frac{1}{\ln^a x}$  这个式子，其趋于 0 的速度一定比  $\frac{1}{x}$ 慢，因为 x 这个幂函数趋于无穷的速度一定比对数快，所以  $\frac{1}{\ln^a x}$  一定比  $\frac{1}{x}$  大，而  $\frac{1}{x}$  是发散的，所以这个式子也一定是发散的

**ii  $\int_0^2 \ln^a x dx$  一定是收敛的**

这是因为 ln x 趋于无穷大的速度一定小于幂函数，因此对于一个收敛的幂函数  $\frac{1}{x^{1/2}}$ ，在趋于零的时候 ln x 的无穷阶数一定比它小，因此一定收敛

**iii $\ln^a x$  在分子上的情况，即  $\int_2^{+\infty} \frac{\ln^a x}{x^p}；\int_0^1\frac{\ln^a x}{x^q}$ ** 

其敛散性跟去掉 $\ln^a x$  的敛散性是一样的，注意只有瑕点 0 和无穷的时候分子才能直接忽略 $\ln^a x$，如果瑕点是 1，分子则需要进行无穷小替换

**iv  $\ln^a x$  在分母上的情况，比如  $\int_2^{+\infty} \frac{1}{x^p \ln^a x} dx$ 以及  $\int_0^{1/2} \frac{1}{x^p \ln^a x} dx$ 

这个时候还是以幂函数为主，我们先看幂函数的次数

如果幂函数的次数不是 1，此时对数完全可以忽略，比如  $\int_2^{+\infty} \frac{1}{x^2 \ln^a x}$  这个式子的敛散性是和  $\frac{1}{x^2}$ 的敛散性是一样的，无穷的瑕点处是收敛的

当幂函数的次数是 1 的时候才开始看对数，此时 a  > 1 的时候才收敛，a <= 1 的时候发散，此时不管瑕点是 0 还是无穷这个结论都成立，注意与 p，q 积分取等的时候不一样，但是不管是什么积分，**幂等于 1 的时候始终发散**

处理反常积分就需要记住下面几个

（1）记住反常积分收敛的本质，其实就是越小越容易收敛

（2）找瑕点

（3）同阶替换，指数的速度不管是趋于零还是无穷速度都超过幂函数，对数就想办法替换成上面 4 中情况，注意对数

（4）其实本质还是最开始的思想，无穷区间的反常积分，无穷小的阶数越高越容易收敛，无界函数的反常积分，无穷小的阶数越低越容易收敛，反正就是越小越容易收敛

## 多元函数微分学

### 二次极限与二重极限

二次极限是 $\lim_{ x \to x_{0} }\lim_{ y \to y_{0} }f(x, y)$

二重极限是 $\lim_{ x \to x_{0} , y\to y_{0} } f(x, y)$

二重极限是点 (x, y) 沿着任意的路径趋近于（x 0, y 0）

二次极限是先固定 x，让 y 趋近于 y 0，然后固定 y，让 x 趋近 x 0，其趋近路线是固定的，其本质是取了两次一元函数的极限

两者的趋近路线图如下所示，左侧是二重极限，右侧是二次极限
![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250507110231.png)

举一个例子，比如下面的函数

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250507110410.png)


这个函数的二重极限是不存在的，但是二次极限，先 x -> 0，然后 y -> 0

对于先固定 y，x 趋近于 0，假如 y != 0，那么第一次极限结果就是 0；假如 y = 0，那么这个式子就是 0；所以第一次极限结果就是 0，然后第二次极限趋近当然也是 0；所以二次极限就是 0

### 二重极限的处理方法

二重极限的计算一般就采用
（1）等价代换
（2）四则运算
（3）夹逼准则

==一元函数微分学的可微定义==

对于函数 `f(x)`，在 x 0 处（即固定 x 0）的函数增量有：$f(x0 + \Delta x) - f(x0) = \Delta y$

### 二阶混合偏导和一阶偏导先带后求的易错点

一阶偏导先带后求不用多说，即 $\frac{\partial u(x, y)}{\partial y}|_{(x_{0}, y_{0})}$ 一定是先代入 x 0 到 u (x, y) 中然后对 y 求偏导

二阶混合偏导先带后求，比如求 $\frac{\partial^2 u}{\partial x \partial y}|(x_{0}, y_{0})$

我们一定是先求出 $\frac{\partial u}{\partial x}$，这是一个关于 x, y 的函数，然后再使用先带后求，一定是在一阶导中代入值然后求偏导；因为求 $\frac{\partial^2 u}{\partial x \partial y}|(x_{0}, y_{0})$ 的含义就是 $\left( \frac{\partial\left( \frac{\partial u}{\partial x}(x, y) \right)}{\partial y} \right)|_{(x_{0}, y_{0})}$，所以此时先带后求就是先将 x 0 代入 $\frac{\partial u}{\partial x}(x, y)$ 这个关于 x, y 的函数中，然后再对 y 求偏导

而不能一开始对 x 求偏导的时候就代入 y 0，这样做是错的，前面代入 y 0 后面就没办法求二阶偏导了，而且也不符合题目的含义，题目的含义就是让你先求出 $\frac{\partial u}{\partial x}(x, y)$，求这个表达式只能硬求，不能代值

### 全微分的形式不变性的理解

假如有 $z = f(u, v), u = \phi(x, y), v = \Phi(x, y)$，显然，这里 z 是关于 x，y 的函数，那么对于 z 就有全微分：

$$
dz = \frac{\partial z}{\partial x} dx + \frac{\partial z}{\partial y} dy
$$

但是 dz 也可以写成：

$$
dz = \frac{\partial z}{\partial u} du + \frac{\partial z}{\partial v} dv
$$

这里的形式不变性是针对中间变量的，意思是虽然 u，v 是中间变量，但是 dz 仍然可以写成关于这两个中间变量的全微分，并且这个全微分与 dz 关于实际变量 x, y 的全微分具有相同的形式，称为全微分的形式不变性

这个用处在于，如果 z = f (u, v) 的 u，v 后面有更复杂的复合形式，但是我们可以不用管，直接写出 z 关于 u, v 的全微分，然后再处理 du 和 dv

隐函数的公式是：

其推导过程为：

公式法中的 $F'_{x}$ 不是对第一个位置的偏导，也不是将 z 看作 x, y 的函数的时候真正对 x 的偏导，**而是将 x, y , z 看作同等地位的变量对 x 的偏导**



比如 $F (xyz , x^2 + y^2 + z^2, z) = xyz + x^2 + y^2 + z^2 + z = 0$

此时虽然将 z 看作 x 和 y 的函数，但是这里的 $F'_{x}$ 只代表锁链中最左侧对 x 求到底的偏导，将
x, y , z 看作同等地位的变量，即
$$
F'_{x} = yz + 2x
$$
同理 $F'_{z}$ 也是将 x, y , z 看作同等地位对 z 的偏导，即

$$
F'_{z} = xy + 2z  + 1
$$
根据公式得到：

$$
\frac{\partial z}{\partial x} = -\frac{yz + 2x}{xy + 2z + 1}
$$
我们可以将 z 看作 x, y 的函数，然后用等式两边对 x 的真实求导到底来验证一下：

$$
yz + xyz'_{x} + 2x + 2zz'_{x} + z'_{x} = 0
$$

得到

$$
\frac{\partial z}{\partial x} = -\frac{yz + 2x}{xy + 2z + 1}
$$
所以隐函数的存在定理公式中的 $F'_{x}$ 与 F (x, y, z) = 0 等式两边对 x 求偏导要区分开来，$F'_{x}$ 是将 x, y, z 看作同等地位的变量对 x 的偏导，而等式两边对 x 求偏导则是将 z 看作 x, y 的函数根据链式复合法则对x 的真实偏导

这是因为 $F'_{x}$ 仅仅表示三元函数 $F(x, y, z)$ 对 x 的偏导，此时这个函数还没有等于零，三个变量还是独立的

而写成等式之后 F (x, y, z) = 0，此时有了等式关系，z 就是关于 x, y 的函数，等式两边对 x 求偏导当然要按照复合函数求偏导的链式法则将 z 看作 z(x, y)来处理

这样写当然对，如果有 $F(\phi(x, y), \psi(x, y), z) = 0$，其中 $\phi(x, y) = x^2 + y^2, \psi(x, y) = x + y$ 那么全微分当然可以写成

$$

（1）隐函数公式中的 $F'_{x}$ 是将 x, y, z 看作同等变量对 x 求偏导的结果

所以二重积分的累次计算，固定谁，谁就放在左边，比如固定 x，x 就放在左边，然后将 x 当作常数放在右边的积分上下限，计算另一个变量 y 的积分

先对 y 积分，那么就是固定 x，y 的上下限就是一条平行 y 轴的直线与区域的最下端和最上端的交点；其上下限含 x，x 看作一个常数

### 极坐标下二重积分的理解

用换元的思想理解

二重积分变成极坐标下的积分本质其实就是换元，令 $x = r\cos \theta$，$y = r \sin \theta$ 则有：

$dxdy = rdr d\theta$，$f(x, y) = f(r\cos \theta, r\sin \theta)$

即 $\int \int_{D} f(x, y)d xdy = \int \int_{D'}f(r\cos \theta, r\sin \theta)r dr d\theta$

这里在 D'上的积分其实还是一个直角坐标的积分，只不过未知变量是 r 和 $\theta$，至于这个范围 D'如何确定，因为极坐标换元的特殊性，可以根据原来 D 上的范围，按照极坐标在 D 上的对应规律（r 表示距离原点的范围，theta 表示与原点连线距离 x 轴正方向的偏角）来确定 r 和 theta，以及 D'

只不过大多数情况下不需要画出来 D'，只用在 D 上确定 r 和 $\theta$ 的范围直接对 $\int \int_{D'}f(r\cos \theta, r\sin \theta)r dr d\theta$ 进行累次积分了

由于 D 的图形旋转的角度很容易确定，所以很容易得到固定 $\theta$，用 $\theta$ 来表示 r 的累次积分，即可以直接根据 D 的形状确定 $\int \int_{D'}f(r\cos \theta, r\sin \theta)r dr d\theta$ ，这个积分，关于先对 r 积分，然后对 $\theta$ 积分的累次积分表达式



### 二重积分奇偶对称性的理解

这里是用积分的定义来理解的，这里以区域 D 关于 x 轴对称为例进行分析

假如区域 D 关于 x 轴对称，那么一定有关于 x 轴对称的两点 (x, y), (x -y)

这两点处的高是 f （x, y）, f (x, -y)

所以这两个点处的体积微元就是：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250515080120.png)

如果 f (x, y) = f (x, -y)，即 f (x, y) 关于 y 是偶函数，那么就说明 $f(x, y) d \sigma = f(x, -y)d\sigma$，也就是说，上面 D 1 每一个点处的小体积都有 D 2 中对称的点的小体积与其相等

那么你将 D 1 中的所有小体积全部加起来，也就是 $\int \int_{D_{1}}f(x, y)d\sigma$，与下面的所有小体积加起来的结果相等

即 $\int \int_{D_{1}}f(x, y)d\sigma = \int \int_{D_{2}}f(x, y)d\sigma$

所以就是 $\int \int_{D}f(x, y)d\sigma = 2\int \int_{D_{1}}f(x, y)d\sigma$

同理如果 f (x, y) 是关于 y 的奇函数也是这样理解的，那两个小体积是互为相反数，加起来当然就抵消了

### 二重积分轮换对称性的理解

这里用换元的思想来理解

假设 D 1 和 D 2 关于 y = x 对称：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250515104225.png)

对于 $\int \int_{D_{1}}f(x, y)dxdy$，令 x  = u, y = v，并且有 u = y, v = x，那么换元之后有：

$$
\int \int_{D_{1}}f(x, y)dxdy = \int \int_{D'}f(u, v)dudv
$$
上式中的 D'是在 u-v 坐标系下的图形：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250515104244.png)


由于 u = y, v = x，所以再将 D'中的图形映射到 x-y 坐标中的图形时可以得到，也就是 D 2：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250515104416.png)

所以有：

$$
\int \int_{D_{1}}f(x, y)dxdy = \int \int_{D'}f(u, v)dudv = \int \int_{D_{2}}f(y, x)dxdy
$$
上式中 u, v，D' 是 u - v 坐标系中的图像，D 1，D 2 则是 x-y 坐标系中的图像，并且 D 1 D 2 刚好关于 y = x 对称，于是当 D 1 D 2 关于 y = x 对称的时候就有：

$$
\int \int_{D_{1}}f(x, y)dxdy  = \int \int_{D_{2}}f(y, x)dxdy
$$

上式中等式左右的 x, y 都是同一个坐标下的 x, y ，因此可以互相加减合并

根据这个结论，如果区域 D 关于 y = x 对称，那么我们可以将其拆成 D 1, D 2，D 1 和 D 2 关于 y = x 对称，所以可以得到：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250515093313.png)

同时，如果 f (x, y) = f (y, x) 的话，那么就有：

$$
\int \int_{D}f(x, y) dxdy = \int \int_{D_{1}}f(x, y)dxdy + \int \int_{D_{2}}f(x, y)dxdy 
$$

也就是：

$$
\int \int_{D}f(x, y) dxdy = \int \int_{D_{1}}f(x, y)dxdy + \int \int_{D_{2}}f(y,x)dxdy = 2\int \int_{D_{1}}f(x, y)dxdy
$$

$$

两个收敛，那就是两个极限都存在，所以极限之和存在

### 不改变级数顺序任意加括号后的敛散性

假设：

$$
\lim_{ n \to \infty } S_{n} = \sum_{n = 1}^\infty u_{n} = u_{1} + u_{2} +\dots\dots + u_{n} +\dots
$$
也就是：
$$
S_{n} = u_{1} + u_{2} + \dots + u_{n}
$$
如果我们将相邻的两项加上括号，可以得到：

$$
G_{n} = (u_{1} + u_{2}) + (u_{3} + u_{4}) +\dots + (u_{n - 1} + u_{n})
$$

所以，G 1 = S 2, G 2 = S 4，G 3 = S 6

也就是说数列{Gn}是数列{Sn}的偶子列

所以当数列极限 $\lim_{ n \to \infty } S_{n}$ 存在的时候，也就是原级数收敛，这个偶子列的极限 $\lim_{ n \to \infty }G_{n}$ 也一定存在，即加上了括号之后的级数也一定收敛

所以加上了括号之后其实原来的级数变得更加收敛了，反过来，如果这个偶子列不收敛，极限不存在，加了括号之后级数不收敛，那么原来的数列 Sn 其极限也必然不存在，原级数也必然不收敛

### 条件收敛的级数正项和负项性质

条件收敛的级数其正项构成的级数和负项构成的级数都是发散的

条件收敛的级数的正项的通项是 $\frac{u_{n} + |u_{n|}}{2}$

条件收敛的级数的负项的通项是 $\frac{u_{n} - |u_{n}|}{2}$

正项的级数是 $\Sigma \frac{u_{n} + |u_{n|}}{2}$

负项的级数是 $\Sigma \frac{u_{n} - |u_{n}|}{2}$

这两个级数均是一个收敛的级数和一个发散的级数之和，所以结果就是发散的

按照这个思路，绝对收敛的级数的正项和负项就是收敛的

**级数拆成两个级数之和是求和符合加法的基本运算性质，是一定成立的，与级数是否敛散无关，注意其跟极限的式子拆开还是不一样的，极限只有两个式子的极限均存在才能进行加减，所以将一个式子拆成两个式子的极限必须保证两个式子的极限均存在这样拆才成立**如果极限拆成一个极限存在为 0，一个极限不存在，那这样拆就不正确，不能通过拆了之后的两个式子的极限来计算原式子极限

（1）原本发散的级数加上绝对值之后也是发散的
（2）加上绝对值收敛的级数原级数也一定是收敛的

### 和函数的理解

对于一个常数项级数，其是有可能收敛为一个具体的数值的

而对于一个函数项幂级数：

$$
\sum_{ n = 1}^\infty a_{n}x^n = a_{1}x^1 + a_{2}x^2\dots\dots
$$
它也有可能收敛为一个不带 n 的具体的函数 S (x)，即：

$$
S(x) = \sum_{ n = 1}^\infty a_{n}x^n = a_{1}x^1 + a_{2}x^2\dots\dots
$$
这个具体的 S (x) 就称为和函数

**这个和函数的定义域就是这个幂级数的收敛域**，这是因为和函数是建立在收敛上的概念，x 取一个具体的值 x 0，然后原级数对应收敛到一个值 y 0，x 取另外一个值 x 1, 然后原级数对应收敛到另一个值 y 1，这样的一一对应映射关系构成了一个函数映射，所以才有和函数的概念

假如 x 取收敛域外面的值，假如原级数还能写成一个具体的 S(x) 和函数，那原级数无法映射到一个具体的数，但是和函数又是一个具体的数，所以就不能划等号，所以和函数 S (x) 就不能取收敛域外面的数

### 求解和函数的过程中收敛域的理解

如果我们想要求一个级数的和函数 $S (x) = \sum$

此时我们先求出了这个级数的收敛域，即和函数的定义域是 I

假如我们对这个级数的和式变形得到 $S (x) = \sum = \sum_{1}+  \sum_{2} = G(x) + H(x)$

那么我们可以通过求 G (x) 和 H (x) 从而分别求得 $\sum_{1},\sum_{2}$ 这两个级数的和函数，从而求得 S (x)，这里需要注意两个跟定义域有关的问题

**（1）求 H (x) 和 G (x) 的时候，一定是在 I 的范围下处理 $\sum_{1},\sum_{2}$ 这两个级数的**

这是很显然的，因为我们需要通过将 H (x) 和G（x）的解析式回代入原来的式子求出 S (x)，那就应该在满足 S (x) 的定义域下求出这两个解析式，这样才能直接回代入 $S (x) = \sum = \sum_{1}+  \sum_{2} = G(x) + H(x)$ 求出 S (x)

因此就不需要重新对 $\sum_{1},\sum_{2}$ 求收敛域了，可以直接用 I 的范围对这两个级数进行处理，从而快速得到 G (x) 和 H (x)，比如如果 I 的范围是 (-1, 1)，而 $\sum_{1},\sum_{2}$ 又是等比级数，那么就可以根据(-1, 1) 下等比级数的结论直接写出 G (x) 和 H (x)，而不用考虑 $\sum_{1},\sum_{2}$ 本身的收敛域

**（2）$\sum_{1},\sum_{2}$ 这两个级数的收敛域可能不会包含 I 的全部范围**

比如，如果 $\sum_{1},\sum_{2}$ 中有 1/x 这样的项，那么就得去掉 x = 0 来求 H (x) 和 G (x)

不过这样没关系，我们还是在 I 的范围背景下求 G (x) 和 H (x)，我们在 I 中合法的范围 I 1, I 2 下求得 G (x) 和 H (x)，剩下的范围再对 $\sum$ 这个原级数进行讨论即可

比如 I 的范围是 (-1, 1)，但是 $\sum_{1},\sum_{2}$ 中有 1/x 这样的项，那就得在 $(-1, 0)\cup (0, 1)$ 这样的范围求出 G (x) 和 H (x)，代入式子表达出 S (x) 之后，这个表达式在 $(-1, 0)\cup (0, 1)$ 成立

我们单端讨论点 x = 0 原级数 $\sum$ 的收敛情况，即求出 S (0)

然后根据定义域 I 将不同范围的式子合并成一个分段函数就行了

### 利用常见函数展开来处理幂函数展开的方法和理解

一个常见函数的幂级数展开式是：

$$
\frac{1}{1 - x} = \sum_{n = 0}^\infty x^n = 1 + x + x^2 + \dots\dots
$$
这是函数 $f(x) = \frac{1}{1 - x}$ 在 x = 0 处的幂级数展开

如果我们要求的是 g (x) 在 x = x 0 处的幂级数展开，那么幂级数就必须写成 (x - x 0) 的形式

一种常见的做法是在 g (x) 中凑出 x - x 0，将 x - x 0 看作一个整体，g (x) 在 x = x 0 的展开就等价于 g(x) 以这个整体 x - x 0 = t 在 t = 0 处的展开

然后套用常见的函数麦克劳林级数公式，将 x 换成 x - x 0 即可

比如求 1/x 在 x = 1 处的展开，我们凑成 1/1- x 的形式:

$$
\frac{1}{1 - (1 -x)} = \frac{1}{x}
$$
然后将 1/1- x 的展开式中的 x 替换成 (1 - x)：

$$
\frac{1}{ x } = 1 + (1 - x) + (1 - x)^2 + \dots\dots
$$

这里还需要注意收敛域的问题，$\frac{1}{1 - x}$ 的收敛域是-1 < x < 1，这里用 (1 - x) 替换了 x，那么就必须保证-1 < (1 - x) < 1，得到 1/x 展开的收敛域


这里这种做法的原理是：

（1）f (x) 在 x 0 处的展开，就等价于将 f (x) 凑成 g (x - x 0)，然后 g (x - x 0) 在 x - x 0 = 0 处的展开，几乎只能这样凑，因为幂级数展开必须写成 x  - x 0 的形式

（2）基本函数的麦克劳林展开中 x 代表的是变量，而不是死板的 x，所以可以直接用别的变量进行替换，基本麦克劳林展开中的各个函数都是在 x = 0 处的展开，那么对于 g (x - x 0)，如果能将 g (x - x 0) 凑成基本函数的形式，用 x - x 0 替换公式中的 x，它也是在 x - x 0 =0 处的展开，这样就可以得到结果了




### 幂级数的收敛半径收敛区间的理解 + 求导或者积分之后的收敛域的变化


对于任意一个普通的幂级数 $\sum a_{n}(x -x_{0})^n$，令 x - x 0 = t，其可以写成 $\sum a_{n}t^n$ 的形式，那么对于当|t| < R 使得 $\sum a_{n}t^n$ 收敛，那此时的 R 就是收敛半径，将 t 带回去解|x - x 0| < R 得到的 x 范围就是收敛区间，再判断一下端点是否收敛，就可以得到完整的收敛域

幂级数求导或者积分之后的收敛半径不会发生改变，而对任意一个幂级数，其求导或者积分之后的形式不变，还是（x - x 0）这样的形式，**既然收敛半径不变，那么求导或者积分之后目标级数中令 x - x 0 = t 改写之后还是|t| < R，所以解出来的 x收敛区间也没有发生改变**

所以原幂级数求导之后收敛域缩小，只可能在端点缩小
原幂级数积分之后收敛域扩大，只可能在端点扩大

### 先二后一确定二重积分区域的方法

先二后一，就是先固定 z，将 z 看作一个常数，用一个垂直 z 轴的平面去截积分区域，得到的平面就是先二重积分的积分区域

这里由于先二重积分是将 z 看作常数，如果题目中给的区域是 $x^2 + y^2 + z^2 \leq 1$ 之类的，或者 $x + y + z = 1$ 与坐标轴围成的区域

可以直接将 z 移动到等式或者不等式右边，从而直接得到用 z 去截积分区域的 Dz 的范围

比如 $x^2 + y^2 + z^2 \leq 1$ 用 z 截的区域一定是 $x^2 + y^2 \leq 1-z^2$

$x + y + z = 1$ 与坐标轴围成的区域用 z 去截一定是 $x + y = 1 - z$，当然这里必须指定 x >=0, y >= 0

先二后一法适用于被积函数只有一个变量的情况，这样先二重积分的时候被积函数就是一个常数，根据上述区域式子，只用算面积就行了

### 第一类曲线积分的上下限问题

第一类曲线积分是无方向的积分，跟上文中的弧微分的思想类似，为了保证弧微分是正的，其积分上下限一定是从小积分到大

### 线面积分的被积函数与积分曲线方程的关系

线面积分都是在线或者面上的积分，而二重积分或者三重积分是在区域内部的积分，所以对于线面积分来讲被积函数是一定满足线或者面的方程的，这是因为在线或者面的某一点处 (x 0, y 0)，线或者面的被积函数跟线本身和面本身使用的是同一个点的坐标，这个点的坐标一定同时满足被积函数以及线或者面本身的方程，所以可以利用线或者面本身的方程来化简被积函数

但是二重积分和三重积分的被积函数只是在区域内部，其不是都满足区域的边界，所以不能根据区域边界方程进行化简

另外，线面积分的一般计算方式，即直接根据曲线的参数方程代入被积函数进行求解的原理也是这样，因为在某一点 (x, y) 处，曲线（面）满足参数方程 (x (t), y (t))，而曲线上的被积函数在同一点取值就是 f(x (t), y (t))，这一点的弧微分就是 $\sqrt{ x'(t)^2 + y'(t)^2 }dt$ ，所以这一点满足 $f(x, y) ds = f(x(t), y(t)) \sqrt{ x' (t)^2 + y' (t)^2}$ ，所以就可以直接将曲线（曲面）的参数方程代入到积分中，化为参数方程的变量积分进行计算了

### 第一类曲线积分的对称性

第一类曲线积分的对称性是和二重积分以及三重积分的对称性是一样的

对于一个平面上的曲线积分 $\int_{L} f(x, y) ds$，如果 L 关于 y 轴对称，f(x, y) 关于 x 是奇函数，那么在对称的两点处，ds 的取值一样（全都一样），但是 f (x, y) 是相反数，那这两点的 f (x, y) ds 相加就是零，根据积分定义，合起来就是零；理解方式与二重积分对称性完全一样

空间曲线的对称性也是这样分析，L 关于 xoy 平面对称那就分析 f (x, y, z) 关于 z 的对称性

所以第一类曲线积分的对称性是和二重积分以及三重积分是完全一样的

判断对称性也是跟二重积分和三重积分一样，判断是否关于 xoy 平面对称，就是将曲线方程 z 换成-z 观察定义域和方程是否发生变化

判断轮换对称性就是将 x 和 y 互换，看是否方程和定义域不会发生变化

曲面的侧始终看的是法向量的指向

对于封闭曲面，法向量指向外侧，那这个曲面就是外侧，法向量指向内测，曲面就是内侧

对于开放曲面，则分前后侧，左右侧，上下侧，这些都是按照法向量的指向来区分的：
![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250527150102.png)

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250527145435.png)

这个曲面的单位法向量就是 $(\cos \alpha, \cos \beta, \cos \gamma)$

通过单位法向量的三个方向余弦的正负来区分法向量指向的方向来确定曲面的哪一侧

### 矩阵 A 的所有 s 阶子式等于零，则所有大于 s 阶的子式也必然都等于零

s 阶子式等于零，说明矩阵 A 中任意取 s 行 s 列构成的行列式等于零

对于 s + 1 阶的子式，这个子式的计算方法就是按某一行或者某一列展开，展开的时候是每个元素乘相应的代数余子式，由于矩阵 A 的任意 s 阶的子式都是零，而这些代数余子式又都是矩阵 A 中抽出来的 s 阶的子式，所以这些代数余子式都为零

所以任意 s + 1 阶子式都为零，以此类推，只要大于 s 阶的子式都等于零

所以如果矩阵 A 的秩 >= r，即存在一个大于等于 r 阶的子式不等于零，那就一定说明存在一个 r 阶的子式不等于零

反过来，如果存在一个 r 阶的子式不等于零，那就说明矩阵 A 的秩一定大于等于 r

即：

$$
r(A) \geq r  \Leftrightarrow 存在一个r阶子式不等于零
$$

### 伴随矩阵 $A^*$ 的秩与 A 的秩的关系

（1）如果 r (A) = n，则 $r(A^*) = n$

这是因为 $AA^* = |A|E$，既然 A 满秩，所以 A 的行列式不等于零，所以 A 伴随的行列式不等于零，所以 A 伴随满秩

（2）如果 r (A) = n - 1，则 $r(A^*) = 1$

既然 r (A) = n - 1，所以 A 存在一个 n - 1 阶的子式不等于零，而 A 伴随的每个元素都是由 A 的 n - 1 阶子式增加正负号构成，所以 A 伴随至少有一个元素不等于零，所以 $r(A^*) \geq 1$

而根据 $AA^* = |A|E = 0$，可以得到 $r(A) + r(A^*) \leq n$，所以 $r(A^*) \leq 1$

所以 $r(A^*) = 1$

（3）如果 r (A) < n - 1，则 $r(A^*) = 0$

由于 A 的 n - 1 阶子式全部为零，所以 A 伴随的每一个元素都为 0，所以 A 伴随就是一个零矩阵，所以成立

**上述三个结论都可以互相推导**
