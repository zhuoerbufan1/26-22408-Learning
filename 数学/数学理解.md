### 互逆计算法则

$\arctan x = a$  这个东西如果不知道 x 或者 a，可以直接两边取 tan，得到  $x = \tan a$ 

tan 和 arctan 是互为逆运算

同样 ln 和 e 也是互逆运算

这里的互逆运算的应用就是通过等式左右同时一次运算可以消掉另外一个运算符号，比如上面的 x = tan a，左右同时进行 arctan 得到：
$$
\arctan x = a
$$
那右边就消掉了 tan

比如 lnx  = t，左右同时进行 e 运算：
$$
x = e^t
$$
那左边就消掉了 ln


### 对函数解析式 f (x) 的理解

这个写法其实包含两个部分，f 表示解析式的形式，x 表示变量

对于 f (x) 和 f (y) 来说，解析式是完全一样的，只是变量不一样，那么当 x = y = a 的时候

$f (x) * f (y) = f (a)^2$

比如 f (x) = 2 x + 1， f (y) = 2 y + 1，那么当 x = y  = a 的时候

$f (x) * f (y) = (2 a + 1)(2 a + 1) = f (a)^2$

（1）洛必达必须是 0 比 0 或者无穷比无穷类型的式子才能继续，但是其实只要分母是无穷就直接可以洛

（2）洛必达必须要求分子分母在点 a 处的去心邻域可导，并且分母的导函数不等于 0

（3）只要你能洛出来，那么极限就等于这个值，但是如果你洛不出来，那么极限不一定不存在，只能说洛必达失效

### 泰勒公式确定阶数方法以及正确性

**（1）对于 A - B 类型，需要展开到 A 和 B 的系数不相等的最低次幂**

这是因为泰勒展开是恒等变换，也就是说：$A - B = ax^k + o(x^k)$ 这是一个恒等式

那么当 x -> 0 的时候 $\lim_{ x \to 0 } \frac{A-B}{ax^k} = \frac{ax^k + o(k^k)}{ax^k} = 1$，即 $A - B \sim ax^k$ ，所以在 x -> 0 的时候就可以直接用 $ax^k$ 来替代 A - B

分子或者分母没有被消掉的幂最低的项其实就是应该展开的阶数

**（2）对于 A/B 的类型，你先确定分子 A 或者分母 B 的阶数，展成 f (x) + o (x^k) 形式，直接去掉 o (x^k)，然后另一个分母 B 或者分子 A 的整体阶数只要展开大于等于 f (x) 的阶数 k 就行了一般的操作是将分子或者分母参与有效计算的项的阶数展开到大于 f (x) 的阶数就可以了**

也就是将分子或者分母展开成 x^k + o (x^k) 的形式，让多项式的最高次幂大于等于确定好了的阶数

对于分子或者分母，这里有一条规则就是，只要分子或者分母可以写成一个多项式+无穷小的形式，即 $f(x) + o(x^k)$，这里的无穷小是 f (x) 的高阶无穷小，比如 x^3 + o (x^3) 这种，那么这里的无穷小就可以直接去掉

这是因为泰勒展开在趋于 0 的时候是恒等变换，并且我们是在极限意义下使用的泰勒展开，下面是 A/B 与 f(x)/B 的等价性：

$$
\lim_{ x \to 0 } \frac{\left( \frac{A}{B} \right)}{\frac{f(x)}{B}} = \lim_{ x \to 0 } \frac{A}{f(x)} = \lim_{ x \to 0 } \frac{f(x) + o(x^k)}{f(x)} = 1 + \lim_{ x \to 0 } \frac{o(x^k)}{f(x)} = 1 + 0 = 1
$$

所以，对于 A/B 类型的式子，只要你能很快确认一个分子或者分母可以写成 f (x) + o (x^k)，那么就可以用 f (x) 直接代替这个分子或者分母；然后剩下的分母或者分子进行泰勒展开，参与计算的有效式子，展开的无穷小阶数大于等于 f (x) 就行了，一般只要能展开到同阶就能做出来了，反正你只要记住分母或者分子本身展开的多项式加上 o (x^k)，这里的 o (x^k) 就是可以直接吞掉，这个是泰勒展开的正确性基础

并且注意，这里只有整体展开的 f (x) + o (x^k)，这里 o (x^k) 可以直接吞掉，分子或者分母的某一项展开得到了 o (x^k) 不能直接吞

### 海涅定理及其两点使用

（1）对于 f (xn) 和 f (x)，如果 f (x) 在 x -> x 0 的时候极限存在，即  $\lim_{ x \to x_{0} } f (x) = a$ ，那么当 xn 收敛于 x 0 的时候，可以将 f (xn) 转化为求解 f (x)，即  $\lim_{ n \to \infty } f (x_{n}) = \lim_{ x \to x_{0} } f (x) = a$ 

海涅定理的意义在于，对于 f (x) -> A，(x->x 0)，那么对于任意一个 $x_{n} \to x_{0} (n\to \infty)$ 的数列，它的值代入 f (x) 之后 n 趋近于无穷，那么结果还是 A

跟前面的复合函数求极限思想类似，只要能满足 f (x) -> A，(x->x 0)，且一个 $x_{n} \to x_{0} (n\to \infty)$ 的数列，那么就有：$\lim_{ n \to \infty } f (x_{n}) = \lim_{ x \to x_{0} } f (x) = a$



其用处在于可以==将一个复杂的数列极限表达式转化为函数极限的表达式==，用求函数极限的方法来求解，比如：

![image.png|411x204](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250414115619.png)

这个数列极限中，{xn} -> 无穷 (x 0)，并且一般题目中给定的数列就是 xn->x 0 (n->无穷) 的，所以只要 f (x) = $x^2[\arctan (x + 1) - \arctan x]$ 这个趋于无穷 (x 0) 的极限存在，那么就满足了上述两个条件，就可以得到 $\lim_{ x \to \infty }x^2[\arctan(x + 1) - \arctan x] = \lim_{ n \to \infty } n^2[\arctan(n + 1) - \arctan n]$

所以只要验证这个 f (x) 的极限就好了，只要能求出来 f (x) 的极限，那么函数和数列的极限就相等，所以这个就是直接将数列转化为函数极限的正确性说明


（2）xn 其实可以看作是 f (x) 的变量 x 的一个子列，根据数列收敛的性质，只有所有收敛于 x 0 的子列 xn 都有 f (xn) 极限为 a 的时候，才有 f (x) 的极限为 a

这个命题的用处在于其逆否命题，==用于说明函数极限不存在==，我们判断  $\lim_{ x \to x_{0} }f (x)$  ，的时候，只要找到趋于 x 0 的两个子列，这个两个子列代入 f () 之后的极限不相等，那么函数的极限就不存在

比如对于函数极限 $\lim_{ x \to 0 }\sin\frac{1}{x}$

取  $xn = \frac{1}{n\pi} ， bn = \frac{1}{n\pi + \frac{\pi}{2}}$ ，代入可以发现 f (xn) 与 f (bn) 的极限不一样，因此  $\lim_{ x \to x_{0} }f (x)$  的极限就不存在





### $e^{f(x)}$ 求极限的理解 (复合函数求极限规则)

处理这个函数求极限的的时候的依据是复合函数的极限运算法则：
![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250707103914.png)

复合函数求极限，就是极限中换元的依据，比如 $\lim_{ x \to 2 }\frac{\ln(1 +4-2x)}{4-2x}$，此时就将 4 - 2 x 看作一个整体：

$$
\lim_{ x \to 2 }\frac{\ln(1 +4-2x)}{4-2x} = \lim_{ u \to 0 }  \frac{\ln(1 + u)}{u} = 1
$$
![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250707103815.png)

**这样就可以将对 e 的整体求极限转为求指数式子的极限：(这个结论记住，可以直接对 f (x) 用等价替换)**

$$
\lim_{ x \to x_{0} } e^{f(x)} = e^{\lim_{ x \to x_{0} } f(x)}
$$
这是因为这里将 e^x 看作外层函数，f (x) 是内层函数，这里的意思是如果 $\lim_{ x \to x_{0} }f(x) = A$，并且 e^x 在 x = A 连续（显然），这是两个条件，如果这两个条件成立，则有：

$$
\lim_{ x \to x_{0} } e^{f(x)} = e^{\lim_{ x \to x_{0} } f(x)}
$$

题目中一般给的是要求 $\lim_{ x \to x_{0} } e^{f(x)}$，我们只要能求出 $\lim_{ x \to x_{0} }f(x) = A$，那么条件就成立，就有 $\lim_{ x \to x_{0} } e^{f(x)} = e^{\lim_{ x \to x_{0} } f(x)} = e^A$

所以只用求 $\lim_{ x \to x_{0} }f(x)$ 就好了，并且在求这个极限的时候可以直接对这个式子进行等价代换等操作

同理还有类似的 $\frac{1}{1 + f(x)}$ 这一类的极限，外层是 $\frac{1}{1 + x}$，内层是 f (x)

只要满足条件：$\lim_{ x \to 0 }f(x) = A$，并且 $\frac{1}{1 + x}$ 在 A 处连续，则极限符号就可以内移动：

$$
\lim_{ x \to 0 } \frac{1}{1 + f(x)} = \frac{1}{1 + \lim_{ x \to 0 } f(x)}
$$

而且题目一般就是要求 $\lim_{ x \to 0 } \frac{1}{1 + f(x)}$

那么我们就是求 $\lim_{ x \to 0 }f(x)$，如果它能存在 = A，而且一般外层的都是在 A 连续的，所以就可以直接将这个极限代入到式子中得到了：

$$
\lim_{ x \to 0 } \frac{1}{1 + f(x)} = \frac{1}{1 + \lim_{ x \to 0 } f(x)} = \frac{1}{1 + A}
$$
那么在求 f (x) 的时候就可以随意使用等价代换了，这个时候其实是对单个式子 f (x) 的等价代换，而不是对外层的一部分 $f(x)$ 进行的等价代换，而且一般题目中的 f (x) 它的极限等于 A 都可以求出来

所以有时候是默认可以直接极限内移的，并且有时候直接对外层的一部分 f (x) 进行等价代换，这些虽然不严谨，但其实都是对的，**因为大部分题目都是默认了 f (x) 极限是存在并且外层在此处连续**，那么极限内移了当然就可以随意进行等价代换了：

$$
\lim_{ x \to 0 } \frac{1}{1 + f(x)} = \frac{1}{1 + \lim_{ x \to 0 } f(x)} =  \frac{1}{1 + \lim_{ x \to 0 } g(x)} = \frac{1}{1 + A}
$$

### $1^\infty$ 的简化计算与理解

对于 $(1 + f(x))^{g(x)}$，如果 $f (x) -> 0$，并且 $g(x) \to \infty$，$f(x)g(x) \to A$，则有：
$$
\lim (1 + f(x))^{g(x)} = e^A 
$$
也就是将 $1^\infty$ 的计算直接变成了式子中两项乘积极限的计算

这道题目直接将括号中凑成 1 + f (x) 的形式，然后计算乘积极限即可

==一个需要注意的地方==

注意只有 $\lim_{ x \to 0 }(1 + x)^{1/x} = e$

这里括号中的 x 和幂中的 x 必须是一致的结果才是 e；并且只用保持一致即可，至于 x 是趋于 0+还是 0-，结果都是 e

因此遇到 $(1  + f(x))^{g(x)}$ （f (x) - > 0）的时候一定要化为：$(1 + f(x))^{\frac{1}{f(x)} * f(x)g(x)} = e^{f(x)g(x)}$

### 可微的定义以及对线性主部和图像的理解

对于函数 `f(x)`，在 x 0 处（即固定 x 0）的函数增量有：$f(x0 + \Delta x) - f(x0) = \Delta y$

这里 Delta x 成变量，Delta y 成 Delta x 变化的时候的因变量

如果 $\Delta y$ 可以写成 $\Delta y = A(x_{0}) \Delta x+\alpha(\Delta x)$，其中 A (x 0) 是与 Delta x 无关的量，并且 $\alpha(\Delta x)$ 是当 $\Delta x$ 趋于 0 的时候的无穷小

那么此时可以称为 f (x) 在 x 0 处可微，此时的对于式子 $\Delta y = A(x_{0}) \Delta x+\alpha(\Delta x)$ 来说，$A(x_{0}) \Delta x$ 是其线性部分，称为线性主部，记作 $dy|_{x = x_{0}}$，并且规定 $\Delta x = dx$

于是我们根据求导数定义的公式可以发现 $A(x_{0}) = f'(x_{0})$，因此就有 $\frac{dy}{dx}|_{x_{0}} = f'(x_{0})$

**这里 x 0 固定，Delta y 可以看作是 Delta x 的函数**

如果可以写成 $\Delta y = A(x_{0}) \Delta x+\alpha(\Delta x)$ 的情况下，即可微的情况下，我们发现 A (x 0) 就是 f (x) 在 x 0 处的导数，于是可以将其在图像中表示出来：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250421090704.png)

注意上图中的 dy 并不是在 Deltax 趋于 0 的时候才有意义，dy 仅仅代表式子 $\Delta y = A(x_{0}) \Delta x+\alpha(\Delta x)$ 有可微下的线性主部，是一个与 dx 有关的量，而上图中 Delta y 和 dy 的差值才在 Delta x 趋于 0 的时候有意义，是一个 Dleta x 趋于零的时候的无穷小量

x 0 固定的时候，dx 的变化导致 dy 的变化，但是 dy 除以 dx 的结果就是导数，是在 x 0 处的导数，此时 dy 就是关于 dx 的一个一次函数；

当 x 0 变化的时候 dy/dx 整体就是关于 x 0 的函数了，就是原函数的导函数，即 $\frac{dy}{dx}|_{x=x_{0}} = f'(x_{0})$

而在 $\Delta x$ 趋于 0 的时候的有关意义是，可以用 d y 代替 $\Delta y$，即在 $\Delta x$ 趋于零的时候就可以以直线代替曲线了

### 微分形式的不变性的理解

所谓微分形式不变性的意思就是，对于一个符合函数 $y = f[g(x)]= f(u)$，这里无论将 u 当作自变量对 y 求微分，得到 dy = f' (u) du，还是将 u 当作因变量，对 y 求微分 dy = f' (u) g' (x) dx，得到的 y 的微分形式始终是 dy = f' d 这种等式右边一个导数乘一个微元的形式，这个称为微分形式不变性

### 弧微分的推导和弧微分参与的积分的上下限问题

其实弧微分的本质是 $\sqrt{ (dx)^2 + (dy)^2 } = ds$，就是下面的图：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250505092133.png)

如果我们在根号中提取一个 dx 到根号外面，就可以得到：
$$
\sqrt{ 1 + ( \frac{dy}{dx} )^2 } dx = ds
$$

这样就得到 y = f (x) 的弧微分公式了：$\sqrt{ 1 + f' (x)^2 } dx = dx$

同理参数方程和极坐标方程都是看作换元利用 $\sqrt{ (dx)^2 + (dy)^2 } = ds$ 来推导的

另外在弧微分参与运算中如果涉及换元的问题，最好是先写出 y 和 x 的表达式，然后再按照换元的思想处理积分上下限，如果想直接套公式写出 $\int ds$，利用弧微分公式计算（有些情况只能套公式，不能先写出 y 和 x 然后换元），那么积分上下限一定是从小积到大

例如一个函数 $y = \sqrt{ 1 - x^2 }$ 中 $0 \le x \le$ 1 的弧长（这是一个 1/4 的圆）

正常情况下是 $\int_{0}^1 \sqrt{ 1 + y' (x)^2 }dx$，我们换元，令 $x = \cos t, y = \sin t$，积分上下限变成了 $\frac{\pi}{2} \le t \le 0$ 代入得到：

$$
\int_{\frac{\pi}{2}}^0 \sqrt{ 1 +  (\frac{\cos t}{\sin t})^2  } (-\sin t) dt
$$

将 $\sin t$ 放入根号中，它会自动调整成 $\int_0^{\frac{\pi}{2}} \sqrt{ \sin^2 t + \cos^2 t }dt = \frac{\pi}{2}$

但是如果想要直接用 $ds  = \sqrt{ (y' (t)^2 +  x' (t)^2} dt$ 这个公式计算这一段的弧长，即 $\int ds = \int \sqrt{ (y' (t)^2 +  x' (t)^2} dt$

这个时候的积分上下限就不能根据换元的思想来确定了，因为这里不是换元的过程了而是直接套公式了，所以为了保证弧长最后的结果是正的，**这里的积分上下限必须是从小到大**

这两种做法的区别在于直接套公式是将 ds 看作了一个整体，即正的弧微分参与了运算，所以上下限必须要保证其是正的，因此一定是从小到大，而换元则是按照换元的原则进行处理，上下限也是按照换元的原则一一对应

另外弧长参与的面积运算也是这样的，如果按照换元，那么上下限的确定一定是按照换元的思想严格一一对应，但是如果直接套公式，那么上下限一般就是从小到大，如果最后分不清的话可以看结果是正还是负，反正面积一定是正的

### 变上限积分（积分上限函数）的两个定理

### 变限积分的连续性及其推导

f (x) 可积，变限积分一定连续

f (x) 可积，变限积分一定存在，所以在考研中看到变限积分一般都是连续的

证明变限积分的连续性就是证明：

$$
\lim_{ \Delta x \to 0 } F (x + \Delta x) - F (x) = 0

$$

也就是：

$$
\lim_{ \Delta x \to 0 } \int_{a}^{x + \Delta x} f (t) dt - \int_{a}^xf (t) dt = 0
$$


这个式子根据区间可加性，也就是要证明：

$$
\lim_{ \Delta x \to 0 } \int_{x}^{x + \Delta x} f (t) dt = 0
$$

因为这个被积函数是可积的，所以一定是有界的，这里当 $\Delta x \to 0$ 的时候这里的面积显然就是 0 了，所以变限积分一定连续

**即，f (x) 可积，则变限积分一定连续**

### 变限积分在极限中的等价关系（积分的等价代换）


==被积函数的等价替换==
![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250506090901.png)

比如在 x -> 0 的时候 $\sin x \sim e^x - 1$，那么 x ->0 的时候就有 $\int_{0}^x \sin xdx \sim \int_{0}^x e^x - 1 dx$

这个结论有几点说明：

（1）**这里不要求 x -> 0 的时候 f (x) 和 g (x) 是无穷小**，只要满足两者的极限之比为 1 等价即可，比如 x->0 的时候 $\lim_{ x \to 0 } \frac{e^t}{\cos t} = 1$，那么 x->0 的时候同样有 $\int_{0}^x e^t dt \sim \int_{0}^x \cos t dt$
证明的方法是洛必达

（2）**这个等价可以广义化**为： $\int_{0}^{\phi (x)} f (t) dt \sim \int_{0}^{\phi (x)} g (t) dt$，要求是 $\phi (x)$ 在 x 的去心领域可导并且导数不为零（保证洛必达）

（3）**x 可以不一定趋于 0**，也可以趋于 a，我们可以研究在 x = 0 处的变限积分等价情况，也可以研究在 x = a 点的等价情况，于是上面的条件可以换成若 $\lim_{ x \to a } \frac{f (x)}{g (x)} = 1$，则当 x -> a 的时候有：$\int_{a}^x f (t) dt \sim \int_{a}^x g (t) dt$

（4）**进行积分等价替换的时候必须保证上下积分的被积函数中变量是同一个，具有相同的趋近性**

比如：$\frac{ \int_{0}^x f (t) dt}{\int_{0}^x g (t) dt}$，此时上下函数的 t 是同一个，当 t -> a 的时候 $f (t) \sim g (t)$，才能有 $\int_{a}^x f (t) dt \sim \int_{a}^x g (t) dt$

如果对分母进行了一次换元得到 $g (t) = h (u)$，此时哪怕 $h (a) \sim f (a)$，也不能进行积分代换，因为此时分母的 u 和分子的 t 无法同时取到 a，h (u) 中的 u 和 f (t) 中的 t 因为换元而产生关联，所以没有相同的趋近性，处理 $\lim_{ x \to a } \frac{h (x)}{f (x)}$ 是毫无意义的事情

这个结论的最好还是换成洛必达，洛一次同样可以得到结果，并且洛必达不会出错

### 一元函数微分学和多元函数微分学的可微定义

==一元函数微分学的可微定义==

对于函数 `f (x)`，在 x 0 处（即固定 x 0）的函数增量有：$f (x 0 + \Delta x) - f (x 0) = \Delta y$

这里 Delta x 成变量，Delta y 成 Delta x 变化的时候的因变量

如果 $\Delta y$ 可以写成 $\Delta y = A (x_{0}) \Delta x+\alpha (\Delta x)$，其中 A (x 0) 是与 Delta x 无关的量，并且 $\alpha (\Delta x)$ 是当 $\Delta x$ 趋于 0 的时候的无穷小

那么此时可以称为 f (x) 在 x 0 处可微，此时的对于式子 $\Delta y = A (x_{0}) \Delta x+\alpha (\Delta x)$ 来说，$A (x_{0}) \Delta x$ 是其线性部分，称为线性主部，记作 $dy|_{x = x_{0}}$，并且规定 $\Delta x = dx$

于是我们根据求导数的公式可以发现 $A (x_{0}) = f' (x_{0})$，因此就有 $\frac{dy}{dx}|_{x_{0}} = f' (x_{0})$

### 偏导数和二阶偏导数的定义求解的理解

$f_{x}'(x_{0}, y_{0})$ 他的含义是 f (x, y) 这个二元函数，在 y = y 0 固定的情况下 f (x, y 0) 在 x = x 0 处的导数，因此就有：

$$
f_{x}'(x_{0}, y_{0}) = f'(x, y_{0})|_{x = x_{0}} = \lim_{ x \to x_{0} } \frac{f(x, y_{0}) - f(x_{0}, y_{0})}{x - x_{0}}
$$

同理 $f''_{xy}(x_{0}, y_{0})$，它的含义是 $f'_{x}(x, y)$ 这个二元函数，在 x = x 0 固定的情况下 $f'_{x}(x, y_{0})$ 在 y = y 0 处的导数，因此就有：

$$
f''_{xy}(x_{0}, y_{0}) = f''_{xy}(x_{0}, y)|_{y_{0}} = \lim_{ y \to y_{0} } \frac{f'_{x}(x_{0}, y) - f'_{x}(x_{0}, y_{0})}{y - y_{0}}
$$

所以偏导数的本质其实就是一元导数，因此看下面这个题目：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250730095052.png)

第二小问

根据偏导数的定义, $f''_{xy}(0, 0)$ 其实就是二元函数 $f'_{x}(x, y)$ 在x = 0 的时候对 y 在 0 处的导数，即 $f'_{x}(0, y)$ 对 y 在等于 0 处的导数：

$$
f''_{xy}(0, 0) = f''_{xy}(0, y)|_{y = 0} = \lim_{ y \to 0 } \frac{f'_{x}(0, y) - f'_{x}(0, 0)}{y - 0}
$$

那么上面式子关键就是求 $f'_{x}(0, y)$ 了，$f'_{x}(0, y)$ 虽然是一个关于 y 的函数，但是在用 f(X, Y) 求 f'(0, y) 的时候这里的 y 应该看作一个常量，这个式子其实是 f (X, Y) 在 (0, y) 这里的偏导

这个式子是 $f(X, Y)$ 这个二元函数，在 Y = y 的情况下，在 X = 0 处的导数，根据定义：

$$
f'_{x}(0, y) = \lim_{ X \to 0 } \frac{f(X, y) - f(0, y)}{X - 0} 
$$

所以要对 y 进行分类讨论

当 y = 0 的时候 $f'_{x}(0, y) = 1$

当 y != 0 的时候，$f'_{x}(0, y) = \lim_{ X \to 0 } \frac{f (X, y) - f (0, y)}{X - 0} =\lim_{ X \to 0 } \frac{Xy - y}{X}$

这个式子是不存在的，所以 $f''_{xy}(0, 0)$ 当然就不存在

### 全微分的形式不变性的理解

假如有 $z = f (u, v), u = \phi (x, y), v = \Phi (x, y)$，显然，这里 z 是关于 x，y 的函数，那么对于 z 就有全微分：

$$
dz = \frac{\partial z}{\partial x} dx + \frac{\partial z}{\partial y} dy
$$

但是 dz 也可以写成：

$$
dz = \frac{\partial z}{\partial u} du + \frac{\partial z}{\partial v} dv
$$

这里的形式不变性是针对中间变量的，意思是虽然 u，v 是中间变量，但是 dz 仍然可以写成关于这两个中间变量的全微分，并且这个全微分与 dz 关于实际变量 x, y 的全微分具有相同的形式，称为全微分的形式不变性

这个用处在于，如果 z = f (u, v) 的 u，v 后面有更复杂的复合形式，但是我们可以不用管，直接写出 z 关于 u, v 的全微分，然后再处理 du 和 dv

隐函数的公式是：

其推导过程为：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250511093053.png)

在推导过程中的锁链是：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250511093205.png)

公式法中的 $F'_{x}$ 不是对第一个位置的偏导，也不是将 z 看作 x, y 的函数的时候真正对 x 求到底的偏导，**而是将 x, y , z 看作同等地位的变量对 x 的偏导**，并不是将 x 求到底的偏导



比如 $F (xyz , x^2 + y^2 + z^2, z) = xyz + x^2 + y^2 + z^2 + z = 0$

此时虽然将 z 看作 x 和 y 的函数，但是这里的 $F'_{x}$ 只代表锁链中最左侧对 x 的偏导，也就是：

x, y , z 看作同等地位的变量，即
$$
F'_{x} = yz + 2 x
$$
同理 $F'_{z}$ 也是将 x, y , z 看作同等地位对 z 的偏导，即

$$
F'_{z} = xy + 2 z  + 1
$$
根据公式得到：

$$
\frac{\partial z}{\partial x} = -\frac{yz + 2 x}{xy + 2 z + 1}
$$
我们可以将 z 看作 x, y 的函数，然后用等式两边对 x 的真实求导到底来验证一下，等式两边对 x 求到底：

$$
yz + xyz'_{x} + 2 x + 2 zz'_{x} + z'_{x} = 0
$$

得到

$$
\frac{\partial z}{\partial x} = -\frac{yz + 2 x}{xy + 2 z + 1}
$$
所以隐函数的存在定理公式中的 $F'_{x}$ 与 F (x, y, z) = 0 等式两边对 x 求偏导要区分开来，$F'_{x}$ 是将 x, y, z 看作同等地位的变量对 x 的偏导，而等式两边对 x 求偏导则是将 z 看作 x, y 的函数根据链式复合法则对 x 的真实偏导

这是因为 $F'_{x}$ 仅仅表示三元函数 $F (x, y, z)$ 对 x 的偏导，此时这个函数还没有等于零，三个变量还是独立的

而写成等式之后 F (x, y, z) = 0，此时有了等式关系，z 就是关于 x, y 的函数，等式两边对 x 求偏导当然要按照复合函数求偏导的链式法则将 z 看作 z (x, y) 来处理

全微分中的 $F'_{x}$ 与隐函数公式中的 $F'_{x}$ 是一样的含义，都是将 x, y, z 看作同等地位的变量求导的结果

这样写当然对，如果有 $F (\phi (x, y), \psi (x, y), z) = 0$，其中 $\phi (x, y) = x^2 + y^2, \psi (x, y) = x + y$ 那么全微分当然可以写成
![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250511104918.png)
全微分中的 $F'_{x}$ 与隐函数公式中的 $F'_{x}$ 是一样的含义，都是将 x, y, z 看作同等地位的变量求导的结果
上式全微分也可以写成按位置整体变量偏导微分的形式：

$$
F'_{1}d\phi + F'_{2}d\psi + F'_{3}dz = 0
$$
这样全微分可以忽略更深层次的变量间的关系，然后后面再进行 $d\phi$ 的处理，这样对于处理变量间的复杂关系有奇效

一般情况的话题目中会给出一个 x, y, z 的式子：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250511115725.png)

此时直接将 x, y, z 看作同等地位的变量，然后等式两边全微分即可，这里看作同等变量是因为微分形式不变性可以忽略复杂的变量嵌套关系


总结：
（1）隐函数公式中的 $F'_{x}$ 是将 x, y, z 看作同等变量对 x 求偏导的结果
（2）等式两边对 x 求偏导是将 z 看作 x, y 的函数，根据复合链式法则求偏导
（3）全微分方法，直接将 x, y, z 看作同等地位变量等式两边微分

### 多元函数与一元函数极值点可能取到的点对比

**多元函数**

多元函数的极值点只可能是驻点或者偏导不存在的点

所以我们应该求出所有的驻点和偏导不存在的点，挨个考察

对于每个驻点，使用充分条件考察，但是可能出现充分条件失效 (AC - B^2 =0 )，此时用定义

对于每个偏导不存在的点，用定义

**一元函数**

一元函数的极值点只可能是驻点或者导数不存在的点

所以我们应该求出所有的驻点和偏导不存在的点，挨个考察

对于每个驻点，挨个使用充分条件考察，并且充分条件不会失效

对于每个不可导点，用第一充分条件考察；对于不可导点中的不连续点，再用定义（一般很少见，一元函数充分条件几乎可以应对所有情况）

### 利用定义法来判断对称性

利用定义法理解对称性的本质是考察对称的两个小块上的函数值的关系

### 二重积分最大的区域

对于一个区域 D，让 $\iint_{D}f(x, y)dxdy$ 最大，那么区域 D 就是：

$$
f(x, y) \geq 0
$$

即在 f (x, y ) >= 0 这个区域中，可以保证 f (x, y) 始终为大于等于 0，这个区域是使得 f (x, y) >= 0 的最大的区域

而在这个区域之外，会导致 f (x, y) < 0，这样积分积进去得到的结果当然会变小

所以在 f (x, y) >= 0 的区域 D 中，可以使得积分 $\iint_{D}f(x, y)dxdy$ 最大

### 极坐标下二重积分的理解

用换元的思想理解

二重积分变成极坐标下的积分本质其实就是换元，令 $x = r\cos \theta$，$y = r \sin \theta$ 则有：

$dxdy = rdr d\theta$，$f (x, y) = f (r\cos \theta, r\sin \theta)$

即 $\int \int_{D} f (x, y) d xdy = \int \int_{D'}f (r\cos \theta, r\sin \theta) r dr d\theta$

这里在 D'上的积分其实**还是一个直角坐标的积分，是 r 和 $\theta$ 作为横轴和纵轴的坐标系**， 只不过未知变量是 r 和 $\theta$，至于这个范围 D'如何确定，因为极坐标换元的特殊性，可以根据原来 D 上的范围，按照极坐标在 D 上的对应规律（r 表示距离原点的范围，theta 表示与原点连线距离 x 轴正方向的偏角）来确定 r 和 theta，以及 D'

只不过**大多数情况下不需要画出来 D'**，r 和 $\theta$ 在 D 上有实际的意义， 只用在 D 上确定 r 和 $\theta$ 的范围直接对 $\int \int_{D'}f (r\cos \theta, r\sin \theta) r dr d\theta$ 进行累次积分了

由于 D 的图形旋转的角度很容易确定，所以很容易得到固定 $\theta$，用 $\theta$ 来表示 r 的累次积分，即可以直接根据 D 的形状确定 $\int \int_{D'}f (r\cos \theta, r\sin \theta) r dr d\theta$ 这个积分，这个关于先对 r 积分，然后对 $\theta$ 积分的累次积分表达式

因此你虽然是通过 D 确定了 r 和 $\theta$ 的范围，但是实际上 r 和 $\theta$ 还是一个直角坐标系 D‘中的横轴和纵轴，所以在 D‘中思考的时候，当然可以将 r 和 $\theta$ 按照普通的直角坐标的换序进行处理

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250803123059.png)

这个题的 r 和 $\theta$ 其实就是 D‘中的横轴和纵轴，将其看成 x 和 y 即可，这里的范围如下所示

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250803123859.png)

先对 y 积分，即 $\int_{0}^{a}dy$

然后固定 y 穿过积分区域，左边就是 x 的下限，右边就是 x 的上限

根据 $\frac{y^{2}}{a^{2} } = \sin 2x$，对于左侧的下限，得用 y 来表示 x，所以需要两边同时取 arcsin ，由于左侧下限的 2 x 的范围是 0~pi/2，所以可以直接取 arcsin，得到 $2x = \arcsin \frac{y^{2}}{a^{2}}$，所以下限是 $x = \frac{1}{2}  \arcsin \frac{y^{2}}{a^{2}}$

根据 $\frac{y^{2}}{a^{2} } = \sin 2x$，对于右侧的下限，得用 y 来表示 x，所以需要两边同时取 arcsin ，由于右侧上限的 2 x 的范围是 pi/2 ~ pi，它不在 arcsin 的值域中，所以得将 2 x 变换到 0 ~ pi/2 才可以直接使用两边取 arcsin，这里用一次诱导公式：

$$
\frac{y^{2}}{a^{2} } = \sin (\pi - 2x)
$$

这样对于右侧上限的 x，pi - 2 x 的范围就是 0 ~ pi/2 了

所以可以直接取 arcsin，得到 $\pi - 2x = \arcsin \frac{y^{2}}{a^{2}}$，所以上限是 $x = \frac{\pi}{2} -  \frac{1}{2}\arcsin \frac{y^{2}}{a^{2}}$

所以结果就是：

$$
\int_{0}^a dy \int_{\frac{1}{2}  \arcsin \frac{y^{2}}{a^{2}}}^{\frac{\pi}{2} -  \frac{1}{2}\arcsin \frac{y^{2}}{a^{2}}} f(y\cos x, y\sin x)y dy 
$$

然后再将 x 换成 $\theta$，y 换成 r 即可


### 二重积分的对称性的理解

==关于奇偶对称性与原点对称性==

假设整个积分区域是 D，对称区域是 D 1 和 D 2

只用观察对称的两点 (xi, yi) 与 (ui, vi)，这两个点分别属于 D 1 和 D 2 的坐标变量某个取值

**如果 f (xi, yi) dxdy = f (ui, vi) dudv，那么积分区域 D 的积分就是某个对称区域积分的两倍**

比如 (xi, yi) 与 (ui, vi) 关于原点对称，并且 f 函数也关于原点对称，即 f (x, y) = f (-x, -y)，那么由于 (ui, vi) = (-xi, -yi)，所以 f (xi, yi) dxdy = f (ui, vi) dudv

这个式子表示，D 1 中任意一个坐标的 f (xi, yi) dxdy 值都与 D 2 中某个坐标的值 f (ui, vi) dudv 相等

那么按照二重积分的定义，等式两边求和取极限，每一项都对应相等，所以：

$$
\iint_{D_{1}}f(x, y) dxdy = \iint_{D_{2}}f(u, v)dudv
$$
再根据积分与符号无关，那么就有：

$$
\iint_{D_{1}}f(x, y) dxdy =\iint_{D_{2}}f(x, y)dxdy
$$

那么积分区域 D 的积分就是 D 1 的积分或者 D 2 的积分的两倍

**如果 f (xi, yi) dxdy =- f (ui, vi) dudv，那么积分区域的积分就是 0**

比如 (xi, yi) 与 (ui, vi) 关于原点对称，并且 f 函数有 f (x, y) = -f (-x, -y)，那么由于 (ui, vi) = (-xi, -yi)，所以 f (xi, yi) dxdy =- f (ui, vi) dudv，同上：

$$
\iint_{D_{1}}f(x, y) dxdy = -\iint_{D_{2}}f(u, v)dudv =^{积分与符号无关}-\iint_{D_{2}}f(x, y)dxdy
$$

那么积分区域 D 的积分就是 0

==关于轮换对称性，y = x 对称==

假设整个积分区域是 D，对称区域是 D 1 和 D 2

只用观察对称的两点 (xi, yi) 与 (ui, vi)，这两个点分别属于 D 1 和 D 2 的坐标变量某个取值

这种情况因为 (ui, vi) = (yi, xi) 所以是一定有 f (xi, yi) dxdy = f (vi, ui) dudv 的，这里 D 2 中的坐标 (ui, vi) 交换了位置代入了函数 f

同上，求和，取极限，每一项都会对应相等，因此一定有：

$$
\iint_{D_{1}}f(x, y) dxdy = \iint_{D_{2}}f(v, u)dudv =^{积分与符号无关}\iint_{D_{2}}f(y, x)dxdy
$$


如果题目中又说了 f (x, y) =f (y, x) ，那么就有 f (xi, yi) dxdy = f (vi, ui) dudv  = f (ui, vi) dudv，所以：

$$
\iint_{D_{1}} f(x, y)dxdy = \iint_{D_{2}}  f(x, y)dxdy
$$
那么此时积分区域 D 的积分就是 D 1 的积分或者 D 2 的积分的两倍

### 积分中的平移变换

对于一元函数来说，积分区域统一左移，那么变量就要加一个值，即：

$$
\int_{a}^b f (x) dx = \int_{a-c}^{b - c}  f (x + c) dx
$$
这个在将三角函数的积分区域变换到 0 到 pi/2 的时候非常有用

对于二元函数也是这样的，积分区域左移 c 个单位，那么被积函数的 x 就得加 c 个单位，积分区域右移 c 个单位，被积函数就得减 c 个单位，即：

$$
\iint_{D}f (x, y) dx dy = \iint_{D'}f (x + c, y + c) dxdy
$$

D'是相对于 D 左移以及下移 c 个单位的新的图形，即新的积分区域在 x 轴比原来的积分区域左移（减少了）c 个单位，在 y 轴比原来的积分区域下移（减少了）c 个单位，那么被积函数就得分别加上 c 个单位

积分区域向左平移，积分变量 x就加，向右平移，积分变量 x就减；向下平移，积分变量 y就加，向下平移，积分变量 y就加

### 积分中的伸缩变换

这里跟上文的平移是一样的，如果积分区域相对于原来的 D 缩小，那么被积函数的变量就得扩大，同时，积分微元也得扩大

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250804082642.png)

上图的公式，D'就相对于 D 横坐标方向缩小了 a 倍，纵坐标方向缩小了 b 倍

那么被积函数的积分变量就得扩大 a 倍和 b 倍，同时积分微元也得扩大|ab|倍

==看一个例子==

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250804103203.png)

令 x  = au，y = bv，(u, v) 是伸缩后的 D'的坐标，因此 D'相对于 D 就是 x 缩小了 a 倍，y 缩小了 b 倍

D'的区域就是 $u^2 + v^2 = 1$

由于 D'相对于 D 是缩小了的，所以被积函数以及积分微元就得扩大，所以原二重积分可以变为：

$$
I= \iint_{D'} b^2 v^2 |ab| dudv
$$

这样就转换成了 D'这个圆域上的二重积分了，容易计算多了

### 二重积分与偏导数结合的处理方法

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250806102031.png)

首先，将这个二重积分写成累次积分的形式：

$$
\int_{0}^1 dx \int_{0}^{1} xy f''_{xy}(x, y) dy
$$

接下来的关键是，可以直接将 $f''_{xy}(x, y)$ 移动到 dy 中，变成：

$$
\int_{0}^1 xdx\int_{0}^{1}yd(f'_{x}(x, y))
$$

这样做的原因是，在先对 y 求积分中，x 其实是看作一个常数的

那么在偏导数中，$\frac{\partial f'_{x}(x, y)}{\partial y} = f'_{xy}(x, y)$ 的含义是：x 是一个变量，但是这里将 x 看作常数，然后对 y 求导，结果是 $f''_{xy}(x, y)$

$\frac{df'_{x}(x, y)}{dy}$ 的含义是：x 就是一个常数，然后对 y 求导

很显然，从结果上看两者就是相等的，因为这两个都是直接对 y 求导，不管 x，用的法则是一样的：

$$
\frac{\partial f'_{x}(x, y)}{\partial y} = f'_{xy}(x, y) = \frac{df'_{x}(x, y)}{dy}
$$

所以，然后用分部积分将内部展开：
![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250806103001.png)

得到的是：

$$
f'_{x}(x, 1) - \int_{0}^{1}f'_{x}(x, y)dy
$$

这里 $f'_{x}(x, 1)$ 的含义就是，f(x, y) 中将 y 看作 1 的情况下，对 x 求导的结果，就是 0，所处原式可以化为：

$$
-\int_{0}^{1} xdx\int_{0}^{1} f'_{x}(x, y)dy 
$$
交换一下积分次序：

$$
-\int_{0}^{1}dy \int_{0}^{1}xf'_{x}(x, y) dx
$$

同上面，先对 x 求积分，那么 y 就是一个常数，这里的一阶偏导同样可以移动导微元中：

$$
-\int_{0}^{1}dy \int_{0}^{1}xdf(x, y)
$$

再用一次分部积分将其展开：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250806103912.png)

代入上式，得到：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250806103935.png)

其他情况得到 ln 还是得加上绝对值的，但是在考研范畴其实无所谓，加不加绝对值都行

### 关于微分方程求通解的特殊情况讨论问题

首先，在算微分方程遇到 ln 这种的时候一律不用加绝对值

齐次，如果你的结果得到的是一个含有 C 的方程，一律不用讨论特殊情况，因为要求的是通解，遗漏一些解是无所谓的

比如下面这个题：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250806123228.png)
典型的分离变量做法，直接分离得到：

$$
\frac{dy}{1 + y} = x dx
$$

然后就是 $\ln (1 + y) = 1/2 x^2  + C$

得到 $1 + y = e^{1/2 x^2 + C} = Ce^{1/2 x^2}$

所以 $y = Ce^{1/2 x^2} - 1$

这样的做法就是正确的不用考虑什么别的情况

### 含初值的微分方程求解细节问题

一般含初值的微分方程求解问题，可以根据初值的范围去掉中间过程中的一些绝对值符号或者根号

这是因为题目中要求的是满足这个初值的特解，那么这个特解一定是在满足初值范围的解集范围中

这是因为微分方程的解其实包括非常广泛，只要是满足等式成立的解析式都算方程的解，比如：

y = ln |x|是某个微分方程的解

那么，x > 0，y = ln (x) 是这个方程的解

x < 0, y = ln (- x) 同样是这个方程的解

甚至 y = x，x 取不同的范围就是不同的解

假如初值是 x = 1, y = 1，那么我们要求的解就是满足 x = 1, y = 1 并且满足解析式的一个解，而这个解一定在 x > 0，并且满足解析式的解集合中

那么在中间过程如果遇到了 ln |x|，你去掉了绝对值，这就等于最后求的带 C 的通解都是满足 x > 0 的通解，那么特解满足 x = 1, y = 1 也是满足 x > 0 的解，所以这个特解一定在这个解集中，你直接去掉绝对值符号并没有漏掉它

同理，对于 yy' + y^2 = 0 这种，如果题目中说了初值 y (0) = 1，也可以直接除去 y 得到 y' + y = 0，不用分类讨论，因为你在 y != 0 讨论中解得的通解一定满足初值，一定可以求出一个特解，既然可以求出一个特解，那就无所谓了，这个就是结果了

### 齐次方程的根的形式的讨论

**此外可以用韦达定理来做**

对根的结构进行分类讨论

如果是 $C_{1}e^{r_{1}x}+C_{2}e^{r_{2}x}$，两相异实根，那么 $\Delta = (a - 2)(a + 1) > 0$，得到 $a < -1 并 a > 2$，此时必须保证两个根都小于 0，根据韦达定理 r 1 + r 2 = 2 a < 0，r 1 * r 2 = a + 2 > 0，所以-2 < a < 0，取交集就是-2 < a < -1

如果是 $(C_{1}x + C_{2})e^{rx}$，两相等实根，那么 a = -2 或者 a = -1，那么必须保证这个二重根是一个小于 0 的二重根（不能等于 0），所以 2 a < 0，a + 2 > 0，所以-2 < a < 0，取交集，a = -1

如果是 $e^{\alpha x}(C_{1} \cos \beta x + C_{2} \sin \beta x)$，两非实根，那么 $\Delta = (a - 2)(a + 1) < 0$，所以-1 < a < 2 ，这两个根是 $\alpha \pm \beta i$，你必须保证 $\alpha < 0$，即 $r_{1} + r_{2} = 2a < 0$，所以 a  < 0，取交集，所以-1 < a < 0

上述三种情况的结果并在一起所以 a 的范围就是-2 < a < 0 了


**也可以写出两个解然后分类讨论：**

这个反常积分收敛，因此上面三种情况中，e 的指数部分必须小于 0

特征方程的两个解是：

$$
\frac{2a \pm 2\sqrt{ a^{2} - (a + 2) }}{2} = a\pm \sqrt{ (a-2)(a + 1) }
$$

如果 a > 0

（1）有实根，那么一定会出现指数部分大于 0 的情况，所以不成立
（2）无实根，那么上式左侧的 a 会作为指数部分，> 0，所以不成立

所以 a 不可能大于 0

如果 a = 0

此时无实根，但是你两个三角函数的无穷积分，是可能不收敛的（比如 C 1 和 C 2 随机取数使得被积函数 > 0）结果就是不收敛

如果 a < 0

（1）无实根，即-1 < a < 0，此时是根的结构第三种情况，指数部分小于 0，所以的确收敛

（2）a = -1，此时是根的结构的第二种情况，所以收敛

（3）有实根，即 a < -1，此时是根的结构的第 1 种情况，关键是看 $a + \sqrt{ (a -2)(a + 1) }$，要保证它必须< 0，所以 a > -2

综上 a 的范围就是-2 < a < 0 了

### 线性微分方程的解的性质

==齐次线性微分方程的解的性质==

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250807125831.png)


==非齐次线性微分方程的解的性质==

对于一个二阶线性微分方程：
$$
y'' + py' + qy = f(x)
$$
假如 $y_1, y_2$ 是这个非齐次方程的两个特解，则有：

（1）$k_1 y_1 + k_2 y_2$ 一定是方程 $y'' + py' + qy = k_{1}f(x) + k_{2}f(x) = (k_{1} + k_{2})f(x)$ 的特解

（2）若 $k_1 + k_2 = 0$，则 $k_1 y_1 + k_2 y_2$ 是齐次方程 $y'' + py' + qy = 0$ 的特解

（3）若 $k_1 + k_2 = 1$，则 $k_1 y_1 + k_2 y_2$ 是非齐次方程 $y'' + py' + qy = f$ 的特解

上面（2）（3）两条都可以用第一条来证明

这也是为什么 y 1 y 2 是非齐次的特解，而 y 1 - y 2 就是齐次的通解的原因了

### 高阶常系数线性齐次微分方程的解的结构

对于下面这样一个微分方程：

$$
y^{(n)} + py^{(n-1)} + qy^{(n -2)}\dots  =0 
$$

它的特征方程是：

$$
\lambda^{n} + p\lambda^{n-1} + \dots + \dots = 0
$$

（1）每多出一个单重实根 $\lambda_{1}$，通解中就会多出一项 $C_{1}e^{\lambda_{1}x}$

（2）每多出一个二重实根 $\lambda_{2}$，通解中就会多出一项 $(C_{1} + C_{2}x)e^{\lambda_{2}x}$

（3）每多出一对非实根 $\alpha \pm \beta i$，通解中就会多出一项 $e^{\alpha x}(C_{1} \sin \beta x + C_{2}\cos \beta x)$

那么下面就是按照参数方程的方法分别将 y'和 y''转换成 g'和 g''：

$$
\frac{dy(x)}{dx} =y' =  \frac{dy(e^t)}{dx} = \frac{dy(e^t)}{dt} \frac{dt}{dx} = \frac{dy(e^t)}{dt} \frac{1}{e^{t}} = \frac{dg}{dt} \frac{1}{e^{t}} 
$$ 
然后是二阶导：

$$
\frac{d\left( \frac{dy(x)}{dx} \right)}{dx} = y'' = \frac{d\left( \frac{dy(x)}{dx} \right)}{dt} \frac{dt}{dx} =\frac{d\left(  \frac{dg}{dt} \frac{1}{e^{t}}  \right)}{dt} \frac{1}{e^t} = \frac{1}{e^{t}}\left( \frac{d^{2}g}{dt^{2}} \frac{1}{e^{t}} - \frac{dg}{dt} \frac{1}{e^{t}}\right)
$$

降这些代入到原微分方程，变成 g 和 t 的式子：

$$
g''-9g = 0
$$

这是一个二阶常系数线性微分方程，可以直接解得：

$$
g = C_{1} e^{3t} + C_{2}e^{-3t} = y(e^{t}) = y(x)
$$

下面就是根据 y (1) = 2 和 y' (1) = 6 代入值进去得到 $C_{1} + C_{2} = y(1) = 2$

上式两边对 t 求导才能代入 y' (1)，得到：

$$
C_{1}3e^{3t} -3C_{2}e^{-3t} = y'(x) \frac{dx}{dt} = y'(x) e^{t}
$$

t = 0，x = 1，所以：

$$
3C_{1} - 3C_{2} = y'(1) = 6
$$

所以 C 1 = 2 C 2 =  0

即：

$$
g(t)= y(e^t) = 2e^{3t} = y(x) = 2x^3
$$

### AB = 0 条件的使用总结

这里 A 是 m * n 的矩阵，B 是 n * k 的矩阵

**（1）B 的每一个列向量一定是 Ax = 0 的解**

那么 Ax = 0 的基础解系的解向量个数 n - r (A) 就是 Ax = 0 解空间的所有向量的极大无关组，而 B 的每一列构成的向量组就是这个解空间的部分组，这个部分组的秩当然要小于等于整个解空间的极大无关组（可以用反证法证明，因为假如 r (B) > n - r (A)，那 B 的这个极大无关组，又线性无关，又都是 Ax = 0 的解，所以也是 Ax = 0 的解的线性无关组，但是 Ax = 0 的线性无关组的最多向量个数是 n  - r (A)，所以矛盾）

所以 n - r (A) >= r (B)，即 r (A) + r (B) <= n

**（2）r (A) + r (B) <= n，这里 n 是 A 的列数，B 的行数**

**（3）若 B != 0，则 r (A) < n，即 A 不列满秩**

**（4）若 A != 0，则 r (B) < n，则 B 不行满秩**

（3）（4）都可以根据第二条性质证明

### AB = C 的条件总结

这里 A 是 m * n 的矩阵，B 是 n * k 的矩阵

（1）B 的每一列都是 Ax = ci 的解

（2）C 的每一列 ci 都是 A 的列向量的线性组合，组合系数是对应的 B 的列向量 bi；C 的每一行 ci 都是 B 的行向量的线性组合，组合系数是对应的 A 的行向量 ai（矩阵乘法的本质过程）

（3）C 的列向量是由 A 的列向量线性表示的，C 的行向量是由 B 的行向量线性表示的，根据被表示的秩更小，所以 r (C) < = r (A), r (C) <= r (B)，所以 $r (C) \leq min [r (A), r (B)]$，也就是矩阵的秩，越乘越小

（4）将 A 和 AB 的列叠在一起；或者 B 和 AB 的行叠在一起；秩不发生改变
![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250701102642.png)

这是因为上述中 A | AB，这个叠在一起的矩阵的 AB 部分都可以通过 A 的初等列变换消成零，即变成 A | 0，所以其秩就是 A 的值，对于右边也是同理

上述四条性质是仅仅通过 AB = C 这样一个通用乘法得到的结果

（5）如果 B 可逆，则 A 和 AB 的列向量等价；如果 A 可逆，则 B 和 AB 的行向量等价

因为 AB = C，如果 B 可逆则有：$A = CB^{-1}$，即 A 的列向量也可以由 C 的列向量线性表示，所以 A 和 C 的列向量可以互相表示，所以他们的列向量等价

（6）如果 B 可逆，则 AB = C 是表示对 A 的列向量进行一系列的初等变换得到 C，但是 A 的行的相关性不发生改变；如果 A 可逆，则 AB = C 是表示对 B 的行向量进行一系列的初等变换，但是 B 的列的相关性不发生改变

这里先看 B 的列的相关性，所谓 B 的列的相关性其实就是 Bx = 0 的解向量 x，x 就是 B 的列向量的相关系数，x 就能体现 B 的列向量的线性相关性，这里对 B 进行初等行变换，不改变 Bx = 0 的解集，是同解变换，所以当然不会改变 B 的列的线性相关性

同理，A 的行的线性相关性，这个结论跟上面 B 的列的相关性是对称的，不多说了

关于 r (A, B) >= max{r (A), r (B)}

关于 r (A, B) <= r (A) + r (B)

简单理解下，因为有可能 A 和 B 的极大无关组拼起来之后两者的极大无关组之间可能有线性相关的向量出现，所以拼起来之后的极大无关组向量个数可能减少

### 矩阵 A 的所有 s 阶子式等于零，则所有大于 s 阶的子式也必然都等于零

s 阶子式等于零，说明矩阵 A 中任意取 s 行 s 列构成的行列式等于零

对于 s + 1 阶的子式，这个子式的计算方法就是按某一行或者某一列展开，展开的时候是每个元素乘相应的代数余子式，由于矩阵 A 的任意 s 阶的子式都是零，而这些代数余子式又都是矩阵 A 中抽出来的 s 阶的子式，所以这些代数余子式都为零

所以任意 s + 1 阶子式都为零，以此类推，只要大于 s 阶的子式都等于零

所以如果矩阵 A 的秩 >= r，即存在一个大于等于 r 阶的子式不等于零，那就一定说明存在一个 r 阶的子式不等于零

反过来，如果存在一个 r 阶的子式不等于零，那就说明矩阵 A 的秩一定大于等于 r

即：

$$
r (A) \geq r  \Leftrightarrow 存在一个 r 阶子式不等于零
$$

### 伴随矩阵 $A^*$ 的秩与 A 的秩的关系

（1）如果 r (A) = n，则 $r (A^*) = n$

这是因为 $AA^* = |A|E$，既然 A 满秩，所以 A 的行列式不等于零，所以 A 伴随的行列式不等于零，所以 A 伴随满秩

（2）如果 r (A) = n - 1，则 $r (A^*) = 1$

既然 r (A) = n - 1，所以 A 存在一个 n - 1 阶的子式不等于零，而 A 伴随的每个元素都是由 A 的 n - 1 阶子式增加正负号构成，所以 A 伴随至少有一个元素不等于零，所以 $r (A^*) \geq 1$

而根据 $AA^* = |A|E = 0$，可以得到 $r (A) + r (A^*) \leq n$，所以 $r (A^*) \leq 1$

所以 $r (A^*) = 1$

（3）如果 r (A) < n - 1，则 $r (A^*) = 0$

由于 A 的 n - 1 阶子式全部为零，所以 A 伴随的每一个元素都为 0，所以 A 伴随就是一个零矩阵，所以成立

**上述三个结论都可以互相推导**



### 线代中向量的模的处理

对于 $||\alpha + \beta||$，在线代中是矩阵，其可以转化为：

$$
||\alpha + \beta||^2 = (\alpha + \beta)^T (\alpha + \beta) = (\alpha^T + \beta^T)(\alpha + \beta)
$$

在高数中 $\alpha, \beta$ 都是坐标，那么就是按照向量坐标的点乘进行：

$$
||\alpha + \beta||^2 = (\alpha + \beta) \cdot (\alpha + \beta) 
$$

虽然这两类的表示形式不同，但是都是向量，都可以用几何意义来理解，因为虽然表现形式不一样，但是运算法则会有一一对应关系，对向量分量的数字操作也具有一一对应关系，比如 $\alpha$ 和 $\beta$ 正交，就对应 $\alpha^T\beta = 0$，这个逻辑就对应坐标表现中 $\alpha \cdot \beta = 0$，所以几何意义中 $\alpha$ 和 $\beta$ 垂直就表示矩阵下的正交（根据两类表现形式的定义的运算的对应关系，可以将几何中的向量关系与矩阵表现得向量对应起来，比如几何中平行那就是两个向量的分量对应成比例，几何中的垂直那就是 $\alpha^T\beta = 0$）

总而言之，对于矩阵下的向量 $\alpha, \beta$，也可以通过几何意义来进行处理，几何意义处理得到的坐标下 $\alpha, \beta$ 的对应分量的关系，也就是原来的矩阵下的向量 $\alpha, \beta$ 对应分量的关系

## 向量与方程组


### 矩阵方程与向量组的互相表示 + 向量组表示的等价条件

如果一个向量组 $B  = [\beta_{1},\beta_{2}\dots]$，可以由另一个向量组 $A = [\alpha_{1},\alpha_{2},\alpha_{3}\dots]$ 线性表示，那就是说 B 中的每一个向量都可以由 A 线性表示，写成方程组的形式就是：
![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250606084547.png)
上图方程组中每一个方程都是 $Ax = \beta$，将这个方程组写成矩阵的形式就是：

$$
AX = B
$$
这个矩阵方程有解，这里的 X 也是一个矩阵，其每一列都由 x 1, x 2, x 3 构成，即 $A[x_{1}, x_{2}, x_{3}\dots] = B$


那么此时将系数矩阵 A 和 B 拼接在一起，一定有：

$$
r (\alpha_{1}, \alpha_{2},\alpha_{3}..) = r (\alpha_{1}, \alpha_{2},\alpha_{3}..|\beta_{1}, \beta_{2},\beta_{3}\dots)
$$
因为这里对增广阵进行行变换将 $\alpha_{1}, \alpha_{2}\dots$ 化成最简阶梯型，由于每一个 $Ax_{i} = \beta_{i}$ 都有解，并且对 A 进行行变换对于每一个 $Ax_{i} = \beta_{i}$ 都是一样的操作，所以每一个 $\beta_{i}$ 进行同步行变换的时候其非零行也一定不会超过 $\alpha_{1}, \alpha_{2}\dots$ 行变换后的最简阶梯型的非零行，所以大的增广阵的秩就与原来的一样了

所以向量组之间的线性表示也可以与方程与秩进行等价：

$$
B 可由 A 线性表示 \Leftrightarrow AX = B 有解 \Leftrightarrow r (\alpha_{1}, \alpha_{2},\alpha_{3}..) = r (\alpha_{1}, \alpha_{2},\alpha_{3}..|\beta_{1}, \beta_{2},\beta_{3}\dots)
$$

同时由 AX = B，可以得到 $r (\beta_{1}, \beta_{2},\beta_{3}\dots) \leq r (\alpha_{1}, \alpha_{2},\alpha_{3}..)$，即被表示的秩一定更小



==所以线性表示（or 线性相关），与方程组有解无解，与方程的秩和增广的秩，这三者之间就是互相等价的！==

### 矩阵方程与线性表示

根据 AB = C，可以得到 C 的列向量可以由 A 的列向量线性表示，表示系数就是 B 的对应的列向量：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250611081602.png)

并且此时有 r (A) = r (A|C)

这是因为将 AB = C 拆成多个非齐次线性方程 Ax  = c，这样每一个非齐次线性方程因为有解，所以其增广矩阵 r (A|c)，对 A 经过初等变换变成阶梯型之后 c 的非零行一定小于 A 变换之后的非零行

所以对于 r (A|C)，对 A 进行初等变换变成阶梯型，那么 C 的每一列跟着 A 进行初等行变换与 Ax = c 的操作相同，所以 C 进行同步初等行变换之后非零行不会超过 A，所以 r (A) = r (A|C)




### 单个向量可由其他向量线性表示，向量组整体线性相关的结论

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250607075643.png)
这里只说第二句话
必要性（=>）
如果向量组 $A = (\alpha_{1}, \alpha_{2}, \dots \alpha_{s})$，线性无关，那么对任意一个向量 $\alpha_{i}$，构成的增广矩阵：$[\alpha_{1}, \alpha_{2}\dots \alpha_{s}|\alpha_{i}]$

这个增广矩阵就是原来的向量组，这个向量组是线性无关的，所以向量组作为齐次方程的系数的方程组只有零解，所以 r = s，即增广阵的秩 = s；而对于 $\alpha_{1}, \alpha_{2},\dots \alpha_{s}$ 这些剔除了 $\alpha_{i}$ 的向量组，其秩一定小于等于 s  - 1

所以这个增广矩阵构成的非齐次方程组中增广阵的整体的秩大于系数矩阵的秩，所以无解，所以任意一个向量都不能又其余的向量表示

充分性（<=）
这里用反证法，在任意一个向量都不能由其余的 s - 1 个向量表示的情况下，假设线性相关，可以得到矛盾

这个结论的意思是对这个向量组构成的矩阵作行交换，不改变向量之间的相关性

### 在线性无关的向量组中加一个向量变成线性相关，则加的向量一定可以被原向量线性表示

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250607090940.png)

这里还是用方程组来理解

根据 $\beta_{1}, \beta_{2}\dots \beta_{s}$ 线性无关，所以 $r (\beta_{1}, \beta_{2}\dots \beta_{s}) = s$

那么加上 $\alpha$ 之后线性相关，所以 $r (\beta_{1}, \beta_{2}\dots \beta_{s}|\alpha) < s + 1$

根据增广矩阵的性质 $r (\beta_{1}, \beta_{2}\dots \beta_{s}) \leq r (\beta_{1}, \beta_{2}\dots \beta_{s}|\alpha)$

所以得到 $r (\beta_{1}, \beta_{2}\dots \beta_{s}) = r (\beta_{1}, \beta_{2}\dots \beta_{s}|\alpha) = s$

所以 $\beta_{1}, \beta_{2}\dots \beta_{s}|\alpha$ 构成的非线性方程组有解，并且由于矩阵的秩 = 未知数个数 s，所以解唯一





### 对于行变换不改变矩阵的线性相关性的理解

所谓线性相关性，即 Ax = 0，中的解向量 x 就反应了 A 的线性相关性，x 就是 A 的列向量的相关系数，所以这里对 A 进行初等行变换不改变线性相关性，也就是不改变解向量 x 的值

因为初等行变换相等于左乘一个可逆矩阵 P，即:

$$
PAx = (PA) x = B x = P (Ax) = 0
$$
所以此时的解向量 x 仍然是进行初等行变换之后的矩阵 B 的解

这里的线性相关性不仅仅包括 B 和 A 的极大无关组的对应关系，还包括极大无关组对于其他向量的表示关系，这些 B 和 A 都是相同的

比如假如 B 的前三个向量 $\alpha_{1},\alpha_{2},\alpha_{3}$ 是极大无关组，可以通过 $x_{1}, x_{2}, x_{3}$ 来表示 $\alpha_{4}$，即 $x_{1}\alpha_{1} +x_{2}\alpha_{2} + x_{3}\alpha_{3} = \alpha_{4}$，如果 B 有五个列向量的话，此时对于 B 来说就有一个解向量 x 保证：

$$
[\alpha_{1},\alpha_{2},\alpha_{3},\alpha_{4},\alpha_{5}][x_{1}, x_{2}, x_{3},-1,0]^T = 0
$$

这个解向量就体现了极大无关组 $\alpha_{1},\alpha_{2},\alpha_{3}$ 对向量 $\alpha_{4}$ 的线性表示，同时这个解向量也是初等行变换之前的矩阵 A 的解向量，所以也体现了 A 中的极大无关组对第四个向量的线性表示

因此极大无关组对别的向量的线性表示在初等行变换之后也是一样的

这样就可以：

（1）可以对 A 进行初等行变换到阶梯型矩阵 B，找到 B 对应的极大无关组，同时也就对应的是 A 的极大无关组

（2）B 的极大无关组表示别的向量的系数也就是对应的 A 的极大无关组表示别的向量的系数




### 同秩变换，等价变换，同解变换，不改变列向量线性相关性变换的区别

首先关于秩有矩阵 A 的行向量组的秩（行秩） = 矩阵 A 的秩  = 矩阵 A 的列向量组的秩（列秩）

==同秩变换==

对矩阵 A 进行初等行变换，或者进行初等列变换，不改变矩阵 A 的秩

==等价变换==

矩阵等价，即两个矩阵的秩相等；所以同秩变换就是等价变换

==同解变换==

对矩阵 A 进行初等行变换才是同解变换，初等行变换相当于正常的解方程消元的过程；但是初等列变换不是同解变换，初等列变换会改变方程某一列未知数的系数，不再是原来的方程组

同解变换得到的系数矩阵 B 的行向量组与 A 的行向量组等价（很显然，B 的每个向量都是由 A 初等变换过来得到的，当然可以由 A 的向量线性表示，反之亦然）

也可以说两个矩阵 A 和 B 同解，那么在 A 和 B 的行数相同的情况下，一定可以通过行变换互相转换，比如 A 和 A^TA 就是同解，两者可以通过行变换互相转换，这里 A 是 n * n 阶矩阵

==不改变线性相关性的变换==

对矩阵进行同解变换，不改变方程的解，因此也不会改变列向量的线性表示，所以也是不会改变列向量的线性相关性的变换

### 同解变换与行向量组等价

A 进行同解变换得到的矩阵 B，这两个矩阵的行向量组一定是等价的，因为 A 是通过左乘一个可逆矩阵 P 得到的 B，即 PA = B，同理有 $A = P^{-1}B$

也可以说 A 和 B 同解，那么 A 和 B 的行向量组就是等价的

但是如果说 PA = B，P 没有说可逆，此时只有存在一个矩阵 D，满足 DPA = DB = A，此时才能说 A 和矩阵 B 的行向量组才是等价的

反过来，如果两个矩阵的行向量组等价，那一定是同解的，因为一定有矩阵满足 PA = B 以及 DB = A，这样 Bx =0 的解也一定是 Ax = 0 的解；Ax = 0 的解也一定是 Bx = 0 的解

A 和 B 同解，那么 A 和 B 的行向量互相等价，反过来也成立，但是只有 A 和 B 的行数相同的时候，A 和 B 才能通过初等行变换进行互相转换

### n - r (A) 的理解

对于 AX = 0 这样一个齐次方程组，r (A) 是化作阶梯型之后的非零行的个数，也就是 AX = 0 的有效方程的个数，同时也是主元的个数

n - r (A) 中 n 是未知数的个数，J (A)  = n - r (A) 就是基础解系的极大无关组中向量个数，也就是基础解系中解向量的个数，也是 Ax = 0 中自由未知数的个数



### 判断一个向量组线性无关的方法

==（1）按照定义==

如果 $k_{1}\alpha_{1} + k_{2}\alpha_{2} +\dots k_{m}\alpha_{m} = 0$ 的时候有 k 1 = k 2 = k 3 ... =km =  0，则线性无关

==（2）按照秩==

如果 $r (\alpha_{1}, \alpha_{2},\alpha_{3}\dots \alpha _{m}) = m$，说明线性无关，即秩 = 向量组的个数就说明线性无关

这是因为矩阵的秩 = 行向量组的秩 = 列向量组的秩，这里列向量组的秩是 m，所以这些列向量组成的矩阵 A 的秩就与 Ax = 0 中的未知数的个数相等，所以 Ax = 0 就只有零解，根据定义，线性无关

==（3）如果是方阵，可以按照行列式==

此时列向量组的个数就是 n，列向量组构成的矩阵是 A

如果 |A| = 0，说明 r (A) < n，所以线性相关，如果|A| != 0，说明 r (A) = n，说明线性无关

==（4）按照矩阵乘法进行拆分==

比如一个向量组是 $2\alpha_{1} + \alpha_{2} + \alpha_{3},\alpha_{2} + \alpha_{3},\alpha_{1} + \alpha_{2} + \alpha_{3}$

它是 $\alpha_{1},\alpha_{2},\alpha_{3}$ 右乘一个矩阵得到：


$$
[\alpha_{1},\alpha_{2},\alpha_{3}] \begin{bmatrix}
 2 & 0& 1\\
  1&  1& 1\\
 1 & 1 &1
\end{bmatrix}
$$

那么如果右乘的这个矩阵是可逆的，那就说明向量组 $2\alpha_{1} + \alpha_{2} + \alpha_{3},\alpha_{2} + \alpha_{3},\alpha_{1} + \alpha_{2} + \alpha_{3}$ 与原来的向量组 $\alpha_{1},\alpha_{2},\alpha_{3}$ 秩相等，所以可以通过秩来进行判断

这里右乘的不一定是一个方阵，但是拆分思路是一样的，后面就是根据拆分的两个矩阵的秩的情况来分析向量组的秩的情况

### 向量组线性无关向量个数与秩的关系

向量组中极大线性无关组中向量的个数就是向量组的秩，也就是矩阵的秩

如果这个向量组中所有向量都线性无关，那么矩阵的秩就等于向量的个数（上文按照 Ax = 0 来说明）

### Ax = 0 的解向量组最多有 n - r (A) 个线性无关的解向量；Ax = b 的解向量组最多有 n - r (A) + 1 个线性无关的解向量


首先 Ax = 0，其基础解系的解向量个数就是 n - r (A) 个，基础解系的解向量就是 Ax = 0 解向量组中的极大无关组，所以 Ax = 0 的线性无关的解向量个数最多就是 n - r (A) 个，这个完全正确

那么假如说 Ax = 0 最多有 n - r (A) = s 个线性无关的解：$\alpha_{1},\alpha_{2},\dots \alpha_{s}$

假设 $\eta$ 是 Ax = b 的一个特解

那么对于 $[\alpha_{1} + \eta, \alpha_{2} + \eta..\alpha_{s} + \eta, \eta]$，用最后一列的 $\eta$ 消去前面所有列的 $\eta$ 不会改变这个向量组的秩：$\alpha_{1}, \alpha_{2},\dots \alpha_{3},\eta$，这里由于 $\alpha_{1},\alpha_{2},\dots \alpha_{s}$ 线性无关，所以 $r (\alpha_{1}, \alpha_{2},\dots \alpha_{3},\eta) \geq r (\alpha_{1},\alpha_{2},\dots \alpha_{s}) = s$


$\eta$ 是 $Ax = b$ 的特解，而 $\alpha_{1},\alpha_{2},\dots \alpha_{s}$ 是 Ax = 0 的基础解系，所以 $\eta \ne 0$ 并且不可能由 $\alpha_{1},\alpha_{2},\dots \alpha_{s}$ 线性表示（假如能够线性表示那 $\eta$ 就是 Ax = 0 的解了，显然不成立）

即 $\alpha_{1},\alpha_{2},\dots \alpha_{s}$ 组成的系数矩阵 B，就有 Bx = $\eta$ 无解，所以增广阵就一定有:

$$
r (\alpha_{1}, \alpha_{2},\dots \alpha_{3},\eta) > r (\alpha_{1},\alpha_{2},\dots \alpha_{s}) = s
$$

即 $r (\alpha_{1}, \alpha_{2},\dots \alpha_{3},\eta) =s + 1$

也就是 $r ([\alpha_{1} + \eta, \alpha_{2} + \eta..\alpha_{s} + \eta, \eta]) = s + 1$

这 s + 1 个向量都是 Ax = b 的解，并且线性无关 (r = s + 1 = 向量个数)

所以 Ax = b 的线性无关的解的个数至少就是 s + 1 个

假如 Ax = b 的线性无关的解的个数多于 s + 1 个是 s + 2 个，假设是 $\eta_{1}, \eta_{2}\dots \eta_{s + 2}$，这 s + 2 个列向量线性无关，所以 $r (\eta_{1}, \eta_{2}\dots \eta_{s + 2}) = s + 2$

那么对这 s + 2 个向量组成的矩阵进行列变换，不改变矩阵的秩：

$$
r (\eta_{1}, \eta_{2}-\eta_{1}, \eta_{3} - \eta_{1}, \dots \eta_{s + 2}-\eta_{1}) = s + 2
$$

这 s + 2 个向量仍然线性无关，因此其部分组也线性无关，即 $\eta_{2}-\eta_{1}, \eta_{3} - \eta_{1}, \eta_{s + 2}-\eta_{1}$ 这 s + 1 个向量线性无关，而这 s + 1 个向量又是 Ax = 0 的解，所以这样就会得到 Ax = 0 的线性无关的解的个数大于 s 个，但是其基础解系也才 n - r (A) = s 个，所以矛盾

所以 Ax = b 的线性无关的解的个数最多就是 n - r (A) + 1 = s + 1 个


注意这里 Ax = 0 和 Ax = b 的线性无关的解向量个数分析都是分析两者的一个解向量组中最多线性无关的解向量的个数，得先挑出一些解向量放到一个组中，然后研究他们的线性相关性；当然也可以说最多在解向量中找到 s 或者 s + 1 个向量线性无关


### 基变换中过渡矩阵的唯一性和可逆性

基变换如下：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250620081014.png)

由于 $\alpha_{1}, \alpha_{2}, \dots \alpha_{s}$ 是列满秩的，并且互相线性无关，所以单个矩阵方程组 $c_{11}\alpha_{1}+ c_{21}\alpha_{2}+\dots +c_{s 1}\alpha_{s} = \beta_{1}$ 中，$r (\alpha_{1}, \alpha_{2}\dots \alpha_{s}) = s$，即有效方程的个数等于未知数的个数，所以有唯一的解，所以 $c_{11}, c_{21}\dots$ 有唯一的解

所以过渡矩阵就有唯一的解，即过渡矩阵唯一

如果过渡矩阵 P 不可逆，即 r (P) < s，那么 $r (\beta_{1}, \beta_{2}, \dots)\leq r (\alpha_{1}, \alpha_{2}, \dots)$ 且 $r (\beta_{1}, \beta_{2}, \dots) < r (P) = s$，所以 $r (\beta_{1}, \beta_{2}, \beta_{3}\dots) < s$，出现矛盾，所以 P 一定是可逆的

综上，如果一个向量空间的两组基之间有 $B = AP$，B 和 A 分别是两组基构成的矩阵，那么 P 一定是唯一的并且可逆

同时 B 向 A 进行变化有 $BA^{-1} = P$，并且如果题目给出了 A 和 B 是一个方阵，那么 A 和 B 都是满秩矩阵，所以可以通过 $BA^{-1} = P$ 得到 P

### 向量 $\eta$ 在不同基下的坐标变换公式

如果一个向量 $\eta$ 在向量空间两个基 $\alpha_{1}, \alpha_{2}\dots\alpha_{s}$, $\beta_{1}, \beta_{2}, \dots \beta_{s}$ 下的坐标分别是 $x_{1}, x_{2}, x_{3}\dots x_{s}$, $y_{1}, y_{2}, y_{3}\dots y_{s}$

即：$\eta = (\alpha_{1}, \alpha_{2}\dots\alpha_{s})(x_{1}, x_{2}, \dots x_{s})^T = (\beta_{1}, \beta_{2}\dots\beta_{s})(y_{1}, y_{2}, \dots y_{s})^T$


并且这两个基之间有基变换：$(\beta_{1}, \beta_{2}\dots \beta_{s}) = (\alpha_{1}, \alpha_{2}\dots\alpha_{s}) P$

那么对于 $\eta$ 有：

$$
\eta = (\alpha_{1}, \alpha_{2}\dots\alpha_{s})(x_{1}, x_{2}, \dots x_{s})^T = (\alpha_{1}, \alpha_{2}\dots\alpha_{s}) P (y_{1}, y_{2}, \dots y_{s})^T
$$

即 $\eta = Ax = APy$

经过变换即：$A (x - Py) = 0$，由于 A 的有效方程个数（秩）等于未知数个数，所以 A $\xi = 0$ 只有零解，即 $x  - Py = 0$，所以 x = Py，由于 P 可逆，即 $xP^{-1} = y$

也就是通过两个基之间的变换得到向量 $\eta$ 分别在两者基下的坐标的变换

**这个公式记住推导原理**

### 特征值对应的特征向量的性质

### 特征值重数为 1 的情况分析 + r (A) = 1 的矩阵 A 的相似对角化情况分析

假设 $\lambda$ 的特征值的重数为 1，此时其对应的特征向量是 $(A - \lambda E) x = 0$ 的解

由于 $|A - \lambda E| = 0$，所以一定有非零解，即基础解系的解向量个数>= 1，而又根据特征值的几何重数必然<=代数重数，所以基础解系的解向量个数 <= 1

所以特征值 $\lambda$ 的重数为 1 的时候对应的最大线性无关的解向量个数就是 1 个

根据此，可以判断一个 r = 1 的矩阵 A 的相似的对角化情况；

对于一个 r = 1 的矩阵，其特征值是一个 1 重的 tr (A) 和 n - 1 重的 0

假设 tr (A) != 0

对于特征值 = 0 的情况，对应的最大的线性无关的特征向量个数就是 Ax = 0 的基础解系解向量的个数，由于 r (A) = 1，所以 Ax = 0 的基础解系的解向量个数就是 n - 1 个；即对于 n - 1 重的特征值 0，其对应最多 n - 1 个线性无关的解向量；即对于 n - 1 重的特征值 0，其几何重数等于代数重数

对于特征值 = tr (A) 的情况，其是 1 重，根据上文，显然有几何重数等于代数重数；综上当 tr (A) != 0 的时候 A 可相似对角化

假设 tr (A) = 0，此时特征值= 0 就是 n 重特征值；但是 Ax = 0 对应的基础解系的解向量的个数是 n - 1 个，也就是特征值 0 对应的最多的线性无关的特征向量个数，此时特征值 0 的几何重数！= 代数重数，所以 A 不可相似的对角化

### 对矩阵 A 进行相似对角化的理解

### $A^n$ 问题的处理

**（1）r = 1，拆成一个列向量乘行向量**

这种情况直接将这个矩阵拆乘一个列向量乘一个行向量，然后直接乘，按照结合律结合行向量和列向量的乘积即可

**（2）拆成一个幂零矩阵 + 对角阵（A = B + kE），然后使用二项式定理**

幂次方几次之后就是零矩阵了

**（3）用相似对角化 $P^{-1}A P=  \wedge$ 来做**

**（4）如果（1）（2）（3）都用不了，那就算几次然后找规律了**


### 实对称矩阵可正交相似对角化的充要性

一个实对称矩阵一定可以正交相似对角化，即一定存在一个正交矩阵 P 使得实对称矩阵 A 有：

$$
P^{-1} A P = \wedge
$$
反过来，如果一个矩阵 A 可以进行正交相似对角化，那么这个矩阵也一定是实对称矩阵

即假如有 $P^{-1} A P = \wedge$，并且 P 是正交矩阵，那么变换得到：

$$
A = P \wedge P^{-1} = P\wedge P^T
$$

上式等式两边取转置得到：

$$
A^T = (P^T)^T \wedge^T P^T = P \wedge P^T = A
$$

所以 A 也一定是一个实对称矩阵


另外需要注意的是，实对称矩阵自己可以进行普通的相似对角化，也可以进行正交相似对角化

这种思路的正确是，只剩下最后一个二重特征值 $\lambda = 1$ 的时候其一定会对应两个线性无关的特征向量与 (1, 1, 1) 正交（根据对称矩阵的形式）

也就是说，属于最后一个特征值 $\lambda = 1$ 的两个线性无关的特征向量 $\alpha_{1}, \alpha_{2}$ 一定在下图与 (1, 1, 1)  = $\alpha_{3}$ 垂直的平面上：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250623124542.png)

那么与 $\alpha_{3}$ 垂直的任意一个向量，即方程 x 1 + x 2 + x 3 = 0 的解向量，也一定在这个平面上，于是就一定可以被 $\alpha_{1}, \alpha_{2}$ 线性表示，从而一定是属于 $\lambda_{1} = 1$ 的特征向量；所以可以认为与 (1, 1, 1) 正交的非零向量都是 $\lambda_{1} = 1$ 的特征向量，通过列方程，随意赋值得到两个线性无关的解向量当作 $\lambda_{1} = 1$ 的两个特征向量

==但是，如果不是剩下最后一个特征值，这种思路就是错误的==

比如一个三阶矩阵 A，其特征值是 $\lambda_{1}, \lambda_{2}, \lambda_{3}$，已知 $\lambda_{1}$ 的特征向量是 $\alpha_{1} = (a, b, c)$

那么就绝对不能认为与 $\alpha_{1}$ 正交的向量都是属于 $\lambda_{2}$ 或者 $\lambda_{3}$ 的特征向量

因为与 $\alpha_{1}$ 正交的向量，即 $ax_{1}+bx_{2} +cx_{3} = 0$ 的解向量是在与 $\alpha_{1}$ 垂直的平面上：

![image.png200\*200](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250623125249.png)

假设 $\lambda_{2}$ 的特征向量是 $\alpha_{2}$，$\lambda_{3}$ 的特征向量是 $\alpha_{3}$，这两个向量同样是在上图与 $\alpha_{1}$ 垂直的平面上，并且 $\alpha_{3}$ 与 $\alpha_{2}$ 线性无关

所以这个平面上的任意一个向量都可以用 $\alpha_{2}$ 与 $\alpha_{3}$ 线性表示

那么对于 $ax_{1}+bx_{2} +cx_{3} = 0$ 的解向量，即这个平面上的某个向量 $x_{i}$，其很可能是 $\alpha_{2},\alpha_{3}$ 的线性组合即：$x_{i } = k_{2}\alpha_{2} + k_{3}\alpha_{3}$ 且组合系数不是零

那此时 xi 是分别属于不同特征值的两个特征向量的线性组合，并且 xi 与 $\alpha_{1}$ 正交，但是 xi 不是 A 的特征向量

所以这种思路来求解 A 的剩下的特征向量就是错误的

### 对称矩阵 A 与 A 伴随的相似对角化使用的正交矩阵 Q 是同一个正交矩阵

根据 $Q^{T}AQ = \wedge$ 两边取伴随得到 $Q^{*} A^{*} (Q^{T})^{*} = \wedge^{*}$

根据 $Q^{*} = |Q|Q^{-1} = |Q|Q^{T}$，得到：

$$
|Q|Q^{T} A^{*} (Q^{*})^{T} = \wedge^{*} = |Q| Q^{T} A^{*} (|Q|Q^{T})^{T} = (|Q|)^{2}Q^{T}A^{*}Q
$$

正交矩阵的特征值只可能是-1 或者 1，所以得到：

$$
Q^{T}A^{*}Q = \wedge^{*}
$$

即对称矩阵的伴随矩阵相似对角化的过程中使用的 Q 矩阵与原对称矩阵使用的 Q 矩阵是相同的

同样，A + $A^{*}$ 在相似对角化的过程中使用的仍然是矩阵 Q

### AB = BA，则 A 对应 n 个互不相同的特征值的时候，A 的特征向量都是 B 的特征向量

这里假设 $Ax = \lambda x$

x 是 A 的特征向量

那么对于 AB = BA，右乘一个 x，得到：

ABx = BAx = B $\lambda$ x = $\lambda$ Bx

如果 Bx ！= 0，那么 Bx 一定是 A 的特征向量，Bx 既然是 A 的属于 $\lambda$ 的特征向量，那么 Bx 一定与 A 的特征向量 x成比例，即 Bx = $k$ x，那么显然，x 就是 B 的特征向量

如果 Bx = 0，那么显然 x 就是属于 B 的特征值为 0 的特征向量

所以 A 的任意一个特征向量 x 都是 B 的特征向量

### 二次型的可逆线性变换说明的东西 + 可逆线性变换与合同的关系

如下：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250630075558.png)

对二次型 f (X) 进行另外一组变量 g (Y) 线性表示，其实就是有一个矩阵 C 满足
$$
x = Cy
$$
这个过程就是指对 x 进行了线性变换

将 Cy 代入到 f (x 1, x 2, x 3, ... xn)，可以得到：
$$
g (y_1, y_2, y_3... y_n) = f (x_1, x_2, x_3, ... x_n)
$$
假设 A，B 分别是 f 和 g 两个二次型的矩阵，那么有：
$$
C^T A C = B
$$

二次型的可逆线性变换说明的就是上面三个关系等价，对二次型 f 进行线性变换变成 g，假设 A，B 分别是 f 和 g 两个二次型的矩阵，当 $x = Cy$ 的时候就有 $C^T A C = B$

==因此两个二次型的变量经过可逆线性变换 x = Cy 的话，那么这两个二次型的矩阵一定是合同的==

==对二次型的变量进行可逆线性变换，无论是否化成了标准型，这就是对二次型的矩阵进行合同变换，不改变二次型的正负惯性指数==

### 易错点：二次型标准化与正交标准化

如果 f 的二次型矩阵是 A，f 进行标准化变成二次型 g，g 对应的矩阵是 B，B 是一个对角阵

则 $C^{T}AC = B$ 是肯定的，这两个二次型的矩阵之间一定合同，且 f 的变量 X 与 g 的变量 Y 有 X = CY，这里的 C 一定可逆，任意一个二次型一定可以通过正交变换成一个标准型

但是 C 不一定是正交矩阵，即不一定有 $C^{-1}AC = B = C^{T}AC$，B 这里的对角线元素不一定是 A 的特征值！

虽然 A 一定可以通过正交变换成一个对角阵，但是在一般情况下，C 矩阵只是一个可逆阵，而不是正交阵，只用正交变换 f -> g 才是一个正交阵，并且正交变换下 A 与对角阵B 即合同又相似
### 二次型的正负惯性指数的理解

如果一个二次型的矩阵是 A，那么我们总是可以将 A 进行正交变换成一个对角矩阵 $\wedge$

即 $C^TAC = C^{-1}AC = \wedge$

这个对角矩阵的对角线元素就是矩阵 A 的特征值了

### 平方和二次型的性质

所谓平方和二次型，就是类似下面形状的二次型：

### 二次型正定 <=> 二次型矩阵 A 与单位阵 E 合同

**必要性：**

A 一定可以化成一个标准型，由于 A 正定，并且线性变换不改变二次型的正定性，所以这个标准型就是正定的，所以这个标准型的系数一定都是大于 0 的，而这个标准型又可以化为一个规范型，所以这个规范型就是一个系数都 = 1 的二次型，这个规范型的二次型的矩阵就是 E

所以对于 A 来说就可以通过线性变换成一个单位阵 E，也就是 A 与 E 合同

**充分性：**

A 与 E 合同，那么就是 A 可以通过一个线性变换变到单位阵 E，单位阵对应的二次型是正定的，所以 A 也是正定的

### 二次型正定 <=> 二次型 A 可以写成 $A = P^TP$，其中 P 可逆

根据上文二次型正定，A 与单位阵合同，即 $C^T A C = E$，这里左乘 $(C^T)^{-1}$，右乘 $C^{-1}$，得到 $A = (C^{-1})^TC^{-1}$

这里的 P 就是 $C^{-1}$

这个性质与上文 A 与单位阵 E 合同是一个意思
