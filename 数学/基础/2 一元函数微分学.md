### 6 导函数在某点存在与连续的区别以及各自的处理方式

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250418112018.png)

导函数在某点的值，即导函数在某点存在，可以通过对原函数使用定义来判断导函数在这一点处是否存在值，导函数在某点存在，也就是原函数在这点处可导

导函数在某点 x 0 连续，则必须求出导函数在不等于 x 0 的区间的表达式，然后对导函数的式子取极限来判断导函数在 x 0 的极限是否等于导函数在 x 0 点的值

导函数在某点 x 0 存在并不意味着导函数在这一点连续，对原函数使用导数的定义求左右导数并不是导函数在这个点处的左右极限

所以这道题目对原函数使用导数的定义求得到的关于 $\alpha, \beta$ 的范围只是决定了导函数在这一点存在值
对于连续性，还得分别在 0 左右求导得到导函数的解析式，然后取极限判断是否连续


### 7 对导数定义的深刻理解

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250418113400.png)

**导数的定义必要要有两个要素：**
**（1）分子必须是一个动点，一个静点**
**（2）分子分母必须是从两侧趋近静点**

一动一静点是为了保证函数连续，两侧趋近是为了保证左右导数一样，对于分子和分母中的变化量，两者可以不一样，只要保证同阶就可以了，因为同阶的话分母可以进行等价无穷小替换，从而替换成分子中的变化量，只是多了系数

A：只是一侧趋近
B：分母可以等价替换为分子的变化量，所以可行，**所以在导数定义的处理中，哪怕分子和分母的变化量不一样，其实也可以通过等价替换成一样的**
C：虽然可以从两侧趋近，但是分子分母不同阶，对分母进行替换后的结果是：

D：这个极限都不是一个动点一个静点，甚至无法得到在 0 处连续；
比如这里是一个符号函数：

### 10 微分定义的理解

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250421091854.png)

题中说明 x = -1 的时候 dx = -0.1, dy = 0.1，因此 y 在 x = -1 处的导数就是-1，即：

$f'(x^2)2x|_{x=-1} = -1$，从而求得 f' (1) = 0.5

这里的 dx 和 dy 并不是趋于零才有意义，dy 和 dx 的对应关系是 $dy = f'(x_{0}) dx$ 这里可以将 dx 看作自变量，dy 看作 dx 的函数
