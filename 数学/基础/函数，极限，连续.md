## 数列极限

### 1 利用数列极限定义来证明收敛

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250414095549.png)

充分性，对于任意的 $\epsilon_{0} \in (0, 2)$，令 $\epsilon = \frac{1}{2} \epsilon_{0}$，则根据题意，一定有正整数 N, 当 n>= N 的时候，|xn - a| <= $\epsilon_{0}$

如果对于任意的一个数 b >= 2，因为一定有 N, 当 n >= N 的时候|xn - a| <= $\epsilon_{0}$，因此|xn - a| <= $\epsilon_{0}$ < b

所以对于一个任意的 $\epsilon_{2}$，都存在一个 N，当 n >= N 的时候 $|x_{n} - a| \le \epsilon_{2}$，所以收敛于 a


### 2 数列极限的加减运算存在性判断

![image.png|547x282](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250414103704.png)

> [!NOTE]
> （1）xn 极限存在，yn 极限存在，则 xn $\pm$ yn 极限存在
> （2）xn 极限存在，yn 极限不存在，则 xn $\pm$ yn 极限不存在
> （3）xn 极限不存在，yn 极限不存在，则 xn $\pm$ yn 极限无法判断，可能两者直接抵消了，比如 xn = n = yn
>
