## 无穷小及其阶数

### 12 易错点：同阶无穷小没有高阶无穷小的运算性质 + 不同阶无穷小的运算性质

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250416100806.png)

这道题目不能这样做：即如果 b = 1，那么 x - tanx 是三阶无穷小，然后 a + cx^2+dx^3 也是 x^3 的同阶无穷小，所以整体是 x^3 同阶无穷小，不是 x^3 的高阶无穷小，所以 b 不能等于 1；这种做法的错处在于同阶无穷小运算之后可能消去某些项，其无穷小阶数可能会发生变化的

比如 $x^3 - \sin x^3$，这两项都是 x^3 的同阶无穷小，但是运算之后消掉了 x^3就变成了 x^6 的同阶无穷小，同阶无穷小并没有高阶无穷小加减的吸收性质

但是如果两项是不同阶的，则跟高阶无穷小的运算性质一样，仍然是低阶的吸收高阶的，比如 $x^2 + x^6$，这个式子整体是与 $x^2$ 同阶的无穷小

无穷小总结：
（0）一般一个式子有自己的无穷小阶数，如果说它是 x^k 的高阶无穷小的话，记作 o (x^k)，但是其阶数不是k 阶，一般无穷小的运算性质是指高阶无穷小的运算
（1）如果 f (x) 和 g (x) 可以确定阶数并且不是同阶无穷小的话，两者加减乘符合高阶无穷小的运算性质，即低阶吸收高阶，乘起来其无穷小的阶数也会相乘，可以确定运算之后的无穷小阶数
（2）如果 f (x) 和 g (x) 可以确定阶数并且两者是同阶无穷小的话，乘可以，但是加减不好说，不能确定最后结果的无穷小阶数，因为 f (x) 和 g (x) 中的低阶可能直接抵消了，最后阶数可能变大，最好的方法是将 f (x) 和 g (x) 写成确定的阶数跟上一个高阶无穷小的尾巴，然后代换进行计算比如下文 14 题，比如 x^3 - sin x^3
（3）如果 f (x) 和 g (x) 不能确定阶数，只知道是某个阶数的高阶无穷小，那么直接按照高阶无穷小的运算性质计算即可

这道题目正确做法是用泰勒展开

## 单调有界准则

### 17 根据递推关系利用数列极限的单调有界性来证明极限存在

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250417085108.png)

首先，题目中说了极限存在，那么可以在草稿上根据 $x_{n+1} \sqrt{ 6 + x_{n} }$ 两边取极限算出来极限 A = 3 or -2；由于是根号，所以-2 舍去

然后多写几次结果，x 1 = 10, x 2 = 4, x 3 = sqrt (10)，所以猜测这个数列就是单调递减有下界，下界可能就是 3

（1）答题通法
于是答题的时候就围绕单调减，并且有下界来证明

首先证明有界，一般而言我们求出的极限 3 就是下界，所以可以直接利用数归来证明 xn >= 3，这个很容易证明，不再赘述

这里证明单调递减的时候可以做除法 $\frac{x_{n+1}}{x_{n}}$ 根据 xn 的有界性可以发现这个是小于等于 1 的，所以是递减的

这种题目一般就是从单调性和有界性两个方面证明，但是在草稿上我们可以先求出极限，然后猜测递增还是递减，利用极限作为上界或者下界证明有界，然后利用有界性证明单调

（2）证明单调性的方法

这里还可以作差证明，即证明 $x_{n +  1} - x_{n}  \le 0$，将 xn+1 的表达式代入并有理化，于是我们要证的就转化为：$\frac{x_{n} - x_{n-1}}{\sqrt{ 6 + x_{n} } + \sqrt{ 6 + x_{n - 1} }} \le_{0}$，那么对于 xn - xn-1 我们继续往前递推，要证的就转化为 xn-1 - xn-2 <= 0，这样一步步转化为要证 x 2 - x 1 <= 0，显然这个是成立的，于是反推回去 $x_{n+1} - x_{n} \le 0$ 就成立，有点类似于数归

**结论：对于 $x_{n + 1} = f(x_{n})$ 这样的式子一般都可以用上述方式证明，对于 $x_{n+1} = f(x_{n})$，如果 f 是单调递增的，那么{xn}这个数列就是单调的，至于单调增还是单调减取决于 x 2 和 x 1，如果 x 2 > x 1 那就是单增，如果 x 2 < x 1 那就是单调减**

这个结论的正确性在于，xn+1 - xn 可以写成 $x_{n + 1} - x_{n} = f(x_{n}) - f(x_{n-1})$，那么如果 f 是单调增的，那么这个差值的正负就取决于 xn 和 xn-1 的正负，而 xn 与 xn-1 作差又可以继续往前取决于 xn-1 和 xn-2 的正负，一直递推到 x 2 - x 1，当 x 2 - x 1 > 0 的时候由于 f 单调增，因此 f (x 2) - f (x 1) > 0，因此推出 x 3 > x 2，继续推出 x 4 > x 3 一直推出 xn+1 > xn，那么 {xn}就是递增的了

如果 xn+1 = f (xn) 中 f 是单调减的，那么{xn}一定不单调

### 21 间断点的判断

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250417120819.png)

一般来说函数无定义（比如分母为零），或者有绝对值导致函数在点的左右发生变化的点都可能是间断点，然后在这些候选间断点左右求极限并与函数值比较从而验证这个点到底是不是间断点；因为考研涉及的大多是初等函数的组合，所以其他的点就不用研究了

这道题目分母为零的点都可能是间断点，也就是所有 x 整数的点可能是间断点

观察分子，可以发现 x  = -1， 0， 1 的时候分子分母是 0 比 0 型的式子；而 x 取其他整数的时候分子是一个数，分母是零，所以是无穷间断点

然后就是验证-1， 0， 1 这三个点了；我们分别在这三个点两边取极限计算即可
