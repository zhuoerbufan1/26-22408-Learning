### f (x) 在 x 0极限存在与|f (x)|在 x 0极限存在的关系

（1）f (x）存在 = A，可以推出|f (x)|存在，结果就是|A|，但是反过来不行
（2）f (x) 存在 = 0，可以推出|f (x)|存在，结果就是 0，反过来也可以

==看一道例题==

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20251115194806.png)

这道题显然|f (x)|存在并且是 0，那么显然可以推出 f (x) 存在，结果就是 0

于是这道题可以变换为：

$$
\lim_{ x \to a } \frac{|f(x) - f(a)| }{x -a}存在 = A
$$

加上绝对值，也就是：

$$
\lim_{ x \to a } | \frac{f(x) - f(a)}{x-a}|存在 = |A|
$$

这个带绝对值的左右极限，那么就有：

$$
\lim_{ x \to a+ } \frac{|(f(x)-f(a))|}{x-a} =\lim_{ x \to a- } - \frac{|(f(x)-f(a))|}{x-a} = |A|存在
$$

这个右极限刚好与 $\lim_{ x \to a } \frac{|f(x) - f(a)| }{x -a}存在 = A$ 是相等的，左极限刚好是它的左极限

所以 A = -A = |A| ，所以 A= 0

因此：

$$
\lim_{ x \to a } | \frac{f(x) - f(a)}{x-a}|存在 = 0
$$

所以根据|f(x)|存在，得到 f(x) 存在：

$$
\lim_{ x \to a } \frac{f(x) - f(a)}{x-a}存在，结果就是0
$$

（1）当 g (a) = 0 的时候 f (x) 在 x = a 处可导

\lim_{ x \to a } \frac{|x - a| g(x)}{x - a} = f'(a)(定义)
$$

只有当 g (a) = 0 的时候这里极限才存在

### 曲率和曲率半径公式

曲率是 K，曲率半径是 1/K

K 的两个公式如下：

曲率 K 的公式：

**参数方程：**
$$
K = \frac{|x^{'}(t)y^{''}(t) - x^{''}(t)y^{'}(t)|}{[x^{'}(t)^2 + y^{'}(t)^2]^{\frac{3}{2}}}
$$
也就是分子是两个式子一阶导和二阶导乘积的差值，分母是两者一阶导平方和开 3/2 次方

**一般方程：**

这是知道了 y (x) 的公式，这里可以将 x 看作参数，所以公式变成：
$$
K = \frac{|y^{''}(x)|}{[1 + y^{'}(x)^2]^{\frac{3}{2}}}
$$
曲率取个倒数就是曲率半径，注意曲率圆的半径是 K 的倒数，而如果题中给出了曲率圆的方程，其常数项其实是曲率半径的平方，别傻乎乎的直接将这个平方数代入了当作半径

y = f (x) 与 x 0 处的曲率圆具有相同的曲率和切线

### 极值点和拐点和驻点的定义

==极值点的定义是：==

x 在 x 0 的一个邻域中 f (x) > f (x 0) 则 x 0 是极小值点，极大值点也是这样定义

**此处是严格小于，并且不要求 f (x) 在 x 0 处可导，也不要求 f (x) 在 x 0 处连续，只要有定义即可**

==拐点的定义：==

连接 f (x) 凹弧和凸弧的点，即 f (x) 一阶导单调性变化的点

**此处 f (x) 必须在拐点 (x 0, f (x 0)) 处连续，但是拐点处的一阶导可以不存在**

==驻点的定义：==

使得函数的一阶导 $f'(x) = 0$ 的点是驻点

**驻点不一定是极值点，极值点也不一定是驻点，不过加上可导之后，极值点当然就是驻点，但是驻点还是不一定是极值点**

### 极值点和拐点的充分条件

==极值点的充分条件：==

**（1）f (x) 在 x 0 处连续，在 x 0 的去心领域可导，如果 x 0 左右的 f' (x) 变号，则 x 0 是极值点，如果同号，则不是极值点（教材原话）**

<font color="#2DC26B">第一充分条件使用的前提是 f (x) 在 x 0 处必须连续</font>，并且 f (x) 在 x 0 的去心领域可导，此时才能通过判断 x 0 左右两侧的导数符号来判断 x 0 是否是极值，以及是极大值还是极小值，如果不连续，则判定条件失效：

如果函数不连续，则判断失效，比如下面：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250425114243.png)

此时这个点左侧函数大于零，右侧小于零，但是根据定义这个点不是极大值，这就是因为此处函数不连续

**（2）f (x) 在 x 0 二阶可导，在 x 0 处 f' (x) = 0， f'' (x) != 0，则 x 0 是极值点**

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250504102308.png)


**（3）f (x) 在 x 0 n 阶可导，在 x 0 处前 n-1 阶导全部为 0，且 $f^{(n)} (x_{0}) \ne 0$，如果 n 是偶数，则 x 0 是极值点**

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250504102324.png)


==拐点的充分条件：==

**（1）连续函数 f (x)，在 x = x 0 两侧 f'' (x) 异号，则 (x 0, f (x 0)) 是 f (x) 的拐点，如果在 x = x 0 两侧 f'' (x) 不异号，则不是拐点（数分教材原话）**

这里必须连续，如果不连续，则不是拐点

**（2）f (x) 在 x = x 0 的领域内三阶可导，且 f'' (x 0) = 0，f''' (x 0) != 0，则 (x 0, f (x 0)) 是 f (x) 的拐点**

**（3）f (x) 在 x 0 n 阶可导，在 x 0 处从二阶导到 n-1 阶导全部为 0，且 $f^{(n)} (x_{0}) \ne 0$，如果 n 是奇数，则 (x 0, f (x 0)) 是 f (x) 的拐点**

### 极值点和拐点的必要条件

==极值点的必要条件==

f (x) 在 x 0 可导，并且在 x 0 处取得极值，则 f' (x 0) = 0

反过来不行，比如常函数

极值可以在驻点，或者一阶导不存在的点取得

==拐点的必要条件：==

f (x) 在 x 0 有二阶导数，并且在（x 0, f (x 0)）处是拐点，则 f'' (x 0) = 0

反过来不行，比如常函数

拐点可以在 f'' (x) = 0，或者二阶导不存在的点取得


### 极值点和拐点的计算方法和区别

==极值点的计算方法：==

极值只可能在驻点或者不可导点中取得，因此我们挨个考察驻点和不可导点，对这些点挨个使用充分条件，判断左右两侧符号，**如果异号则是极值点，如果同号，则不是极值点**

当然有可能三大充分条件全部失效 （一般题目不会出这样的）比如 f (x) 在 x 0 处不连续，此时可以用定义来考察这个点

==拐点的计算方法：==

根据拐点的必要条件，拐点只可能在二阶导等于零和二阶不可导点中取得，因此我们挨个考察这些点两侧二阶导的符号，**如果异号则是拐点，如果同号则不是拐点**

当然有可能这个点不是 f (x) 的连续点，不连续那肯定就不是拐点（不满足定义）

### 极值点和拐点第一充分条件使用前提的区别和联系

（1）极值点要求 f (x) 在 x 0 处必须连续才能使用第一充分条件，如果不连续则应该用定义判断；拐点也要求在 x 0 处连续才能使用第一充分条件，如果不连续就不符合拐点定义，肯定不是拐点

（2）同时拐点第一充分条件的使用并不要求一阶导在 x 0 处连续，极值点的第一充分条件也不要求一阶导在 x 0 处连续

第一充分条件一般是选填中判断极值点和拐点的最常用方法，只要函数连续，就可以使用，如果不连续，那么无论是极值点还是拐点的判断方法全部失效，这个点是否是极值点得用定义，并且一定不是拐点

### 极值点和拐点对原函数，导函数，二阶导的存在性要求

==极值点==

极值点必须要求原函数在 x 0 处存在，不要求原函数 f (x) 在 x 0 连续，也不要求导函数，二阶导在 x 0 处存在

==拐点==

拐点必须要求原函数在 x 0 处连续，不要求导函数，二阶导在 x 0 处存在


因此在图像判断极值点和拐点的时候，一般给出的是 f' (x) 和 f'' (x) 的图像，这个图像中的不存在的点也要用充分性进行考察

### 极值点和拐点的联系和区别

==拐点和极值点的联系和区别==

**（1）f (x) 在拐点处必须连续，但是 f (x) 在极值点处不一定连续**

**（2）拐点处的一阶导可以不存在，极值点处的一阶导也可以不存在**

**（3）一个函数的拐点和极值点可以同时取得，但是此处的导数一定不存在，这个函数的脑袋一定是尖尖的，对于函数的可导点，极值点和拐点无法同时取得**
![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250424084834.png)

（4）**拐点不能简单看作是一阶导的极值点，因为此处的导数可以不存在**，比如上面脑袋尖尖的函数；这是因为拐点本质上来说是原函数 f (x) 的性质，是连接一段凹一段凸的点，这个点处当然可能函数导数不存在

（5）判断极值点是找到一阶导等于零和不存在的点；判断拐点是找到二阶导等于零和不存在的点；判断方法都是观察两侧的一阶导和二阶导符号，变号则是极值点或者拐点，不变号则不是极值点或者拐点；区别在于当 f (x) 在 x 0 不连续，第一充分条件判定失效，此时判断极值点的时候需要用定义，而拐点可以直接根据不连续判定 x 0 不是拐点

### 质心和形心公式

形心是均匀质量下的质心，记住质心公式即可

假如一个平面的质量是 $\rho(x, y)$，那么质心的坐标 x 的公式是，横坐标与质量微元的乘积全部加起来除以质量微元全部加起来：

$$
\bar{x} = \frac{\iint x\rho(x, y)dxdy}{\iint \rho(x, y)dxdy}
$$ 
质心的坐标 y 的公式是，纵坐标与质量微元的乘积全部加起来除以质量微元全部加起来：

$$
\bar{y}=\frac{\iint y\rho(x, y)dxdy}{\iint \rho(x, y)dxdy}
$$

上面就是质心的公式了

当质量均匀的时候（质量为常数）上面公式就退化成形心的公式：

$$
\bar{x} = \frac{\iint xdxdy}{\iint dxdy}，\bar{y} = \frac{\iint ydxdy}{\iint dxdy}
$$

## 多元函数微分学

### 多元可微和一元可微的写法和用法

下面的式子均保证在 (x0, y0) 处可微

==多元可微==

如果f (x, y) 在 (x0, y0) 处可微，则可以写成
$$
f(x, y) - f(x_{0}, y_{0}) = f_{x}'(x_{0},y_{0})(x - x_{0}) + f_{y}'(x_{0}, y_{0})(y - y_{0}) + \rho(\sqrt{ (x-x_{0})^{2} + (y - y_{0})^{2} })
$$
这里的 $\rho$ 是x -> x0, y -> y0时候的无穷小

另外一种等价的写法：

$$
f(x_{0} + \Delta x, y_{0} + \Delta y) - f(x_{0}, y_{0}) = f_{x}'(x_{0}, y_{0})\Delta x + f_{y}'(x_{0}, y_{0})\Delta + \rho(\sqrt{ \Delta x^{2} + \Delta y^{2} })
$$

这里的 $\rho$ 是 $\Delta x, \Delta y$ 趋于0的无穷小

当x0 = y0 = 0的时候可以写成：

$$
f(x, y) -f(0,0) = f_{x}'(0, 0)x + f'_{y}(0, 0)y + \rho(\sqrt{ x^{2} + y^{2} })
$$

同样可以写成：

$$
f(\Delta x, \Delta y) - f(0, 0) = f'_{x}(0 ,0)\Delta x + f'_{y}(0, 0)\Delta y
$$

==一元可微==

$$
y(x) - y(x_{0}) = y'(x_{0})(x - x_{0})+o(\sqrt{ (x - x_{0})^{2} })
$$


同样可以写成：

$$
y(x_{0} + \Delta x) - y(x_{0}) = y'(x_{0})\Delta x + o(\sqrt{ \Delta x^{2} })
$$
 当x 0 = 0的时候可以写成：

$$
y(x) - y(0) = y'(0)x + o(x)
$$

同样可以写成:

$$
y(\Delta x) - y(0) = y'(0)\Delta x + o(\Delta x)
$$


上述的写法都是恒等式，可以在一些式子中进行替换，尤其是在一些极限式子中，比如x -> x0, y->y0的时候进行替换，上式中的无穷小项一般变成了分母的无穷小项，其余项可以根据题目条件进行处理

上面的恒等式的用处在于，它可以直接恒等替换f (x, y)【虽然要带个无穷小量】，那么在x->x0, y->y0的条件下，尤其是在一些极限中，进行恒等替换之后可以方便得到结果

==看一个例子==

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20251023130616.png)



这道题经过换序，积分中值定理，等价代换之后可以得到：

$$

\lim_{ x \to 0 } - \frac{f(\eta,x)}{x},\eta \in(0, x^{2})
$$

由于f (x, y) 在0,0处可微，所以可以直接用上文f (x, y) 在0, 0处的可微恒等式进行替换：

$$
\lim_{ x \to 0 } - \frac{f(0,0)+f_{1}'(0, 0)\eta+f_{2}'(0, 0)x +o(\sqrt{ \eta^{2} + x^{2} })}{x}
$$

根据题目条件f (0, 0) = 0, f_2' (0, 0) = 1，得到：

$$
\lim_{ x \to 0 } - \frac{f_{1}'(0, 0)\eta+x +o(\sqrt{ \eta^{2} + x^{2} })}{x}
$$

将这个极限式子拆开对于含有 $\eta$ 的式子，直接用夹逼，得到结果是0

所以最后结果就是-1


### 偏导数的定义公式 + 偏导理解

==偏导定义==
$$f'_x(x_0, y_0) = \lim_{\Delta x \to 0} \frac{f(x_0 + \Delta x, y_0) - f(x_0, y_0)}{\Delta x}$$


或者另外一种：

$$
f'_x(x_0, y_0) = \lim_{x \to x_{0}} \frac{f(x , y_0) - f(x_0, y_0)}{x - x_{0}}
$$

==理解==

$f_{x}'(x_{0}, y_{0})$ 其实就是求 f (x, y 0) 这样一个一元函数在 x =x 0 的导数，所以完全可以用一元函数的性质来判断 $f'(x_{0},y_{0})$

### 偏导数定义的四种等价写法

$f_{x}'(x_{0}, y_{0})$ 表示 f (x, y) 在 (x 0, y 0) 处对 x 的偏导数，它的含义同样是 f (x, y) 在 y = y 0 情况下对 x 在 x = x 0 处的导数

他的四个等价写法：

$$
f'_x(x_0, y_0) = \lim_{\Delta x \to 0} \frac{f(x_0 + \Delta x, y_0) - f(x_0, y_0)}{\Delta x} = \frac{\partial f}{\partial x}|_{x_{0}, y_{0}} = \lim_{x \to x_{0}} \frac{f(x , y_0) - f(x_0, y_0)}{x - x_{0}}
$$

## 微分方程

### 线性微分方程的解的性质

==齐次线性微分方程的解的性质==

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250807125831.png)


==非齐次线性微分方程的解的性质==

对于一个二阶线性微分方程：
$$
y'' + py' + qy = f(x)
$$
假如 $y_1, y_2$ 是这个非齐次方程的两个特解，则有：

（1）$k_1 y_1 + k_2 y_2$ 一定是方程 $y'' + py' + qy = k_{1}f(x) + k_{2}f(x) = (k_{1} + k_{2})f(x)$ 的特解

（2）若 $k_1 + k_2 = 0$，则 $k_1 y_1 + k_2 y_2$ 是齐次方程 $y'' + py' + qy = 0$ 的特解

（3）若 $k_1 + k_2 = 1$，则 $k_1 y_1 + k_2 y_2$ 是非齐次方程 $y'' + py' + qy = f$ 的特解

上面（2）（3）两条都可以用第一条来证明

这也是为什么 y 1 y 2 是非齐次的特解，而 y 1 - y 2 就是齐次的通解的原因了

一个 n 阶的行列式其实是 n! 项的和

对于其中的一项，其实是 n 个元素的乘积，每个元素依次按顺序取自这 n 行，但是列是不同的

并乘这些元素的-1 的逆序数次幂，这里以 3 阶为例来说明，比如下面一个三阶的行列式：

<img src="https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/image-20241121161529453.png" alt="image-20241121161529453" style="zoom:33%;" />

其中一项是三个元素的乘积

假如第一个元素取第一行第一列，就是 a 11

那么第二个元素取第二行，由于第一列被取过，因此就只有两种取法，只能在第 2 列和第 3 列中取，假设我们取 a 23

那么第三个元素取第三行，就只能取第二列的元素 a 32 了

因此这一行的乘积就是 a 11 * a 23 * a 32

再乘以-1 的逆序对数次幂，这里的逆序对是 a 11 a 23 a 32 这三个元素，任意两个如果列号大的在前面那就是一个逆序对，比如 a 23 a 32 第三列反而排在 a 32 前面这就是一个逆序对，而这个排列中只有这一个逆序对，因此需要乘 ￥(-1)^1￥

因此这一项就是：
￥￥
(-1)^{1}a_{11} a_{23} a_{32}
￥￥
当然这只是其中的一项

第一个元素可以取第一行的 n 列中一共 n 个不同的元素

第一行取了之后第二行只能取 n - 1 列了

第三行只能取 n - 2 列了

因此一共有 n! 中取法，也就有 n! 项乘积，每个乘积项都要乘自己的-1 的逆序数幂，然后将这 n! 项加起来就是行列式的值了

## 向量与线性方程组

### 同秩变换，等价变换，同解变换，不改变列向量线性相关性变换的区别

首先关于秩有矩阵 A 的行向量组的秩（行秩） = 矩阵 A 的秩  = 矩阵 A 的列向量组的秩（列秩）

==同秩变换==

对矩阵 A 进行初等行变换，或者进行初等列变换，不改变矩阵 A 的秩

==等价变换==

矩阵等价，即两个矩阵的秩相等；所以同秩变换就是等价变换

==同解变换==

对矩阵 A 进行初等行变换才是同解变换，初等行变换相当于正常的解方程消元的过程；但是初等列变换不是同解变换，初等列变换会改变方程某一列未知数的系数，不再是原来的方程组

同解变换得到的系数矩阵 B 的行向量组与 A 的行向量组等价（很显然，B 的每个向量都是由 A 初等变换过来得到的，当然可以由 A 的向量线性表示，反之亦然）

也可以说两个矩阵 A 和 B 同解，那么在 A 和 B 的行数相同的情况下，一定可以通过行变换互相转换，比如 A 和 A^TA 就是同解，两者可以通过行变换互相转换，这里 A 是 n * n 阶矩阵

==不改变线性相关性的变换==

对矩阵进行同解变换，不改变方程的解，因此也不会改变列向量的线性表示，所以也是不会改变列向量的线性相关性的变换

r (A) = r 代表行阶梯非零行的行数，有效方程数量，基础变量个数

### 列向量组线性相关，线性无关的4个等价说法

假设 $[\alpha_{1}, \alpha_{2}, \alpha_{3}\dots.\alpha_{n}] = A$

如果说A的这些列向量线性相关，说明：

（1）一定存在一个向量可以由其他的向量线性表示，这里是存在一个即可
（2）存在一组不全为0的k1, k2, ... kn使得 $k_{1}\alpha_{1}+k_{2}\alpha_{2}\dots k_{n}\alpha_{n} = 0$
（3）Ax = 0有非零解，因此在A是n阶方阵的情况下|A| = 0
（4）r（A）< n

如果说这些列向量线性无关，说明：

（1）任意一个向量都不可能由其他向量线性表示，并且所有向量非零向量
（2）如果 $k_{1}\alpha_{1}+k_{2}\alpha_{2}\dots k_{n}\alpha_{n} = 0$，则k1, k2... kn必然 = 0
（3）Ax = 0只有零解，因此在A是n阶方阵的情况下，|A| != 0
（4）r (A) = n

### 特征值对应的特征向量的性质

==同一个特征值==

同一个特征值对应的特征向量一定有无数个，因为 $|A - \lambda_{0}E| = 0$，因此 $(A - \lambda_{0}E) x = 0$ 有无穷多个解；所以可以用基础解系来表示一个特征值 $\lambda_{0}$ 的所有非零特征向量

==不同特征值==

不同特征值（互异特征值）对应的特征向量之间必然线性无关
### 三阶矩阵特征多项式的韦达定理

三阶矩阵的特征多项式就是：
$$
|A - \lambda E| = 0 = \lambda^3 + a \lambda^2 + b\lambda + c = 0 
$$
我们可以得到：

（1）特征值的乘积，就是行列式，就是常数项的相反数：
$$
\lambda_1 \lambda_2 \lambda_3 = -c = |A|
$$
（2）特征值的和，就是矩阵的迹，就是二次型的相反数：
$$
\lambda_1  + \lambda_2 + \lambda_3 = -a = tr(A)
$$
（3）特征值的交叉项和，就是伴随矩阵的迹，就是一次项：
$$
\lambda_1 \lambda_2 + \lambda_1 \lambda_3 +\lambda_2 \lambda_3 = b = tr(A^*)
$$
 这个比较容易证，因为伴随矩阵的特征值就是 $\frac{|A|}{\lambda_1},\frac{|A|}{\lambda_2},\frac{|A|}{\lambda_3}$，代入|A| = $\lambda_1 \lambda_2 \lambda_3$ 就是了


### 特征值的代数重数和几何重数以及互相关系

==代数重数==

对于 $|A - \lambda E| = 0$，每个特征值 $\lambda_{0}$ 必然有一个自己的重数 k，所有 k 的数值加起来必然是 A 的阶数 n，这里每个特征值 $\lambda_{0}$ 的阶数 k 称为特征值 $\lambda_{0}$ 的代数重数

==几何重数==

对于 A 的某个特征值 $\lambda_{0}$，其由于 $|A - \lambda E| = 0$，所以 $(A - \lambda_{0} E) x = 0$ 一定有无穷个解，这个方程的基础解系中解向量的个数 p，就是特征值 $\lambda_{0}$ 的几何重数，同时也是特征值 $\lambda_{0}$ 所对应的最大的线性无关的特征值个数，同时也是 $\lambda_{0}$ 所对应的特征值的极大无关组中向量个数

==两者关系==

特征值 $\lambda_{0}$ 的几何重数是一定小于等于代数重数 k 的，即一个 k 重特征值 $\lambda_{0}$ ，其最多有 k 个线性无关的特征向量

也可以说一个特征值 $\lambda_{0}$ 其对应的特征向量的极大线性无关组的向量个数 p 一定小于等于 k

### 矩阵 A 的特征向量的含义以及几个数量关系


对于 A 的属于特征值 $\eta$ 的特征向量，假设特征值的重数是 k，即代数重数是 k

（1）A 的特征向量一定是非零向量

（2）A 的属于 $\eta$ 的特征向量是 $(A - \eta E)x = 0$ 的非零解

（3）A 的属于 $\eta$ 的所有特征向量的极大无关组就是 $(A - \eta E)x = 0$ 的基础解系的解向量，其个数就是 $n - r(A -\eta E)$，即基础解系解向量个数

（4）A 的属于 $\eta$ 的最大的线性无关特征向量个数 = A 的属于 $\eta$ 的所有特征向量的极大无关组向量个数  = $(A - \eta E)x = 0$ 的基础解系的解向量个数 = $n - r(A -\eta E)$ = A 的特征值 $\eta$ 的几何重数

（5）对于 A 的属于一个已经存在的特征值 $\eta$ 的特征向量，它至少对应了一个特征向量，因为既然 $\eta$ 存在，它就是根据 $|A - \eta E| = 0$ 求解出来的，所以 $(A - \eta E)x = 0$ 一定有非零解，所以当 $\eta$ 的代数重数是 1 的时候此时 A 对应的属于 $\eta$ 的几何重数必然是 1，即必然对应了一个非零特征向量，必然 $\eta$ 对应的最大线性无关的特征向量个数就是 1

### 矩阵合同的三条性质（以及充要条件）

矩阵 A 和 B 合同，也就是存在一个可逆矩阵 C 使得 $C^T A C = B$

因此合同之后：
（1）矩阵 A 和矩阵 B 等价
（2）矩阵 A 和矩阵 B 具有完全相同的秩
（3）矩阵 A 和矩阵 B 的正负惯性指数均相等 (充要条件)


### 可逆线性变换的三种等价关系

二次型 `f(X)` 经过线性变换得到二次型 `g(Y)`，那么下面三种关系是等价的：

**（1）`f(X) = g(Y)`**

这是因为 f (X) 本质上是做了一个换元处理，很显然就是不改变二次型整体的大小

**（2）二次型的变量有：$x = Cy$

**（3）若 A 是 f (X) 的矩阵，B 是 g (Y) 的矩阵，那么有：$C^T A C = B$**

上面三个关系有一就有剩下两个
