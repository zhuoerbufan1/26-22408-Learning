### lnx 与x, tanx 与 x, sinx 与 x 的比值函数的处理方式

按照对应函数图像上的点与原点的连线的斜率来进行考虑

==lnx 与 x==

对于类似这种 $f(x) = \frac{\ln x}{x}$，它实际上是 lnx 这个函数图像上的一点与原点连线的斜率

对齐求导之后可以发现在 (0, e) 递增，在 (e, infty) 递减，所以有：

$$
0 < \frac{\ln x}{x} \leq \frac{1}{e}(x \in(0, \infty))
$$



==tanx 与 x==


对于 tan x / x，它同样满足这里的斜率关系，当 $x \in\left( 0, \frac{\pi}{4} \right)$ 的时候，首先 tan x / x 一定大于 1，tan x 是始终 > x 的

然后在 (pi/4, 1) 处的斜线斜率是 4/pi，所以 tan x / x 一定小于 4/pi，即：

$$
1 < \frac{\tan x}{x} < \frac{4}{\pi}\left( x\in\left( 0, \frac{\pi}{4} \right) \right)
$$

==sinx 与 x==

当 $x \in \left( 0, \frac{\pi}{2} \right)$ 的时候，根据 sin x 的图像，sinx /x 同样是 sin x 上的点与原点连线的斜率：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250712085115.png)

(x, sinx) 点处的斜率与原点连线的斜率是夹在 k = 1 和 k = pi/2 之间的

所以就有：

$$
\frac{\pi}{2} < \frac{\sin x}{x } < 1\left( x \in \left( 0, \frac{\pi}{2} \right) \right)
$$

所以有不等式：

$$
\frac{\pi}{2}x < \sin x < x\left( x \in \left( 0, \frac{\pi}{2} \right) \right)
$$

### 极限中泰勒公式确定阶数方法

**（1）对于 A - B 类型，需要展开到 A 和 B 的系数不相等的最低次幂**



**（2）对于 A/B 的类型，你先确定分子 A 或者分母 B 的阶数，展成 f (x) + o (x^k) 形式，直接去掉 o (x^k)，然后另一个分母 B 或者分子 A 的整体阶数只要展开大于等于 f (x) 的阶数 k 就行了一般的操作是将分子或者分母参与有效计算的项的阶数展开到大于 f (x) 的阶数就可以了**

也就是将分子或者分母展开成 x^k + o (x^k) 的形式，让多项式的最高次幂大于等于确定好了的阶数

对于分子或者分母，这里有一条规则就是，只要分子或者分母可以写成一个多项式+无穷小的形式，即 $f(x) + o(x^k)$，这里的无穷小是 f (x) 的高阶无穷小，比如 x^3 + o (x^3) 这种，那么这里的无穷小就可以直接去掉

### 变限积分无穷小阶数的处理方法

==积分的等价代换==

当 x -> 0 的时候 f (x) ~ g (x) 是等价无穷小，则有：

$$
 \int_{0}^{\phi(x)} f(t)\sim \int_{0}^{\phi(x)}g(t) dt
$$

这两个积分是等价无穷小，上式中 x -> 0 有 $\phi(x) \to 0$，也就是说，当一个积分是无穷小的时候可以直接将被积函数换成一个与其等价的无穷小式子

### 条件处理：$a_{n} = \sqrt{ a + a_{n - 1} }$

这类条件形成的结构就是无限的根号套娃：

$$
a_{n} = \sqrt{ a + \sqrt{ a + \sqrt{ \dots } } }
$$

它的处理方式是进行放缩，从而找到 an 的边界，这里的放缩思想是，想办法让 an-1 小于一个数 k，这个数 k 代入 $a_{n} = \sqrt{ a + a_{n - 1} }$ 的时候可以去掉根号

比如 $a_{n} = \sqrt{ 6 + a_{n - 1} }$，这里可以令 $a_{n - 1} < 3$，代入之后发现 $a_{n} < \sqrt{ 6 + 3 } = 3$，从而可以用数归进行证明

因此这里可以令 an - 1 < $2\sqrt{ a } + 1$

可以得到：

$$
a_{n} < \sqrt{ a } + 1 < 2\sqrt{ a } + 1
$$

因此 an 一定是有界的

再根据 an 的函数表达式 f (x) = $\sqrt{ a + x }$，所以 an 一定单调有界极限存在

### xn 和 f (xn) 的敛散性处理方法

主要用于判断选择题中一些 xn 和 f (xn) 的关系，比如下题：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250915110301.png)


=={xn}收敛 => f (xn) 收敛==


数列极限{xn}收敛并不意味着 f (xn) 收敛，比如 xn = $\frac{(-1)^n}{n}$ 这是一个来回震荡趋近于 0 的数列

但是如果 f (x) 是一个符号函数，这个符号函数，只有在 x= 0 的时候等于 0，x > 0 f (x) = 1，x < 0 f (x) = -1

那么 f (xn)，n 趋于无穷的时候 xn 是可能趋于 0 +和 0-两种情况的，所以 f (xn) 的趋近情况是震荡的，极限不存在，因此不收敛

**假如{xn}趋于 a，那么加上 f (x) 在 a 点连续，这样就保证 f (xn) 也收敛了（或者 $\lim_{ x \to a }f(x)$ 存在即可），此时就有：**

$$
\lim_{ n \to \infty } f(x_{n}) = \lim_{ x \to a } f(x)
$$

==f (xn) 收敛 => xn 收敛==

这个普通情况下也是无法推出的，因为 f (x) 如果收敛于 a，那么它可能对应多个 x，比如下面：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250713081901.png)

你 f (x) = a 对应两个自变量取值，那么数列只要收敛于这两个点来回摆动就可以让 f (x) 收敛于 a 了，就比如 f (x) = x^2，对于 f (xn)，只要 xn 收敛于正负对称的两个值，f (x) 还是收敛于相同的平方值，因此 f (xn) 收敛不能推出 xn 收敛

此时必须加上 f (x) 在定义域中与 x 一一对应，即 f (x) 有反函数（f (x) 连续单调是一一映射的子集，f (x) 连续单调则一定是一一映射的），并且 $\lim_{ n \to \infty }f(x_{n} ) = a$ 的这个 a 必须在 f (x) 的值域中

这里关于 a 必须在 f (x) 的值域中的意思是 f (x) 可能是下面的图像：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250713082810.png)

f (x) 在无穷的时候趋近于一个值 a，但是这个 a 不在 f (x) 的值域中，那么说 $\lim_{ n \to \infty }f(x_{n}) = a$，此时这个 a 在 f (x) 的定义域中没有对应的点，那么 xn 只能趋于无穷了，所以也不能推出 xn 收敛

**f (x) 与 x 一一对应，即 f (x) 有反函数，并且 $\lim_{ n \to \infty }f(x_{n} ) = a$ 的这个 a 必须在 f (x) 的值域中，此时才能说 f (xn) 收敛于 a，可以推出 xn 收敛（收敛于 f (x) = a 的时候对应的 x 的值）**

### 利用泰勒公式求 n 阶导的方法


泰勒公式的写法有两种，一种是拉格朗日余项，一种是皮亚诺余项：

![image-20241119150538406](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/image-20241119150538406.png)

上面这个公式是所有函数的泰勒展开的一般写法，也是带未知系数的写法，也可以说是理论写法，其可以直接简写成下面：

$$
f(x) = a_{0} + a_{1}(x - x_{0}) + a_{2}(x - x_{0})^2 + \dots \dots +a_{n}(x - x_{0})^n + o((x - x_{0})^n)
$$

这个是带皮亚诺余项的泰勒展开，不过我们这里主要说明一下系数与教材给的常见具体的泰勒展开的通项对应关系，这里是皮亚诺余项还是拉格朗日余项其实无所谓

一般教材中会直接给出一些常见函数的泰勒展开，比如 ln ( x + 1) 在 x 0 = 0 处的泰勒展开具体的系数通项：

$$
\ln (1+x) = \sum_{n=0}^\infty \frac{(-1)^n}{n+1} x^{n+1} = x - \frac{x^2}{2} + \frac{x^3}{3} - \cdots \quad 
$$
但是这里的通项不一定对应上面带未知系数的第 n 项，**这里主要看 x 的次数**，这里的 ln (1 + x) 的具体系数通项次数是 n + 1 次，所以这里的具体系数通项应该对应于 ln ( 1 + x) 带未知系数的泰勒展开的第 n + 1 项，即：

$$
a_{n + 1} = \frac{f^{(n + 1)}(x_{0})}{(n + 1)!} = \frac{(-1)^n}{n + 1}
$$

x 0 = 0，也就得到了 ln ( 1+ x) 在 0 处的 n + 1 阶导数：

$$
f^{(n + 1)}(x_{0})= \frac{(-1)^n}{n + 1}(n + 1)!
$$

**所以这里想说的是，那种一般的，带未知系数的通项的 n 阶导一般你是无法自己求出来的，只能记住常见的泰勒公式的具体带系数的展开，通过 x 的次数来找到对应关系，从而得到 n 阶导；**


### 复合函数求导的一个快速做法

若 y = f (u)，且 u = g (x)

那么就有：

$$
\frac{dy}{dx} = \frac{dy}{du} \frac{du}{dx} = f'(u) g'(x) 
$$

他的含义不仅仅在求解析式这么简单，同时在于求值的时候，即：

$$
\frac{dy}{dx}|_{x=x_{0}} = f'(u_{0})g'(x_{0})[其中u_{0}=g(x_{0})]
$$

也就是 y 对 x 在 x 0 处的导数的值 == f 对 u 在 u 0 处的导数的值 * u 对 x 在 x 处的导数的值【其中 u 0 = g(x 0)】

这里 y 对 x 在  e 处的导数的值 = f [f (x)] 对 f (x) 在 f (x 0) 处的导数的值 * f (x) 对 x 在 x 0 处的导数的值

#### 利用泰勒展开求 n 阶导的方法 

一般这种问题就是直接求函数的 n 阶导不好求，需要利用常见的泰勒带具体系数的展开，来得到 an 和系数的关系，从而得到 n 阶导

题中给定一个常见的函数我们可以明确知道其泰勒带具体系数展开，比如 $x^2\ln(x + 1)$，这时题目要求这个函数在 x 0 处的 n 阶导，为了不出错，应该遵循下面的步骤

（1）写出 f (x) 在 x 0 处的带未知系数的展开（幂级数）：
$$
x^2 \ln(x + 1) = a_{0} + a_{1}(x - x_{0}) + a_{2}(x - x_{0})^2 + \dots \dots +a_{n}(x - x_{0})^n + o((x - x_{0})^n)
$$
（2）写出 $f(x)$ 的具体的系数的泰勒展开（一般是常用函数的泰勒展开）：
$$
x^2 \ln(x + 1) = (x - x_{0})^3 - \frac{1}{2}(x - x_{0})^4 + \frac{1}{3} (x - x_{0})^5 + \dots\dots \frac{(-1)^n}{n + 1}(x - x_{0})^{n + 3}
$$
（3）根据具体的通项泰勒**展开的次数**判断其对应带未知系数展开的哪一项，比如这里具体通项中是 n + 3 次，所以应该对应带未知系数展开中的第 n + 3 项，即 a (n + 3)，而不是 an

（4）写出带未知系数展开中的第 n 项对应的具体泰勒展开通项，这里就是 $a_{n}(x - x_{0})^n = \frac{(-1)^{n-3}}{n -2}(x - x_{0})^{n}$

然后根据 $a_{n} = \frac{f^{(n)}(x_{0})}{n!}$，从而得到 f (x) 在 x 0 处的 n 阶导

主要根据就是三点：

（1）带未知系数的这种泰勒展开是所有函数的通法，即 $\sum a_{i}(x-x_{0})^i$ 这种，它这里的系数有一个公式就是 $a_{i} = \frac{f^{(i)}(x_{0})}{i!}$，这是第 i 项的系数

（2）一个常见函数我们可以直接凑出具体的泰勒展开，我们同样可以得到第 i 项的系数，并且这个系数是具体的可知的

（3）根据具体的泰勒展开和带未知系数的泰勒展开的次数对应关系来得到 ai 的表达式，而 $a_{i} = \frac{f^{(i)}(x_{0})}{i!}$，这样就可以求出 i 阶导数了



#### 利用泰勒展开求非零处的 n 阶导的方法

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250719100531.png)

这里需要求的是 f (x) 在 x = 1 处的泰勒展开，但是你 ln (1 + x) 中的 x 是趋于 1 的，所以不能用常见的泰勒公式直接展开成具体系数的形式

这里的处理措施是将 ln (1 + x) 中凑成 ln (1 + A)，其中 A 是 x - 1 的形式，这样 x = 1 的时候 A = 0 于是就可以将 A 看作一个整体进行泰勒展开了：

$$
f(x) = (x - 1)^2\ln(2 + x - 1 ) = (x - 1)^2 \ln\left( \frac{2 + x - 1}{2} * 2\right ) = (x - 1)^2\ln 2 + (x - 1)^2\ln(1 + \frac{x-1}{2})
$$

也就是 $f(x) = (x - 1)^2\ln 2 + (x - 1)^2\ln(1 + \frac{x-1}{2}) = (x - 1)^2\ln 2 + g(x)$

这个函数的的 2025 阶导是和 g (x) 的 2025 阶导是一样的，所以我们只用求 g (x) 在 x = 1 处的 2025 阶导即可

$$
g(x) =  (x - 1)^2\ln(1 + \frac{x-1}{2})
$$

那就是求这个函数在 x = 1 处的泰勒展开具体形式的系数了

理论带未知系数的形式是：

$$
g(x) = a_{0}  + a_{1}(x - 1) + a_{2}(x - 1)^2 + \dots \dots +a_{n}(x - 1)^n + o((x - 1)^n)
$$

然后就是利用常见的公式写出带具体系数的泰勒展开，你这里将 x-1/2 看作一个整体，对这个整体在 0 处的展开为：

$$
g(x) = (x - 1)^2\left[ \frac{x-1}{2}  - \frac{1}{2} \left( \frac{x-1}{2} \right)^2 + \dots (-1)^{n - 1} \frac{1}{n} \left( \frac{x-1}{2} \right)^n \dots\right]
$$

它的通项就是：

$$
(-1)^{n-1}  \frac{1}{n} \frac{1}{2^n}(x - 1)^{n + 2}
$$

你这里，虽然是对 x-1/2 整体在 0 处的展开，但是**写成的形式是关于 x-1 的多项式，所以对于 g (x) 来说就是在 x = 1 处的展开**

根据 x - 1 的次数关系，所以有：

$$
a_{n + 2} = \frac{g^{(n  + 2)}(1)}{(n + 2)!} = (-1)^{n - 1} \frac{1}{n} \frac{1}{2^n}(x - 1)^{n + 2}
$$


因此 $g^{(n + 2)}(1) = (-1)^{n - 1} \frac{1}{n} \frac{1}{2^n}(n + 2)!$


n = 2023 就是结果了

### 用定积分定义处理和式极限的做法

一般题目中给出的是一个 n 项和的极限，我们需要将这个 n 项和式极限写成定积分的形式来处理，转化成定积分的方式如下：

**（1）凑出 $\frac{i}{n}$ 或者 2 i/n 或者 2 i - 1 / 2 n 这样的变化的项，这个是作为自变量，从而确定函数是什么**

**（2）观察 $\frac{i}{n}$ 或者 2 i/n 或者 2 i - 1 / 2 n 这样的项的变化范围，从而确定积分的上下限**


如果 i/n 从 1/n 变化到 n/n，那么 n 取极限，那区间就是 0 到 1

如果我们凑出的是 2 i/n，那么这个变化范围就是 2/n 到 2 n/n，同样 n 取极限，那么区间就是 0 到 2

注意这里的变化范围不是根据 i 从 0 变化到 2 n 所以确定其范围是 0 到 2，而是变量变化的端点从 2/n 到 2 n/n， n 取极限之后，才得到区间是 0 到 2

**（3）确定步长**

主要就是观察 i 每增加一次增长了多少，比如是 i/n，i 每加 1 这个变量就是增长了 1/n 所以步长就是 1/n；如果是我们凑出的变量是 (2 i - 1)/ 2 n，i 每增加 1，这个变量就是增长了 1/n 所以步长还是 i/n；如果凑出的变量是 2 i - 1 / n，那么 i 每增加 1，这个变量增长了 2 / n，所以步长就是 2 / n

这里的步长是通过这个变化的项的增加 1 来算出来的

或者有一个更简单的做法，在（2 ）中我们知道了积分的区间，可以直接用区间长度除以项的个数，这样就可以直接得到步长了

比如，凑出的变量是 (2 i - 1)/n，如果项数是 n 项，那么积分区间就是 (0, 2)，步长当然是 2/n 了；如果项数是 2 n 项，那么积分区间就是 (0, 4)，步长同样是 2/n 项；这跟凑出的变量直接加 1 判断步长的结果完全一样

如果题目给出的式子与我们确定的步长不一样则我们需要增加一些系数凑出步长，比如 $\sum_{i = 1}^{2n} \frac{2}{n} \ln\left( 1 + \frac{i}{n} \right)$

这里区间显然是 0 ~ 2，一共 2 n 项，所以步长应该是 1/n 所以我们应该将系数 2 提出去凑出 1/n：

$$
\sum_{i = 1}^{2n} \frac{2}{n} \ln\left( 1 + \frac{i}{n} \right)=2\sum_{i = 1}^{2n} \frac{1}{n} \ln\left( 1 + \frac{i}{n} \right) = 2\int_{0}^{2}\ln(1 + x)dx
$$

比如下面这道题目：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250726114928.png)

A 的区间是 (0, 1)，项数是 n 项，所以步长应该是 1/n，因此错

B 的区间是 (0, 1)，项数是 n 项，所以步长是 1/n，因此正确

C 的区间是 (0, 1)，项数是 2 n 项，所以步长应该是 1/2 n，所以错误

D 的区间是 (0, 1) 项数是 2 n 项，所以步长应该是 1/2 n，所以错误

**（4）配出步长乘函数的形式**

也就是配出  $\Sigma_{i = 1}^n \frac{1}{n}f\left ( \frac{i}{n} \right)$ 或者 $\Sigma_{i = 1}^n \frac{2}{n}f\left ( \frac{2 i}{n} \right)$ 这样的步长乘一个函数值的形式

**只有按照上文的步长乘函数才能凑出定积分的定义**，配出来之后还需要将这个式子与题中所给的式子进行比较，看看能不等对上，增加一些系数等等

### 反常积分处理方法

如果题目中是要求计算，则优先使用定义法，直接将被积函数积出来然后计算

如果题目中要求判断敛散性，则优先使用下面的审敛法，定性判断

#### **（1）基本思想**

首先反常积分其实有两种，积分到无穷的反常积分和函数无界的反常积分

**积分到无穷的的积分，即区间无限的反常积分：**
$$
\int_a^{\infty}f (x) dx
$$
这种积分的图像大致为：

显然，只有当 f (x) 是无穷小的时候这种积分才会收敛，并且 f (x) 的无穷小的阶数越高，其就越收敛

**函数无界的反常积分：**
$$
\int_a^bf (x) dx
$$
这种积分一般有端点导致 f (x) 无界，其图像大致为：

这种积分默认了 f (x) 在某个端点处就是无穷的，所以这一类积分想要收敛，那显然 f (x) 这个函数的无穷阶数越小越容易收敛

以上就是对两类积分的感性认识

#### **（2）记住四个特殊积分：**

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250726124644.png)


首先，记住这四个反常积分的被积函数

然后，当 p = 1 的时候这些积分全部发散

对于 P 积分和广义 P 积分，当趋于无穷的时候被积函数足够小才能收敛，此时被积函数整体是一个无穷小，所以次数 p 越大，无穷小的阶数越高，也就越小，所以 p > 1 的时候是收敛的

对于 Q 积分，还是，当趋于这个点的时候被积函数足够小才能收敛，此时被积函数是一个无穷大，所以次数 q 越小，无穷大的阶数越小，也就越小，所以 q < 1 的时候是收敛的；同理当次数 q 越大，无穷大的次数就越大，整个积分就越大，那当然就不是收敛的了

#### **（3）解题的基本方法：**

**i 找出瑕点并划分区间**

这里的瑕点指的是可能导致积分发散得点，比如无穷点，以及上述 q 积分中得点 a 这个端点，比如  $\int _1^{+\infty} \frac{1}{x \ln x} dx$  中的  $1, +\infty$

这里的划分区间的意思是保证划分出来的区间中只有一个瑕点，这样通过分别判定两个不同区间的上的积分的敛散性来判断总体的敛散性，比如  $\int_0^2\frac{1}{\sqrt{x} (1 - \sqrt{x})} dx = \int_0^{\frac{1}{2}}\frac{1}{\sqrt{x} (1 - \sqrt{x})} dx + \int_{\frac{1}{2}}^2\frac{1}{\sqrt{x} (1 - \sqrt{x})} dx$ 

这样划分区间之后第一个区间只有 0 是瑕点，第二个区间中 1 是瑕点，这里的区间划分是随意的，**并且只有所有区间的积分都收敛才能保证整体收敛**

**ii 在每个瑕点对被积函数进行同阶替换，每个瑕点操作一次**

这里的同阶替换的意思是在 x 趋近于瑕点的时候被积函数整体的极限与同阶替换后的函数极限的比阶是一个常数，这样原函数与替换后的同阶函数在瑕点处具有相同的敛散性

比如 $1/sin x$ 与 $1/x，x = 0$ 显然是瑕点，这两个函数就可以同阶替换，这样  $\int_0^1 \frac{1}{\sin x}$  就与  $\int_0^1 \frac{1}{x}$  在 x = 0 处具有相同的敛散性

举一个例子： $\int_0^2\frac{1}{\sqrt{x} (1 - \sqrt{x})} dx$ 

有两个瑕点

x = 0 的时候进行同阶替换： $\frac{1}{\sqrt{x} (1 - \sqrt{x})} \sim \frac{1}{\sqrt{x}}$

x = 1 的时候进行同阶替换： $\frac{1}{\sqrt{x} (1 - \sqrt{x})} \sim \frac{1}{ (1 - \sqrt{x})} \sim \frac{1}{1 - \sqrt{x - 1  + 1}} \sim \frac{1}{x - 1}$  (注意这里是同阶替换，不是等价替换，可以直接省去系数）

然后直接分析同阶替换后的函数在瑕点处的积分敛散性即可

这里的同阶替换的意思是在瑕点处原被积函数和同阶函数在瑕点处具有相同的积分敛散性（比如上面例子  $\int_0^2\frac{1}{\sqrt{x} (1 - \sqrt{x})} dx$ ，原函数从一个正常点积分到 0 与  $\frac{1}{\sqrt{x}}$  积分到零具有相同的敛散性），所以我们在考虑敛散性的时候只用考虑同阶函数在瑕点的敛散性即可，当然多个瑕点积分区间还得划分一下，比如上面例子随便划分下区间：
$$
\int_0^2\frac{1}{\sqrt{x} (1 - \sqrt{x})} dx = \int_0^{\frac{1}{2}}\frac{1}{\sqrt{x} (1 - \sqrt{x})} dx + \int_{\frac{1}{2}}^2\frac{1}{\sqrt{x} (1 - \sqrt{x})} dx
$$
左边只用考虑在 0 处的敛散性，右边得考虑在 1 处的敛散性，分别做同阶替换，然后分别得到两个积分的敛散性，只要有一个发散，那两个的和就发散；当然 1 其实在区间里面，可以进一步划分左右趋近，不过可以简单一点
 
当然其实直接进行同阶替换然后考虑敛散性就行，区间划分其实无所谓

#### （4）注意事项

i 注意利用瑕点处的同阶替换的时候，如果这个瑕点是无穷，那一定是往 p 积分上凑，如果瑕点是一个数，那一定是往 q 积分上凑，然后根据 p 或者 q 的阶数来判断敛散性

ii 这里的同阶替换，只要保证趋于瑕点的时候是一个数即可，比如上面趋于瑕点 1 的替换： $\frac{1}{\sqrt{x} (1 - \sqrt{x})} \sim \frac{1}{ (1 - \sqrt{x})} \sim \frac{1}{1 - \sqrt{x - 1  + 1}} \sim \frac{1}{x - 1}$ 

其实做到  $\frac{1}{\sqrt{x} (1 - \sqrt{x})} \sim \frac{1}{ (1 - \sqrt{x})}$  这里的时候就可以将  \sqrt{x}  看作一个整体了，底下看作一个 q 积分了，因为我们通过趋于 1 的时候极限：
$$
\frac{1 - \sqrt{x}}{1 - x} = 常数
$$
趋于常数得到验证

#### **（5）对于积分式子中含有指数怎么处理**

如果积分式子中产生了指数，其实还是进行同阶替换

**根据反常积分的本质，对于趋于无穷的瑕点，当然是趋于零越快，越容易收敛**

**对于趋于趋于某个数的无界函数瑕点，当然是无穷大的阶数越小，越容易收敛**

所以指数反而变得更简单了，因为对于趋于无穷的瑕点，如果**因为指数导致了无穷大，那么指数的无穷大阶数一定大于任何幂函数**

**如果因为指数导致了 0，那么指数趋于零的速度也一定大于任何幂函数**

同理对于趋于某个具体的点处的瑕点也是这样

比如  $\frac{1}{e^x - 1}$ ，x 趋于无穷的时候其同阶就是  $\frac{1}{e^x}$ ，这个式子导致的无穷小的速度远远超过分子是幂函数时的无穷小，因此一定是收敛的

#### （6）对于积分式子中含有对数怎么处理

**无穷区间上的反常积分，其趋于零越快，越容易收敛**
**无界函数的反常积分，无穷阶数越小，越容易收敛**
**因此无论是无穷区间上的反常积分，还是无界函数的反常积分，一律是越小越容易收敛**

当 x 趋于 1 的时候 ln x 是一个无穷小处理很简单，直接同阶替换成幂函数即可，比较麻烦的是 ln x 趋于无穷大的情况，**需要注意的是 ln x 趋于无穷大的情况，无论是 x 趋于无穷的时候的无穷大，还是 x 趋于零的无穷大，其趋于无穷大的速度一定小于幂函数**

常见的有下面的几个处理方式：

（1）对于趋于 1 的反常积分，令 lnx 直接无穷小代换成 (x - 1)
（2）对于趋于无穷的反常积分，令 lnx = t 换元

上面两个处理之和再和一般的幂函数一样的过程判断敛散性


如果上面几个处理不行，那再进行下面的结论

**然后记住下面几个结论（一般同阶替换就往下面几种式子上取替换）：**

**i  $\int_2^{+\infty} \frac{1}{\ln^a x} dx$  一定是发散的**

 这是因为区间无穷的反常积分，其趋于无穷的时候越小越容易收敛，对于  $\frac{1}{\ln^a x}$  这个式子，其趋于 0 的速度一定比  $\frac{1}{x}$ 慢，因为 x 这个幂函数趋于无穷的速度一定比对数快，所以  $\frac{1}{\ln^a x}$  一定比  $\frac{1}{x}$  大，而  $\frac{1}{x}$  是发散的，所以这个式子也一定是发散的

**ii  $\int_0^2 \ln^a x dx$  一定是收敛的**

这是因为 ln x 趋于无穷大的速度一定小于幂函数，因此对于一个收敛的幂函数  $\frac{1}{x^{1/2}}$ ，在趋于零的时候 ln x 的无穷阶数一定比它小，因此一定收敛

**iii $\ln^a x$  在分子上的情况，即  $\int_2^{+\infty} \frac{\ln^a x}{x^p}；\int_0^1\frac{\ln^a x}{x^q}$ ** 

其敛散性跟去掉 $\ln^a x$  的敛散性是一样的，注意只有瑕点 0 和无穷的时候分子才能直接忽略 $\ln^a x$，如果瑕点是 1，分子则需要进行无穷小替换

**iv  $\ln^a x$  在分母上的情况，比如  $\int_2^{+\infty} \frac{1}{x^p \ln^a x} dx$ 以及  $\int_0^{1/2} \frac{1}{x^p \ln^a x} dx$ 

这个时候还是以幂函数为主，我们先看幂函数的次数

如果幂函数的次数不是 1，此时对数完全可以忽略，比如  $\int_2^{+\infty} \frac{1}{x^2 \ln^a x}$  这个式子的敛散性是和  $\frac{1}{x^2}$ 的敛散性是一样的，无穷的瑕点处是收敛的

当幂函数的次数是 1 的时候才开始看对数，此时 a  > 1 的时候才收敛，a <= 1 的时候发散，此时不管瑕点是 0 还是无穷这个结论都成立，注意与 p，q 积分取等的时候不一样，但是不管是什么积分，**幂等于 1 的时候始终发散**

#### （7）总结

处理反常积分就需要记住下面几个

（1）记住反常积分收敛的本质，其实就是越小越容易收敛

（2）找瑕点

（3）同阶替换，指数的速度不管是趋于零还是无穷速度都超过幂函数，对数就想办法替换成上面 4 中情况，注意对数

（4）其实本质还是最开始的思想，无穷区间的反常积分，无穷小的阶数越高越容易收敛，无界函数的反常积分，无穷小的阶数越低越容易收敛，反正就是越小越容易收敛

### 带 ln 的反常积分处理方法

#### **（1）对 ln x 进行换元，然后凑微分**

比如最基本的广义 p 积分：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250727075953.png)

将 1/x 提到 dx 中，得到：

$$
\int _{a}^\infty  \frac{1}{\ln^px}d\ln x
$$

令 lnx = u 得到：

$$
\int_{\ln a}^\infty \frac{1}{u^p}du
$$

这样就变成了一个普通的 p 积分，因此 p > 1 的时候收敛


#### **（2）有瑕点 1 的时候， x -> 1 的时候利用 $\ln x \sim x-1$ 来将 lnx 等价替换**

一般含有 lnx 的被积函数会将 ln x 放到分母，然后 x = 1 导致分母为 0 然后积分无界，是一个瑕点，在这个瑕点处 lnx 就可以直接替换成 x - 1

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250727080552.png)

这里 x = 0 不是瑕点，x = 0 的时候被积函数趋于 0：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250727080705.png)

x = 1 是瑕点，在 x -> 1 的时候整个被积函数同阶替换为：

$$
\frac{\sqrt{ 1 - x }}{\ln x} \sim \frac{\sqrt{ 1 - x }}{1 - x} \sim \frac{1}{\sqrt{ 1 -x  }}
$$

这样就转换成了一个 q 积分，幂是小于 1 的，表示无穷大的次数更小，所以就是收敛的了

#### **（3）无论 x ->0 还是 x -> 无穷，lnx 它趋于无穷大的速度是远小于幂函数的**

这种情况其实有一个常用的固定流程，==即对 x 的多项式幂的部分进行分类讨论==

比如下面这道题目：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250727104448.png)

这道题在趋于无穷的瑕点的敛散性的处理是，首先，ln 趋于无穷的速度远小于分母的幂函数，所以对幂函数进行分类讨论

如果 q > 1

那么这个式子一定可以写成 $\frac{1}{x^{q - q^+} } \frac{\ln (1 + x^p)}{x^{q^+}}$，这里的 q+是一个很小的数，保证 q - q+ 还是 > 1；那么此时 $\frac{1}{x^{q - q^+} }$ 是收敛的，而右边的对数除以一个幂函数在趋于无穷的时候是为 0 的，一个无穷小，所以 $\frac{1}{x^{q - q^+} } \frac{\ln (1 + x^p)}{x^{q^+}} <\frac{1}{x^{q - q^+}}$ 一定是收敛的

如果 q = 1

那么 1/x 本身就是一个发散的了，所以此时 1/x 乘一个无穷大的数，变得更大，所以一定是发散的了

如果 q < 1

同上，1/x^q 就已经是一个发散的了，所以此时又乘一个无穷大的数，变得更大，一定是发散的

**再看一个例子：**

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250727111359.png)

x = 1 不用多说，还是看无穷处

这里还是对 p 进行分类讨论

如果 p > 1

那么 $\frac{1}{x^p}$ 本身就是一个收敛的式子，那再乘 $\frac{1}{\ln^q x}$ 这样一个无穷小式子，结果必然是收敛的

如果 p = 1

这个就是广义 p 积分了，按照广义 p 积分分析即可，可以换元

如果 p < 1

这里将这个式子拆成：

$$
\frac{1}{x^{p + p^+}} \frac{1}{\frac{\ln^q x}{x^{p^+}}}
$$

这里保证 p + p+仍然是 < 1 的，所以当 x 趋于无穷的时候左侧式子发散，而右侧式子分母是趋于 0 的，所以右侧式子整体趋于正无穷，这样一个原本就发散的式子乘一个正无穷，那就更大了，所以整体是发散的

**再看一个例子**

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250727112205.png)

这里主要讨论 x = 0 处的瑕点

这个式子与 $\frac{\ln x}{x^p}$，在 x = 0 的瑕点处有相同的敛散性

这里仍然对幂函数进行分类讨论

如果 p > 1

那 1/x^p 本来就是一个发散的，然后 lnx 又趋于无穷，变成一个更大的式子，所以整体发散

如果 p = 1

同上，仍然是发散的

如果 p < 1

还是想办法凑一个 p +出来：

$$
\frac{1}{x^{p + p^+}} x^{p^+} \ln x
$$
这里 p+保证 p + p^+ < 1，这样左侧式子还是收敛的，然后右侧，因为 x ->0 的时候右侧整体是趋于一个 0 的无穷小，所以整个式子变得更小，所以当然就是收敛的了

所以  x = 0 处要想收敛，那就是 p < 1



以上几种情况，如果 p < 1 那就凑 p + p^+，如果 p > 1 那就凑 p - p^+

**再看一个例子**

对于 $\int_{0}^1 \ln^qx dx$

这个在 x = 0 瑕点处，这里其实是 $x^0 \ln^q x$，0 < 1，仍然可以凑：

$$
\frac{1}{x^{q^+}} x^{q^+}\ln^q x
$$

这里保证 q^+ < 1

这样左侧的式子就是收敛的，右侧又是一个 x -> 0 的时候的无穷小，所以整个式子一定在 x -> 0 的时候收敛，这里的思想与上文几个例子完全一样

### $f (x)\int_{0}^x f (t) dt = g (x)$ 结构的处理方法

这种结构中 $\int_{0}^x f (t) dt$ 求导之后就是 f (x)，所以一般的处理方法就是两边同时积分，**将 f (x) 放到 dt 的微元中**：

$$
\int f (x)\int_{0}^xf (t) dt dx = \int \left ( \int_{0}^xf (t) dt \right) d\left ( \int_{0}^xf (t) dt \right)= \int g (x) dx
$$

这样等式左边可以得到一个关于 $\int_{0}^xf (t) dt$ 的式子

### 证明 $\int_{a}^x f(t)dt$ 是周期函数的充要条件是 $\int_{0}^{T} f(t)dt = 0$ 的方法

前提条件是 f (x) 是以 T 为周期的函数

基本思想就是进行区间拆分：

$$
\int_{a}^{x+T}f(t)dt = \int_{a}^{x} + \int_{x}^{x + T} 
$$

根据周期函数在任意一个周期长度的区间的积分大小相等，可以得到：

$$
\int_{a}^{x+T}f(t)dt = \int_{a}^{x} + \int_{x}^{x + T} =\int_{a}^{x} + \int_{0}^{T}f(t)dt
$$

这样，无论是从左到右证明，还是从右到左证明，都可以证明充要性了

### 处理隐函数的两个常用方法

**（1）对于 F (x, y, z) = 0，将 z 看作 z(x, y)直接两边对 x 求导或者对 y 求导**

比如 $F (xyz , x^2 + y^2 + z^2, z) = xyz + x^2 + y^2 + z^2 + z = 0$

我们可以将 z 看作 x, y 的函数，然后用等式两边对 x 求导到底来，等式两边对 x 求到底：

得到

$$
\frac{\partial z}{\partial x} = -\frac{yz + 2 x}{xy + 2 z + 1}
$$

**（2）对于 F (x, y, z) = 0，将 x, y, z 看作同等地位的变量，直接两边全微分**


比如 $F (xyz , x^2 + y^2 + z^2, z) = xyz + x^2 + y^2 + z^2 + z = 0$

两边全微分得到：

$$
yzdx + xzdy + xydz + 2xdx + 2ydy + 2zdy + dz = 0
$$

所以：

$$
dz = -\frac{yz + 2 x}{xy + 2 z + 1} dx + \dots dy
$$

### 行列式的逆序数计算方式

一个 n 阶的行列式其实是 n! 项的和

对于其中的一项，其实是 n 个元素的乘积，每个元素依次按顺序取自这 n 行，但是列是不同的

并乘这些元素的-1 的逆序数次幂，这里以 3 阶为例来说明，比如下面一个三阶的行列式：

<img src="https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/image-20241121161529453.png" alt="image-20241121161529453" style="zoom:33%;" />

其中一项是三个元素的乘积

假如第一个元素取第一行第一列，就是 a 11

那么第二个元素取第二行，由于第一列被取过，因此就只有两种取法，只能在第 2 列和第 3 列中取，假设我们取 a 23

那么第三个元素取第三行，就只能取第二列的元素 a 32 了

因此这一行的乘积就是 a 11 * a 23 * a 32

再乘以-1 的逆序对数次幂，这里的逆序对是 a 11 a 23 a 32 这三个元素，任意两个如果列号大的在前面那就是一个逆序对，比如 a 23 a 32 第三列反而排在 a 32 前面这就是一个逆序对，而这个排列中只有这一个逆序对，因此需要乘 ￥(-1)^1￥

因此这一项就是：
$$
(-1)^{1}a_{11} a_{23} a_{32}
$$
当然这只是其中的一项

第一个元素可以取第一行的 n 列中一共 n 个不同的元素

第一行取了之后第二行只能取 n - 1 列了

第三行只能取 n - 2 列了

因此一共有 n! 中取法，也就有 n! 项乘积，每个乘积项都要乘自己的-1 的逆序数幂，然后将这 n! 项加起来就是行列式的值了

<img src="https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/image-20241121162651099.png" alt="image-20241121162651099" style="zoom:50%;" />

反正只需要记住有 n! 项

每一项元素按顺序取自 1，2，3。。。n 行，并且保证这些元素不再同一列

再乘逆序数幂，逆序数是这一项乘积元素的列排列中逆序对数

### 条件处理： $A = - A^T$ 

也就是 A 是一个反对称矩阵的性质

（1）反对称矩阵的对称线上的元素全为 0

（2）奇数阶的反对称矩阵的行列式为 0

（3）对于任意的向量 x，有 $xAx^{T} = 0$ 

$xAx^{T}$ 其实是一个数字，它取转置有：

$$
(xAx^{T})^{T} = xA^{T}x^{T} = -xAx^{T} = xAx^{T} \implies xAx^{T} = 0
$$

**（3）A 必然可以相似对角化**

对于 $\lambda = 0$，也就是 Ax = 0 的极大无关组的解向量个数 $n - r (A)$ 和 $Ax = x \implies (A - E) x = 0$ 的解向量个数 $n - r (A - E)$ 之和是否是 n（这是因为不同特征值之间的特征向量一定线性无关，然后同一特征值 $\lambda$ 又对应 n - r 个线性无关的特征向量，所以合起来一定线性无关）


根据第二条性质，两者相加恰好是 n，所以 A 对应 n 个线性无关的特征向量，所以 A 可以相似对角化

### 条件处理：$A^{2} = E$


**（1）根据 $f (A)$ 与 $f (E)$ 的关系**

得到 $\lambda^2 - 1 = 0$，所以 $\lambda = \pm 1$

**（2）得到 A - E 和 A + E 的秩的关系**

由于 (A - E)(A + E) = 0，所以 r (A -E) + r (A + E) <= n

与上面类似，根据 r (A - E) + r (A + E) >= r ((A- E) - (A + E)) =  n

得到 r (A - E) + r (A + E) = n

**（3）A 必然可以相似对角化**

### 判断两个矩阵 A 和 B 相似的方法



**（1）首先用相似矩阵的必要条件来排除**

比如相似矩阵拥有完全一样的特征值，特征向量，行列式的秩，矩阵的迹，如果不满足这些条件，那就可以直接判断不相似

**（2）如果可以对角化，利用相似的传递性**

一般而言强行判断两个一般矩阵是否相似是非常困难的，所以题目中给的矩阵都非常有特点，可以通过 A ~ $\wedge$，并且 B ~ $\wedge$ 来判断 AB 是否相似，或者不是一个对角矩阵，而是某个中间的 C 矩阵根据传递性来判断


**（3）如果是两个普通的矩阵，那就只能用定义来做了**

通过 AP = PB，设出 P，然后解一堆的方程，一般第三种情况是二阶的；或者直接猜


### 求普通矩阵 A 和 B 相似，以及求 P 矩阵的方法

一般出现在大题中，就使用对角矩阵作为一个桥梁

根据 $P_{1}^{-1}AP_{1} = \wedge=P_{2}^{-1}BP_{2}$，得到：

$$
P_{2}P_{1}^{-1}AP_{1}P_{2}^{-1} = B
$$


### 由 A ~ B 来证明 $A^{T} \sim B^{T}$，以及 $A^{-1}\sim B^{-1}, A^{*} \sim B^{*}$ 的方法（A, B 可逆）

思路就是根据 $P^{-1}AP = B$，两边同时取伴随得到：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250825144624.png)

但是上面伴随运算的乘法有点超纲，大题最好别用，但是逆和转置可以直接使用

在处理伴随的时候可以直接对 $P^{-1}AP = B$ 两边取逆得到：

$$
P^{-1}A^{-1}P = B^{-1}
$$

然后根据 $A^{-1}$ 和 $B^{-1}$ 与伴随的关系得到 $A^{-1} = \frac{A^{*}}{|A|}$，同理 B 逆也是这样，然后代入逆矩阵相似的上面式子，于是得到：

$$
P^{-1}A^{*} P = B^{*}
$$

也就是说，逆矩阵和伴随矩阵，还有原矩阵，他们的相似关系中的 P 矩阵是完全一样的

### 条件处理：$A - \lambda E$ 的两种处理方式

（1）在 A 可相似对角化以及知道了特征值的重数的情况下可以得到 $A - \lambda E$ 的秩的情况

这是因为 A 可相似对角化，n -  $A - \lambda E$ 的秩 = $\lambda$ 的重数

（2）当 $\lambda = 0$ ，并且 A 可相似对角化的情况下可以得到 A 的秩的情况

同理以上两点都可以反推，根据 $A - \lambda E$ 的秩的情况反推

### 证明正交阵特征值为正负 1 的方法

假设一个正交阵 Q，其特征值和特征向量 x 有：

$$
Q x = \eta x
$$
为了用到正交阵的形式即 $Q^TQ = E$，所以上式两边同时取转置得到：

$$
x^TQ^T = \eta x^T
$$

要凑出 $Q^TQ = E$ 的形式，所以第二个等式同时右乘 $Q x = \eta x$，得到：

$$
x^TQ^TQx = \eta x^T\eta x
$$

也就是：

$$
x^Tx = \eta^2 x^Tx
$$
由于 x 是特征向量，所以不是 0 向量，其转置乘自己结果就是一个不为零的数 a，所以有：

$$
a (\eta^2 - 1) = 0 (a \neq 0) \implies \eta = \pm {1}
$$

### 求两个普通二次型转换的合同矩阵的方法

==两个矩阵即相似又合同，利用正交变换，用标准型作为桥梁==

一个普通二次型 f的矩阵是 A，另一个普通二次型 g的矩阵是 B，普通的意思是不是标准型的二次型

假如有 $Q^{T}AQ = B$ ，这里的 Q 是正交矩阵（正交合同变换很特殊）

那么有：

（1）A 和 B 既相似又合同
（2）如果要求 Q，那么就以 f 和 g 分别正交标准化的二次型 h 作为桥梁，A 和 B 因为相似并且是对称矩阵，所以 A 和 B 一定可以通过正交变换法化成同一个对角矩阵，即 f 和 g 可以变换成同一个标准型二次型 h

对于 f 有 $Q_{1}^{T}AQ_{1} = \wedge$，对于 g 有 $Q_{2}^{T}BQ_{2} = \wedge$

这两个二次型矩阵是对称阵并且是相似的，所以两者正交变换化成的标准型一定是相同的，即：

$$
Q_{1}^{T}AQ_{1} = \wedge = Q_{2}^{T}BQ_{2}\implies Q_{2}Q_{1}^{T}AQ_{1}Q_{2}^{T} = B
$$

这里的 $Q_{1}Q_{2}^{T}$ 就是要求的正交矩阵 Q

或者根据二次型的可逆线性变换三者等价性，可以根据变量线性变换角度来理解

x = Q 1 z, y = Q 2 z，所以 $z = Q_{2}^{T}y$，所以 $x = Q_{1}Q_{2}^{T}y$

这里的 $Q_{1}Q_{2}^{T}$ 就是正交合同变换矩阵 Q 了

==两个矩阵只是合同，利用普通的可逆线性变换，利用规范型作为桥梁==

一个普通二次型 f 的矩阵是 A，另一个普通二次型 g 的矩阵是 B，普通的意思是不是标准型的二次型

假如有 $Q^{T}AQ = B$ ，这里的 Q 是普通的可逆矩阵

说明：

（1）A 和 B 合同
（2）这里不能用标准型做中间桥梁，因为 A 和 B 只是合同，不一定相似，所以 A 和 B 不一定能化成同一个标准型矩阵；这里应该用一个规范型作为桥梁

因为 A 和 B 合同，所以正负惯性指数相等，所以一定有：

$$
Q_{1}^{T}AQ_{1} = \wedge_{规} = Q_{2}^{T}BQ_{2}\implies (Q_{2}^{T})^{-1}Q_{1}^{T}AQ_{1}Q_{2}^{-1} = B
$$

所以 $P = Q_{1}Q_{2}^{-1}$，这样就有：$P^{T}AP = B$

如果用坐标变换来处理的话，就是：

$$
x = P_{1}z, y = P_{2}z \implies z = P_{2}^{-1}y\implies x = P_{1}P_{2}^{-1}y = Py\implies P = P_{1}P_{2}^{-1}
$$

事实上一般用坐标变换更方便一些，因为根据 y = P 2 z 可以利用代数方法来得到 z = C y ，这里的 C 就是 P 2 的逆矩阵，这样可以避免求逆矩阵的过程，这在一些数字奇葩的题目中很好用 

**这个方法其实是更通用的方法，无论两个矩阵是否相似，只要合同，就能用规范型做桥梁来求普通的可逆合同矩阵**

### 二次型最值问题的处理方法

要分析 f = x^TAx 的范围，**首先对 x 进行正交变换 x = Qy，将这个二次型转换成标准二次型**，这个标准二次型的矩阵是一个对角阵

将 X = QY 代入 f (X) 得到：
$$
f (X) = x^T A x = y^T Q^TAQy =y^{T}\wedge y = \lambda_1 y_1^2 + \lambda_2 y_2^2 + \lambda_3 y_3^2
$$
这里 y 1, y 2, y 3 的系数是随意的，主要看你正交矩阵 Q 的排布

**然后根据特征值进行放缩**

对于这个对角阵元素，他们是矩阵 A 的特征值，这些特征值一定有：
$$
\lambda_1 \le \lambda_2 \le \lambda_3
$$
所以可以直接对 f (X) 进行放缩：
$$
\lambda_1 y^Ty \le \lambda_1 y_1^2 + \lambda_2 y_2^2 + \lambda_3 y_3^2 \le \lambda_3 y^T y
$$
这样我们就得到了 f (X) 的一个范围



由于 Q 是正交矩阵，**而 X 进行正交变换是不改变向量模的大小的，即：**
$$
x^T x  = (Qy)^T (Qy) = y^Ty
$$
所以我们可以直接得到：
$$
\lambda_1 x^T x \le \lambda_1 y_1^2 + \lambda_2 y_2^2 + \lambda_3 y_3^2 = f (X) \le \lambda_3 x^Tx
$$
也就是：

$$
\lambda_{1}y_{1}^{2} + \lambda_{1}y_{2}^{2}+\lambda_{1}y_{3}^{2} \leq \lambda_1 y_1^2 + \lambda_2 y_2^2 + \lambda_3 y_3^2 = f(X) \leq \lambda_{3}y_{1}^{2} + \lambda_{3}y_{2}^{2}+\lambda_{3}y_{3}^{2}
$$
**最后是取等情况**

注意上式的等号一定可以取到，因为这里 Y 是随机变量，可以随意赋值

左边取等的条件是 y 2 = y 3 = 0 即可

右边取等的条件是 y 1 = y 2 = 0 即可

（不过有时 y 1, y 2, y 3 的系数不一定按序增大，因为这个主要取决于正交矩阵 Q 的列向量排布，反正取等的时候就按照等号进行推导一下即可）

上面是一个结论需要直接记住，而题目中经常给出的是 $x^Tx$ 的约束关系，这样我们就得到了 f (X) 的最大值和最小值了

### A 正定，证明 A = $D^{T}D$ 的两个方法是什么？

#### ==第一个方法，利用 A 与单位阵合同==

A 正定，那么 A 一个可以通过一个线性变换变成 E

即 $C^{T}AC = E$，所以 $A = (C^{T})^{-1}C^{-1}$ 这里的 $D = C^{-1}$

一般来说，可以通过 $Q^{T}AQ = \wedge$，即 X = QY，然后再对 Y 进行线性变换到 Z，h (Z) 是一个规范型，其二次型矩阵就是 E，根据这个过程得到 X=CY
$$
f\to^{X = QY} g\to^{Y = DZ} h\implies f\to^{X = CZ} h \implies C^{T}AC = E
$$


#### ==第二个方法利用正交变换进行平方拆分==

A 可以通过正交变换成一个对角矩阵：

$$
Q^{T}AQ = \wedge \implies A = Q\wedge Q^{T}
$$

由于 A 正定，所以 A 的所有特征值均大于 0，所以这个对角矩阵的对角线元素都大于 0，所以这个对角矩阵可以拆成两个对角元素开根号的矩阵乘积：

$$
A = Q\wedge_{1} \wedge_{1} Q^{T} = (\wedge_{1}Q^{T})^{T} (\wedge_{1}Q^{T}) = D^{T}D
$$

这里拆分的两个对角矩阵如下：

如果在这两个拆分对对角矩阵中间插入 $Q^{T}Q$，那么 A 就可以写成一个矩阵的平方的形式了
