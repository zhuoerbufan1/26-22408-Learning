### lnx 与x, tanx 与 x, sinx 与 x 的比值函数的处理方式

按照对应函数图像上的点与原点的连线的斜率来进行考虑

==lnx 与 x==

对于类似这种 $f(x) = \frac{\ln x}{x}$，它实际上是 lnx 这个函数图像上的一点与原点连线的斜率

对齐求导之后可以发现在 (0, e) 递增，在 (e, infty) 递减，所以有：

$$
0 < \frac{\ln x}{x} \leq \frac{1}{e}(x \in(0, \infty))
$$



==tanx 与 x==


对于 tan x / x，它同样满足这里的斜率关系，当 $x \in\left( 0, \frac{\pi}{4} \right)$ 的时候，首先 tan x / x 一定大于 1，tan x 是始终 > x 的

然后在 (pi/4, 1) 处的斜线斜率是 4/pi，所以 tan x / x 一定小于 4/pi，即：

$$
1 < \frac{\tan x}{x} < \frac{4}{\pi}\left( x\in\left( 0, \frac{\pi}{4} \right) \right)
$$

==sinx 与 x==

当 $x \in \left( 0, \frac{\pi}{2} \right)$ 的时候，根据 sin x 的图像，sinx /x 同样是 sin x 上的点与原点连线的斜率：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250712085115.png)

(x, sinx) 点处的斜率与原点连线的斜率是夹在 k = 1 和 k = pi/2 之间的

所以就有：

$$
\frac{\pi}{2} < \frac{\sin x}{x } < 1\left( x \in \left( 0, \frac{\pi}{2} \right) \right)
$$

所以有不等式：

$$
\frac{\pi}{2}x < \sin x < x\left( x \in \left( 0, \frac{\pi}{2} \right) \right)
$$

### 极限中泰勒公式确定阶数方法

**（1）对于 A - B 类型，需要展开到 A 和 B 的系数不相等的最低次幂**



**（2）对于 A/B 的类型，你先确定分子 A 或者分母 B 的阶数，展成 f (x) + o (x^k) 形式，直接去掉 o (x^k)，然后另一个分母 B 或者分子 A 的整体阶数只要展开大于等于 f (x) 的阶数 k 就行了一般的操作是将分子或者分母参与有效计算的项的阶数展开到大于 f (x) 的阶数就可以了**

也就是将分子或者分母展开成 x^k + o (x^k) 的形式，让多项式的最高次幂大于等于确定好了的阶数

对于分子或者分母，这里有一条规则就是，只要分子或者分母可以写成一个多项式+无穷小的形式，即 $f(x) + o(x^k)$，这里的无穷小是 f (x) 的高阶无穷小，比如 x^3 + o (x^3) 这种，那么这里的无穷小就可以直接去掉

### 条件处理：$a_{n} = \sqrt{ a + a_{n - 1} }$

这类条件形成的结构就是无限的根号套娃：

$$
a_{n} = \sqrt{ a + \sqrt{ a + \sqrt{ \dots } } }
$$

它的处理方式是进行放缩，从而找到 an 的边界，这里的放缩思想是，想办法让 an-1 小于一个数 k，这个数 k 代入 $a_{n} = \sqrt{ a + a_{n - 1} }$ 的时候可以去掉根号

比如 $a_{n} = \sqrt{ 6 + a_{n - 1} }$，这里可以令 $a_{n - 1} < 3$，代入之后发现 $a_{n} < \sqrt{ 6 + 3 } = 3$，从而可以用数归进行证明

因此这里可以令 an - 1 < $2\sqrt{ a } + 1$

可以得到：

$$
a_{n} < \sqrt{ a } + 1 < 2\sqrt{ a } + 1
$$

因此 an 一定是有界的

再根据 an 的函数表达式 f (x) = $\sqrt{ a + x }$，所以 an 一定单调有界极限存在

### xn 和 f (xn) 的敛散性处理方法

主要用于判断选择题中一些 xn 和 f (xn) 的关系，比如下题：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250915110301.png)


=={xn}收敛 => f (xn) 收敛==


数列极限{xn}收敛并不意味着 f (xn) 收敛，比如 xn = $\frac{(-1)^n}{n}$ 这是一个来回震荡趋近于 0 的数列

但是如果 f (x) 是一个符号函数，这个符号函数，只有在 x= 0 的时候等于 0，x > 0 f (x) = 1，x < 0 f (x) = -1

那么 f (xn)，n 趋于无穷的时候 xn 是可能趋于 0 +和 0-两种情况的，所以 f (xn) 的趋近情况是震荡的，极限不存在，因此不收敛

**假如{xn}趋于 a，那么加上 f (x) 在 a 点连续，这样就保证 f (xn) 也收敛了（或者 $\lim_{ x \to a }f(x)$ 存在即可），此时就有：**

$$
\lim_{ n \to \infty } f(x_{n}) = \lim_{ x \to a } f(x)
$$

==f (xn) 收敛 => xn 收敛==

这个普通情况下也是无法推出的，因为 f (x) 如果收敛于 a，那么它可能对应多个 x，比如下面：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250713081901.png)

你 f (x) = a 对应两个自变量取值，那么数列只要收敛于这两个点来回摆动就可以让 f (x) 收敛于 a 了，就比如 f (x) = x^2，对于 f (xn)，只要 xn 收敛于正负对称的两个值，f (x) 还是收敛于相同的平方值，因此 f (xn) 收敛不能推出 xn 收敛

此时必须加上 f (x) 在定义域中与 x 一一对应，即 f (x) 有反函数（f (x) 连续单调是一一映射的子集，f (x) 连续单调则一定是一一映射的），并且 $\lim_{ n \to \infty }f(x_{n} ) = a$ 的这个 a 必须在 f (x) 的值域中

这里关于 a 必须在 f (x) 的值域中的意思是 f (x) 可能是下面的图像：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250713082810.png)

f (x) 在无穷的时候趋近于一个值 a，但是这个 a 不在 f (x) 的值域中，那么说 $\lim_{ n \to \infty }f(x_{n}) = a$，此时这个 a 在 f (x) 的定义域中没有对应的点，那么 xn 只能趋于无穷了，所以也不能推出 xn 收敛

**f (x) 与 x 一一对应，即 f (x) 有反函数，并且 $\lim_{ n \to \infty }f(x_{n} ) = a$ 的这个 a 必须在 f (x) 的值域中，此时才能说 f (xn) 收敛于 a，可以推出 xn 收敛（收敛于 f (x) = a 的时候对应的 x 的值）**

### 利用泰勒公式求 n 阶导的方法


泰勒公式的写法有两种，一种是拉格朗日余项，一种是皮亚诺余项：

![image-20241119150538406](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/image-20241119150538406.png)

上面这个公式是所有函数的泰勒展开的一般写法，也是带未知系数的写法，也可以说是理论写法，其可以直接简写成下面：

$$
f(x) = a_{0} + a_{1}(x - x_{0}) + a_{2}(x - x_{0})^2 + \dots \dots +a_{n}(x - x_{0})^n + o((x - x_{0})^n)
$$

这个是带皮亚诺余项的泰勒展开，不过我们这里主要说明一下系数与教材给的常见具体的泰勒展开的通项对应关系，这里是皮亚诺余项还是拉格朗日余项其实无所谓

一般教材中会直接给出一些常见函数的泰勒展开，比如 ln ( x + 1) 在 x 0 = 0 处的泰勒展开具体的系数通项：

$$
\ln (1+x) = \sum_{n=0}^\infty \frac{(-1)^n}{n+1} x^{n+1} = x - \frac{x^2}{2} + \frac{x^3}{3} - \cdots \quad 
$$
但是这里的通项不一定对应上面带未知系数的第 n 项，**这里主要看 x 的次数**，这里的 ln (1 + x) 的具体系数通项次数是 n + 1 次，所以这里的具体系数通项应该对应于 ln ( 1 + x) 带未知系数的泰勒展开的第 n + 1 项，即：

$$
a_{n + 1} = \frac{f^{(n + 1)}(x_{0})}{(n + 1)!} = \frac{(-1)^n}{n + 1}
$$

x 0 = 0，也就得到了 ln ( 1+ x) 在 0 处的 n + 1 阶导数：

$$
f^{(n + 1)}(x_{0})= \frac{(-1)^n}{n + 1}(n + 1)!
$$

**所以这里想说的是，那种一般的，带未知系数的通项的 n 阶导一般你是无法自己求出来的，只能记住常见的泰勒公式的具体带系数的展开，通过 x 的次数来找到对应关系，从而得到 n 阶导；**


### 复合函数求导的一个快速做法

若 y = f (u)，且 u = g (x)

那么就有：

$$
\frac{dy}{dx} = \frac{dy}{du} \frac{du}{dx} = f'(u) g'(x) 
$$

他的含义不仅仅在求解析式这么简单，同时在于求值的时候，即：

$$
\frac{dy}{dx}|_{x=x_{0}} = f'(u_{0})g'(x_{0})[其中u_{0}=g(x_{0})]
$$

也就是 y 对 x 在 x 0 处的导数的值 == f 对 u 在 u 0 处的导数的值 * u 对 x 在 x 处的导数的值【其中 u 0 = g(x 0)】

#### 泰勒证明凹凸性的方法

令 $\lambda x_{1} + (1 - \lambda) x_{2} = x_{0}$，然后在 x 0 处泰勒展开，一般泰勒展开就是在中间位置进行展开，而不是端点：

$$
f (x) = f (x_{0}) + f' (x_{0})(x - x_{0}) + \frac{f'' (\xi)}{2}(x - x_{0})^2
$$

然后将 x 1 和 x 2 这两个端点代入得到：

$$
f (x_{1}) = f (x_{0}) +f' (x_{0})(x_{1} - x_{0}) + \frac{f'' (\xi_{1})}{2} (x_{1} - x_{0})^2
$$

x 2：

$$
f (x_{2}) = f (x_{0}) +f' (x_{0})(x_{2} - x_{0}) + \frac{f'' (\xi_{2})}{2} (x_{2} - x_{0})^2
$$

这两个式子凑成题目要证明的样子，第一个式子乘 $\lambda$，第二个式子乘 $1 - \lambda$，然后相加：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250718105420.png)

这个式子等号右侧的末尾两项都是 >0 的，所以有：

$$
\lambda f (x_{1}) + (1 - \lambda) f (x_{2}) > f (x_{0})
$$

也就得到了证明

这 n 个式子还是乘系数 1/n 全部加起来凑出题目要证的东西得到：

#### 利用泰勒展开求 n 阶导的方法 

一般这种问题就是直接求函数的 n 阶导不好求，需要利用常见的泰勒带具体系数的展开，来得到 an 和系数的关系，从而得到 n 阶导

题中给定一个常见的函数我们可以明确知道其泰勒带具体系数展开，比如 $x^2\ln(x + 1)$，这时题目要求这个函数在 x 0 处的 n 阶导，为了不出错，应该遵循下面的步骤

（1）写出 f (x) 在 x 0 处的带未知系数的展开（幂级数）：
$$
x^2 \ln(x + 1) = a_{0} + a_{1}(x - x_{0}) + a_{2}(x - x_{0})^2 + \dots \dots +a_{n}(x - x_{0})^n + o((x - x_{0})^n)
$$
（2）写出 $f(x)$ 的具体的系数的泰勒展开（一般是常用函数的泰勒展开）：
$$
x^2 \ln(x + 1) = (x - x_{0})^3 - \frac{1}{2}(x - x_{0})^4 + \frac{1}{3} (x - x_{0})^5 + \dots\dots \frac{(-1)^n}{n + 1}(x - x_{0})^{n + 3}
$$
（3）根据具体的通项泰勒**展开的次数**判断其对应带未知系数展开的哪一项，比如这里具体通项中是 n + 3 次，所以应该对应带未知系数展开中的第 n + 3 项，即 a (n + 3)，而不是 an

（4）写出带未知系数展开中的第 n 项对应的具体泰勒展开通项，这里就是 $a_{n}(x - x_{0})^n = \frac{(-1)^{n-3}}{n -2}(x - x_{0})^{n}$

然后根据 $a_{n} = \frac{f^{(n)}(x_{0})}{n!}$，从而得到 f (x) 在 x 0 处的 n 阶导

主要根据就是三点：

（1）带未知系数的这种泰勒展开是所有函数的通法，即 $\sum a_{i}(x-x_{0})^i$ 这种，它这里的系数有一个公式就是 $a_{i} = \frac{f^{(i)}(x_{0})}{i!}$，这是第 i 项的系数

（2）一个常见函数我们可以直接凑出具体的泰勒展开，我们同样可以得到第 i 项的系数，并且这个系数是具体的可知的

（3）根据具体的泰勒展开和带未知系数的泰勒展开的次数对应关系来得到 ai 的表达式，而 $a_{i} = \frac{f^{(i)}(x_{0})}{i!}$，这样就可以求出 i 阶导数了



#### 利用泰勒展开求非零处的 n 阶导的方法

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250719100531.png)

这里需要求的是 f (x) 在 x = 1 处的泰勒展开，但是你 ln (1 + x) 中的 x 是趋于 1 的，所以不能用常见的泰勒公式直接展开成具体系数的形式

这里的处理措施是将 ln (1 + x) 中凑成 ln (1 + A)，其中 A 是 x - 1 的形式，这样 x = 1 的时候 A = 0 于是就可以将 A 看作一个整体进行泰勒展开了：

$$
f(x) = (x - 1)^2\ln(2 + x - 1 ) = (x - 1)^2 \ln\left( \frac{2 + x - 1}{2} * 2\right ) = (x - 1)^2\ln 2 + (x - 1)^2\ln(1 + \frac{x-1}{2})
$$

也就是 $f(x) = (x - 1)^2\ln 2 + (x - 1)^2\ln(1 + \frac{x-1}{2}) = (x - 1)^2\ln 2 + g(x)$

这个函数的的 2025 阶导是和 g (x) 的 2025 阶导是一样的，所以我们只用求 g (x) 在 x = 1 处的 2025 阶导即可

$$
g(x) =  (x - 1)^2\ln(1 + \frac{x-1}{2})
$$

那就是求这个函数在 x = 1 处的泰勒展开具体形式的系数了

理论带未知系数的形式是：

$$
g(x) = a_{0}  + a_{1}(x - 1) + a_{2}(x - 1)^2 + \dots \dots +a_{n}(x - 1)^n + o((x - 1)^n)
$$

然后就是利用常见的公式写出带具体系数的泰勒展开，你这里将 x-1/2 看作一个整体，对这个整体在 0 处的展开为：

$$
g(x) = (x - 1)^2\left[ \frac{x-1}{2}  - \frac{1}{2} \left( \frac{x-1}{2} \right)^2 + \dots (-1)^{n - 1} \frac{1}{n} \left( \frac{x-1}{2} \right)^n \dots\right]
$$

它的通项就是：

$$
(-1)^{n-1}  \frac{1}{n} \frac{1}{2^n}(x - 1)^{n + 2}
$$

你这里，虽然是对 x-1/2 整体在 0 处的展开，但是**写成的形式是关于 x-1 的多项式，所以对于 g (x) 来说就是在 x = 1 处的展开**

根据 x - 1 的次数关系，所以有：

$$
a_{n + 2} = \frac{g^{(n  + 2)}(1)}{(n + 2)!} = (-1)^{n - 1} \frac{1}{n} \frac{1}{2^n}(x - 1)^{n + 2}
$$


因此 $g^{(n + 2)}(1) = (-1)^{n - 1} \frac{1}{n} \frac{1}{2^n}(n + 2)!$


n = 2023 就是结果了

### 行列式的逆序数计算方式

一个 n 阶的行列式其实是 n! 项的和

对于其中的一项，其实是 n 个元素的乘积，每个元素依次按顺序取自这 n 行，但是列是不同的

并乘这些元素的-1 的逆序数次幂，这里以 3 阶为例来说明，比如下面一个三阶的行列式：

<img src="https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/image-20241121161529453.png" alt="image-20241121161529453" style="zoom:33%;" />

其中一项是三个元素的乘积

假如第一个元素取第一行第一列，就是 a 11

那么第二个元素取第二行，由于第一列被取过，因此就只有两种取法，只能在第 2 列和第 3 列中取，假设我们取 a 23

那么第三个元素取第三行，就只能取第二列的元素 a 32 了

因此这一行的乘积就是 a 11 * a 23 * a 32

再乘以-1 的逆序对数次幂，这里的逆序对是 a 11 a 23 a 32 这三个元素，任意两个如果列号大的在前面那就是一个逆序对，比如 a 23 a 32 第三列反而排在 a 32 前面这就是一个逆序对，而这个排列中只有这一个逆序对，因此需要乘 ￥(-1)^1￥

因此这一项就是：
￥￥
(-1)^{1}a_{11} a_{23} a_{32}
￥￥
当然这只是其中的一项

第一个元素可以取第一行的 n 列中一共 n 个不同的元素

第一行取了之后第二行只能取 n - 1 列了

第三行只能取 n - 2 列了

因此一共有 n! 中取法，也就有 n! 项乘积，每个乘积项都要乘自己的-1 的逆序数幂，然后将这 n! 项加起来就是行列式的值了

<img src="https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/image-20241121162651099.png" alt="image-20241121162651099" style="zoom:50%;" />

反正只需要记住有 n! 项

每一项元素按顺序取自 1，2，3。。。n 行，并且保证这些元素不再同一列

再乘逆序数幂，逆序数是这一项乘积元素的列排列中逆序对数

### 条件处理： $A = - A^T$ 

也就是 A 是一个反对称矩阵的性质

（1）反对称矩阵的对称线上的元素全为 0

（2）奇数阶的反对称矩阵的行列式为 0

（3）对于任意的向量 x，有 $xAx^{T} = 0$

$$
(xAx^{T})^{T} = xA^{T}x^{T} = -xAx^{T} = xAx^{T} \implies xAx^{T} = 0

### 条件处理：向量组线性无关

一个向量组线性无关，可以得到三个角度的结论

（1）根据定义，满足 k 1 a 1 + k 2 a 2 + k 3 a 3 + ... k 4 a 4 + ... km am = 0 的 k 1, k 2 ... km 必须全部都是 0

（2）根据方程组，向量组构成的矩阵 A，Ax = 0 只有零解

（3）根据秩，向量组的秩等于向量组的向量个数

（4）根据行列式，如果向量组是 n 维并且是 n 个向量的话，这个向量组构成的矩阵的行列式不等于 0

得到 r (A - E) + r (A + E) = n

### 判断两个矩阵 A 和 B 相似的方法



**（1）首先用相似矩阵的必要条件来排除**

比如相似矩阵拥有完全一样的特征值，特征向量，行列式的秩，矩阵的迹，如果不满足这些条件，那就可以直接判断不相似

**（2）如果可以对角化，利用相似的传递性**

一般而言强行判断两个一般矩阵是否相似是非常困难的，所以题目中给的矩阵都非常有特点，可以通过 A ~ $\wedge$，并且 B ~ $\wedge$ 来判断 AB 是否相似，或者不是一个对角矩阵，而是某个中间的 C 矩阵根据传递性来判断


**（3）如果是两个普通的矩阵，那就只能用定义来做了**

通过 AP = PB，设出 P，然后解一堆的方程，一般第三种情况是二阶的；或者直接猜


### 求普通矩阵 A 和 B 相似，以及求 P 矩阵的方法

一般出现在大题中，就使用对角矩阵作为一个桥梁

根据 $P_{1}^{-1}AP_{1} = \wedge=P_{2}^{-1}BP_{2}$，得到：

$$
P_{2}P_{1}^{-1}AP_{1}P_{2}^{-1} = B
$$


### 由 A ~ B 来证明 $A^{T} \sim B^{T}$，以及 $A^{-1}\sim B^{-1}, A^{*} \sim B^{*}$ 的方法（A, B 可逆）

思路就是根据 $P^{-1}AP = B$，两边同时取伴随得到：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250825144624.png)

但是上面伴随运算的乘法有点超纲，大题最好别用，但是逆和转置可以直接使用

在处理伴随的时候可以直接对 $P^{-1}AP = B$ 两边取逆得到：

$$
P^{-1}A^{-1}P = B^{-1}
$$

然后根据 $A^{-1}$ 和 $B^{-1}$ 与伴随的关系得到 $A^{-1} = \frac{A^{*}}{|A|}$，同理 B 逆也是这样，然后代入逆矩阵相似的上面式子，于是得到：

$$
P^{-1}A^{*} P = B^{*}
$$

也就是说，逆矩阵和伴随矩阵，还有原矩阵，他们的相似关系中的 P 矩阵是完全一样的

### 条件处理：$A - \lambda E$ 的两种处理方式

（1）在 A 可相似对角化以及知道了特征值的重数的情况下可以得到 $A - \lambda E$ 的秩的情况

这是因为 A 可相似对角化，n -  $A - \lambda E$ 的秩 = $\lambda$ 的重数

（2）当 $\lambda = 0$ ，并且 A 可相似对角化的情况下可以得到 A 的秩的情况

同理以上两点都可以反推，根据 $A - \lambda E$ 的秩的情况反推

### 证明正交阵特征值为正负 1 的方法

假设一个正交阵 Q，其特征值和特征向量 x 有：

$$
Q x = \eta x
$$
为了用到正交阵的形式即 $Q^TQ = E$，所以上式两边同时取转置得到：

$$
x^TQ^T = \eta x^T
$$

要凑出 $Q^TQ = E$ 的形式，所以第二个等式同时右乘 $Q x = \eta x$，得到：

$$
x^TQ^TQx = \eta x^T\eta x
$$

也就是：

$$
x^Tx = \eta^2 x^Tx
$$
由于 x 是特征向量，所以不是 0 向量，其转置乘自己结果就是一个不为零的数 a，所以有：

$$
a (\eta^2 - 1) = 0 (a \neq 0) \implies \eta = \pm {1}
$$

### 求两个普通二次型转换的合同矩阵的方法

==两个矩阵即相似又合同，利用正交变换，用标准型作为桥梁==

一个普通二次型 f的矩阵是 A，另一个普通二次型 g的矩阵是 B，普通的意思是不是标准型的二次型

假如有 $Q^{T}AQ = B$ ，这里的 Q 是正交矩阵（正交合同变换很特殊）

那么有：

（1）A 和 B 既相似又合同
（2）如果要求 Q，那么就以 f 和 g 分别正交标准化的二次型 h 作为桥梁，A 和 B 因为相似并且是对称矩阵，所以 A 和 B 一定可以通过正交变换法化成同一个对角矩阵，即 f 和 g 可以变换成同一个标准型二次型 h

对于 f 有 $Q_{1}^{T}AQ_{1} = \wedge$，对于 g 有 $Q_{2}^{T}BQ_{2} = \wedge$

这两个二次型矩阵是对称阵并且是相似的，所以两者正交变换化成的标准型一定是相同的，即：

$$
Q_{1}^{T}AQ_{1} = \wedge = Q_{2}^{T}BQ_{2}\implies Q_{2}Q_{1}^{T}AQ_{1}Q_{2}^{T} = B
$$

这里的 $Q_{1}Q_{2}^{T}$ 就是要求的正交矩阵 Q

或者根据二次型的可逆线性变换三者等价性，可以根据变量线性变换角度来理解

x = Q 1 z, y = Q 2 z，所以 $z = Q_{2}^{T}y$，所以 $x = Q_{1}Q_{2}^{T}y$

这里的 $Q_{1}Q_{2}^{T}$ 就是正交合同变换矩阵 Q 了

==两个矩阵只是合同，利用普通的可逆线性变换，利用规范型作为桥梁==

一个普通二次型 f 的矩阵是 A，另一个普通二次型 g 的矩阵是 B，普通的意思是不是标准型的二次型

假如有 $Q^{T}AQ = B$ ，这里的 Q 是普通的可逆矩阵

说明：

（1）A 和 B 合同
（2）这里不能用标准型做中间桥梁，因为 A 和 B 只是合同，不一定相似，所以 A 和 B 不一定能化成同一个标准型矩阵；这里应该用一个规范型作为桥梁

因为 A 和 B 合同，所以正负惯性指数相等，所以一定有：

$$
Q_{1}^{T}AQ_{1} = \wedge_{规} = Q_{2}^{T}BQ_{2}\implies (Q_{2}^{T})^{-1}Q_{1}^{T}AQ_{1}Q_{2}^{-1} = B
$$

所以 $P = Q_{1}Q_{2}^{-1}$，这样就有：$P^{T}AP = B$

如果用坐标变换来处理的话，就是：

$$
x = P_{1}z, y = P_{2}z \implies z = P_{2}^{-1}y\implies x = P_{1}P_{2}^{-1}y = Py\implies P = P_{1}P_{2}^{-1}
$$

事实上一般用坐标变换更方便一些，因为根据 y = P 2 z 可以利用代数方法来得到 z = C y ，这里的 C 就是 P 2 的逆矩阵，这样可以避免求逆矩阵的过程，这在一些数字奇葩的题目中很好用 

**这个方法其实是更通用的方法，无论两个矩阵是否相似，只要合同，就能用规范型做桥梁来求普通的可逆合同矩阵**

### 二次型最值问题的处理方法

要分析 f = x^TAx 的范围，**首先对 x 进行正交变换 x = Qy，将这个二次型转换成标准二次型**，这个标准二次型的矩阵是一个对角阵

将 X = QY 代入 f (X) 得到：
$$
f (X) = x^T A x = y^T Q^TAQy =y^{T}\wedge y = \lambda_1 y_1^2 + \lambda_2 y_2^2 + \lambda_3 y_3^2
$$
这里 y 1, y 2, y 3 的系数是随意的，主要看你正交矩阵 Q 的排布

**然后根据特征值进行放缩**

对于这个对角阵元素，他们是矩阵 A 的特征值，这些特征值一定有：
$$
\lambda_1 \le \lambda_2 \le \lambda_3
$$
所以可以直接对 f (X) 进行放缩：
$$
\lambda_1 y^Ty \le \lambda_1 y_1^2 + \lambda_2 y_2^2 + \lambda_3 y_3^2 \le \lambda_3 y^T y
$$
这样我们就得到了 f (X) 的一个范围



由于 Q 是正交矩阵，**而 X 进行正交变换是不改变向量模的大小的，即：**
$$
x^T x  = (Qy)^T (Qy) = y^Ty
$$
所以我们可以直接得到：
$$
\lambda_1 x^T x \le \lambda_1 y_1^2 + \lambda_2 y_2^2 + \lambda_3 y_3^2 = f (X) \le \lambda_3 x^Tx
$$
也就是：

$$
\lambda_{1}y_{1}^{2} + \lambda_{1}y_{2}^{2}+\lambda_{1}y_{3}^{2} \leq \lambda_1 y_1^2 + \lambda_2 y_2^2 + \lambda_3 y_3^2 = f(X) \leq \lambda_{3}y_{1}^{2} + \lambda_{3}y_{2}^{2}+\lambda_{3}y_{3}^{2}
$$
**最后是取等情况**

注意上式的等号一定可以取到，因为这里 Y 是随机变量，可以随意赋值

左边取等的条件是 y 2 = y 3 = 0 即可

右边取等的条件是 y 1 = y 2 = 0 即可

（不过有时 y 1, y 2, y 3 的系数不一定按序增大，因为这个主要取决于正交矩阵 Q 的列向量排布，反正取等的时候就按照等号进行推导一下即可）

上面是一个结论需要直接记住，而题目中经常给出的是 $x^Tx$ 的约束关系，这样我们就得到了 f (X) 的最大值和最小值了

### A 正定，证明 A = $D^{T}D$ 的两个方法是什么？

#### ==第一个方法，利用 A 与单位阵合同==

A 正定，那么 A 一个可以通过一个线性变换变成 E

即 $C^{T}AC = E$，所以 $A = (C^{T})^{-1}C^{-1}$ 这里的 $D = C^{-1}$

一般来说，可以通过 $Q^{T}AQ = \wedge$，即 X = QY，然后再对 Y 进行线性变换到 Z，h (Z) 是一个规范型，其二次型矩阵就是 E，根据这个过程得到 X=CY
$$
f\to^{X = QY} g\to^{Y = DZ} h\implies f\to^{X = CZ} h \implies C^{T}AC = E
$$


#### ==第二个方法利用正交变换进行平方拆分==

A 可以通过正交变换成一个对角矩阵：

$$
Q^{T}AQ = \wedge \implies A = Q\wedge Q^{T}
$$

由于 A 正定，所以 A 的所有特征值均大于 0，所以这个对角矩阵的对角线元素都大于 0，所以这个对角矩阵可以拆成两个对角元素开根号的矩阵乘积：

$$
A = Q\wedge_{1} \wedge_{1} Q^{T} = (\wedge_{1}Q^{T})^{T} (\wedge_{1}Q^{T}) = D^{T}D
$$

这里拆分的两个对角矩阵如下：

如果在这两个拆分对对角矩阵中间插入 $Q^{T}Q$，那么 A 就可以写成一个矩阵的平方的形式了
