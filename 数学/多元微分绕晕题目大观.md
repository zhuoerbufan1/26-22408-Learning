## 0 链式法则

一般来说就是异路相加，同路相乘

## 1 关于位置的形式一致

对于 f (x, y); f (u, y); f (x+y, 2 x)，这三种 f 的表达式，他们的形式是一样的，都是关于第一个位置和第二个位置的函数，因此当这三者两个位置的值相等时，结果相等

即 x = 1, y = 2, f (x, y) = A 的时候

那么当 u = 1, v = 2 的时候同样有 f (u, v) = A

 当x + y = 1, 2 x = 2 的时候同样有 f (x+y, 2 x) = A

具有相同映射关系的两个表达式，不管实际上是什么变量的函数，只要映射关系一样，那么其关于位置的表达式就是形式一致的，对位置求导之后的表达式关于位置变量的形式也是一致的，所以当位置取值相等的时候，函数值也就相等

比如，对于两个映射关系一样但是复合函数不一样的两个函数，比如 f (u, v), f (x, y)，这里假设 u, v 都是关于 x, y 的函数，即 f (u (x, y), v (x, y)), f (x,  y)

只要映射关系一样，那么这个映射关系对位置求导的形式就是一样的

也就是说 $f'_{1}(u, v)$ 与 $f'_{1}(x, y)$ 的中，将 $f'_{1}(u, v)$ 看作 u, v 的函数的表达式，其与 $f'_{1}(x, y)$ 看作 x, y 的表达式的区别仅仅在于未知数的符号不一样，形式完全是一致的，那么当 u = 1, v = 1，x =1, y = 1 的时候这两个偏导数的值就是一样的即 $f_{1}'(u, v) =f_{1}'(x, y)$



 $f'_{2}(u, v)$ 与 $f'_{2}(x, y)$ 也是这样

## 2 关于写法的规范

如果还是混着用，那么此时 $\frac{\partial f}{\partial x}$ 是表示对第二个位置的偏导还是作为二元函数对 x 求到底的偏导就说不清了

因此这里规定，映射法则一律与位置联系在一起，并且最好是写成 $f_{1}', f_{2}'$ 这种形式； 变量一律与求到底的自变量联系在一起

因此对于这种混合的多元函数，有两种写法是规范的：

（1）$映射与位置联系在一起$，比如上面的 $f'_{1}, f'_{2}$ 就代表映射 f (u, x, y) 对第 1个位置以及第 2 个位置求偏导，只要是映射，就是与位置联系一起的，比如 $f_{x}'$ 这个也表示 f (u , x, y) 对第二个位置的偏导，它的含义与 $f_{2}'$ 相同

（2）$\frac{\partial 变量}{\partial 自变量}$，比如上面的 $\frac{\partial z}{\partial x}$，就代表 z 作为 x, y 的二元函数对 x 求到底的偏导，而不是 z (u, x, y) 这样的三元函数，中 z 对第二个位置变量 x 的偏导

**映射法则的偏导就单单表示对位置复合整体的求导，变量对自变量求偏导则是穿过复合函数一直求导到底

在自己写题目的时候规范写法就是两种，$f_{1}'$ 映射法则加数字下标，表示对位置偏导；$\frac{\partial z}{\partial x}$ 表示 z 对自变量求到底的偏导

==但是有的题目不是很规范，要看情况具体分析==

## 5 先带后求的问题


一阶偏导先带后求不用多说，即 $\frac{\partial u (x, y)}{\partial y}|_{(x_{0}, y_{0})}$ 一定是先代入 x 0 到 u (x, y) 中然后对 y 求偏导，这个式子的含义就是 u (x, y) 在 x = x 0 的情况下，u (x 0, y) 对 y 在 y 0 处的导数

二阶混合偏导先带后求，比如求 $\frac{\partial^2 u}{\partial x \partial y}|(x_{0}, y_{0})$，这个式子的含义是 $\frac{\partial u}{\partial x}(x, y)$ 这个关于 x, y 的函数, 在 x = x 0 的情况下，$\frac{\partial u}{\partial x}(x_{0}, y)$ 对于 y 在 y 0 处的导数

所以我们一定是先求出 $\frac{\partial u}{\partial x}$，这是一个关于 x, y 的函数，然后再使用先带后求，一定是在一阶导中代入值 x 0 然后求偏导，所以此时先带后求就是先将 x 0 代入 $\frac{\partial u}{\partial x}(x, y)$ 这个关于 x, y 的函数中，然后再对 y 求偏导

而不能一开始对 x 求偏导的时候就代入 y 0，这样做是错的，前面代入 y 0 后面就没办法求二阶偏导了，而且也不符合这个式子的含义

$$
df(1, 1) = f_{1}'(1, 1)d(s_{1}) + f_{2}'(1, 1)d(s_{2})
$$

那么对于题目给出的两个式子列出方程：

$$
\frac{df}{dx} = f_{1}'(x + 1, e^{x})dx + f_{2}'(x + 1, e^{x})e^{x}dx

这样解出来就得到结果了

$$

这道题这里的 $f'_{y}(x, x + y) = 2y$ 的含义是对 y 求到底的偏导的意思

这里为了方便看直接令 $f(x, x +y)=g(x, y)$

因此有 $g_{y}'(x, y)=2y$

所以 $f(x, x + y) =g(x, y) = y^{2} + \phi(x)$

根据 f (x, x) = x^2，可以在 f (x, x + y) 中令 y = 0 从而得到 $\phi(x) = x^{2}$

所以 $f(x, x + y) =y^{2} + x^{2}$

但是题目中的 $f_{x}'(x, y)$ 这个明显是对位置的偏导，所以得对 f (x, x + y) 的式子进行换元处理

令 x = u, x + y = v 得到：

$$
f(u, v) = u^{2} + (v-u)^{2}
$$
所以 f 对第一个位置的偏导结果就是 4 u - 2 v

因此 D 正确

图中做法的错误之处在于，题中要求的 $f_{x}'(x, y)$ 是对第一个位置的偏导结果，并且第一个位置用 x 表示，第二个位置用 y 表示

而图中的做法 $f_{1}'$ 的确也是对位置的偏导结果，但是得到的 x 和 y 并不代表位置，图中做法的 x +y 才代表第一个位置，x/y 代表第二个位置，图中做法的 x 和 y 与题目要求的 x 和 y 是不一样的

就比如 f (x+y, x/y) = x+y + x/y，在这里 x 和 y 并不代表位置，f 关于位置的映射应该是 f(u, v) = u + v，所以如果要将这个函数写成 f (x, y)，那么应该写成 f (x, y) = x  + y，这里的 x 和 y 才代表位置

因此这道题目的正确做法是令 x + y = u， x/y = v，代入之后变成 f (u, v) 的关于 u 和 v 两个位置的函数，然后再对 u 求偏导，然后再写成 x 和 y
