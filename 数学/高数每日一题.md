
### 1 变限积分求导 + 极值和导数的充要条件 + 高阶导数

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20251109194600.png)

这道题直接将 f (x) 拆开求三阶导，可以发现：

$$
f'''(x) = e^{\sin x}\cos x + e^{-\sin x}\cos x
$$

三阶导不等于 0，根据极值点和拐点的充分条件，所以 2 3 对，1 错

求 f 高阶导代入 $2\pi$

这里可以令：

$$
g(t) = f'''(2\pi + t) = e^{\sin t}\cos t + e^{-\sin t}\cos t
$$

所以：

$$
g'''(t) = f^{(6)}(2\pi + t) \implies f'''(2\pi) = f^{(6)}(2\pi +t)|_{t = 0} = g'''(0)
$$


由于 g (t) 是一个偶函数，所以求三次导之后是一个奇函数，所以 g''' (0) = 0，所以 4 正确

### 5 数列 n 项和的敛散性

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20251111081439.png)

**特值法**

首先观察 an 是递增的，所以 an 发散只可能发散到无穷，所以可以举 an = n ，那么 an+1 = n + 1，于是 bn 可以举 n + 0.5，显然 an 和 bn 都是发散的，所以 A 错

当 an 递增且收敛的时候，可以举 an = 1 - 1/n，那么 an = 1- 1/(n+1)，bn 卡在中间，于是 bn 可以举 1 - 1/(n+0.5 )，所以此时 an 和 bn 都是收敛的

所以 ABD 都可以排除了

**严格证明 C**

如果 an 收敛，那么对 an < bn < an + 1 两边使用夹逼，可以得到 bn 同样是收敛的
如果 bn 收敛，根据 an < bn < an + 1，可以得到 bn < an + 1 < bn + 1，同样用一次夹逼可以得到 an 也是收敛的；
或者当 bn 收敛的时候 bn 一定是有界的，即 bn < M，因此 an < M，所以 an 是单调增并且有上界，所以 an 也是收敛的

因此 an 和 bn 就是同敛散性的

### 8* 定积分定义的一种特殊处理思路

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20251112111355.png)

这道题的底数部分很容易处理，用定积分定义可以得到结果就是 ln (1 + $\sqrt{ 2 }$)

这里的指数 n 别一起算，底数的极限是 ln ( 1 + $\sqrt{ 2 }$) < 1，所以原式的底数在 n 足够大的时候一定小于一个小于 1 的常数 r

因此当 n 足够大的时候有：

$$
0 < \left[ \frac{1}{\sqrt{ n^{2}  +1 }}\dots \right]^{n}< r^{n} = 0
$$

所以取极限根据夹逼的结果就是 0
