#### 递推函数法证明数列单调性方法

**结论：对于 $x_{n + 1} = f(x_{n})$ 这样的式子一般都可以用上述方式证明，对于 $x_{n+1} = f(x_{n})$，如果 f 是单调递增的，那么{xn}这个数列就是单调的，至于单调增还是单调减取决于 x 2 和 x 1，如果 x 2 > x 1 那就是单增，如果 x 2 < x 1 那就是单调减**

这个结论的正确性在于，xn+1 - xn 可以写成 $x_{n + 1} - x_{n} = f(x_{n}) - f(x_{n-1}) = f'(\xi)(x_{n} - x_{n - 1})$，那么如果 f 是单调增的，所以 $f'(\xi) > 0$，所以这个差值的正负就取决于 xn 和 xn-1 的正负，而 xn 与 xn-1 作差又可以继续往前取决于 xn-1 和 xn-2 的正负，一直递推到 x 2 - x 1，当 x 2 - x 1 > 0 的时候推出 x 3 > x 2，继续推出 x 4 > x 3 一直推出 xn+1 > xn，那么 {xn}就是递增的了

如果 xn+1 = f (xn) 中 f 是单调减的，那么{xn}一定不单调



### 压缩映射法证明不单调数列的极限

压缩映射法主要用于证明不单调的数列的极限，它包括两个定理：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250721210924.png)

（1）

第一个定理的正确性在于，给定的条件 $|x_{n + 1} - a| = |f(x_{n}) - f(a)| \leq r|x_{n} - a|$ 可以一直递推下去：

$$
|x_{n + 1} - a| = |f(x_{n}) - f(a)| \leq r|x_{n} - a|\dots \leq r^n|x_{1} - a|
$$

这样，对 $|x_{n + 1} - a|$ 使用夹逼：

$$
0 \leq |x_{n + 1} - a| \leq r^n|x_{1} - a|(\to 0)
$$

所以 $\lim_{ n \to \infty } |x_{n + 1} - a| = 0$，因此极限就是 a，所以其实如果能直接猜出极限 a 的话，就可以按照上面过程装模做样证明一下


（2）

这个定理它给的条件仍然是 f (a) = a，不过多加了一个导数

它的正确性在于：

$$
|x_{n + 1} - a| = |f(x_{n}) - f(a)| = |f'(\xi)| \cdot|x_{n} - a|\leq r|x_{n} - a|
$$

仍然跟第一个定理一样继续递推下去，用夹逼，得到极限就是 a

#### ==分析过程==

证明有界，那就直接先作差：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250911111724.png)

然后对分子进行研究，构造函数：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250911111743.png)

这个函数在 0 的左右是先增后减的，并且在 0 处取得 0，所以整个函数就是小于 0 的

因此 $e^{x_{n + 1}} - e^{x_{n}}$ 的正负就取决于分母

所以 0 就是分界点，如果 xn > 0，那么 xn+1 就递减，往 0 靠近；如果 xn < 0，那么 xn + 1 就递增，还是向 0 靠近

因此 0 很可能就是极限，因此 0 很可能就是下界或者上界

**以上是分析猜测内容，可以猜出 0 就是分界点，所以单调有界的有界性应该使用 0**

#### ==有界性==


下面证明有界性，根据上文分析，那就是观察 xn 与 0 的大小关系

这里使用数学归纳法来证明 xn 与 0 的关系，即用数学归纳法证明有界性

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250911113624.png)

将 xk 移动过去得到：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250911113641.png)

根据基本不等式，$e^{x_{k + 1}} > 1$，所以 xk+1 > 0

因此可以得到了 xn 的有界性，即有下界 > 0
