## 递推函数法证明数列单调性方法

**结论：对于 $x_{n + 1} = f(x_{n})$ 这样的式子一般都可以用上述方式证明，对于 $x_{n+1} = f(x_{n})$，如果 f 是单调递增的，那么{xn}这个数列就是单调的，至于单调增还是单调减取决于 x 2 和 x 1，如果 x 2 > x 1 那就是单增，如果 x 2 < x 1 那就是单调减**

这个结论的正确性在于，xn+1 - xn 可以写成 $x_{n + 1} - x_{n} = f(x_{n}) - f(x_{n-1}) = f'(\xi)(x_{n} - x_{n - 1})$，那么如果 f 是单调增的，所以 $f'(\xi) > 0$，所以这个差值的正负就取决于 xn 和 xn-1 的正负，而 xn 与 xn-1 作差又可以继续往前取决于 xn-1 和 xn-2 的正负，一直递推到 x 2 - x 1，当 x 2 - x 1 > 0 的时候推出 x 3 > x 2，继续推出 x 4 > x 3 一直推出 xn+1 > xn，那么 {xn}就是递增的了

如果 xn+1 = f (xn) 中 f 是单调减的，那么{xn}一定不单调



## 压缩映射法证明不单调数列的极限

压缩映射法主要用于证明不单调的数列的极限，它包括两个定理：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250721210924.png)

==第一个定理的使用方法==

首先求出 a，这一步在草稿纸上进行，其实就是 $x_{n+1} = f(x_{n})$ 两边取极限，得到 f (a) = a，解出来即可，下面都是在答题卡上进行的装模做样的证明


然后直接将 a 代入，想办法写成： $|x_{n + 1} - a| = |f(x_{n}) - f(a)| \leq r|x_{n} - a|$ 

有时候这个条件是题目告诉的，有时候需要自己推


这样就可以一直递推下去：

$$
|x_{n + 1} - a| = |f(x_{n}) - f(a)| \leq r|x_{n} - a|\dots \leq r^n|x_{1} - a|
$$

这样，对 $|x_{n + 1} - a|$ 使用夹逼：

$$
0 \leq |x_{n + 1} - a| \leq r^n|x_{1} - a|(\to 0)
$$

所以 $\lim_{ n \to \infty } |x_{n + 1} - a| = 0$，因此极限就是 a


==第二个定理使用方法==

这个定理的使用过程与第一个定理一样，只不过这里用的是微分中值定理：

$$
|x_{n + 1} - a| = |f(x_{n}) - f(a)| = |f'(\xi)| \cdot|x_{n} - a|\leq r|x_{n} - a|
$$

仍然跟第一个定理一样继续递推下去，用夹逼，得到极限就是 a


==总结==

上面是两个压缩映射的使用思路

一般就是写成 $|x_{n+1} -a| = |f(x_{n}) - f(a)|$ 的形式

如果给了 f (x) 的具体表达式，那么就按照思路 1 进行通分，化简，放缩，凑出 xn - a


如果给了导数相关的信息，那么就按思路二，利用微分中值定理直接得到 xn - a 的关系

## 罗尔定理

### 罗尔定理还原法构造函数

罗尔定理构造函数一般是类似下面的题型：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250422085210.png)

一般来讲这种构造函数不是容易想到，这里可以用还原法，所谓还原法就是将题目中给的式子进行变形，或者四则运算，变成容易看到的求原函数的结构，一般有下面几个步骤：

1. 将式子的所有项统一移动到左边变成.... = 0 的形式
2. 将字母换成 x，这道题目就是 $xf(x) +f'(x) = 0$
3. 尽量让 f (x) 相关的集中在一起，这里加减变形都不好弄，这里同时除以 f (x) 得到 $x + \frac{f'(x)}{f(x)} = 0$，可以轻松看到这里式子两项就是 1/2 x^2 和 ln f (x) 的导数：$\left( \frac{1}{2}x^2 + \ln f(x) \right)' = 0$，一般做到这一步就得到原函数了，但是这里面含有 ln，所以需要再加一步合并
4. 将式子合并成一个，即 $[\ln e^{1/2x^2}f(x)]' = 0$，此时去掉外层的 ln 就是原函数了，一般合并得到的 ln () 或者 e^()，去掉外层的 ln 或者 e 得到的函数就是原函数，这个是固定结论

即构造 h (x) =  $e^{\frac{1}{2}x^2}f(x)$
