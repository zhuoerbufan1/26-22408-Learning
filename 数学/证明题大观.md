## 递推函数法证明数列单调性方法

**结论：对于 $x_{n + 1} = f(x_{n})$ 这样的式子一般都可以用上述方式证明，对于 $x_{n+1} = f(x_{n})$，如果 f 是单调递增的，那么{xn}这个数列就是单调的，至于单调增还是单调减取决于 x 2 和 x 1，如果 x 2 > x 1 那就是单增，如果 x 2 < x 1 那就是单调减**

这个结论的正确性在于，xn+1 - xn 可以写成 $x_{n + 1} - x_{n} = f(x_{n}) - f(x_{n-1}) = f'(\xi)(x_{n} - x_{n - 1})$，那么如果 f 是单调增的，所以 $f'(\xi) > 0$，所以这个差值的正负就取决于 xn 和 xn-1 的正负，而 xn 与 xn-1 作差又可以继续往前取决于 xn-1 和 xn-2 的正负，一直递推到 x 2 - x 1，当 x 2 - x 1 > 0 的时候推出 x 3 > x 2，继续推出 x 4 > x 3 一直推出 xn+1 > xn，那么 {xn}就是递增的了

**如果 xn+1 = f (xn) 中 f 是单调减的，那么{xn}一定不单调**



## 压缩映射法证明不单调数列的极限

压缩映射法主要用于证明不单调的数列的极限，它包括两个定理：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250721210924.png)

==第一个定理的使用方法==

首先求出 a，这一步在草稿纸上进行，其实就是 $x_{n+1} = f(x_{n})$ 两边取极限，得到 f (a) = a，解出来即可，下面都是在答题卡上进行的装模做样的证明


然后直接将 a 代入，想办法写成： $|x_{n + 1} - a| = |f(x_{n}) - f(a)| \leq r|x_{n} - a|$ 

有时候这个条件是题目告诉的，有时候需要自己推


这样就可以一直递推下去：

$$
|x_{n + 1} - a| = |f(x_{n}) - f(a)| \leq r|x_{n} - a|\dots \leq r^n|x_{1} - a|
$$

这样，对 $|x_{n + 1} - a|$ 使用夹逼：

$$
0 \leq |x_{n + 1} - a| \leq r^n|x_{1} - a|(\to 0)
$$

所以 $\lim_{ n \to \infty } |x_{n + 1} - a| = 0$，因此极限就是 a


==第二个定理使用方法==

这个定理的使用过程与第一个定理一样，只不过这里用的是微分中值定理：

$$
|x_{n + 1} - a| = |f(x_{n}) - f(a)| = |f'(\xi)| \cdot|x_{n} - a|\leq r|x_{n} - a|
$$

仍然跟第一个定理一样继续递推下去，用夹逼，得到极限就是 a


==总结==

上面是两个压缩映射的使用思路

一般就是写成 $|x_{n+1} -a| = |f(x_{n}) - f(a)|$ 的形式

如果给了 f (x) 的具体表达式，那么就按照思路 1 进行通分，化简，放缩，凑出 xn - a


如果给了导数相关的信息，那么就按思路二，利用微分中值定理直接得到 xn - a 的关系

## 罗尔定理

罗尔定理构造函数的基本思想就是，想办法找到一个函数 F (x)

（1）F (x) 求导之后是题目式子
（2）F (x) 有两个零点

这类题目的难点可能在寻找 F (x) 上，也可能在寻找零点上

### 罗尔定理还原法构造辅助函数

罗尔定理构造函数一般是类似下面的题型：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250422085210.png)

一般来讲这种构造函数不是容易想到，这里可以用还原法，所谓还原法就是将题目中给的式子进行变形，或者四则运算，变成容易看到的求原函数的结构，一般有下面几个步骤：

1. 将式子的所有项统一移动到左边变成.... = 0 的形式
2. 将字母换成 x，这道题目就是 $xf(x) +f'(x) = 0$
3. 尽量让 f (x) 相关的集中在一起，这里加减变形都不好弄，这里同时除以 f (x) 得到 $x + \frac{f'(x)}{f(x)} = 0$，可以轻松看到这里式子两项就是 1/2 x^2 和 ln f (x) 的导数：$\left( \frac{1}{2}x^2 + \ln f(x) \right)' = 0$，一般做到这一步就得到原函数了，但是这里面含有 ln，所以需要再加一步合并
4. 将式子合并成一个，即 $[\ln e^{1/2x^2}f(x)]' = 0$，此时去掉外层的 ln 就是原函数了，一般合并得到的 ln () 或者 e^()，去掉外层的 ln 或者 e 得到的函数就是原函数，这个是固定结论

即构造 h (x) =  $e^{\frac{1}{2}x^2}f(x)$

### 罗尔定理和拉格朗日定理的三点图处理方法

罗尔定理的三点图和拉格朗日三点图：
（1）罗尔定理三点图的前提条件是三个函数值为零，罗尔定理三点图得到的导数和二阶导是等于零的信息

（2）拉格朗日三点图的前提条件是两个函数相等，一个函数在这两个函数的上方或者下方，拉格朗日三点图得到的是导数和二阶导是不为零的信息

（3）**两者都需要连续使用三次定理（两层）**，并且连续两层定理的结构是完全一致的，都是两个函数点之间使用一层定理得到两个导数信息，然后两个导数对应的点之间再用一层定理，得到二阶导的信息

####  拉格朗日三点图

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250718101625.png)

仍然是在 (a, c)，(c, b) 使用两次拉格朗日中值定理

$$
f' (\xi_{1})(c - a) = f (c) - f (a); f' (\xi_{2})(b - c) = f (b) - f (c)
$$

可以得到 $f' (\xi_{1}) > 0, f' (\xi_{2}) < 0$，并且 $\xi_{2} > \xi_{1}$ 

然后在这两个导数对应的点之间再用一次拉格朗日中值定理：

$$
f'' (\xi_{3})(\xi_{2} - \xi_{1}) = f' (\xi_{2}) - f' (\xi_{1})
$$

所以 $f'' (\xi_{3}) < 0$

这个就是拉格朗日的三点图：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250718103244.png)

**另外，这里拉格朗日的三点图这里还有一个更强的命题**

就是如果 f (a) = f (b) = 0，并且二阶导 f'' (x) < 0，则在 (a, b) 中一定是 f (x) > 0

它的证明方式是假设一个点 f (x 0) = 0 用三次罗尔定理，得到有一个 f'' (x') = 0，得到矛盾

或者假设一个点 f (x 0) > 0，用三次拉格朗日定理，得到有一个 f'' (x') > 0，得到矛盾

### 严格证明凸函数围成的面积大于割线围成面积的方法


![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250919092534.png)

$$
\int_{a}^b f(x) dx > \frac{b - a}{2} f(x)

$$

这里 f (x) 是上图曲线上的任意一点，由于是凸函数，所以 f'' (x) < 0

$$
\int_{a}^b f(x) dx > \frac{b - a}{2} f(x_{0})

$$

这里的 f (x 0) 是 f (x) 的最大值

这里可以在 x 0 的两端分别证明，只要能证明曲线始终在割线的上方即可

在 x 0 的左边：

关于函数凹凸性的其实都可以用泰勒公式来证明，流程完全一致，都是在中间点展开，然后乘系数凑出要证明的凹凸性定义

#### 泰勒证明凹凸性的方法

令 $\lambda x_{1} + (1 - \lambda) x_{2} = x_{0}$，然后在 x 0 处泰勒展开，一般泰勒展开就是在中间位置进行展开，而不是端点：

$$
f (x) = f (x_{0}) + f' (x_{0})(x - x_{0}) + \frac{f'' (\xi)}{2}(x - x_{0})^2
$$

然后将 x 1 和 x 2 这两个端点代入得到：

$$
f (x_{1}) = f (x_{0}) +f' (x_{0})(x_{1} - x_{0}) + \frac{f'' (\xi_{1})}{2} (x_{1} - x_{0})^2
$$

x 2：

$$
f (x_{2}) = f (x_{0}) +f' (x_{0})(x_{2} - x_{0}) + \frac{f'' (\xi_{2})}{2} (x_{2} - x_{0})^2
$$

这两个式子凑成题目要证明的样子，第一个式子乘 $\lambda$，第二个式子乘 $1 - \lambda$，然后相加：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250718105420.png)

这个式子等号右侧的末尾两项都是 >0 的，所以有：

$$
\lambda f (x_{1}) + (1 - \lambda) f (x_{2}) > f (x_{0})
$$

也就得到了证明

#### 泰勒证明广义凹凸性（琴声不等式）的方法

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250425103547.png)
这里还是令 $x_{0} = \frac{x_{1} + x_{2} + \dots\dots x_{n}}{n}$，在 x 0 点展开：

$$
f (x) = f (x_{0}) + f' (x_{0})(x - x_{0}) + \frac{1}{2}f'' (\xi)(x - x_{0})^2
$$

证明思路完全一样，还是想办法凑出题目要证的式子，代入 x i，得到 n 个式子：

$$
f (x_{i}) = f (x_{0}) + f' (x_{0})(x_{i} - x_{0}) + \frac{1}{2}f'' (\xi_{i})(x_{i} - x_{0})^2
$$

这 n 个式子还是乘系数 1/n 全部加起来凑出题目要证的东西得到：

$$
\frac{1}{n} \sum_{i = 1}^n f (x_{i}) = f (x_{0}) + \frac{1}{n}\sum_{i = 1}^nf' (x_{0})(x_{i} -x_{0}) + \frac{1}{n}\sum_{i = 1}^n \frac{1}{2}f'' (\xi_{i})(x_{i} - x_{0})^2
$$

这个式子中间的一阶导项其实为 0，后边的二阶导项是负的，所以：

$$
\frac{1}{n} \sum_{i = 1}^n f (x_{i}) < f (x_{0})
$$

也就是题目中要证明的东西了

# 一些放缩总结


### （1）泰勒公式放缩 1 - 平方和放缩

在泰勒公式中，x 0 处于 (a, b) 中间，那么有 $(a - x 0)^2 + (b - x 0)^2 \leq (a - b)^2$

**在 a > 0, b > 0 的情况下，一定有 $a^{2} + b^{2} \leq (a + b)^{2}$**


这是因为 x 0 在 (a, b) 中，那么 x 0 - a > 0, b - x 0 > 0，所以有：

$$
(a - x 0)^2 + (b - x 0)^2 = (x_{0} - a)^2 + (b - x 0)^2 
$$

而 $(x 0 - a + b - x 0)^2 = (x_{0} - a)^2 + (b - x 0)^2 + 2 (x 0 - a)(b - x 0)$

这里带的交叉项是大于=0 的，所以：

$$
(x 0 - a + b - x 0)^2 = (a - b)^{2} \geq (x_{0} - a)^2 + (b - x_{0})^2 
$$

==看一个例子==

这道题显然是取对数，这里的指数部分就是：

$$
\ln\left( 1 + \frac{1}{n^{2}} \right) + \ln \left(  1 + \frac{2}{n^{2}} \right) +\dots \ln\left( 1 + \frac{n}{n^{2}} \right)
$$

根据 ln (1 + x ) <= x，可以放缩成：

$$
\ln\left( 1 + \frac{1}{n^{2}} \right) + \ln \left(  1 + \frac{2}{n^{2}} \right) +\dots \ln\left( 1 + \frac{n}{n^{2}} \right) \leq \frac{1}{n^{2}} + \frac{2}{n^{2}}+\dots \frac{n}{n^{2}} = \frac{1}{2} + \frac{1}{2n}
$$

当 n 趋于无穷的时候不等号右边趋于 1/2

根据 $\ln\left( 1 + \frac{1}{x} \right) \geq \frac{1}{x + 1}$，此时左边可以放缩成：

$$
\frac{1}{n^{2}  +1}  + \frac{2}{n^{2} + 2} + \dots \frac{n}{n^{2} + n} \leq \ln\left( 1 + \frac{1}{n^{2}} \right) + \ln \left(  1 + \frac{2}{n^{2}} \right) +\dots \ln\left( 1 + \frac{n}{n^{2}} \right)
$$

左边的这种结构可以进一步放缩，将分母部分的变化量全部放缩成 n：

$$
\frac{1}{n^{2}  + n} + \frac{2}{n^{2} + n} + \dots \frac{n}{n^{2} + n } <\frac{1}{n^{2}  +1}  + \frac{2}{n^{2} + 2} + \dots \frac{n}{n^{2} + n} \leq \ln\left( 1 + \frac{1}{n^{2}} \right) + \ln \left(  1 + \frac{2}{n^{2}} \right) +\dots \ln\left( 1 + \frac{n}{n^{2}} \right)
$$ 
n 取极限左边也趋近于 1/2

所以指数部分就是趋近 1/2，所以整个结果就是趋近 $\sqrt{ e }$ 了
