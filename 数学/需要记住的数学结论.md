### 三角函数诱导公式

奇变偶不变，符号看象限

这里看的象限是将  $\alpha$  看作锐角的时候原函数的符号，而不是改变之后的函数的符号

比如  $\sin\left( \frac{\pi}{2} + \alpha \right)$  这里在  $\alpha$  的基础上增加了一个  $\frac{\pi}{2}$ ，那么变成  $\cos$ 的符号就是将  $\alpha$  看作锐角的时候的  $\sin\left( \frac{\pi}{2} + \alpha \right)$  的符号，这里就是正的因此有：

$$
\sin\left( \frac{\pi}{2} + \alpha \right) = \cos \left( \alpha\right)
$$

### 曲率和曲率半径公式

曲率是 K，曲率半径是 1/K

K 的两个公式如下：

曲率 K 的公式：

**参数方程：**
$$
K = \frac{|x^{'}(t)y^{''}(t) - x^{''}(t)y^{'}(t)|}{[x^{'}(t)^2 + y^{'}(t)^2]^{\frac{3}{2}}}
$$
也就是分子是两个式子一阶导和二阶导乘积的差值，分母是两者一阶导平方和开 3/2 次方

**一般方程：**

这是知道了 y (x) 的公式，这里可以将 x 看作参数，所以公式变成：
$$
K = \frac{|y^{''}(x)|}{[1 + y^{'}(x)^2]^{\frac{3}{2}}}
$$
曲率取个倒数就是曲率半径，注意曲率圆的半径是 K 的倒数，而如果题中给出了曲率圆的方程，其常数项其实是曲率半径的平方，别傻乎乎的直接将这个平方数代入了当作半径

### 弧长公式

弧微分 ds 为（参数方程下）：
$$
ds = \sqrt{x'(t)^2 + y'(t)^2} dt
$$
跟前面的曲率一样，x 看成参数得到普通的弧微分：
$$
ds = \sqrt{1 + y'(x)^2}dx
$$

## 多元函数微分学

### 偏导数的定义公式 + 偏导理解

==偏导定义==
$$f'_x(x_0, y_0) = \lim_{\Delta x \to 0} \frac{f(x_0 + \Delta x, y_0) - f(x_0, y_0)}{\Delta x}$$


或者另外一种：

$$
f'_x(x_0, y_0) = \lim_{x \to x_{0}} \frac{f(x , y_0) - f(x_0, y_0)}{x - x_{0}}
$$

==理解==

$f_{x}'(x_{0}, y_{0})$ 其实就是求 f (x, y 0) 这样一个一元函数在 x = 0 的导数，所以完全可以用一元函数的性质来判断 $f'(x_{0},y_{0})$
### 偏导连续，可微，偏导存在，函数连续的关系 + 几个特殊的反例（5 个）

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250508090222.png)

**（1）十字架函数（0，0 处不连续，极限不存在，但是偏导存在）**

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250610094625.png)

这个函数不连续，趋于 (0, 0) 的时候极限不存在，因为在三维坐标中沿着坐标轴趋近于 (0, 0) 是 0，但是沿着其他方向趋近于 (0, 0) 则是 1

但是在 (0, 0) 处的 x 偏导和 y 的偏导都存在，因为这个函数在三维坐标中的图像就是一个十字架，坐标轴上的值是 0，其他地方的值都是 1，$f_{x}'(0, 0)$ 就是 y = 0 与图像的交线（就是 x 轴）对 x 的求导，显然等于 0（当然也可以用定义，偏导也存在）

**（2）$f(x) = |x| + |y|$，连续但是不可微，偏导不存在**

连续是显然的，(0, 0) 处偏导不存在也是显然的，f (x, 0) 显然导数不存在，所以不可微

**（3）$f(x) = \frac{xy}{x^2 + y^2}((x, y) \neq (0, 0)), f(x) = 0, ((x, y) = (0, 0))$，偏导存在，但是不连续**

偏导存在，但是不连续（y = kx 趋近的时候 k 取不同的值结果不同），极限不存在


**（4）$f(x) = \frac{xy}{x^2 - y^2}((x, y) \neq (0, 0)), f(x) = 0, ((x, y) = (0, 0))$，偏导存在，但是不连续，领域不完全有定义**

偏导存在，但是在 (0, 0) 领域中不是都有定义，当然其也不连续

**（5）可微，偏导存在，连续，极限存在，但是偏导不连续**

### 方向导数和梯度的计算

==方向导数==

f (x, y, z) 在点 M(x 0, y 0, z 0)沿着 $\vec{l} = (\cos\alpha, \cos\beta,\cos\gamma)$ 的方向导数定义为：

$$
\frac{\partial f}{\partial l}|_{x_{0},y_{0},z_{0}} = (f_{x}'\cos\alpha + f_{y}' \cos\beta + f_{z}'\cos\gamma)|_{x_{0},y_{0},z_{0}}
$$

上述的 $\cos\alpha, \cos\beta,\cos\gamma$ 是 l 方向向量的方向余弦，其计算方式是：

对于一个向量：a  = (a 1, a 2, a 3)

它的方向角是其与 x，y，z 轴的夹角

这些角的余弦就是方向余弦：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250522103136.png)

==梯度==

f (x, y, z) 在 M (x 0, y 0, z 0) 的梯度是一个向量，即：

$$
\left( \frac{\partial f}{\partial x},\frac{\partial f}{\partial y},\frac{\partial f}{\partial z} \right)|_{(x_{0},y_{0},z_{0})}
$$

梯度方向是方向导数最大的方向，并且此时梯度的模就是方向导数最大的值

## 级数

### 麦克劳林展开

#### 指数函数
$$ e^x = \sum_{n=0}^\infty \frac{x^n}{n!} = 1 + x + \frac{x^2}{2!} + \frac{x^3}{3!} + \cdots \quad (x \in \mathbb{R}) $$

#### 三角函数

- **正弦函数**  
$$   \sin x = \sum_{n=0}^\infty \frac{(-1)^n}{(2 n+1)!} x^{2 n+1} = x - \frac{x^3}{3!} + \frac{x^5}{5!} - \cdots \quad (x \in \mathbb{R}) $$

- **余弦函数**  
$$   \cos x = \sum_{n=0}^\infty \frac{(-1)^n}{(2 n)!} x^{2 n} = 1 - \frac{x^2}{2!} + \frac{x^4}{4!} - \cdots \quad (x \in \mathbb{R}) $$

- **正切函数**  
$$   \tan x = \sum_{n=1}^\infty \frac{B_{2 n} (-4)^n (1-4^n)}{(2 n)!} x^{2 n-1} = x + \frac{x^3}{3} + \frac{2 x^5}{15} + \frac{17 x^7}{315} + \cdots \quad (x \in (-\frac{\pi}{2}, \frac{\pi}{2}))   $$

注：$B_{2 n}$ 为伯努利数）

#### 对数函数

$$ \ln (1+x) = \sum_{n=0}^\infty \frac{(-1)^n}{n+1} x^{n+1} = x - \frac{x^2}{2} + \frac{x^3}{3} - \cdots \quad (x \in (-1, 1]) $$

#### 几何级数


- **标准形式**  
$$   \frac{1}{1-x} = \sum_{n=0}^\infty x^n = 1 + x + x^2 + x^3 + \cdots \quad (x \in (-1, 1)) $$

- **变体形式**  
$$   \frac{1}{1+x} = \sum_{n=0}^\infty (-1)^n x^n = 1 - x + x^2 - x^3 + \cdots \quad (x \in (-1, 1)) $$

#### 二项式级数

$$ (1+x)^a = 1 + \sum_{n=1}^\infty \frac{a (a-1)\cdots (a-n+1)}{n!} x^n = 1 + a x + \frac{a (a-1)}{2!} x^2 + \cdots \quad (x \in (-1, 1)) $$

#### 反三角函数

- **反正切函数**  
$$   \arctan x = \sum_{n=0}^\infty \frac{(-1)^n}{2 n+1} x^{2 n+1} = x - \frac{x^3}{3} + \frac{x^5}{5} - \cdots \quad (x \in [-1, 1]) $$

- **反正弦函数**  
$$   \arcsin x = \sum_{n=0}^\infty \frac{(2 n)!}{4^n (n!)^2 (2 n+1)} x^{2 n+1} = x + \frac{x^3}{6} + \frac{3 x^5}{40} + \cdots \quad (x \in (-1, 1)) $$

### 行列式的逆序数计算方式

一个 n 阶的行列式其实是 n! 项的和

对于其中的一项，其实是 n 个元素的乘积，每个元素依次按顺序取自这 n 行，但是列是不同的

并乘这些元素的-1 的逆序数次幂，这里以 3 阶为例来说明，比如下面一个三阶的行列式：

<img src="https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/image-20241121161529453.png" alt="image-20241121161529453" style="zoom:33%;" />

其中一项是三个元素的乘积

假如第一个元素取第一行第一列，就是 a 11

那么第二个元素取第二行，由于第一列被取过，因此就只有两种取法，只能在第 2 列和第 3 列中取，假设我们取 a 23

那么第三个元素取第三行，就只能取第二列的元素 a 32 了

因此这一行的乘积就是 a 11 * a 23 * a 32

再乘以-1 的逆序对数次幂，这里的逆序对是 a 11 a 23 a 32 这三个元素，任意两个如果列号大的在前面那就是一个逆序对，比如 a 23 a 32 第三列反而排在 a 32 前面这就是一个逆序对，而这个排列中只有这一个逆序对，因此需要乘 ￥(-1)^1￥

因此这一项就是：
￥￥
(-1)^{1}a_{11} a_{23} a_{32}
￥￥
当然这只是其中的一项

第一个元素可以取第一行的 n 列中一共 n 个不同的元素

第一行取了之后第二行只能取 n - 1 列了

第三行只能取 n - 2 列了

因此一共有 n! 中取法，也就有 n! 项乘积，每个乘积项都要乘自己的-1 的逆序数幂，然后将这 n! 项加起来就是行列式的值了

每一项元素按顺序取自 1，2，3。。。n 行，并且保证这些元素不再同一列

那么可以利用两个矩阵对角化后的对角矩阵 $\wedge$ 为桥梁，根据 $P_1^{-1} A P_1 = \wedge$，$P_{2}^{-1}BP_{2} = \wedge$，得到：

$$P_1^{-1} A P_1 = P_{2}^{-1}BP_{2} \implies P_{2}P_{1}^{-1}AP_{1}P_{2}^{-1} = B = Q^{-1} A Q $$

### 三阶矩阵特征多项式的韦达定理

三阶矩阵的特征多项式就是：
$$
|A - \lambda E| = 0 = \lambda^3 + a \lambda^2 + b\lambda + c = 0 
$$
我们可以得到：

（1）特征值的乘积，就是行列式，就是常数项的相反数：
$$
\lambda_1 \lambda_2 \lambda_3 = -c = |A|
$$
（2）特征值的和，就是矩阵的迹，就是二次型的相反数：
$$
\lambda_1  + \lambda_2 + \lambda_3 = -a = tr(A)
$$
（3）特征值的交叉项和，就是伴随矩阵的迹，就是一次项：
$$
\lambda_1 \lambda_2 + \lambda_1 \lambda_3 +\lambda_2 \lambda_3 = b = tr(A^*)
$$
 这个比较容易证，因为伴随矩阵的特征值就是 $\frac{|A|}{\lambda_1},\frac{|A|}{\lambda_2},\frac{|A|}{\lambda_3}$，代入|A| = $\lambda_1 \lambda_2 \lambda_3$ 就是了



## 二次型

### 矩阵合同的性质

矩阵 A 和 B 合同，也就是存在一个可逆矩阵 C 使得 $C^T A C = B$

因此合同之后：
（1）矩阵 A 和矩阵 B 等价
（2）矩阵 A 和矩阵 B 具有完全相同的秩
（3）矩阵 A 和矩阵 B 的正负惯性指数均相等 (充要条件)

### 判断矩阵合同以及求矩阵合同的方法

==**判断两个矩阵合同的方法：**==

（1）根据矩阵合同的充要条件：

**两个实对称矩阵合同的充要条件就是他们的正，负特征值个数都相等，即正，负惯性指数都相等**，所以可以直接通过求两个对称矩阵的特征值来判断是否合同，**所以实对称矩阵相似是一定合同的**

（2）只有实对称矩阵才有矩阵合同的概念：

实对称矩阵才能合同实对称矩阵，非实对称矩阵只能合同非实对称矩阵，一般而言矩阵合同仅仅是实对称矩阵之间的概念

==**求合同矩阵的方法（当然前提是知道了两个矩阵合同）：**==

先写出两个矩阵对应的二次型

（1）**通法是利用规范型作为桥梁**

通过 X = Q 1 Z，Y = Q 2 Z，X，Y 这两个二次型都通过线性变换变成了规范型 Z，利用 Z 这个桥梁构造 X 和 Y 的关系

（2）将两个二次型分别化成标准型，然后观察配凑

这种方式一般需要比较强的观察能力

（3）对两个二次型的矩阵强行进行配凑

强行通过观察凑出 $Q^T A Q = B$ 这种方法一般在选填的二阶矩阵中使用，超过三阶之后就非常难用了



### 可逆线性变换的三种等价关系

二次型 `f(X)` 经过线性变换得到二次型 `g(Y)`，那么下面三种关系是等价的：

**（1）`f(X) = g(Y)`**

**（3）若 A 是 f (X) 的矩阵，B 是 g (Y) 的矩阵，那么有：$C^T A C = B$**

上面三个关系有一就有剩下两个

当 X 和 Y 都是连续型随机变量的时候在 Y = y 0 的条件下 X < x 的概率不能直接用条件概率公式来做：

$$

$$

因为上式等式右边的分子分母都是 0，这样计算不出来

然后 $f_{X}(x|y_{0})$ 就是 $P (X < x | Y = y_{0})$ 的概率密度函数，对 x 的范围进行积分即可

==一个结论==

n 个独立同分布的随机变量之和就近似的服从正态分布，这个是**
**中心极限定理的一个本质特征，当 n 趋于无穷的时候就是正态分布**

在这里每个随机变量的**期望和方差**都存在的情况下，即：

$$
\sum_{i = 1}^n X_{i} \sim^{近似} N(n\mu, n\sigma^2)
$$

当 n 取极限的时候就不是近似了，而是就是正态分布，注意这里不是什么依概率收敛，而是当 n 取极限的时候就是正态分布：

$$
\lim_{ n \to \infty } \sum_{i = 1}^n X_{i} \sim N(n\mu, n\sigma^2)
$$
即 $Y =\lim_{ n \to \infty } \sum_{i = 1}^n X_{i}$ 这个随机变量就是服从正态分布的
