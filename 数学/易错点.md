### 计算函数极限 $x \to 0$ 的易错点，分正负零讨论

计算函数极限的时候，当 $x \to 0$，此时 $\frac{1}{x}, e^{\frac{1}{x}}, \arctan\frac{1}{x}$，这些式子在 0 负和 0 正的情况是不一样的

$\arctan {x}$，当 x 趋于正无穷的时候其趋近于 $\frac{\pi}{2}$，x 趋近于负无穷的时候其趋近于 $-\frac{\pi}{2}$

### 函数极限乘除运算的易错点，已知项非零

在计算 $\lim_{ x \to x_{0} } f(x)g(x), \lim_{ x \to x_{0}} \frac{f(x)}{g(x)}$ 的时候，如果 g (x) 的极限已知 = A，一般只有 A $\ne 0$ 的时候才能拆成 $A * \lim_{ x \to x_{0} } f(x), \lim_{ x \to x_{0}} \frac{f(x)}{A}$ ，通过计算 f (x) 的极限来做

而当 A = 0 的时候则考虑不能拆开来做，这是因为：

(1) 当计算乘积的时候，如果 f (x) 的极限是无穷，则无法拆成 0 * 无穷来计算整体乘积极限
(2) 当计算除法的时候，如果 A = 0，那就更不能拆开分别计算了
(3) 当然如果 f (x) 极限是有界量，那乘积其实还是可以拆开做的，但是除法还是不能拆开


### 洛必达法则易错点，n 阶导连续

其定义如下：

![image.png|684x341](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250415083902.png)


注意只要是 f (x) 和 g (x) 在 a 的一个空心领域中可导就可以洛一次，即：$lim \frac{f(x)}{g(x)} = lim \frac{f’(x)}{g’(x)}$，洛必达是通过结果反推的，如果可洛，洛完之后可以计算出极限 A，则原来的极限就是 A；但是如果洛完之后发现算不出，此时不能说明原来的极限不存在，需要换方法进行计算

但是计算 $lim \frac{f’(x)}{g’(x)}$ 不能直接代入 f’(x) 或 g’(x)，因为只有 f’(x) 和 g’(x) 在 a 点连续的时候才能代入

如果是抽象函数，题目没有说 f’(x) 和 g’(x) 在 a 点连续那就不能使用洛必达，因为洛出来的结果未知得不到 $lim \frac{f’(x)}{g’(x)}$ 是否等于 A，所以上面洛一次就是错误的，不能使用洛必达

但是如果是具体函数，可以用定义算出 a 点的 f (x) 和 g (x) 的导函数，即可以算出 $lim \frac{f’(x)}{g’(x)} = A$，那洛必达就是有效的

所以只要能求出 $lim \frac{f’(x)}{g’(x)} = A$ 即，$lim \frac{f’(x)}{g’(x)}$ 存在或者是无穷，那洛必达就是可用的，至于导数连不连续则是在代入极限需要做的事情，一般而言如果 n 阶导数存在并且连续，那么就可以洛到 n 阶，但是如果 n 阶导数只是存在没有说连续，则此时计算有关 n 阶导有关的东西时就需要凑导数的定义，而不是直接代入 n 阶导在趋于 a 处的值

### 无穷小运算易错点，无穷小运算的等号更像是属于，而不是相等

对于无穷小加减运算来说，低阶无穷小会吸收高阶无穷小：

$$
o(x^2) \pm o(x^3) = o(x^2)
$$

这里的等号更像是左边集合属于右边的集合，并不意味着左右两边的次数相等

比如 $x^2 - \sin x^2 = o(x^2)$，左边的式子在相减之后与 x^6 同阶，但是仍然属于 o (x^2)，所以无穷小的运算中的等号其实是一个很粗略的信息，不能确定式子的具体阶数

一般如果知道了式子 $f(x)$ 的具体阶数 k的话，可以直接将其替换成 $Cx^k + o(x^k)$ 放到式子中，这样不容易犯错

比如上面 $\sin x^2$ 其实是 $x^2 - \frac{1}{6} x^6 + o(x^6)$，那么这个式子其实真实等价于 $x^2 - x^2 + \frac{1}{6}x^6 + o(x^6)$，可以看到其是一个与 x^6 同阶的无穷小

### 无穷大和无界的易错点，无穷大是无界，但是无界不一定是无穷大

无穷大的定义是 $\lim_{ x \to x_{0} } f(x) = \infty$（此时极限仍然不存在），而无界的定义是对任意的正数 M，存在 x 0 使得 |f (x 0)|>M

无界可能是震荡的，而无穷就是要求函数中所有未知数子列代入函数都是趋于无穷的
