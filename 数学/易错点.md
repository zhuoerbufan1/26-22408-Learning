### 函数极限 $x \to 0$ 的易错点，分正负零讨论

计算函数极限的时候，当 $x \to 0$，此时 $\frac{1}{x}, e^{\frac{1}{x}}, \arctan\frac{1}{x}$，这些式子在 0 负和 0 正的情况是不一样的

$\arctan {x}$，当 x 趋于正无穷的时候其趋近于 $\frac{\pi}{2}$，x 趋近于负无穷的时候其趋近于 $-\frac{\pi}{2}$

### 函数极限乘除运算的易错点，已知项必须非零

在计算 $\lim_{ x \to x_{0} } f(x)g(x), \lim_{ x \to x_{0}} \frac{f(x)}{g(x)}$ 的时候，如果 g (x) 的极限已知 = A，只有 A $\ne 0$ 的时候才能拆成 $A * \lim_{ x \to x_{0} } f(x), \lim_{ x \to x_{0}} \frac{f(x)}{A}$ ，通过计算 f (x) 的极限来做

而当 A = 0 的时候则不能拆开来做，这是因为题目此时要求两者乘积的极限，而当 f (x) 的极限为无穷的时候两者乘积极限同样可以计算出来，但是单独拆分 f (x) 来计算整体极限就不行了
