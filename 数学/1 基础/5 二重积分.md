## 二重积分的定义和性质

### 4 二重积分的定义

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250513081955.png)

给一元积分的定义类似，首先还是凑出变化的量，这里是两个变化的量：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250513082149.png)

然后可以发现 $\frac{i}{n}$ 和 $\frac{j}{n}$ 其范围都是从 1 到 n，取极限之后就是 0 到 1，所以 x 和 y 的范围都应该是 0 到 1

然后确定积分区域和微小量步长（二重积分中就是小面积）

根据求和符号，这个和式是将整个正方形取满了的（固定一个 i，j 从 1 取到 n；然后 i 又从 i 取到 n，所以取满），所以积分区域大致就是下面的一个正方形，根据和式中的上限 n，x 轴和 y 轴分别划分了 n 份，所以一个微小量步长就是 $\frac{1}{n^2}$

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250513082656.png)

如果这里的第二个求和符号上面是 i，则积分区域就不是一个正方形，而是正方形右下角的三角形，如果第二个求和符号下面是 i，则积分区域是正方形左上角的三角形；但是这里微小量步长确定仍然不变，是 $\frac{\left( \frac{1}{2} \right)}{\frac{1}{2n^2} }= \frac{1}{n^2}$

按照原来的区域的话，凑出这样的无限求和的形式：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250513082812.png)

显然这个积分区域是一个完整的正方形，而不是 AB 选项的三角形

所以是 D

所以对于这种二重积分的定义处理：

（1）还是先凑出变化的量
（2）通过变化的量取极限得到变化的量的范围，确定大致的积分区域
（3）通过求和符号的上下限来精确确定积分区域
（4）通过求和符号的上下限来观察 x 轴和 y 轴被划分了多少份来确定微元步长
（5）写出微元步长乘函数然后求和的形式，确定二重积分的表达式


### 5 二重积分取最大的时候积分区域的选取

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250513092529.png)

这个区域可以保证取到所有使得被积函数大于零的 x, y 范围，超过这个范围被积函数就小于零了，显然对积分的贡献就是负的，会导致积分变小

### 6 二重积分的比较，积分区域中变量范围的确定

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250513094143.png)

一般就是将 x + y 看作一个整体来进行比较的，通过这个区域可以得到 x + y 的一个整体的范围

注意，此时 x + y 的范围是 1/2 到 1，整体比较，而不要单独根据 1/2 < x < 1 并且 1/2 < y < 1 得到 1 < x + y < 2，这样是不对的，因为 x 和 y 有一个区域进行限制，不能简单叠加

而且 1/2 < x < 1 并且 1/2 < y < 1 这个范围本身就是错的，只是 1/2 < x + y < 1，但是x 和 y 在这个区域中是可以取到 0 到 1 的，必须根据这个区域对 x + y 整体看待，不能简单根据 x 和 y 的范围进行简单叠加（这里叠加也行，只是范围不够精确）

### 8 易错点：交换积分次序之后反三角的易错点

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250513113310.png)

这道题目的积分区域是一个 sinx：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250513113407.png)

固定了 y 之后确定 x 的积分上下限时需要对 y 进行反三角

但是，注意 arcsin x 的图像为：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250513113531.png)

定义域是-1 到 1，值域是 $-\frac{\pi}{2}$ 到 $\frac{\pi}{2}$

在这道题目中 y = sinx ，固定 y，确定 x 的时候取反三角 x = arcsin y，首先看第一个点，y 在 0 到 1 之间，此时 x 的范围也是 0 到 pi/2，所以可以直接两边取反三角：

$$
\arcsin y = \arcsin (\sin x) = x
$$

对于第二个点，x 的范围不在 $-\frac{\pi}{2}$ 到 $\frac{\pi}{2}$，此时进行反三角运算必须用到诱导公式将 sin 里面的变量范围诱导到 $-\frac{\pi}{2}$ 到 $\frac{\pi}{2}$，才能通过反三角逆运算直接去掉 sin 符号：

$$
\arcsin y = \arcsin(\sin x) = \arcsin(\sin(\pi - x)) = \pi - x
$$

所以这里的下限是 arcsin y 上限是 pi - arcsin y，结果是：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250513115803.png)
