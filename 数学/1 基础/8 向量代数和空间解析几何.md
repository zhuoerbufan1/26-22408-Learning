### 3 求直线方程 - 直线相交的条件处理

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250522152241.png)

这道题目知道了一个点，求直线 L 方程，那么下一步就是求直线的方向向量了，设方向向量是 S

设平面的法向量是 n

于是有第一个条件 S 垂直 n

L 1 与 L 相交，这个条件说明 L 1 和 L  在同一个平面上：
![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250522152604.png)

既然这里涉及了平面，当然就要考虑这个平面的法向量 n 1，n 1 刚好与 S 垂直

所以如果我们能够求得这个平面的法向量，那就可以得到第二个条件 n 1 垂直 S

根据 n 1 垂直 S，n 垂直 S，n 叉乘 n 1 就得到 S 了

所以下一步就是求 n 1

n 1 显然垂直 L 1 的法向量 S 1，我们在 L 1 上取一个点，L 上再取一个点（题中给的），这样可以得到另一个向量 AB，n 1 垂直 AB，所以可以通过 AB 叉乘 S 1 求出 n 1

n, n 1 都知道，所以就可以求出 S 了

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250522152938.png)

## 曲面和空间曲线

### 4 求任意一条曲线绕某个轴旋转的曲面方程

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250523090723.png)

求某个曲线绕轴旋转的方法与坐标面上的曲线绕轴旋转的曲面推导过程非常类似

首先，还是简单画出这个线绕 z 轴大大致图形，画出直线上的某个点形成的维圆，然后设出三个点：
![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250523092444.png)

接下来就是根据各种关系表达出 M 中的 x, y, z 三者关系

（1）三点处于同一高度，所以 z = z 0

（2）M 和 M 0 到圆心的距离相等，所以 $x^2 + y^2 = x_{0}^2 + y_{0}^2$

（3）M 0 在直线上，得到两个关系 $x_{0} - 1 = 0, z_{0}-1 = 2y_{0}$

将第二个条件中的 x 0，y 0 分别换成 1 和 z，于是就得到了方程：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250523092727.png)

坐标面上的曲线绕轴旋转得到的曲面最后是用 x, y, z 表示 x 0, y 0, z 0 然后代入曲线方程

这里是用 x, y, z 表示 x 0, y 0, z 0，只不过代入的是一个等式

反正就是想办法将 x 0, y 0 z 0 换成 x, y z 然后得到 z, y, z 的关系
