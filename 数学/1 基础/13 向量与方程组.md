==第一题==

用定义证明，起手先假设：

$$
k_{1}\alpha_{1} + k_{2}\alpha_{2} + k_{3}\alpha_{3}\dots = 0
$$

然后左乘一个 A：
![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250606103808.png)
这里可以用上式减去最开始的假设，得到：

$$
k_{2}\alpha_{1} + k_{3}\alpha_{2} = 0
$$
然后继续左乘继续用式子相减即可


或者可以整理第一次左乘 A得到：

$$
(k_{1} + k_{2})\alpha_{1} + (k_{2} + k_{3})\alpha_{2} + k_{3}\alpha_{3} = 0
$$
从而 k 1 = k 2 = k 3 = 0

### 2 向量组等价的判定

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250611073926.png)

根据 k, m 不等于零，可以将 $\gamma, \alpha$ 移动到等式右边

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250611074658.png)

所以是 $\alpha$ 可以由 $\beta, \gamma$ 线性表示，也就是 $\beta,\gamma = B$，形成的方程组 $Bx = \alpha$ 有解，所以增广阵的秩等于系数矩阵的秩， 所以 $r(\gamma,\beta|\alpha) = r(\gamma, \beta)$

同理可得 $r(\alpha,\beta|\gamma) = r(\alpha, \beta)$

所以得到三秩相等：$r(\alpha, \beta) = r(\gamma, \beta) = r(\alpha, \beta, \gamma)$，所以 B 正确

###  4 Ax = 0 与 Ax = b 分别可以取出的最多线性无关的解向量个数

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250613115907.png)

由 Ax = b 有 3 个线性无关的解，得到 3 - r (A)  + 1 >= 3，得到 r (A) < = 1

由于 b 不为 0，所以 A 不是零向量，所以 r (A) = 1

所以 Ax = 0 的基础解系的解向量的个数就是 3 - 1 = 2，所以排除 AB

再根据特解排除 D

然后分析两个通解是否线性无关的时候，可以用定义法

或者按照矩阵分解， $\eta_{3} - \eta_{1}, \eta_{2} - \eta_{1}$ 是 $\eta_{1}, \eta_{2}, \eta_{3}$ 右乘一个矩阵 B的结果，这里 r (B) = 2 不多说，又 $\eta_{1}, \eta_{2}, \eta_{3}$ 线性无关，所以 $r(\eta_{3} - \eta_{1}, \eta_{2} - \eta_{1}) = 2$，所以这两个向量线性无关；同理 D 的两个通解的向量的线性无关性也是这样判断

==另一个判断 r(A) 的方法==

根据 $\eta_{1}, \eta_{2},\eta_{3}$ 是 Ax = b 的解向量，得到 $\eta_{3} - \eta_{1}, \eta_{2} - \eta_{1}$ 这两个向量是线性无关的并且是 Ax = 0 的解，所以 n - r (A) >= 2,，所以 r (A) <= 1，所以 r (A) = 1，所以 Ax = 0 的基础解系的解向量个数就是 2
