### 22 定积分的比较 - 对形如 $\frac{f(x)}{x}$ 的理解和处理

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250502083337.png)

这两个积分的大小容易得到，关键是看与 1 的大小比较，I 2 一定小于 1，这不用多说

关键是看 I 1 与 1 的大小

==利用凹凸性割线斜率判断单调性：==

$\tan x /x$ 这个式子可以看作 tant 这个函数上的一点（x, tanx）与原点连线的斜率，由于 tant 是凹函数，所以连线的斜率在递增，所以这个函数递增

因此当 x 在[0, pi/4]的时候有：$\tan x/ x \le \frac{\tan \frac{\pi}{4}}{\frac{\pi}{4}} = \frac{4}{\pi}$
两边同时取积分，由于等号只在一个点处取得，所以求积分之后是严格小于：

$$
\int_{0}^{\frac{\pi}{4}} \frac{\tan x}{x} < \int_{0}^{\frac{\pi}{4}} \frac{4}{\pi} = 1
$$ 
==利用作差求导判断：==

另外一种方式是根据积分等于 1 的情况直接想到 $\int_{0}^{\frac{\pi}{4}} \frac{4}{\pi} = 1$，然后判断 $\frac{\tan x}{x}$ 与 $\frac{4}{\pi}$ 的大小即可，这里作差求导即可证明

### 41 变限积分极限的处理方式 + 变限积分的等价替换易错点 + 积分再现公式的理解 + 积分中值定理在变限积分极限中的使用

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250506095208.png)

这道题目如果对分母换元令 $x - t = u$，可以得到：

$$
\lim_{ x \to 0 } \frac{ \int_{0}^x (x - t) f(t)dt}{\int_{0}^x xf(u)du}
$$

此时不能根据 $g(t) = (x - t)f(t), h(u) = xf(u)$，因为 t ->0 和 u -> 0 的时候 $g(t) \sim h(u)$ 从而这个积分极限直接等于 1

这种做法是错误的，因为积分等价代换中，被积函数等价的前提是上下都是一个变量，这个变量同时趋于 0；但是在这里，**我们换元之后 t 和 u 不再是同一个变量**，在换元之前被积函数中的 t 是一个变量，但是换元之后的 u = x - t，所以当分子 t->0 的时候分母中的 u 应该趋于 x，所以无法得到上下被积函数在 t ->0 的等价性，也就不能使用积分等价来做

同理，如果在分母使用一次积分再现，积分再现公式是 $\int_{a}^b f (x) dx = \int_{a}^b f (a + b - x) dx$，虽然结果相等，但是积分重现的本质是换元，所以等号两边的 x 显然不是同一个 x，因此在这道题中对分母使用一次积分重现：

$$
\lim_{ x \to 0 } \frac{ \int_{0}^x (x - t) f(t)dt}{\int_{0}^x xf(t)dt}
$$
上下两个被积函数中的 t 此时就不是同一个 t 了，当分子的 t 趋于 0 的时候分母的 t 并不趋近 0，所以也不能使用积分的等价代换公式

这道题的正确处理方式是换元之后使用一次洛必达：

然后用一次积分中值定理：
