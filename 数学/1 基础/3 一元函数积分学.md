### 4 分部积分法计算 - 组合积分法 + $(\tan x + 1)^2$ 这个式子的处理 + 特殊的积分再现

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250428102000.png)

组合积分法是用于处理形如下面被积函数的积分式子的情况的：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250428102045.png)

这里有两种特别的情况，当 u = e^x 的时候：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250428102119.png)

我们可以将 f (x) 和 f' (x) 组合起来，直接得到 e^x f (x) + C

另外一种情况是 u = e^(2 x) 的时候：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250428102212.png)

我们可以将 2 f (x) +f' (x) 组合起来，直接得到 e^2 x * f (x)

这道题目，将 (tanx + 1)^2 拆开得到 tan^x + 1 + 2 tanx = sec^x + 2 tanx，完美符合组合积分法，所以结果直接就是 e^2 x * tan x


==或者另外一种做法：==

这里还是先将 (tanx + 1)^2 拆开得到 tan^x + 1 + 2 tanx = sec^x + 2 tanx，从而将式子变成两个部分：
![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250428102856.png)

这个式子变成两项之后，后面一项非常不好处理，所以就看前面，发现将 sec^x 凑进 dx 后可以再现 e^2 x * tanx，那么前面贡献一个这样的式子是否与后面的一项可以相消呢，发现刚好可以：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250428103032.png)

### 5 分部积分法计算 - 降次  + 分组积分法

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250428103144.png)

这里的思路是，一般积分式子中的次数越高我们越不好处理，而分部积分法就有降次的功能，可以将高次作为 v'放入 dx 中，从而生成两个次数更低的式子

这道题目就是将 $(1 + x)^{-2}$ 放入 dx 中，从而降次：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250428103443.png)


或者使用组合积分法，对 $\frac{x}{(x + 1)^2}$ 变形一下，得到：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250428103632.png)

括号中就是 $\frac{1}{(1 + x)}$ 的 $f(x) + f'(x)$，从而很容易得到结果

### 6 分部积分法与换元的结合 + $\int\frac{1}{1 + e^x}dx$ 的处理方式

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250428114051.png)

（1）换元

令 $\sqrt{ e^x - 1 } = t$ 换元即可

（2）换元 + 降次

令 $\sqrt{ \frac{1 - x}{1  +x } } = t$ 换元，然后先别急求 dx，这里先将 1/x^2 放进 dx 中利用分部积分法进行降次，降一次后会得到一个 $\frac{t^2 + 1}{t^2 - 1} dt$ 的结构，这个就好做了

或者换元之后求完 dx，后面处理的时候有一步需要进行降次，然后变成好做的结构

==另外一种方式是直接开始降次得到：==

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250428115415.png)

对此时被积函数的一大坨求导是荒谬的，得想办法处理，通过观察可以发现根号中的式子是一个齐次项，所以我们可以通过同时上下除以 x 来变成 1/x，然后进行换元

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250428115702.png)

接下来当然可以继续换元，但是这里可以进行分子有理化，得到 $\sqrt{ t^2 - 1 }$ 这样的结构：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250428115836.png)

下面就容易处理了


（3）换元

这道题目如果将分母拆成 (1+x^2) * (1 + x^2)^(1/2)，然后将分子放到 dx 中，这种做法后面处理会非常麻烦

这里考虑直接进行换元，根据分子和分母的提示，令 $\arctan x = t$，或者令 $\tan t = x$，第二种做法代入化简非常方便，得到：

 ![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250428121003.png)

这就非常简单了

（4）换元 + 分部

令 $e^x = t$，然后就是一个非常明显的分部积分的结构，利用分部积分可以得到一个 $\int \frac{1}{t} \frac{1}{\sqrt{ 1 - t^2 }}dt$ 的结构，这种处理方式，直接令 t = sin x 即可

或者先不急换元，通过分部积分可以得到：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250428121919.png)

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250428122024.png)

所以结果就是：
