==第一种做法，直接用几何概型分析==

要求 P (X <= x)，直接对 x 进行分类讨论，P (X <= x) 的含义是，将区间分成两端，较小的一段小于等于 x 的概率

x < 0

即将 (0, 2) 分成两段，较小的一段小于 x 的概率，由于此时 x < 0，所以不可能分成较小的一段小于 0，所以 P (X <= x) = 0 = F (x)

0 <= x < 2

这个时候会发现 x 取 0 到 2 之间的时候可能有点问题，因为在区间的中点 1 左侧分段与在 1 右侧分段这两种情况是等价的，所以此时需要将 x 再进行一次细化讨论

当 0 <= x < 1

即将 (0, 2) 分成两段，较小的一段小于 x 的概率，由于 X 的取值就是[0, 1]，X 在[0, 1]中是等可能取值的（当然是等可能的，因为怎么划分是随机的），x 又在这个区间中，那么 P (X <= x) 就是一个几何概型问题，即 P (X <= x) = F (x) = x

当 1 <= x < 2

即将 (0, 2) 分成两段，较小的一段小于 x 的概率，由于 X 的取值就是[0, 1]，所以 X <= x 就是一个必然事件，所以 P (X <= x) = 1 = F (x)

当 2 <= x

同上 P (X <= x) = 1 = F (x)

==第二种方法，利用取点是均匀分布来做==

如果我们在区间取一个点，这个点的取值 Y 服从均匀分布 Y ~ U (0, 2)

那么此时我们再考虑 X，首先，X 的取值范围肯定是 (0, 1)

求其分布函数，还是对 x 进行分类讨论

当 x < 0 的时候 P (X < x) = F (x) = 0

当 1 <= x 的时候 P (X < x) = F (x) = 1

当 0 <= x < 1 的时候，分成两种情况

第一种情况，较短的部分在左侧：
![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250617092157.png)
此时 x 应该看成是一个定值常量，那么 P (X <= x) = F (x) 的含义就是在这个区间中取一次，既然是在左侧，那 x 也应该在左侧，此时 X在左侧应该小于等于 x 的概率，映射到 Y 的话那就是 Y 应该取在 x 的左侧这样形成的 X 才会小于 x，即：

$$
P(X \leq x) = F(x) = P(Y < x) = \frac{x}{2}
$$

第二种情况，较短的部分在右侧：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250617092624.png)

那么此时，为例保证 X <= x，并且较短部分在右侧，那么Y 应该取在 x 的右侧，即：

$$
P(X \leq x) = F(x) = P(Y>2-x) = \frac{2 - (2 - x)}{2} = \frac{x}{2}
$$

两种情况合起来的概率就是 $P(X \leq x) = F(x) = x$

==第三种做法，按照随机变量的函数来做==

如果在 (0, 2) 上取一点 V，那么其将这个区间分成了 V 和 2 - V 两个部分

既然 X 是分成的较小的一段，那么可以知道 X 与 V 的函数就是 X = min{V, 2 - V}
