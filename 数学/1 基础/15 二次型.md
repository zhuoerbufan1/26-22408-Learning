### 1 按照方程组来处理正定二次型

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250701084145.png)

这道题的 f 是正定的，说明只有当 x 1 = x 2 = x 3 = 0 的时候 f  = 0，其他情况 f > 0

f = 0 等价于 ax 1 + 2 x 2 - 3 x 3 = x 2 - 2 x 3 = x 1 + ax 2 - x 3 = 0

也就是只有 x 1 = x 2 = x 3 = 0 的时候 ax 1 + 2 x 2 - 3 x 3 = x 2 - 2 x 3 = x 1 + ax 2 - x 3 = 0

也就是说 ax 1 + 2 x 2 - 3 x 3 = x 2 - 2 x 3 = x 1 + ax 2 - x 3 = 0 构成的齐次线性方程组只有 0 解

系数矩阵的行列式不等于 0，所以 C 正确

==另外一种做法：==

题目说了这个二次型是可逆的，那么令：

ax 1 + 2 x 2 - 3 x 3 = y 1

x 2 - 2 x 3 = y 2

x 1 + ax 2 - x 3 = y 3

这个线性变换一定是可逆的

因为它是正定的，所以 g (Y) = y 1^2 + y 2^2 + y 3^3 一定是他的规范型，而这个二次型变换成规范型就是按照上述线性变换进行的，所以这个线性变换一定是可逆线性变换

所以这个变换矩阵一定是可逆的

这个变换矩阵就是第一种方法的系数矩阵，其行列式不等于 0 即可

所以 C 正确


### 2 用定义法来处理正定

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250701085423.png)

正定的充要条件有 5 个，正惯性指数 = n，特征值都大于 0，顺序主子式都大于 0，与 E 合同，可以写成可逆矩阵 $P^TP$

但是这道题目这五条都不好用，所以只能用定义来做了

左右乘 x 得到：

$$
x^T\lambda x + x^TA^TA x = \lambda x^Tx + (Ax)^T(Ax)
$$

上式的左半部分和右半部分都是一个平方和的形式，所以当 $\lambda > 0$ 的时候当然就是正定的
