## 多元函数微分学的基本概念

### 1 二重极限的计算方法

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250507111349.png)

二重极限的计算一般就采用
（1）等价代换
（2）四则运算
（3）夹逼准则
利用上面三种手段将式子变换到可以直接代入 （x 0, y 0）得到确定的值，此时这个值就是极限了

说明二重积分的极限不存在一般就取特定路径

==第一题==

用等价代换，可以得到

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250507111448.png)

这个分子分母消掉之后两者趋于零的时候一定是 0 了，**这里趋于零是显而易见的，不需要再考虑什么特殊路径之类的，因为这里代入 x = 0, y = 0 之后有确定的值**，其他的是因为出现了 0 比 0 不能直接通过代入得到式子的值，所以才需要按照取极限的思路考虑

==第二题==

等价代换和四则运算都不好用，这里考虑使用夹逼准则，$\frac{y^2}{x^2 + y^2}$ 可以进行放缩，整个式子取绝对值然后夹逼
