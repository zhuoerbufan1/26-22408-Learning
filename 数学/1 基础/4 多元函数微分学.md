![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250507111349.png)

二重极限的计算一般就采用
（1）等价代换
（2）四则运算
（3）夹逼准则
利用上面三种手段将式子变换到可以直接代入 （x 0, y 0）得到确定的值，此时这个值就是极限了

说明二重积分的极限不存在一般就取特定路径

### 13 根据偏导求原二元函数

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250508124439.png)


这道题目主要得步骤清晰

首先根据二阶偏导等于 1 可以得到关于 x 的偏导：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250508132352.png)

然后这个式子再求一次偏积分求到底，然后看能不能利用题中的条件：
![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250508132914.png)

这个式子中的 G (x) + h (y) 是 g (x) 对 x求偏积分的结果，因为 **g(x) 中只含有变量 x，所以这一部分一定是由原来的不含 y 的一部分函数求导而来，所以其对 x 求偏积分的结果一定是一个只含有 x 的函数 G (x) 和一个关于 y 的函数 h (y)**，并且 G (x) 就是 g (x) 的不定积分，即 $G(x) = \int g(x)dx$

令 x = 0 和 y = 0 得到：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250508142817.png)

对 $G(x) + h(0)  = \sin x$ 求一次导，得到 $g(x) = \cos x$，从而得到一个偏导：$\frac{\partial z}{\partial x} = y + \cos x$

同理得到另一个偏导：$\frac{\partial z}{\partial y} = x + \cos y$

于是后面就容易处理了

==另外一种方法==


首先根据二阶偏导等于 1 可以得到关于 x 的偏导：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250508132352.png)

**根据先带后导的思想（先代入 y = 0 求偏导，与先求偏导再代入 y = 0 的结果一样）**：

$$
\frac{\partial z}{\partial x}|_{y = 0} = g(x) = \frac{\partial z(x, 0)}{\partial x} = \sin x
$$

可以直接得到 g (x) = sin x，同理得到另一个偏导

后面的处理就简单了

### 15 相同映射关系关于位置表达式的理解

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250509115920.png)

具有相同映射关系的两个表达式，不管实际上是什么变量的函数，只要映射关系一样，那么其关于位置的表达式就是形式一致的，对位置求导之后的表达式关于位置变量的形式也是一致的，所以当位置取值相等的时候，函数值也就相当

比如，对于两个映射关系一样但是复合函数不一样的两个函数，比如 f (u, v), f (x, y)，这里假设 u, v 都是关于 x, y 的函数，即 f (u (x, y), v (x, y)), f (x,  y)

只要映射关系一样，那么这个映射关系对位置求导的形式就是一样的

也就是说 $f'_{1}(u, v)$ 与 $f'_{1}(x, y)$ 的中，将 $f'_{1}(u, v)$ 看作 u, v 的函数的表达式，其与 $f'_{1}(x, y)$ 看作 x, y的表达式的区别仅仅在于未知数的符号不一样，形式完全是一致的

 $f'_{2}(u, v)$ 与 $f'_{2}(x, y)$ 也是这样

所以在这道题目中，我们让 F 对 x 求一次导得到：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250509120604.png)

上式中 $f'_{1}(x, f(x, 2x))$ 与 $f'_{1}(x, 2x)$，如果将 $f'_{1}(x, f(x, 2x))$ 看作 x 和 f (x, 2 x) 的函数，$f'_{1}(x, 2x)$ 看作 x 和 2 x 的函数；那么两者就是形式一致的 (虽然两者关于 x 的实际具体表达式不一样）

所以当 x = 1 的时候，$f'_{1}(x, f(x, 2x))$ 看作 x 和 f (x, 2 x) 的函数，这个表达式两个位置取值就是 1， 2 即 $f'_{1}(1, 2)$，同理 $f'_{1}(x, 2x)$ 看作 x 和 2 x 的函数，位置取值也是 1, 2，即 $f'_{1}(1, 2)$

所以两者结果就是相等的
