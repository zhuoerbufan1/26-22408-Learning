## 任意项级数的敛散性判别

### 13 $\sin (\pi \sqrt{ n^2 + 1 })$ 的处理 + 任意项级数处理的步骤 + 比较判别法的极限形式等价代换判断正项级数敛散性

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250520085331.png)

这里用到一个公式：$\sin (x + n\pi) = (-1)^n \sin x$

所以这里对括号内加上一个 npi 再减去一个 npi：

$$
\sin(\pi \sqrt{ n^2 + 1 } + n\pi - n\pi) = (-1)^n \sin(\pi \sqrt{ n^2 + 1 } - n\pi)
$$

所以我们要处理的就是下面级数的敛散性：

$$
\sum(-1)^n \sin(\pi \sqrt{ n^2 + 1 } - n\pi)
$$

第一步，观察通项是否趋于零，显然趋于零

第二步，判断是否绝对收敛，对于 sin 内部的式子其实不是很好看，我们进行一次分子有理化：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250520091133.png)

可以发现 sin 内部式子是递减趋于零的，最大值是 n = 1 此时这个内部式子小于 pi，所以 sin 大于零，所以在 n 趋于无穷的过程中，内部式子从一个小于 pi 的数趋于零，所以 sin 在这个过程中始终大于零

因此我们判断绝对收敛就是判断级数 $\sum \sin(\pi \frac{1}{\sqrt{ n^2 + 1 } + n})$ 的敛散性了

这里直接根据比较判别法极限形式进行等价，当 n 趋于无穷的时候：

$$
\sin\left( \pi \frac{1}{\sqrt{ n^2 + 1 } + n} \right) \sim  \frac{1}{\sqrt{ n^2 + 1 } + n} \sim \frac{1}{2n}
$$ 
所以是发散的

第三步，判断是否条件收敛，利用莱布尼兹准则

首先 $\sin(\pi \frac{1}{\sqrt{ n^2 + 1 } + n})$ 这个式子内部是递减的，范围从一个小于 pi/2 的数趋近于 0，所以外部是递增的，因此综合就是递减的，并且趋近于零，所以条件收敛

### 15 正项级数的比较判别法（一般形式） - 利用基本不等式进行配凑

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250520103218.png)

交错级数，首先判断取绝对值之后的式子

这里已知一个级数收敛，然后判断另一个级数的敛散性一般就是要用到比较判别法，而且很大可能是要用到极限形式

这里用极限形式发现行不通，所以只能用比较判别法的一般形式

既然 $\sum a_{n}^2$ 收敛，我们要判断 $\sum \frac{|a_{n}|}{\sqrt{ n^2 + \lambda }}$，那肯定是要弄出一个小于等于的不等式：

$$
 \frac{|a_{n}|}{\sqrt{ n^2 + \lambda }} \dots\dots.\leq a_{n}^2\dots\dots
$$

关键是这里怎么凑，这里采用的是用基本不等式根据 $a_{n}^2$ 凑出 $\frac{|a_{n}|}{\sqrt{ n^2 + \lambda }}$

根据 $a_{n}^2 + \frac{1}{n^2 + \lambda } \geq 2\sqrt{ \frac{a_{n}^2}{n^2 + \lambda} } = 2 \frac{|a_{n}|}{\sqrt{ n^2 + \lambda }}$，这样就凑出左边的式子了，所以我们得到比较判别法凑出的式子：

$$
\frac{1}{2} (a_{n}^2 + \frac{1}{n^2 + \lambda }) \geq  \frac{|a_{n}|}{\sqrt{ n^2 + \lambda }}
$$

不等式左边的两个通项形成的级数都是收敛的，所以右边是收敛的

所以原级数就是绝对收敛的


**利用一般形式的比较判别法来判断敛散性一般有两种**

**一种是像本道题，会给出一个已知敛散性的级数，这个级数收敛，我们就想办法凑出未知级数小于这个已知敛散性级数；这个级数发散，我们就想办法凑出未知级数大于这个已知敛散性的级数**

**第二种是放缩，将未知级数往大的放缩到一个收敛的级数，或者将未知级数往小的放缩到一个发散的级数**，比如 14 题，11 题

### 18 先求积分再求导处理和函数

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250521093648.png)

这道题目的通项先求导或者直接积分都不好计算，系数很麻烦，如果能直接取出就好了

所以想到如果是 $nx^{n - 1}$ 就好了，因此对这个式子进行变形，根据求和法则，这里变化的量是 n 而不是 x，所以 x 可以直接提出到求和符号外面：

$$
\sum_{n = 1}^\infty n x^n = x\sum nx^{n - 1} = S(x)
$$

收敛域是 (- 1, 1)

当 x = 0 时，S (0) = 0

当 x != 0 时：

$$
\frac{S(x)}{x} = \sum nx^{n - 1}
$$

求不定积分：

$$
\int_{0}^x \frac{S(t)}{t} dt= \int_{0}^x \sum_{n = 1}^\infty n t^{n - 1} dt = \sum_{n = 1}^\infty x^n
$$

上述式子的收敛域还是 (-1, 1) 不变, 即 x 绝对值小于 1，所以得到：

$$
\int_{0}^x \frac{S(t)}{t} dt = \frac{x}{1- x}
$$

求导，得到：

$$
\frac{S(x)}{x} = \frac{1}{(1 - x)^2}
$$

所以:

$$
S(x) = \frac{x}{(1 - x)^2}
$$
x 在 (-1, 1) 都成立

### 19 求和函数中的定义域处理

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250521100342.png)

先求收敛域，x 的收敛域是 $[-1, 1]$

这道题目根据分母可以想到先裂项，然后化简，提取一个 1/x 出来，得到：

$$
S(x) = \left( 1 - \frac{1}{x} \right) \sum_{n = 1}^\infty \frac{x^n}{n} + 1
$$

这里 x != 0

我们将 $\sum \frac{x^n}{n} = G(x)$ 单独领出来求解，得到 $G(x) = -\ln(1 - x)$，定义域是 $[-1, 1)$

我们这里将 G (x) 代入的时候，为了保证式子中各个部分都有意义，必须以定义域更小的为准，也就是代入后得到：

$$
S(x) = \left( \frac{1}{x} -1\right)\ln(1 - x) + 1
$$
定义域是 $[-1, 0) \cup (0, 1)$

但是原来的和函数的定义域是 $[-1, 1]$，还少了两个点怎么办，挨个单独讨论

当 x = 0 的时候 S (0) = 0

当 x = 1 的时候对式子裂项：

$$
S(1) = \sum_{n = 1}^\infty \left( \frac{1}{n} - \frac{1}{n + 1} \right) = 1
$$

综合上面三种情况就得到 S (x) 了：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250521101549.png)

这也是为什么一开始就要求 S (x) 的收敛域的原因，因为在后续求具体式子的过程中为了保证式子有意义收敛域会发生变化，会缺少某些 x 的取值，如果一开始没有确定完整的收敛域的话，最后的结果会缺少一部分

==另一种处理单独点的方式==

由于和函数是一定在收敛域中连续的，可以直接对式子 $\left( \frac{1}{x} -1\right)\ln(1 - x) + 1$ 取逼近于 0 和 1 处的极限得到 S (0) 和 S (1)



### 20 缺项幂级数的处理 - 特殊等比级数式子积累 $\sum x^{2n}$

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250521104918.png)

这道题先求收敛域：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250521104933.png)

然后观察式子，发现 2 n 和 2 n - 1，所以想到通过求导约掉这个 2 n - 1；怎样才能通过求导约掉呢，提一个 x 出去，这样就可以求导约掉了：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250521105030.png)

于是有：

$$
G(x) = \sum_{n = 1}^\infty \frac{(-1)^{n - 1}}{2n - 1}x^{2n -1}
$$
得到：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250521105755.png)

这个式子是一个非常特殊的等比级数，是类似于 $\sum x^{2n}$ 的，对于 $\sum x^{2n}$，我们看作 $\sum (x^2)^n$，公比是 x^2，所以 $\sum (x^2)^n = \frac{1}{1 + x^2}$（下标都从 1 开始）

所以对于本题式子，我们有：
$$
\sum_{n = 1}^\infty = (-x^2)^{n - 1} = \frac{1}{1 + x^2} = G'(x)
$$

收敛域是 (-1, 1)，我们要求 G (x)，所以根据莱布尼兹公式：

$$
\int_{0}^x G'(t) dt = G(x) - G(0) = \int_{0}^x \frac{1}{1 + t^2} dt = \arctan x
$$

所以 G (x) = arctanx 收敛域是 (-1, 1)

所以 S (x) = xarctanx，看看端点的收敛情况，发现也收敛，所以收敛域就是[-1, 1]


### 21 易错点：判断和函数的端点取值要注意下标，不能直接根据通项来判断

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250521122734.png)

首先，这个幂级数的收敛域是 $[-2, 2)$


这道题目可以进行变形：

$$
\frac{1}{x}\sum_{n = 1}^\infty \frac{1}{n} \left( \frac{x}{2} \right)^n
$$

这时的收敛域变成 $[-2, 0) \cup (0, 2)$，我们按照这个定义域往下求

这里将 x/2 看作一个整体，令 $G(x) =\sum_{n = 1}^\infty \frac{1}{n} \left ( \frac{x}{2} \right)^n$ 即可

这就很好处理了，对 G (x) 求导，求出来之后再带回去，可以得到结果：

$$
S(x) = \frac{\left( -\ln\left( 1 - \frac{x}{2} \right) \right)}{x}
$$
此时定义域是 $[-2, 0) \cup (0, 2)$

当 x = 0 时，原级数是：
![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250521123428.png)

**注意 x = 0 确实是可以让这个通项等于零，但是原级数的第一项不受 x = 0 的影响，所以 S (0) = 1/2，而不是 0**
