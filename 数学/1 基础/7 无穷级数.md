### 5 正向级数的敛散性判别 - （比较判别法的极限形式）等价代换

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250519093540.png)

这里跟反常积分的判定类似，当 n 趋于无穷的时候直接对 $\sin \frac{\pi}{2^n}$ 进行等价替换：

$$
\sin \frac{\pi}{2^2} \sim \frac{\pi}{2^n}
$$
然后观察级数 $\sum \frac{\pi}{2^n}$，根据几何级数，其公比<1，所以级数收敛，所以原级数收敛

### 8 比值判别法失效的情况处理

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250519100002.png)

首先看第一个级数，带有 n!，显然是要用到比值判别法，我们可以得到发散和收敛的两种情况 p 的范围：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250519100046.png)

但是当 p = e 的时候比值判别法失效，也就是我们需要判定当 p = e 的时候原级数的收敛情况

下面的方法积累比较难想到，这里还是做一个比值：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250519100522.png)

这个极限确实还是是 1，但是我们要观察其是怎么趋近于 1 的，从而确定 un+1 和 un 的大小关系

我们从分母入手，观察其单调性：

令 $f(x) = \left( 1 + \frac{1}{x} \right)^x$

求导得到：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250519100648.png)

后面的一项中的 ln (1 + 1/x) 可以写成 ln (1 + x) - ln x，利用拉格朗日中值定理：

$$
\ln(1 + x) - \ln x = f'(\xi)(1 + x - x) = \frac{1}{\xi}
$$
这个 $\xi$ 在 (x, x + 1) 之间，所以大于后面的 1/x + 1，所以导数大于零，所以原函数递增

所以 $\frac{e}{\left( 1 +\frac{1}{n} \right)^n}$ 的分母部分是递增的

所以分母是逐渐递增趋近于 e：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250519100945.png)

那么这个极限整体就是逐渐递减趋近于 1：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250519100959.png)

所以 $\lim_{ n \to \infty } \frac{u_{n + 1}}{u_{n}}$ 是逐渐递减趋近于 1，所以 $u_{n + 1} \geq u_{n}$，即这个级数通项是递增的，而 un 又是正数，所以 $u_{n  + 1}$ 不可能在 n 趋于无穷的时候趋近于零

所以 p = e 的时候这个级数发散，因此只有 p < e 的时候这个级数才收敛

对于第二个级数，显然就需要用比值极限的判别法进行处理，首先进行分子有理化：
![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250519103639.png)

然后抓大头进行等价：
![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250519103654.png)

所以其与 $\Sigma \frac{1}{2n^{p + 1/2}}$ 具有相同的敛散性

所以 p + 1/2 <= 1, p <= 1/2

综合起来就是 0 < p <= 1/2

这里，由于 $\lim_{ n \to \infty } u_{n} = 0$，所以一定有一个正数 M，当 n 充分大的时候（n > N）有 un < M，即 un 是有界的（收敛正向级数通项的有界性，其实收敛正向级数的部分和也是有界的）

### 12 比值判别法的使用 - 非正数情况

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250519125030.png)

这句话是对的，这里的证明方式是利用级数收敛的必要条件加上极限的保号性进行

由于这个极限是正的，所以当 n > N 的时候这个通项的比值恒为正，因此通项要么恒为正要么恒为负

假设恒为负，那么当 n > N 的时候 $u_{n + 1} < u_{n}  < 0$，不满足级数收敛的必要条件，所以发散


反过来，如果 $\lim_{ n \to \infty } \frac{u_{n + 1}}{u_{n}} < 1$，则 $\Sigma u_{n}$ 收敛，这句话是错的，因为小于 1 不一定大于零，可能 un 相邻的两个数在摇摆，反例就是 $u_{n} = (-1)^n$，他的比值小于 1，但是确是发散的


同样，当比值是 1 的时候判别法失效

**比值判别法判断发散的情况无论通项是否为正都有效**
