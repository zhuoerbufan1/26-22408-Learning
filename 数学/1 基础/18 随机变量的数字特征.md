### 2 概率密度关于 x = c 对称的时候证明 EX = c

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250703090134.png)

题目中的这个条件就说明 f (x) 是关于 x = c 对称的

既然要证明 EX  = c，那就写出 EX 的公式：

$$
\int_{-\infty}^\infty xf(x) dx = EX
$$

要使用这个条件，你显然要更改一下变量才行：

$$
\int_{-\infty}^\infty (x + c)f(x + c) dx = EX = \int_{-\infty}^\infty xf(x + c) dx + \int_{-\infty}^\infty cf(x + c)dx= EX
$$

上式中 $\int_{-\infty}^\infty cf(x + c) dx = c$，所以变为：

$$
EX =  \int_{-\infty}^\infty xf(x + c) dx + c
$$

所以我们只要能证明 $\int_{-\infty}^\infty xf(x + c) dx = 0$ 就行了

观察 $xf(x +c) = g(x)$，得到：

$$
g(-x) = (-x)f(-x+c) = -x(x +c) = g(x)
$$

所以 xf (x +c) 是一个奇函数，所以结果就是 0

因此证明了 EX = c
