线性微分方程按照最直接的思路写到最后，此时的任意常数 C 会将所有的解包含

### 2 微分方程中绝对值的处理 + 对通解特解的理解

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250516103946.png)

这道题目做法非常简单，就是令 y/x = u，得到：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250516104027.png)

微分方程的解其实包括非常广泛，只要是满足等式成立的解析式都算方程的解，比如：

y = ln |x|是某个微分方程的解

那么，x > 0，y = ln (x) 是这个方程的解

x < 0, y = ln (- x) 同样是这个方程的解

甚至 y = x，x 取不同的范围就是不同的解

换到这道题目，因为题目要求 x = 1, y = 1 下的特解，所以这个特解一定是在 x > 0 的范围成立的解集中

所以我们在解微分方程中直接令 x > 0，解出来的结果就是在 x > 0 范围成立的解集，题目中要求的特解也一定在这些解集中，所以这里其实可以直接去掉绝对值符号，这样做并不会漏掉这个特解：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250516105122.png)

代入得到 C = 1，从而得到：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250516105158.png)

$y^2 = \frac{x^2}{\ln x + 1}$ 是一个在 y 小于零大于零，x>0 成立的特解，但是其开根号就不一定了，开了根号分成两个解，一个解是 y >0 范围的解，一个是在 y < 0 范围的解

题目中要求是 x = 1, y = 1 下的特解，那这个特解一定是在 x >0，且 y > 0 的范围有效（其实是 x>= 1, y >= 1 有效就行）；这样可以去掉负号，因为 $y = - \frac{x}{\sqrt{ \ln x + 1 }}$ 不是 y > 0 范围的解

反正我们根据原来的微分方程求得的解析式一定是解，题目中又只要求特解，所以我们随意指定一个满足题意的解就行了，所以 $y = \frac{x}{\sqrt{ \ln x + 1 }}$

**只要是满足微分方程的解析式子，其实都是解，至于 x 范围多少，y 范围多少，C 的范围多少其实都无所谓，取不同的范围那就是不同的解；所以如果要求某一特定的解，我们完全可以通过这个特定的解的 x, y 范围来判断这个特解满足的范围，缩小解集，从而简化变换原微分方程中的步骤（去绝对值负号或者二阶先确定某个常数 C 1等等）**

### 3 二阶可降阶方程中的细节处理

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250516123820.png)

这道题目做法很简单，令 p = y'

然后得到：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250516123853.png)

这是头重脚轻的形式，那就倒反天罡一下，将 x 看作 p 的函数，这是一个一阶线性微分方程，可以直接用公式，得到：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250516124029.png)

即 $x = p^2 + C_{1}p$

这时再往下求不好弄，因为此时 p = p'，但是这里带了一个常数

通过观察题目，我们发现 x = 1 的时候 y' = x = 1，利用这个关系先求出 C 1 = 0，这里的思想跟上一道题类似，这里 $x = p^2 + C_{1}p$ 中 C 1 取多少其实无所谓，反正往后求都是最开始的微分方程的解，那么就根据题目中的条件缩小一下后面的解集范围，即满足题目条件的特解一定是在 C 1 = 0 后，根据 $x = p^2$ 求的的解集中

（C 1 ！= 0 那 $x = p^2 + C_{1}p$ 直接就不满足特解条件了，在不满足特解条件下求得的解当然不满足题中的条件，所以题中要求的解就不在这些解中）

从而得到：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250516124706.png)

与上一题类似，特解一定是满足 y' > 0 的解集中，所以这里去掉负号，进一步缩小范围

（如果这里不去负号，那么此时就是在 y' < 0 下求出的解，那么求出来的解就会一律要求 y' < 0，显然这些解不包含题中要求的特解）：

  ![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250516124923.png)

**反正遇到这种题中给定初始条件的题目，就可以直接利用条件来对中间过程方程进行处理（去绝对值，算出自由变量 C，去负号，等等），从而缩小解集范围，简化计算**
