### 14 罗尔定理的使用-构造函数 + 还原法找到构造函数 + 构造函数的万能公式

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250422085210.png)

（1）构造 x f (x)，直接观察构造函数
（2）构造 $e^{\frac{1}{2}x^2}f(x)$


**还原法构造函数：**

一般来讲这种构造函数不是容易想到，这里可以用还原法，所谓还原法就是将题目中给的式子进行变形，或者四则运算，变成容易看到的求原函数的结构，一般有下面几个步骤：

1. 将式子的所有项统一移动到左边变成.... = 0 的形式
2. 将字母换成 x，这道题目就是 $xf(x) +f'(x) = 0$
3. 加减变形都不好弄，这里同时除以 f (x) 得到 $x + \frac{f'(x)}{f(x)} = 0$，可以轻松看到这里式子两项就是 1/2 x^2 和 ln f (x) 的导数：$\left( \frac{1}{2}x^2 + \ln f(x) \right)' = 0$
4. 将式子合并成一个，即 $[\ln e^{1/2x^2}f(x)]' = 0$，此时去掉外层的 ln 就是原函数了

即构造 h (x) =  $e^{\frac{1}{2}x^2}f(x)$


**万能公式构造函数：**

对于题中形如 $f'(\xi) + g(\xi)f(\xi) = 0$ 的证明形式，我们可以直接构造：$\psi(x) = e^{\int g(x)dx}f(x)$

代入这道题目，直接就得到了构造函数了

但是万能构造一般不能处理二阶导的情况

## 泰勒公式

### 20 泰勒公式的展开式系数 ak 与原函数的 k 阶导关系 + 泰勒公式求 k 次项系数 ak 的方法

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250422115041.png)

这道题目简单，但是其背后的思想是泰勒公式的原函数与展开式的对应关系，首先，将函数展开为幂级数的形式：
$$
f(x) = a_{0} + a_{1}(x - x_{0}) + a_{2}(x - x_{0})^2 + \dots \dots +a_{n}(x - x_{0})^n + o((x - x_{0})^n)
$$
然后有一个对应关系是，**函数 f (x) 在 x 0 处展开，要求多项式在 x 0 处的 k 阶导数与 f (x) 在 x 0 处的 k 阶导数一样，并且这个多项式在 x 0 处的值也是一样**

根据这个对应关系，多项式在 x 0 处的 k 阶导数，就是 k 次项求 k 阶导数暴露出来的常数项，这一项与函数 f (x) 在 x 0 处的 k 阶导数一样，即：
$$
(a_{k}(x - x_{0}))^{(k)}|_{x_{0}} = a_{k}k! = f^{(k)}(x_{0})
$$
比如 n 阶导要求一样，那么多项式求 n 阶导，n 次项左边的项会因为是常数全部消掉，n 次项右边的项因为还有 (x - x 0) 这一项所以代入 x 0 的时候就是零，因此剩下的就是 n 次项求 n 阶导的结果 $a_{n}n!$，这个应该与 f (x) 在 x 0 处求 n 阶导的结果一样，即 $f^{(n)}(x_{0})$，从而得到系数：$a_{n} = \frac{{f^{(n)}(x_{0})}}{n!}$

通用过程就是：
（1）先写出式子 $f(x) = a_{0} + a_{1}(x - x_{0}) + a_{2}(x - x_{0})^2 + \dots \dots +a_{n}(x - x_{0})^n + o((x - x_{0})^n)$
（2）根据多项式在 x 0 处的 k 阶导数与 f (x) 在 x 0 处的 k 阶导数一样，得到：$(a_{k}(x - x_{0}))^{(k)}|_{x_{0}} = a_{k}k! = f^{(k)}(x_{0})$
（3）根据这个式子按照题目的要求进行计算即可


这个对应关系 $(a_{k}(x - x_{0}))^{(k)}|_{x_{0}} = a_{k}k! = f^{(k)}(x_{0})$，一般有两种出题方式：
（1）给定一个函数求其泰勒展开求 $a_{k}$，此时我们根据这个对应关系和函数求函数 k 阶导即可
