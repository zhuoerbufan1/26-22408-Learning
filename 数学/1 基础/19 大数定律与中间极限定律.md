
### 1 大数定律的条件处理

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250703122115.png)
切比雪夫大数定律的要求是 Xi 独立； EXi 和 DXi 都存在，并且 DXi 有公共的上界
辛钦大数定律的要求是 Xi 独立同分布，有 EXi 即可
A：
首先，这里每一个 Xi 都是独立同分布的，这里只用检查一下 EXi 是否存在即可

$$
\sum_{i = 1}^n \frac{c}{m^3} * m
$$
是收敛的，所以 EXi 存在，所以 A 满足辛钦大数定律

B：

首先 Xi 不是同分布的，所以要检查是否满足切比雪夫大数定律，即 EXi 和 DXi 都存在并且所有的 DXi 有公共上界

这里 EXi = i，DXi = i^2，显然 DXi 没有公共上界，不存在一个常数 C 可以满足 DXi <= C

所以不满足切比雪夫大数定律

C：
首先 Xi 不是同分布的，所以要检查是否满足切比雪夫大数定律，即 EXi 和 DXi 都存在并且所有的 DXi 有公共上界

EXi = DXi = i，显然 DXi 没有公共上界

所以不满足切比雪夫大数定律

D：

这里 Xi 是同分布的，但是反常积分 $\int_{-\infty}^\infty \frac{x}{1 + x^2}dx$  = $\int_{-\infty}^0 \frac{x}{(1 + x^2)   } dx+ \int_{0}^\infty \frac{x}{1 + x^2}dx$，等式右侧两个积分都是发散的，所以期望不存在



这道题目很容易弄混分不清 X 1 X 2 X 3... 这些随机变量的各自的分布

可以根据选项写几个，看看是否是同分布的即可

比如 A 选择 P (X 1 = m) = c/m^3；P (X 2 = m) = c/m^3，X 1 和 X 2 是类似于 X 和 Y 这样的同等级的随机变量，所以这样写两个随机变量之后发现他俩的分布律就是一样的，所以是同分布的

比如 B 选择 $f_{X_{1}}(x) =  e^{-x}$，$f_{X_{2}} = 2e^{-2x}$，X 1 和 X 2 这两个随机变量的密度函数不一样，所以就不是同分布的
