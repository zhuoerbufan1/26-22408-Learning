### 3 带绝对值函数的导数定义的处理

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250714103612.png)

f (x) 在 x = a 处可导，也就是：

$$
\lim_{ x \to a } \frac{f(x) - f(a)}{x - a}
$$
存在

函数|f (x)|在 a 处的导数就是：

$$
\lim_{ x \to a }  \frac{|f(x)| - |f(a)|}{x - a}
$$
当 f (a) > 0 或者 < 0 的时候根据极限的保号性，其实绝对值符号可以直接去掉，退化成 $\lim_{ x \to a } \frac{f(x) - f(a)}{x - a}$ 的形式，那么

所以 C，D 选项可以直接排除

A：
当 f (a) = 0 的时候，f (x) 在 x = a 可导，也就是：

$$
\lim_{ x \to a } \frac{f(x)}{x - a}
$$
存在，并且 x -> a 的时候 f (x) 是 x - a 的高阶无穷小

那么对于 $\lim_{ x \to a } \frac{|f(x)|}{x - a}$，其实绝对值去不去就无所谓了，反正结果一定是 0，所以 $|f(x)|$ 一定可导，A 排除

或者严谨一点的话可以对 $\lim_{ x \to a } \frac{|f(x)|}{x - a}$ 求它的左右极限观察 x - a 的正负将其移动到绝对值中凑出 $\lim_{ x \to a } \frac{f(x)}{x - a}$ 的形式，结果其实还是 0

B：
当 f (a) = 0 的时候，f (x) 在 x = a 可导，也就是：

$$
\lim_{ x \to a } \frac{f(x)}{x - a} \ne 0
$$

假设 $\lim_{ x \to a } \frac{f(x)}{x - a} = A > 0$

那么对于 $\lim_{ x \to a } \frac{|f(x)|}{(x - a)}$，当 x -> a+，根据极限的保号性，那么在 $(a, a + \epsilon)$ 这个邻域中 f (x) > 0，在 $(a, a - \epsilon)$，这个邻域中 f (x) < 0， 所以：$\lim_{ x \to a+ } \frac{|f(x)|}{x - a} = \lim_{ x \to a+ } \frac{f(x)}{x - a} = A$

同理对于 |f (x)| 的左导数：

$$
\lim_{ x \to a- } \frac{|f(x)|}{x - a} = \lim_{ x \to a- } - \frac{f(x)}{x - a} = -A
$$

也即|f (x)|的左右导数不一样，所以 f (x) 不可导

### 4 复合函数可导性

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250716090449.png)

A：
可以举一个反例，g (x) = -1 (x < 0), g (x) = 1 (x >= 0)

g (x) 在 x = 0 处不可导，但是平方或者取绝对值之后就可导了

B：
用反证法，假如这个函数始终可导，那么它乘一个可导函数 f (x) 也必然是可导函数，但是得到的结果是 g (x)，不可导

C：
假如 f (x) 是一个常函数，那代入 g(x) 之后，f(g (x)) = 1，x 属于 R，它还是始终可导

D：
假如 f (x) 是一个常函数，f (x) = 1，代入之后得到 g (1) 可能也是可导的

如果 f (x) 和 g (x) 都是可导函数，那么复合之后确实是可导的

如果 f (x) 和 g (x) 有一个不可导，如这个题，复合之后可导性其实未知

如果 f (x) 和 g (x) 两个都有不可导点，那么复合之后其实可导性也还是未知

比如对于 f (g (x))，f (x) = -1 (x < 0), f (x) = 1 (x >= 0)；然后 g (x) 虽然有不可导点，但是恒大于 0，所以 f (g (x)) = 1，x 任意，那这个当然就是可导的（可以直接用定义证明）
当然两个有不可导点的函数复合也可能不可导，所以可导性其实暂定

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250716150301.png)
首先，因为曲率涉及了一阶导和二阶导的信息，所以可以直接对函数进行泰勒展开

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250716150412.png)

然后看极限条件是否是必要条件，切线相等可以推出导数相等，这个没问题；但是曲率相等不能推出二阶导相等，因为曲率的公式那里二阶导是绝对值，所以可能二阶导是正负相反的

比如 f (x) = x^2 和 f (x) = -x^2，曲率确实是相等的，但是显然你二阶导不相等并且恰恰相反
