### 拓扑排序判断环

```cpp
bool bfs(int** G){
    int d[n];//用于维护每个顶点的入度
    for(int i = 0; i < n; i ++) d[i] = 0;

    //得到每个顶点的入度
    for(int i = 0; i < n; i ++)
        for(int j = 0; j < n; j ++)
            if(G[j][i]) d[i] ++;

    //用来bfs图
    queue<int> q;

    int cnt = 0;

    //先将每个入度为0的顶点加入到队列中
    for(int i = 0; i < n; i ++)
        if(d[i] == 0) q.push(i);

    //开始bfs
    while(q.size()){
        int v = q.front();
        q.pop();

        //得到了拓扑序的一个元素v，同时修改v指向的顶点的入度
        for(int i = 0; i < n; i ++)
            if(G[v][i]){
                d[i] --;
                if(d[i] == 0) q.push(i);
            }

        cnt ++;
    }

    if(cnt == n) return true;
    else return false;
}


```

### 拓扑排序（BFS实现）

基本思想是：

（1）一个数组维护每个顶点的入度，将初始度为0的顶点全部加入到队列中

（2）从入度为0的顶点开始bfs遍历，输出，同时更改它所有引出顶点的入度，如果这个点的入度为0，则加入队列成为后续bfs遍历队列的靠后的拓扑序元素

```cpp
int* bfs(int** G, int* result){
    int d[n];
    for(int i = 0; i < n; i ++) d[i] = 0;
    
    for(int i = 0; i < n; i ++)
        for(int j = 0; j < n; j ++)
            if(G[j][i]) d[i] ++;
    
    queue<int> q;
    for(int i = 0; i < n ; i++)
        if(d[i] == 0) q.push(i);
    
    int k = 0;
    while(q.size()){
        int v = q.front();
        q.pop();
        result[k ++] = v;
        for(int i = 0; i < n; i ++)
            if(G[v][i] == 1){
                d[i] --;
                if(d[i] == 0) q.push(i)
            }
    }
    
    return reuslt;
}
```

邻接矩阵这里在得到每个顶点的度的时候时间复杂度是O(n^2)

在BFS顶点的时候时间复杂度也是O(n^2)

所以总的复杂度就是O(n^2)



但是如果是邻接表的存储方式，在得到每个顶点的入度的时候需要遍历整个邻接表的所有边和顶点所以时间复杂度是O(n + e)

在BFS的时候，每个顶点都会遍历一遍，同时在遍历某个顶点的时候需要更改它引出的边的所有顶点的度，所以BFS的时候复杂度同样是O(n + e)

所以邻接表存储矩阵的话，拓扑排序的复杂度就是O(n + e)的级别

### 快速排序

```cpp

int partition(int A[], int low, int high){
	int prviot = A[low];
	
	while(low < high){
		while(low < high && A[high] >= prviot) high --;
		//循环结束找到了从右往左的第一个<枢轴元素的下标high
		A[low] = A[high];
		
		while(low < high && A[low] <= prviot) low ++;
		A[high] = A[low];
	}
	A[low] = prviot;//将枢轴元素放到正确的位置上
	return low;//返回枢轴元素的位置
}


void QuickSort(int A[], int low, int high){
	int index = partition(A, low, high);
	QuickSort(A, low, index - 1);
	QuickSort(A, index + 1, high);
}
```

### 双标志先检查法

```cpp
int flag[2] = [0, 0];

P0{
    while(flag[1] == 1);
    进入临界区;
    flag[0] = 0;
}

```

### 双标志后检查法

```cpp
int flag[2] = [0, 0];

P0{
    flag[0] = 1;
    while(flag[1] == 1);
    进入临界区;
    flag[0] = 0;
}

P1{
    flag[1] = 1;
    while(flag[0] == 1);
    进入临界区;
    flag[1] = 0;
}
```

不满足空闲让进，有限等待，两者进程可能被饿死，因为当P0执行完flag[0] = 1之后切换执行P1，P1也执行晚了flag[1] = 1，此时两个进程都会被卡死



### Peterson算法



```cpp
int flag[2] = 0, 0;
int turn  = 0;

P0{
    flag[0] = 1;
    turn = 1;//谦让一次
    while(flag[1] && turn == 1);//如果对方表达了意愿，并且自己是最后谦让的，则卡死
    进入临界区;
    flag[0] = 0;
}

P1{
    flag[1] = 1;
    turn = 0;
    while(flag[0] && turn == 0);//如果对方表达了意愿，并且自己是最后谦让的，则卡死
    进入临界区;
    flag[1] = 0;
}
```

这种方式满足了忙则等待，空闲让进，有限等待

但是不满足让权等待，也就是P0访问临界区的时候P1会卡死在while循环霸占CPU，而不是让出CPU



# 互斥机制的硬件实现

### TestAndSet指令和使用

```cpp
bool TestAndSet(bool* lock){
    bool old = *lock;
    *lock = true;
    return old;
}

//使用
while(TestAndSet(lock));
进入临界区
*lock = false;

```

（1）lock为所有进程共享，每个进程都可以操控lock变量，所以输入参数是一个指针变量指向lock

（2）TLS的代码作用就是返回lock旧值，同时将指针指向的lock设置为ture

（3）while起到阻拦的作用，lock = true就一直阻拦，直到别的进程推出临界区将lock设置成false，此时当下进程返回的旧值就是false，通过while阻拦进入临界区

### swap指令和使用

```cpp
void swap(bool* a, bool* b){
    bool temp;
    temp = *a;
    *a = *b;
    *b = temp;
}

//swap指令的使用
bool* old = true;
while(old == true){
    swap(old, lock);
}
进入临界区;
*lock = false;
```

（1）swap指令本身只是用来实现两个bool指针指向的变量数值互换

（2）swap指令本质上和TSL指令是一样的，将lock赋值为true并返回lock的值用于while判断

（3）当别的进程在临界区中的时候由于old = true，所以lock被设置成true，当下进程被卡死在while循环中

（4）当别的进程出临界区，将lock设置为false，当下进程的old才会获得lock的新值false，才会出while循环
