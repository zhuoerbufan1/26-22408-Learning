这里应该对碗的个数进行分类讨论

如果碗的个数 m >= n 那么碗的个数就是充足的，那么这就是一个普通的哲学家进餐问题，一个解决普通哲学家问题的方法是，安排一个临界资源  = n - 1 作为门槛，不能让超过 n - 1 个哲学家同时拿到筷子，这样一定会有一个哲学家不会拿到筷子，那么一定会有哲学家可以进餐，这样就不会死锁了


如果碗的个数 m < n，那就将碗作为拿到筷子的门槛，这样一定有哲学家无法拿到筷子，因此也就一定有哲学家可以拿到全部的筷子吃饭，这样就解决了死锁问题了

所以合并一下，其实可以让 k = min (n - 1, m) 作为拿筷子的门槛即可，这样不管 m 是否大于 n，都可以保证门槛个数 < n，这样一定有哲学家无法拿到筷子，因此也就一定有哲学家可以拿到全部的筷子吃饭，这样就解决了死锁问题了

这里哲学家的编号和他的左边的筷子的编号一样，编号顺时针变大，顺时针方向是右


```c
semaphore count = min(n - 1, m);
semaphore chopsticks[n] = {1};

process(i){
	while(1){
		P(count);//获得拿筷子的资格
		
		P(chopsticks[i]);
		P(chopsticks[(i + 1) % n]);//这里取余是为了保证编号第n - 1个哲学家可以拿到他的右边的第0号筷子
		
		eat;
		
		V(chopsticks[i]);
		V(chopsticks[(i + 1) % n]);
		
		V(count);
	
	}

}
```

（1）

从 push 到 ret 指令，他们所占的总大小是 0040104 A - 00401000 + 1 = 4B H，一共75B

push指令的虚拟地址是：0040104A
ret指令的虚拟地址是00401000

页大小是4KB占12bit

主存地址是32bit，所以页号是20bit

由于这两个指令的虚拟地址的页号部分一样，所以是在同一页中

（2）

块大小是2^6B，所以主存地址的最后6bit表示块内偏移地址

4路组相联映射，所以一组有4行，Cache有64行，所以一共有16组，因此组号是4bit

主存与Cache在组内是全相联映射，所以剩下的都是tag位

因此主存地址从右到左，从低位到高位0 ~ 5bit表示块内偏移

6 ~ 9bit是组号

10bit ~ 31bit的22bit是tag位

（3）

call指令的虚拟地址是00401025，写成二进制就是

0000 0000 0100 0000 0001 0000 0010 0101

这个虽然是虚拟地址，但是转换成物理地址的时候页内偏移不变

所以它的物理地址的后12bit不变，即0000 0010 0101是其物理地址的后12bit

所以组号就是0 00

因此是第0号组
