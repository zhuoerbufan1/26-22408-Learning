```C++
//入队操作

//如果队满，则增加一个空闲结点
if(rear->next = front){
	//分配一个新的结点
	LinkNode* newNode = new LinkNode();
	newNode->next = front;
	rear->val = newNum;//进入队列的元素
	rear->next = newNode;
	rear = newNode;
	
}else{
	rear->val = newNum;
	rear = rear->next;
}


//出队操作
if(rear == front) 返回错误;
else{
	firstNum = front->val;
	front = front->next;
	return firstNum;
}
```

这里应该对碗的个数进行分类讨论

如果碗的个数 m >= n 那么碗的个数就是充足的，那么这就是一个普通的哲学家进餐问题，一个解决普通哲学家问题的方法是，安排一个临界资源  = n - 1 作为门槛，不能让超过 n - 1 个哲学家同时拿到筷子，这样一定会有一个哲学家不会拿到筷子，那么一定会有哲学家可以进餐，这样就不会死锁了


如果碗的个数 m < n，那就将碗作为拿到筷子的门槛，这样一定有哲学家无法拿到筷子，因此也就一定有哲学家可以拿到全部的筷子吃饭，这样就解决了死锁问题了

所以合并一下，其实可以让 k = min (n - 1, m) 作为拿筷子的门槛即可
