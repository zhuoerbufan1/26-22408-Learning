## 硬盘的物理格式化到操作系统初始化过程

**物理格式化**

（1）扇区划分，划分物理扇区和磁道
（2）一般由厂家完成

**硬盘分区**

（1）将硬盘进行划分（C 盘，D 盘）
（2）每个分区创建引导扇区和分区表，便于 OS 管理

**逻辑格式化**

（1）每个分区进行文件系统格式化
（2）所有和文件系统相关的初始化工作在这一步完成，比如文件系统根目录，初始化索引结点表等等

**操作系统初始化（加载过程）**

（1）电源自检，确保所有硬件设备正常并就绪

（2）执行主板ROM区中的BIOS，BIOS负责硬件初始化，中断向量初始化工作，并进一步自检

（3）通过自检之后BIOS将硬盘0号扇区（最开始512字节）的主引导记录MBR读入，此时MBR接过CPU控制权

（4）MBR包括磁盘引导程序和分区表两部分，具体来说此时就是MBR中的磁盘引导程序被执行，通过查找分区表判断操作系统在哪个分区，并将分区引导记录PBR调入内存执行，CPU控制权交给PBR

（5）具体来说就是PBR中的分区引导程序在执行，分区引导程序找到操作系统初始化程序，并将控制权交给操作系统初始化程序

（6）操作系统初始化程序负责将OS加载到内存，接着OS正式接过CPU控制权，OS启动完成

**OS启动过程中的几个程序**

（1）ROM中的引导程序：BIOS

（2）磁盘引导程序：在MBR中，负责查找分区表，调入PBR

（3）分区引导程序：在PBR中，负责找到OS初始化程序

（4）启动管理器（OS初始化程序）：负责加载OS到内存，让OS接过CPU控制权

SF是输出的符号位，表达式就是输出结果的最高位，即SF = F15

然后是第二个小问，这里OF标志位按照平时学过的知识，它的表达式应该是次高位进位和最高位进位的异或，但是这里无法用这两个异或来表示，而且题目也说了只能根据A15, B15和F15来表示，所以得思考别的表示方法

这里题干有提示，需要分成A + B和A - B两种情况，那我们就分成这两个情况分别来讨论

当A + B的时候此时又分为4种情况

A > 0, B > 0，此时可能发生溢出，溢出的情况是F15 = 1（两个正数加法变成负数），这个时候是 $\bar{A_{15}}\bar{B_{15}}F_{15}$，也就是说只有 $\bar{A_{15}}\bar{B_{15}}F_{15}$ 这样的表达式才能保证只有单单这种情况溢出位为1，即A15 = B15 = 0，但是F15 = 1的时候溢出位为1

当A > 0, B < 0，不可能溢出

当A < 0, B > 0，不可能溢出

当A < 0, B < 0，此时可能溢出，溢出的情况是F15 = 0（两个负数加法变成正数），这个时候的表达式是 $A_{15}B_{15}\bar{F_{15}}$，这个时候A15 = B15 = 1，F15 = 0

也就是说当A+B的时候OF = $\bar{A_{15}}\bar{B_{15}}F_{15} + A_{15}B_{15}\bar{F_{15}}$，当溢出的时候OF就是有效的，别的情况就是不溢出，不溢出这个表达式就是0

当A - B的时候此时也分为4种情况

A > 0, B > 0，不可能溢出

A > 0, B < 0，可能溢出，溢出的情况是F15  = 1（一个正数 - 一个负数，结果变成负数的情况），此时的情况是 $\bar{A_{15}}B_{15}F_{15}$

A < 0，B > 0，可能溢出，溢出的情况是F15 = 0（一个负数 - 正数，结果变成正数的情况），此时的情况是 $A_{15}\bar{B_{15}}\bar{F_{15}}$

A < 0, B < 0，不可能溢出

所以当A - B的时候OF = $\bar{A_{15}}B_{15}F_{15} + A_{15}\bar{B_{15}}\bar{F_{15}}$，当溢出的时候OF就是有效的了，别的情况就是不溢出，不溢出这个表达式就是0

这道题考察的更加深入，是对带符号加减法溢出判断的最本质考察
