### 五级流水线中，不同指令在各个周期分别做什么事情？

这里以MIPS的几种类型指令为例来说明他们在5级流水线中做的事情

取指阶段：不多说

译码阶段：这个阶段会进行取数操作，简单来说这个阶段就是用来准备好操作数的

执行阶段：R型，I型运算指令会在这个阶段计算出结果；而lw或者sw指令会在着阶段计算出存储器的地址；beq指令会在这个阶段进行减法，以及同时计算出转移目标地址；因此对于R型，I型这些运算指令来说，这个阶段结束就已经得到运算结果了，只是还没有写回寄存器

访存阶段：R型，I型指令这个阶段是空操作；lw指令这个阶段是访存取出操作数；这个时候对于lw指令来说就一定从主存中取出数据了；beq指令在这个阶段根据条件判断决定是否将运算结果送到PC

写回阶段：R型，I型指令这个阶段写回寄存器；lw指令也是写回寄存器；beq指令是空操作

### 文件顺序分配方式插入一个磁盘块的过程是什么？

顺序分配方式插入一个磁盘块，它需要将这个磁盘块前面的一些磁盘块，或者这个磁盘块后面的一些磁盘块后移

这个移动的过程涉及到读入内存以及覆盖的过程，所以移动一个磁盘块需要访问两次磁盘（将磁盘读入内存算一次，然后将内存的磁盘数据再写入磁盘又一次）

    	}

    }
    
}
