
# IP 转发

### 路由表的格式是什么？网络号，下一跳 IP 这些写的是网络号还是具体 IP？

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250920094355.png)
目的网络 IP 地址就写 CIDR 的网络号格式（主机号全 0 那种）

子网掩码就是正常写

下一条 IP，如果有下一条的话就写下一条的具体 IP 地址，如果没有可以空着

接口就是转发的接口地址

### CIDR 的路由聚合方法？

首先得先写出路由器根据路由算法（RIP 或者 OSPF）到达每一个网络的表项，即构造路由表

然后，只有两个表项的接口和下一条地址相同才能进行聚合

两个表项聚合成一个表项，这个表项的网络号是这两个表项网络号的公共最长前缀，然后下一条和接口是不变的
### 主机路由

主机路由在路由表表项中的目的网络 IP 地址是一个具体的 IP 地址，它的子网掩码是全 1，它如果能够匹配的话优先级是最高的，也是最为精确的

### 如何给一个路由器配置路由表项？

（1）对于普通的网络，写出它的网络号和子网掩码以及下一条 IP 和接口即可
（2）对于主机路由，写出具体的 IP，子网掩码是全 1，下一条 IP 和接口
（3）对于剩下的网络，别忘记使用默认路由（一般发往 internet 的会配置成主机路由）

此外，对于某个网络如果路由器可以通过多个接口转发到达，我们配置的表项，即下一条的 IP 和接口应该是最短路径的下一条 IP 和接口，因此对于 RIP 算法来说转发接口可以让距离向量最短，对于 OSPF 来说转发接口可以让路径的代价最小
