### 什么是CISC？什么是RISC？两者各有什么特点，分别举三条

CISC：复杂指令系统计算机
（1）指令系统庞大，指令格式和寻址方式复杂，编译时间慢
（2）指令功能复杂，每种指令都可以访存，耗费多个机器周期
（3）80%左右指令只在 20%的时间中使用到

RISC：精简指令系统计算机
（1）指令长度固定，格式少，优化了编译，减少了程序执行时间
（2）指令中只有存数/取数指令访存，其他指令都在寄存器之间执行
（3）优先选取了使用频率高的指令，避免功能复杂的指令

### 三个偏移寻址方式是什么，分别怎么计算？

**相对寻址**的偏移量是补码形式的有符号整数，是指令中的形式地址，相加时需要符号位扩展

**变址寻址**的偏移量是补码形式的有符号数，在寄存器中，指令中的形式地址是无符号数，相加的时候符号位扩不扩无所谓，反正一般偏移量在寄存器中位数更长

**基址寻址**的偏移量是补码形式的有符号整数，是指令中的形式地址，相加时需要符号位扩展

**偏移寻址相加的时候其实是按补码运算的，至于结果的 EA 一定是一个正数，所以其实不用考虑后续再转换为补码的操作**

### 基址寻址和变址寻址有哪些区别？

（1）基址寄存器中存放的是一个基地址，一旦系统设定之后用户不能改变
（2）变址寄存器中存放地址的修改量，通过变址寄存器的修改来让操作数地址发生变化
（3）基址寄存器内容由系统设定，用户不能更改，变址寄存器内容由用户设定，可以更改
（4）基址寻址一般用于动态定位，变址寻址一般用于数组和串的处理






### 段寻址的计算原理是什么

（1）指令按照正常的寻址方式得到一个暂时的有效地址 `EA'`，也就是段内偏移，这是其他寻址方式得到的有效地址
（2）段地址存放在一个默认的段寄存器 DS 中，暂时的有效地址和段地址都和机器字长一样
（3）段地址和暂时的有效地址错位相加得到一个更大的物理地址，比如 `段地址 * 16 + 段内偏移 = 物理地址` 段地址左移四位与偏移地址相加

## 存储器与 Cache
### 什么是大端存放和小端存放

大端小端存放是针对多字节数据而言的

大端存放，即多字节数据存放的时候低字节部分存放在高字节地址，最高字节数据存放在这个多字节数据的地址处

小端存放，即多字节数据存放的时候低字节部分存放在低字节地址，最低字节数据存放在这个多字节数据的地址处

### 什么是边界对齐，以 32 位字数据为例

边界对齐就是规定多字节数据的地址有着严格的规定

对于 32 位的数据，规定半字长的数据的地址必须是偶地址，单子长数据的地址必须是 4 的倍数，双字长数据的地址必须是 8 的倍数

即数据的长度是字节的多少倍，其地址就必须是几的倍数

### 什么是SRAM和DRAM，其区别是什么

SRAM：静态随机存取存储器
（1）集成度低，功耗大，成本高
（2）不需要刷新电路
（3）常用作高速缓存 Cache

DRAM：动态随机存取存储器
（1）集成度高，功耗小，成本低
（2）需要刷新电路
（3）常用作大容量主存
### DRAM的结构特点

（1）集成度高，容量大
（2）容量大导致地址引脚多，采用多路复用，行地址和列地址用同一组引脚，这样引脚就减半了
（3）行列地址用一组引脚，因此地址需要输入两次进入缓存，延长了存取时间
（4）需要动态刷新电路刷新
### DRAM为什么要刷新，简述各种刷新方式以及特点

因为 DRAM 的电容中的电荷有漏电的现象

（1）集中式刷新：集中安排一段时间刷新所有的行，有死时间的存在
（2）分布式刷新：在读写周期后面增加一个刷新周期，CPU 访存时间增加一倍，有很多多余的刷新操作
（3）异步式刷新：在最大刷新间隔内，保证每行都被刷新且只刷新一次，克服了死时间，并且没有多余的刷新操作，但是硬件结构复杂

### 集中式总线控制的常用判优方法以及各自特点

（1）链式查询模式：
通过一条判断优先级的链路逐个对所有主模块进行串行查询，通常里控制器越近的主模块优先级越高
优先级固定，查询速度慢，不灵活

（2）计数器定时查询模式：
总线控制器中设置一个计数器用作查询，计数器的值作为地址，主模块地址跟计数器的值相同的模块获得总线控制权
灵活性高，可以方便改变响应次序，硬件复杂

（3）独立请求方式：
每个主模块都可以单独向控制器请求总线控制权，总线控制器中设置判优电路来对主模块的请求进行排序，并向优先级最高的模块发送总线允许信号
硬件开销最大，响应最快

### 总线通信是什么？常见的总线通信方式？

总线通信就是在一次总线传输过程中，如果涉及两个或两个以上部件，那么部件之间就需要进行操作时间协调来保证总线传输操作的正确，这个操作协调就是通信

### 总线的异步通信和同步通信的区别是什么？

区别在于同步通信有统一的时标进行控制，而异步通信没有，并且异步通信采用部件之间应答的方式进行协调

### 半同步通信是什么？

半同步通信是异步通信和同步通信的结合，其既有同步通信那样统一的时钟控制，又像异步通信那英允许传输时间不一致；其保留了同步通信控制简单的优点，又具有异步通信的灵活

### 显示器中显存 VRAM 中存放的是什么？其大小如何计算？

VRAM 用来存放整个屏幕的字符信息，即整个屏幕的 ASCII 代码，因此其大小与屏幕的字符个数相对应，通常西文字符以 ASCII 码的形式存放在 VRAM 中，因此 VRAM 中的一个存储单元的最小宽度是一个字节

### 显存 VRAM 种的字符地址与屏幕上字符怎么对应？

VRAM 中的每个单元的地址是由屏幕上字符的行和列决定的，即 VRAM 的地址为字符所在的行号 * 一行的字符个数 + 字符所在的列号

### 显示器中字符发生器 ROM 中存放的是什么？其大小如何计算？

字符发生器的作用就是将 VRAM 中的字符编码（ASCII 码）转化成二进制信息（也就是对应点阵信息）存放到 ROM

对于字符发生器的容量，其取决于整个字符集的大小和点阵规模，一个点阵的点就表示二进制的一个位存放到发生器 ROM 中

比如一个字符集有 95 种字符，每个字符在显示屏上的点阵是 7（列）* 9（行），并且每个字符之间的间隔是一个像素点，那么一个字符占据的点阵规模就是 8（列）* 9（行）

所以这个 ROM 的大小就是 95 * （7 + 1） * 9 bit = 855 B

### 控制屏幕同步的计数器有哪些？分别有什么作用？

点计数器：电子束每扫描屏幕上的一个像素点，点计数器++

字计数器：电子束每扫描屏幕上的一个字符窗口宽度（也就是字符宽度）的像素点，字计数器++

行计数器：电子束每扫描屏幕上的一行像素点，行计数器++

排计数器：电子束每扫描屏幕上的一排字符，排计数器++

### 计数器的模是什么意思？以及各自的模分别是什么？每个计数器输出一次表示什么？

模其实就是计数器的容量大小，每个计数器不停自增，超过这个容量之后从头计数，并输出一个信号

点计数器的模：字符窗口的宽度，点计数器输出一次表示扫描了一个字符宽度的像素点

字计数器的模：一行的字符个数加上水平回扫的时间，字计数器输出一次表示扫描了一行的像素点

行计数器的模：字符窗口的高度，行计数器输出一次表示扫描了一排的字符

排计数器的模：屏幕的字符排数加上垂直回扫的时间，排计数器输出一次表示扫描了整个屏幕的字符

上面这些计数器，前面的计数器输出一次给后面的计数器，于是后面的计数器++

### 三种常见的 IO 数据传送控制方式以及各自特点

（1）程序查询方式
即在现行程序中插入一段程序来进行 IO 数据交换，交换完毕之后由继续执行现行程序
CPU 和 IO 设备串行工作，当需要传输数据的时候如果 IO 设备没有准备好，CPU 需要反复查询 IO 设备是否准备好，且不能做其他的事情，即踏步等待，CPU 效率低

（2）中断方式
需要数据传输并启动 IO 之后 CPU 不必等待 IO 设备准备好，而是继续允许现行程序，当 IO 设备准备好了之后向 CPU 发送中断请求
CPU 和 IO 设备并行工作，CPU 的效率高

（3）DMA 方式
主存和 IO 设备之间直接有一条数据通路，CPU 不参与 IO 和主存之间的信息交换
CPU 和 IO 设备的并行程序进一步提高，CPU 的效率进一步提高

### 完整的中断过程是什么？

简化版本如下（背）：

1. 中断请求
2. 中断判优
3. 中断响应
	1. 关中断
	2. 保护程序断点，PSW（程序断点和 PSW 入栈）
	3. 获得中断服务程序入口地址
4. 中断处理
	1. 保护现场（保存程序中的一些数据）
	2. 开中断
	3. 中断处理（开中断之后这个过程允许多重中断）
	4. 关中断
	5. 恢复现场
5. 中断返回
	1. 程序断点和 PSW 出栈
	2. 开中断

> [!NOTE]
> 一次完整的中断过程分为5个阶段：
> 
> **（1）中断请求**
> 
> IO设备完成操作之后就向CPU发送中断请求，IO接口中有一个中断请求触发器INTR，INTR = 0表示没有请求，INTR = 1表示有请求
> 
> 同时CPU还可以决定是否响应这个请求，IO接口中还有一个中断屏蔽触发器MASK，MASK = 1表示这个IO的中断请求被屏蔽，CPU不理他，MASK = 0表示CPU对这个中断表示响应
> 
> **（2）中断判优**
> 
> 多个中断源同时请求的时候CPU需要对这些中断源进行判优排队，排队主要有串行排队和并行排队两种方式，可以由硬件也可以由软件实现
> 
> **（3）中断响应**
> 
> 中断响应就是CPU受到中断源发出的请求之后开始有所动作，当然CPU自已也可以决定不采取响应，CPU有一个中断允许触发器EINT，EINT = 0表示禁止中断，无论IO怎么法请求CPU都没有动作，EINT = 1表示允许中断；CPU在每条指令执行完了之后都会查询是否有中断请求
> 
> 在中断响应中CPU主要执行三个操作，这三个操作是由硬件自动执行的，就好像有默认的指令一样，所以称为隐指令：
> 
> **i 关中断**
> 
> 即将EINT设置为0，表示CPU正在处理中断，以免别的中断过来有冲突
> 
> **ii 保护程序断点，PSW**
> 
> **iii 获得中断服务程序地址**
> 
> 获得的方法主要有两种，软件查询法和硬件向量法
> 
> **（4）中断服务 - 执行中断服务程序**
> 
> CPU在执行完响应操作得到中断服务地址之后就开始执行中断服务程序，中断服务程序要完成三个工作：
> 
> **i 保护现场**  
> 保护现场主要是保存CPU正在运行的程序的位置以及程序中的一些内容，其有两个方面：
> 
> 保存断点和程序状态字(PSW)，这一步通常在CPU响应中断的时候由隐指令完成，因此保护现场的一些操作主要跟程序内部的内容有关
> 
> 保存寄存器的内容
> 
> **ii 开中断**  
> 这一步是为了在处理的时候允许多重中断
> 
> **iii 中断处理**  
> 这一步就是中断要做的主要工作了，对于IO中断来说就是完成IO与主机之间的数据交换
> 
> **iv 关中断**  
> 因为下一步需要恢复现场，不能被打断，所以这里关中断，不允许别的嵌套别的中断过程
> 
> **v 恢复现场**  
> 恢复现场是保护现场的逆操作，包括恢复寄存器内容和恢复断点和程序状态字
> 
> **（5）中断返回**  
> 即现行程序端点和 PSW 出栈
> 
> 中断返回由中断返回指令执行，通常在中断服务程序的最后一个指令，中断返回就是中断响应的逆操作，将中断断点和PSW出栈以及开中断，表示CPU这时处理完成了中断操作，可以响应别的中断源发出的中断请求了
> 
> 中断返回其实也应该看作中断服务程序中的一部分

### 多周期数据通路分类？以及各自最主要的特点是什么？（给图能辨认）

==（1）分散互联结构==

1. 没有总线
2. 有一个 MDR，但是只有从存储器读数据的时候才会使用
3. ALU 的输入端有两个暂存器 A 和 B，有结果暂存器 ALUOut

==（2）单周期结构==

1. 一根总线，非常好辨认
2. 存储器有 MDR 和 MAR，并且所有数据（指令和操作数）的读取都必须经过这两个暂存器与存储器交互
3. ALU 有两个暂存器 A 和 B，没有结果暂存器 ALUOut

> [!NOTE]
> 单总线与分散互联的结构相比其硬件结构更加规整，但是由于存在总线竞争，因此指令的一些阶段需要的时钟周期更多

==（3）双总线结构==

1. 两根总线和一个总线桥 G
2. 存储器有 MDR 和 MAR，并且所有数据（指令和操作数）的读取都必须经过这两个暂存器与存储器交互
3. ALU 的输入端由两根总线代替，但是需要一个结果暂存器 A

> [!NOTE]
> 双总线与单总线相比增加了一条总线，显然就减少了总线竞争，指令阶段所需的时钟周期就少一些，但是会带来硬件的复杂度上升
> 


### 请分别写出 5 大基本 MIPS指令以及各自的含义？

取数指令：`lw Rt, Imm16(Rs)`，扩展后的立即数 `SigExt(Imm16)` 和寄存器 `Rs` 相加算出存储器地址，然后将存储器中的内容取出放到 `Rt` 寄存器中

存数指令：`sw Rt, Imm16(Rs)`，扩展后的立即数 `SigExt(Imm16)` 和寄存器 `Rs` 相加算出存储器地址，然后将 `Rt` 寄存器中的内容放入存储器中

运算指令：`op Rd, Rs, Rt`，这条指令完成 `(Rs) op (Rt)` 并将结果放入到 `Rd ` 中

有条件跳转指令：`beq Rs, Rt, Addr16`，有条件跳转指令，当 `(Rs) == Rt` 的时候跳转到 `(PC) + SigExt(Addr16) * 4` 的位置处

无条件跳转指令：`j Addr26`，无条件跳转指令，直接跳转到 `PC[31 - 28] || (Addr26) * 4` 的位置处

### 分别写出 5 类 MIPS 指令的分散互联 CPU结构的执行流程 （考的可能性不大，因为很多部件在执行过程中没有用到）

> [!NOTE]
> 分散互联结构比较简单，指令的执行大致分为 5 个时钟周期
> （1）取指周期，将指令取出放入 IR 中，这个周期所有指令统一
> （2）读寄存器以及指令译码，主要是将操作数放入到暂存器 A，B 中
> （3）指令执行，一般是操作数运算过程，算出地址
> （4）访问一次寄存器或存储器，将结果存储起来
> （5）最后一个周期只有 lw 取数指令有，将 MDR 中的数据放入寄存器 Rt 中
> 
> 分散互联结构没有 MAR，并且 MDR 只有从存储器中取操作数的时候才会使用

#### 取数指令： `lw Rt, Imm16(Rs)`

```cpp
(1) 取值周期：

M[PC] -> IR
(PC) + 1 -> PC

(2) 读寄存器以及指令译码：

(Rs) -> A
(Rt) -> B

(3) 执行指令，一般是进行运算得到相关地址:

(A) + SigExt(Imm16) -> ALUOut

(4) 访问一次寄存器或者存储器，存放结果:

M[ALUOut] -> MDR

(5) 最后一个周期，将MDR数据放入Rt中：

(MDR) -> Rt
```

#### 存数指令：`sw Rt, Imm16(Rs)`

```cpp
(1) 取值周期：

M[PC] -> IR
(PC) + 1 -> PC

(2) 读寄存器以及指令译码：

(Rs) -> A
(Rt) -> B

(3) 执行周期，算出地址：

(A) + SigExt(Imm16) -> ALUOut

(4) 访问一次寄存器或者存储器，存放结果:

(B) -> M[ALUOut]
```

#### 运算指令： `op Rd, Rs, Rt`

```cpp
(1) 取值周期：

M[PC] -> IR
(PC) + 1 -> PC

(2) 读寄存器以及指令译码：

(Rs) -> A
(Rt) -> B

(3)执行周期，算出结果：

(A) op (B) -> ALUOut

(4) 访问一次寄存器或者存储器，存放结果:

（ALUOut) -> Rd
```

#### 有条件跳转指令：`beq Rs, Rt, Addr16`

```cpp
(1) 取值周期：

M[PC] -> IR
(PC) + 1 -> PC

(2) 指令执行以及译码阶段：

(Rs) -> A
(Rt) -> B
(PC) + SigExt(Addr16) << 4 -> ALUOut（这里反正ALU也是空闲的，不如直接算出来跳转地址）

(3) 指令执行阶段，直接结束了

if (A) == (B) 
	then (ALUOut) -> PC
	
```
#### 无条件跳转指令： `j Addr26`

```cpp
(1) 取值周期：

M[PC] -> IR
(PC) + 1 -> PC

(2) 指令执行以及译码阶段：

(Rs) -> A
(Rt) -> B
(PC) + SigExt(Addr16) << 4 -> ALUOut

(3) 指令执行阶段，直接结束了：

(Addr26 << 2) || PC[31 - 28] -> PC
```

### 分散互联结构 CPU 和单总线 CPU 双总线 CPU 的数据通路结构有什么不同？

（1）分散互联结构存储器没有 MAR，且 MDR 只有从存储器取数据的时候才使用，单总线和双总线都有 MAR 和 MDR，并且无论是读取地址还是读取数据或是指令都必须通过 MAR 和 MDR 来于存储器交互
（2）分散互联结构的 ALU 有两个输入暂存器且有一个 ALUOut，单总线结构只有两个输入暂存器，没有 ALUOut，双总线结构没有输入暂存器，但是有一个结果暂存器 A


### 什么是流水 CPU？

通过重叠执行多条指令来提高硬件利用率，理想情况下每经过一个时钟周期就完成一条指令的执行
### 流水线冒险分为哪几类？

结构冒险：部件竞争，通过部件冗余来解决

数据冒险：程序的执行需要数据相关性，指令之间执行有因果关系；通过增加气泡，改善编程实现

控制冒险：主要是分支执行指令，导致之前的执行过程无效

### 影响流水加速比的因素？

流水加速比就是流水线执行速度比上非流水线速度

最大流水加速比就是流水线段数，影响流水加速比的主要因素就是流水线段数

微操作：计算机中的最基本操作

微命令：微操作所需的控制命令

微指令：多个微操作组成微指令

微程序：多个微指令组成一串微程序

组合逻辑设计

微程序设计

混合设计
### 简述组合逻辑设计方法和微程序设计方法，及其特点？

组合逻辑：
控制单元是一个组合逻辑网络，产生所需要的全部控制信号
（1）设计思想简单，但是设计过程繁琐，修改困难
（2）产生控制信号快
（3）在后来的 RISC 计算机中普遍使用

微程序设计：
由微程序解释执行机器指令，产生指令执行所需的全部控制信号
（1）设计复杂，硬件结构简单
（2）控制信号产生速度慢
（3）在 CISC 计算机中普遍使用

### 控制器的控制方式有哪些？

所谓控制方式，其实就是控制不同指令的衔接执行过程

同步控制，异步控制，联合控制

### 微指令包含哪两个字段？各有什么作用？

微操作控制字段：产生全部微操作的控制信号

顺序控制字段：指出下一条微指令的地址


### 微操作控制字段的设计方法有哪些？各有什么特点？

（1）直接编码方式：一个位表示一个微命令，这样会导致微指令很长
（2）字段直接编码方式：一个字段表示一个微命令，互斥的微命令放在一个字段中，不同字段的微命令相容，这样压缩了微指令的长度
（3）字段间接编码方式：不同字段合起来决定一个微命令，这样微指令长度进一步压缩
（4）混合编码方式：当字段长度减少到 1 位的时候就变成了直接编码方式了，这种方式兼顾了灵活性和执行速度

### 顺序控制字段的设计方法有哪些？各有什么特点？

（1）直接表示方式：微指令的顺序控制字段直接给出后序地址

（2）增量方式：就是将微指令控制器中的 CMAR 当作 PC 一样让其具有自增的功能，但是顺序微指令和转移微指令的格式不统一，转移灵活性差

（3）增量与下址字段相结合：指令格式统一，但是只能实现两路转移

（4）断定方式：可以实现微程序的多路分支转移
