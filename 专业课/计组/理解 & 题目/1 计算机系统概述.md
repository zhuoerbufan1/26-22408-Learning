### 冯诺依曼机的基本工作方式是什么？

控制流驱动方式，即按照程序顺序执行指令，一条条按照控制流来进行，具体来说，就是根据 PC 指向的位置顺序执行指令
### 冯诺依曼的五个工作特点是什么？


（1）**存储程序工作方式，即程序存储在存储器中**，计算机不断从存储器取出指令和数据执行
（2）**五大部件**：运算器，存储器，控制器，输入输出设备
（3）**按地址访问**，指令和程序存储在存储器中，按地址访问
（4）采用**二进制 0，1 来表示数据**
（5）**指令由操作码和地址码**组成

### 地址译码电路位置在何处？MAR, MDR, IR, PC 这些在 CPU 中嘛？


![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250524124542.png)

一般会将运算其和控制器集成在一起，这个统称为 CPU

CPU 中的核心是运算单元 ALU 和控制单元 CU，当然指令地址寄存器 PC 和指令寄存器 IR 也在 CPU 中，MAR 和 MDR 逻辑上属于主存，但是一般物理上会封装在 CPU 中；同时 CPU 中还有一个寄存器组

地址译码电路是为了根据地址信号发出选通信号去选择对应的存储单元，所以地址译码器应该在主存中（记住即可，比如之前做存储器设计的题目，就还得画出地址译码器）


### 实际程序在计算机上运行可以全面反应计算机的性能嘛？为什么？

因为实际程序的运行会受到多种因素的干扰，比如 OS，硬件等等；而且很有可能的是不同的计算机适用于不同的应用程序（比如专门对某种程序进行优化），这不能说明某个实际程序的运行就能全面反应计算机的性能

### CPU 内部寄存器的可见性

MAR, MDR, IR，这三个寄存器对所有人不可见

PC 对汇编程序员可见，因为汇编程序员可以使用 jmp 指令来修改 PC 的值

状态寄存器 PSW 汇编程序员也是可见的，这些可以影响条件跳转指令，一般在汇编中用于条件转移，比如 ZF, OF 等等状态寄存器，当条件满足的时候就会对这些寄存器赋值

通用寄存器对汇编程序员是可见的，完全可以通过指令来操作这些寄存器

### 程序执行速度的三个因素是什么？

一般而言，一个程序在计算机上的执行速度取决于三个因素：

计算机主频，CPI, 指令条数；计算机主频决定一个时钟周期的时间，CPI 决定一个指令所包含的时钟周期个数，指令条数和 CPI 共同决定程序所包含的总的时钟周期个数

### 时钟周期改变，CPI 会改变嘛？为什么？

CPI 是指一个指令所包含的时钟周期个数，这个与计算机的数据通路结构以及完成指令所需的部件操作（指令的本身功能）是强相关的

一般而言，时钟周期是 CPU 外部时钟源和时钟电路的结构，时钟周期改变， CPU 的运算部分的数据通路结构不一定改变（大多数不变），所以每条指令的指令周期不变，每个指令周期 CPU 执行的基本操作也是不变的，所以每个指令周期的时钟周期个数也是不变的，所以 CPI 一般就是不变的，CPI 也就与时钟周期无关；

只是 CPU 的每个基本操作时间会改变，所以指令的每个指令周期速度会改变

### 兼容是指什么？

兼容是指同一个系列不同型号计算机之间的软件和硬件的通用性（不是软件与硬件的通用性）

# 理解与总结

### 各种字长关系

机器字长：机器字长是 CPU 可以一次处理的二进制位数，通常是 CPU 内部数据通路的宽度，也可以说是 ALU 的操作位数，通常说的 8 位计算机的 8 位，就是机器字长，是指 CPU 内部数据通路的位数，也就是 CPU 可以一次处理的数据位数

字长：字长一般指的就是机器字长

字：字是某个系列的机器的一个计量单位，跟比特类似，只不过字在不同系列机器上的宽度不一样，字不一定等于机器字长，字只是一个信息长度计量单位

编址单位：指按字编址或者按字节编址，就是一个存储单元的宽度，存储单元的内部存储元的地址是一样的

指令字长：就是指令的总长度（可变），半字长指令，双字长指令，单字长指令，说的一般就是机器字长的一半，两倍，相等的指令长度

存储字长：就是一个存储单元中二进制的位数，存储字长取决于编址方式，按字节编址存储字长就是 8 位，按字编址，或者按双字编址，或者按半字编址，存储字长就是一个字长度，双字长度，半字长度；这里的字一般指机器字长；**存储字长不一定和 MDR 相等**，**MDR 一定和数据总线宽度相等**；现代计算机为了保证传输和谐，一般会让 MDR = 机器字长，但是这个也不一定

存储字：存储字单单指一个存储单元中的一串二进制的数，存储字长是这串二进制数的位数，其不是字，字是信息衡量单位，存储字长一般是字的整数倍，或者一半















### 13 计算机的机器字长与寄存器的位数关系

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250525170955.png)

机器字长就是计算机 CPU 可以一次运算处理的最多位数

I:
ALU，显然一样

II:
指令寄存器，这个是存储指令的，与指令字长一样，跟机器字长没有毛线关系

III:
通用寄存器，通用寄存器也会参与 CPU 处理数据过程中，所以通用寄存器也与机器字长一样

IV：
浮点寄存器是计算机中处理浮点运算的寄存器，其与浮点数的运算有关（浮点数的格式与整数时完全不一样的），需要专门一套寄存器来处理浮点数运算；因此这里浮点数寄存器的位数一般与浮点数的标准有关；而与一般说的处理整数的机器字长无关
