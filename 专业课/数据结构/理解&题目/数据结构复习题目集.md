### 循环队列的队首指针和队尾指针分别指向什么位置？

front 指针指向第一个元素
rear 指针指向队尾元素的下一个元素

### 循环队列的入队列和出队列的操作是什么？

入队列：`q[rear] = x, rear = (rear + 1) % MAXSize`

出队列：`x = q[front], front = (front + 1) % MAXSize`

### 循环队列的判断空和判断满的操作是什么？

队空：`front = rear
队满：`(rear + 1) % MAXSize = front`
### 循环队列求元素个数的操作是什么？

`(rear - front  + MAXSize) % MAXSize`

### 如何构造一个字符集的前缀编码？

随便一个二叉树，字符集的字母作为二叉树的叶结点，这个二叉树的左分支编码为 0，右分支编码为 1 即可
### 一个给定的字符串，如何得到这个字符串的最短前缀编码？

字符串中的字符作为叶结点，字符出现的个数作为叶结点的权值

将这些叶结点构造成一个二叉树，左分支编码 0，右分支编码 1，得到各个字符的前缀编码

这种编码方式整个字符串的长度就是这个树的带权路径长度

以 Huffman 树的构造方式构造这个二叉树，这样带权路径长度就是最短的了，因此字符串的编码长度就是最短的了

```cpp
st[N];
void dfs(int u){
	st[u] = true;
	for(auto p = head[u]; p; p = p->next){
		if(!st[u]) dfs(p->id);
	}
}
```
