### 2 $O(f(n))$ 与 $T(n)$ 的含义

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250414163101.png)

无论是 $O(f(n))$ 还是 $T(n)$ 这里面的 n 都指的是问题规模，$T(n)$ 表示算法的所有语句执行频度之和是问题规模的函数，也可以看作执行时间

$O(f(n))$ 表示 $T(n) \le Cf(n)$，$O(f(n))$ 是 $T(n)$ 的量级，称为时间复杂度

### 3 复杂度计算中等比数列求和的应用

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250414165906.png)

这道题目中

i = 1, 执行 1 次
i = 2, 执行 2 次
i = 4，执行 4 次
....
i = n，执行 n 次
所以执行次数就是 1 + 2 + 4 +..... n，这是一个等比数列，公比是 2，项数根据 i 扩大的次数算出，i 每次扩大两倍，当 i 扩大到 n 的时候一共扩大了 $\log n$ 次，所以根据等比数列的计算公式：

$$
S_{n} = \frac{a_{1}(1 - q^n)}{1-q} = \frac{1(1 - 2^{\log n})}{1 - 2}
$$
从而得到复杂度就是 n 级别
### 4 利用求和符号来处理这种复杂度问题

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250609164351.png)

规定一个统一的标准，求和符号的下面写循环遍历的取值，用循环的次数来表示，求和符号的上面写次数的范围

求和符号的内部是固定外部求和符号情况下的处理

这道题目就可以写成：

$$
\sum_{i = 1,3,5\dots 2p + 1}^{2p + 1 \leq n} \sum_{j = 1,2,4\dots 2^q}^{2^q \leq n}\sum_{k = 1,2,3\dots l}^{l \leq j} 1 
$$

上式中，p 是最外层循环的次数，2 p + 1 <= n 规定了外层循环与 n 的关系

第二个求和是在固定外层的 i 情况下 j 的求和，q 是固定一个 i 情况下内层循环的执行次数，2^q < n 规定了内层循环的执行次数范围

第三个求和实在固定第二个 j 的情况下最内层的求和情况，l 是最内层循环的执行次数，l <= j 规定了最内层循环在固定 j 的情况下的范围

最后一个 1 是在固定最内层循环下关键语句的执行次数，这里就是 1 次

从内到外一层层拆开：

$$
\sum_{i = 1,3,5\dots 2p + 1}^{2p + 1 \leq n} \sum_{j = 1,2,4\dots 2^q}^{2^q \leq n}(1 + 1 + 1 +\dots 1) = \sum_{i = 1,3,5\dots 2p + 1}^{2p + 1 \leq n} \sum_{j = 1,2,4\dots 2^q}^{2^q \leq n}j
$$

### 5 利用递归树来处理递归问题的复杂度

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250611151949.png)

题目中的递推关系可以看成是一个递归函数，这个递归函数每次往下递归成 3 个子问题，每个子问题的规模是当前问题规模的 1/4，n^2 表示当前问题规模划分成子问题以及子问题合并成当前问题的复杂度，**或者可以直接看成当前问题规模为 n 的函数自己的复杂度**

所以可以画出这个递归函数的递归树，一个结点表示问题规模为 m的函数，每个结点往下分为 3 个子结点即子函数，每个子结点的规模都是 m/4，并且每个子函数自己的复杂度就是 m^2，比如下图的第二层，是由问题规模为 n 的函数划分而来，这三个子函数自己的复杂度就是 (n/4)^2，化成了 3 个，所以这一层的总的复杂度就是 3 * (n/4)^2：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250611152558.png)
这个递归过程的总的复杂度当然就是每一层的所有子函数的复杂度加起来了

于是总复杂度就是：

$$
n^2 + \left( \frac{3}{16} \right)n^2 + \left( \frac{3}{16} \right)^2 n^2 + \dots +\left( \frac{3}{16} \right)^k n^2
$$

这里的 k 是递归树的高度，问题规模划分到 1 的时候终止，所以高度就是 $\log_{4}n$

这个等比数列求和：

$$
n^2 * \frac{1\left( 1 - \left( \frac{3}{16} \right)^{\log_{4}n} \right)}{1 - \frac{3}{16}}
$$

当 n 足够大的时候这个就逼近 16/15 n^2 了

所以总的复杂度就是 n^2

## 大题

### 1 主定理

**主定理：**

如果一个递归函数的时间复杂度写出来是下面的形式
$$
T(n) = a*T(\frac{n}{b}) + O(n^d)
$$
$T(n)$表示当前递归方法处理问题规模为n的时间复杂度

$T(\frac{n}{b})$表示子递归方法的时间复杂度

$O(n^d)$表示当前递归方法执行除了子递归之外的程序的时间复杂度

a表示调用子递归问题的数量

b表示子递归问题规模缩小的比例

d是子递归之外的代码的时间复杂度参数

我们有如下结论：

![image-20240916171612814](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/image-20240916171612814.png)

上述中的$\log n$表示以2为底

比如二分法中的递推关系为：
$$
T(n) = T(\frac{n}{2}) + O(1)
$$
a = 1，b = 2, d = 0，于是有：
$$
0 = log_21 (d = \log_ba)
$$
所以可以直接得到二分法的时间复杂度为：
$$
O(\log n)
$$
再看这题中：

![image-20240916172020203](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/image-20240916172020203.png)

a = 2, b = 2, d = 1，刚好有$d = \log_2 2$，所以可以直接得到复杂度：
$$
O(n \log n)
$$
