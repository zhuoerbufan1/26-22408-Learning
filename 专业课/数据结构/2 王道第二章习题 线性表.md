### 3 二分查找模板

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250415173226.png)

找到不小于（>=）当前元素 x 的最小下标，使用二分

```cpp
int bsearch(int l, int r, int x){
	while(l < r){
		int mid = l + r >> 1;
		if(a[mid] >= x) r = mid;
		else l = mid + 1;
	}
	return l;
}

// 在顺序表的index处插入值x
void insert(int x, int index){
	......
}

void fun(int x){
	int index = bsearch(1, n, x);//二分法找到这个这个元素或者大于x的最小元素
	if(a[index] == x) swap(a[index], a[index + 1]);
	else insert(x, index);
}
```


这里我们的二分操作是找到比当前元素大的最小元素，因此是区间右侧性质的左端点，所以用的二分模板是下面：

```cpp
bool check(int mid){
    ......
}

void bsearch(int l, int r, int t){
    
    while(l < r){
    	int mid = l + r >> 1;
        //找到区间中右侧性质的右端点，check函数必须满足右侧性质，本题中就是>t
        if(check(mid)) r = mid;
    	else l = mid + 1;//mid不满足右侧性质，那么显然mid指向的是左边性质区域，我们应该向右缩小区域
    }
    return l;
}
```

如果我们要找的是左侧性质的右端点，则使用的模板是下面，并且 check () 函数需要满足左边区间的性质：
```cpp
bool check(){
}

void bsearch(int l, int r, int t){
	while(l < r){
		int mid = l + r + 1 >> 1;
		//找到左边区间的右端点，这里的check满足的是左边区间的性质并且改变的是左端点，显然此时的mid满足左边区间的形式，那么左端点就应该设置为mid，表示我们寻找的左侧性质的右端点在右边[mid, r]部分
		if(check(mid)) l = mid;
		else r = mid - 1//不满足左侧性质，那么此时mid肯定指向右侧性质，所以我们应该将区域往左缩小
	}
}
```

这样记忆：
（1）找左边区间右端点则 check 函数必须满足左侧性质；找右侧区间左端点，check 函数必须满足右侧性质，这里的满足性质指的是 check 函数中 mid 满足某侧性质后返回 ture，满足左侧性质就是 mid 满足左侧性质后返回 ture
（2）check 函数满足的是哪边的性质，那么满足 check 函数更改的就是哪边的端点；这时根据代码意思写出 if 和 else 两个语句即可
（3）mid = l + r + 1 >> 1 和某个区间 - 1 是绑定的，mid = l + r >> 1 与+1 是绑定的，先写出 check 函数，然后判断区域应该往哪里缩小，写出 else 后面的语句，然后再写 mid 应该如何改变

### 5  顺序表的循环移位规律

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250416160706.png)

这里有一个非常有趣的规律，假设线性表的长度是 len，移动的位置是 p
**（1）如果 len 不是 p 的倍数，即 len 不能整除 p，那么我们直接从第一个开始移动即可**

比如 len = 8, p = 3，a[0]移动到 a[3]，然后将 a[3]移动到 a[6]，然后将 a[6]移动到 a[1]，然后 a[1]移动到 a[4]，a[4]移动到 a[7]，a[7]移动到 a[2]，a[2]移动到 a[5]，a[5]移动到 a[0]，当循环到 a[0]的时候刚好全部移动完毕，这个循环移动的组的元素覆盖了所有元素

**（2）如果 len 是 p 的倍数，即 p 可以整除 len，假设 r = len / p，此时数组被分成了 p 组，每组 r 个元素作为一个循环移动单位**

比如 len = 8, p = 4, r = 2，那么就有 4 个循环移动组，我们还是从 a[0]开始
a[0]移动到 a[4]，a[4]又移动到 a[0]，这两个元素作为一个循环移动组，移动完毕之后我们再从 a[1]开始
a[1]移动到 a[5], a[5]又移动到 a[1]，a[1], a[5]作为一个循环移动组
同理 a[2]和 a[6]作为一个循环移动组
a[3]和 a[7]作为一个循环移动组

当 len = 8, p = 2, r = 4 的时候就有两个循环移动组，每组 4 个元素，我们从 a[0]开始移动，p 用来往后遍历循环移动组的首个元素，r 用来控制移动这个组中的元素即可

这样时间复杂度就是 O (n)，空间复杂度就是 O (1)，非常巧妙的思想

### 7 摩尔投票法，用于快速找到个数大于数组总数一半的数

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250416164709.png)

将 x 初始设置为 nums[0]并同时使用一个变量 count = 1

然后从前往后遍历，如果遇到 nums[i] == x，则 count ++；如果遇到 nums[i] != x，则 count -- ；
当遍历到 nums[i]的时候 count = 0，此时将 x 设置为 nums[i + 1]，count 初始化为 1，继续往后遍历

这样遍历完一趟之后我们可以得到一个值 x，当然只有在数组有主元素的情况下值 x 才是主元素，否则这个 x 就是一个瞎找的值

所以我们需要再遍历一趟数组验证一下 x，看看其出现的次数是否大于 n/2 就行了

> [!NOTE]
> 这种做法的原理在于如果原数组有主元素，那么根据摩尔投票法一定可以将这个主元素找出来，因此逆否命题就是如果根据摩尔投票法找出的元素不是主元素，那么原数组就没有主元素；所以我们验证一下根据摩尔投票法找到的元素 x，如果 x 不是主元素，那么根据逆否命题当然原数组就没有主元素；如果 x 是主元素，由于一个数组中主元素就只有一个，此时 x 就是就是结果了

时间复杂度 O (n)，空间复杂度 O (1)

### 8 三指针做法 - 排除的思想

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250416172145.png)

三个指针 i, j, k 分别指向三个集合的第一个元素，假设 S 1[i]是三个指针指向的元素中最小的元素，则向后移动 i，指向 S 1[i + 1]，然后更新 dist

这种做法的思想是排除的思想，即排除 S 1 [i]与 S 2[j], S 3[k]后面所有元素的组合，因为此时 S 1[i], S 2[j], S 3[k]在数轴上的位置是：

S 1[i]            S 2[j]              S 3[k]

如果 j, k 继续向后移动，那么三者之间的距离一定是在变大，所以此刻含有 S 1[i]的三元组一定是所有含有 S 1[i]的三元组中距离最小的；所以后续我们应该排除掉其他含有 S 1 [i]的三元组，也就是向后移动指针 i 了

当某个数组遍历完了之后，此时 dist 就是结果了

双向链表就是除了第一个结点和最后一个结点之外中间的结点既指向自己的前驱，也指向自己的后继，最后一个结点指向自己的前驱，没有后继

### 13 对指针 p, p->next, p->prior->next 的理解

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250417163007.png)

p, p->next, p ->prior->next 其实都是指针，指针也是变量，是存储地址的变量，给这些指针赋值（地址）就是让这些指针指向这个地方

->就是访问指针所指向的元素内部内容的意思，p->next 就是访问 p 指向的元素中的 next 指针，就是访问 p 指向的元素中的 next 指针域的值，p ->val 就是访问 p 指向的元素中的数值

p->prior->next 就是先访问 p 所指向的元素中的 prior 指针，即访问 p 指向的元素的 prior 指针域的值，然后再对这个指针值使用一次->，表示访问 prior 这个指针指向的元素的 next 指针域的值，即访问 prior 指针所指向的元素的next 指针

p->中 p 就是指针，就是指针的地址值，->就是访问这个指针指向元素的内容

**一般做题的时候最好还是画图来做，不用想的这么细致，画图的时候 p 表示某个元素的地址，p->next 就是 p 指向的下一个元素的地址，同时也是 p 指向元素的指针域的值，p->next->next 就是 p 指向的下一个元素的下一个元素的地址，同时表示 p 指向元素的下一个元素的指针域的值，p->next->next = q 就是让 p 指向的下一个元素的下一个元素变成 q，也就是让 p 指向的下一个元素的 next 指针域指向 q**

### 15 O (1) 的空间复杂度翻转链表

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250418160331.png)

一个指针是 pre，一个指针是 cur，一个指针是 temp

temp 和 pre 指向 cur 左边一个结点，此时的状态是，temp 和 pre 指向的结点的 next 已经指向了自己的左边，cur 指向的结点的 next 指向右边

先让 pre 指向 cur，然后 cur 向前移动，然后 pre 的 next 指针指向 temp，然后再让 temp 指向 pre
pre = cur, cur = cur->next, pre->next = temp, temp = pre

这样遍历一趟就能反转了

### 16 快慢指针链表判断环，以及找到环的起点

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250418163458.png)

一个 fast 指针和 slow 指针同时指向链表的起点

fast 指针每次走两步，slow 指针每次走一步，当 fast 和 slow 相遇的时候，说明这个链表一定存在环，并且相遇的地方是环内；如果 fast 指针指向 NULL，那就说明链表无环

当两者第一次相遇之后说明链表有环，此时将 fast 指针再次移动到整个链表的起点，让其每次走一步，slow 指针同样每次走一步，当两者再次相遇的时候就指向环的起点了

第一次相遇的时候慢指针一定还没有将链表遍历完（当满指针进入环中的时候快指针一定在环的某个位置处，其距离慢指针一定小于环的长度，而快指针的速度又是慢指针的两倍，所以慢指针一定是在第一次走环的时候被快指针追上，这里可以用反证法证明，假如慢指针在走大于一次环的时候被追上，那么快指针走过的距离一定大于两倍的环的长度，比如在中途就将慢指针追上了）

第二次相遇的时候快指针一定没有将链表遍历完

所以总的时间复杂度就是 O (n) 的
