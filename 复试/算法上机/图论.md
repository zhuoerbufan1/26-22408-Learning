## 克鲁斯卡尔算法

```cpp
struct Edge{
	int u, v, w;
	Edge(int _u, int _v, int _w) : u(_u), v(_v), w(_w){}
}

vector<Edge> G;
```

不用建图，只用读入所有的边对边进行排序即可

需要建图，建立带边权的邻接表

```cpp
struct Edge{
	int v, w;
	Edge(int _v, int _w) : v(_v), w(_w) {}
}


vector<Edge> G[MAX_COUNT_U];
```

（1）外层循环 k 次，表示不超过 k 条边
（2）内层遍历所有边进行松弛操作，记住代码，对于边 a->b，有 `dist[b] = min(dist[b], backup[a] + b)`
（3）记住这个最核心的代码：

```cpp
memset(dist, 0x3f, sizeof(dist));
dist[1] = 0;
for(int i = 1; i <= k; i ++){
	memcpy(backup, dist, sizeof(dist));
	for(int j = 1; j <= n; j ++){
		for(int l = 0; l < G[j].size(); l ++){
			int u = j;
			int v = G[j][l].v;
			int w = G[j][l].w;
			dist[v] = min(dist[v], backup[u] + w);
		}
	}
}
```

### spfa 判断负环


[852. spfa判断负环 - AcWing题库](https://www.acwing.com/problem/content/854/)

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20260323110955.png)
![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20260323111004.png)


（1）增加一个数组 `cnt[i]`，它表示从源点到顶点 i 所经过的边的个数
（2）对于边 u -> v，当利用 `dist[u]` 来更新 `dist[v]` 的时候，如果 `dist[v]` 被更新，说明 v 应该从源点到 u 的路径再到 v，所以此时 `cnt[v] = cnt[u] + 1`
（3）在有负环的情况下，会存在某个点，从源点到这个点经过的边的个数 > n（因为负环图会始终转圈更新 `dist`）
（4）需要增加一个虚拟源点，保证整个图是可达的（只用判断负环的情况下需要增加虚拟源点，如果同时还要求到源点的距离，则不能加上虚拟源点）
