## 最大公约数

### 板子

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20260323151819.png)


[晴问算法](https://sunnywhy.com/camp/3415/model/3590?itemId=2895)

a 与 b 的最大公约数，也就是 b 与 a mod b 的最大公约数，当 a mod b == 0 的时候返回 b 就好了

比如 4 与 2 的最大公约数，它与 2 和 4 mod 2 = 0 的最大公约数是一样的，就是 2

## 最小公倍数

a 与 b 的最小公倍数就是 a * b / gcd (a, b)

## 判断互质

a 与 b 互质，则 a 与 b 的最大公约数 = 1
