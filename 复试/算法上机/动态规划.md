#### 0 基本原理

以 01 背包为例，`dp[i][j]` 表示选 `[0~i]` 号物品，并且在背包容量为不超过 j 的情况下得到的最大值，最后的结果就是 `dp[n-1][V]`

（1）转移路径是指在 dp 数组中，到达 `dp[n-1][V]` 的路径，比如状态转移方程是 `dp[i][j] = max(dp[i-1][j], dp[i-1][j-w[i]] + c[i])`，如果 `dp[i-1][j] < dp[i-1][j-w[i]] + c[i]`，那么就说明 `dp[i][j]` 由 `dp[i-1][j-w[i]]` 转移而来，两者之间有一条从 `dp[i-1][j-w[i]]` 指向 `dp[i][j]` 的边
（2）每条到达 `dp[n-1][V]` 的路径都对应了一个最佳选择方案
（3）所有指向 `dp[i][j]` 的路径数就是最佳选择方案数目


以 01 背包为例，`dp[i][j]` 表示选 `[0~i]` 号物品，并且在背包容量为不超过 j 的情况下得到的最大值，最后的结果就是 `dp[n-1][V]`

状态转移方程是 `dp[i][j] = max(dp[i-1][j], dp[i-1][j-w[i]] + c[i])`

因此在求出最终结果 `dp[n-1][V]` 的时候其实有一条转移路径

这里每条路径实际上都表示了一个选择物品的最佳方案

比如绿色路径中从 `dp[0][0]` 转移到 ` dp[1][5]`，这就是因为 `dp[0][5] < dp[0][5-w[1]] + c[1]` 导致的，因此这里需要选择物品 1

同理，绿色路径上从 `dp[1][5]` 转移到 `dp[2][6]` 需要选择物品 2

绿色路径从 `dp[2][6]` 转移到 `dp[3][6]` 不用选择物品 3

从 `dp[3][6]` 转移到 `dp[4][8]` 需要选择物品 4

因此绿色路径所对应的物品选择方案就是 1 2 4，这些物品的价值加起来刚好就是 10 了

同样红色路径所对应的物品选择方案就是 0 2 3 4，这些物品的价值加起来也刚好就是 10 

如果想要求转移到最终结果的方案数，那么其实就是所有指向最终的 `dp[4][8]` 的方案数，注意可能 `dp[4][j]` 当 j < 8 的时候仍然价值是 8，但是转移到 `dp[4][j]` 的路径不能加入到总的方案数中，因为这里的 `dp[i][j]` 定义为选 `0~i` 物品，体积**不超过** j 的最大价值方案，它其实包含了 `dp[i][k]` k < j 的情况

`cnt[i][j]` 表示转移到 `dp[i][j]` 的路径条数

如果 `dp[i-1][j] > dp[i-1][j-v[i]] + w[i]` 说明 `dp[i][j]` 由 `dp[i-1][j]` 转移而来，所以 `cnt[i][j] = cnt[i-1][j]`，反之 `cnt[i][j] = cnt[i-1][j-v[i]]`；

如果 `dp[i-1][j] == dp[i-1][j-v[i]] + w[i]`，说明 `dp[i][j]` 可以由 `dp[i-1][j]` 转移而来，也可以由 `dp[i-1][j-v[i]]` 转移而来，所以 `cnt[i][j] = cnt[i-1][j-v[i]] + cnt[i-1][j]`
#### 2 背包问题求具体方法

[12. 背包问题求具体方案 - AcWing题库](https://www.acwing.com/problem/content/12/)

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20260323171142.png)

（1）假如 `dp[i][j]` 表示的是选择物品 1 ~ i，总体积不超过 j 的情况下可以获得的最大价值，那么想要知道最优方案的话得从 `dp[n-1][V]` 开始往上回溯，因为只有最终指向 `dp[n-1][V]` 的路径所对应的方案才是最优方案，但是不容易得到字典序最小的方案

（2）这里我们换一种思路：`dp[i][j]` 表示选择 `[i, n-1]` 物品，重量不超过j的情况下可以获得的价值最大值，这样从下往上指向 `dp[1][V]` 的路径所对应的方案就是最优方案

（3）这种表示方法是为了方便得到字典序最小，`dp[1][V]` 是最终结果，从这个结果开始在dp数组中往下回溯出路径方案，这里采用一个贪心的思想进行从上往下回溯

如果 `dp[i][j]` 可以由 `dp[i+1][j]` 或者由 `dp[i+1][j-w[i]]` 转移过来即 `dp[i+1][j] = dp[i+1][j-v[i]] + w[i]`，此时我们选择由 `dp[i+1][j-w[i]]` 转移过来，因为由它转移过来的路径方案中选择了物品 i，相比于不选择物品i由 `dp[i+1][j]` 转移过来的路径方案，它选择的物品i的字典序更靠前一些，这里肯定不是严谨的选择字典序最小的方案，只是用了一个类似贪心的思想，在大多数情况下都是成立的
