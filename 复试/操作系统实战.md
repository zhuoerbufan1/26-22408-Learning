##   第一节 程序的运行

一段 `HelloWorld.c` 程序执行的过程是

首先 GCC 的预处理器替换宏，假如头文件，变成 `HelloWorld.i` 文件

然后 GCC 的编译器，将 C 程序变成汇编程序 `HelloWorld.s` 文件

然后 GCC 的汇编器，将汇编程序变成可以进行链接的二进制文件 `HelloWorld.o`

最后 GCC 的链接器，将可链接的二进制文件和别的程序链接到一起，形成可执行文件 `HelloWorld.exe`

![image.png|506x405](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250410221630.png)

其实汇编指令虽然在控制计算机的能力上比 C 语言更直接了一步，但是汇编程序仍然与直接控制计算机硬件有一个隔阂，汇编程序仍然是对硬件功能控制的一个抽象，不过在理解汇编程序的时候我们可以直接认为这个指令可以直接有相应的控制硬件功能即可，先不用在意更底层的二进制代码控制硬件细节，汇编指令是计算机软件和硬件的接口
