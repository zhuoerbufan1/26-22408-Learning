### 输出输出格式

#### 常见说明符

（1）整型: %d
（2）长整型：%lld
（3）单精度浮点：%f
（4）双精度浮点：%lf
（5）字符：%c

#### 保留两位小数输出

（1）保留两位小数输出：`printf("%.2lf", float_num)`
（2）不保留小数输出：`printf("%.0lf", float_num)`

以上都是四舍五入规则

#### 按照指定格式读入

（1）指定带分隔符的日期读入：`scanf("%d-%d-%d", &year, &month, &day) //读入2026-12-24`

#### getline 函数

（1）记住使用格式
（2）使用前如果用过了 cin，需要 cin. ignore，用来剔除多余的符号
（3）读取整行数据直到遇到换行

### 优先队列

（1）less 是大顶堆，greater 是小顶堆
#### 自定义元素优先队列

`priority_queue` 中的元素 T 必须支持可比较，如果是自定义结构，需要单独写一个比较类

```cpp
#include <queue>
using namespace std;

struct Node {
    int x, y;
    // 不重载 <
};

// 自定义比较类（仿函数）
struct CompareNode {
// 这里a和b分别表示左右两个元素
 // 这里与sort中的cmp的逻辑刚好是反过来的，从小到大出队(最小堆)是 >；
 //从大到小出队(最大堆) 是 < 


    bool operator() (const Node& a, const Node& b) {
        // 返回 true 表示 a 的优先级 **低于** b（即 b 应该先出队）
        // 例如：按 x 从小到大出队（最小堆）
        return a.x > b.x;
        // 若想按 x 从大到小出队（最大堆），则写 a.x < b.x
    }
};

int main() {
    // 模板参数：元素类型, 底层容器类型, 比较类型
    priority_queue<Node, vector<Node>, CompareNode> pq;
    pq.push({1, 2});
    pq.push({3, 4});
    // 此时 top 是 {1, 2}
    return 0;
}



```
