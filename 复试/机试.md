### 文件 IO

```cpp
#include<stdio.h>
using namespace std;

int main(){
	freopen("input.txt", "r", stdin);
	freopen("output.txt", "w", stdout);
	
	int a, b;
	cin >> a >> b;
	cout << a + b;
	return 0;
}
```

（1）这里必须自己先手动创建一个 input. txt 文件，不过 output. txt 文件不用手动
（2）加上前面两行代码之后后续完全和普通的输入输出一样了

### 输出输出格式

#### 常见说明符

（1）整型: %d
（2）长整型：%lld
（3）单精度浮点：%f
（4）双精度浮点：%lf
（5）字符：%c

#### 保留两位小数输出

（1）保留两位小数输出：`printf("%.2lf", float_num)`
（2）不保留小数输出：`printf("%.0lf", float_num)`

以上都是四舍五入规则

#### 按照指定格式读入

（1）指定带分隔符的日期读入：`scanf("%d-%d-%d", &year, &month, &day) //读入2026-12-24`
