#### 关于 cin >> a 返回的东西

这些会返回输入流本身，如果放到 while 循环条件里面如果仍然有输入则会转换成 true，如果遇到了文件终止符，则会转换成 false，从而实现循环只要输入操作成功且未遇到结束信号，就继续执行循环：

```cpp
#include <iostream>
using namespace std;

int main() {
    int value;
    int sum = 0;

    cout << "请输入一些整数，输入非数字字符或EOF结束：" << endl;
    // 当成功读入一个整数时，循环继续
    while (cin >> value) {
        sum += value;
    }

    cout << "所有整数的和为: " << sum << endl;
    return 0;
}
```

##### 如何读取带有空格的字符串

（1）使用 `getline()` 函数
（2）`getline()` 函数会读取一整行的数据直到遇到换行符，并丢弃换行符，将其从缓冲区中剔除，但是 cin 会保留空格或者换行符在输入缓冲中
（3）为了避免出错，在使用了 cin 之后应该用 `cin.ignore()` 跳过输入缓冲的换行符


```cpp
#include <iostream>
#include <string>

int main() {
    int number;
    std::string text;

    std::cout << "请输入一个数字：";
    std::cin >> number;
    
    // 清除输入缓冲区中的换行符等残留内容
    std::cin.ignore(); 
    
    std::cout << "请输入一行文本：";
    std::getline(std::cin, text);
    std::cout << "数字：" << number << ", 文本：" << text << std::endl;

    return 0;
}
```

### sort 函数

#### 普通的升序排序

sort 函数是 C++中的函数

==对 vector 进行升序的操作是 :==

```cpp
vector<int> a;
sort(a.begin(), a.end());
```

上面的 a.begin () 表示指向 a 的第一个元素的指针；a.end () 是指向最后一个元素的后一个位置的指针, sort 函数的括号中对元素是左闭右开的

==对普通数组 a[]进行升序排序是：==

```cpp
int a[n];
sort(a, a + n);
```

#### 降序排序

如果想要降序操作还得加上一个 cmp 函数：

```cpp
bool cmp(int &x, int &y) {
   return x > y;
}

int main(){
	int a[n];
	
	sort(a, a + n, cmp);//此时降序排列
}
```

这里 cmp 函数的含义就是保证前后两个元素 x, y 满足 cmp 函数中为 ture 的规则

如果想要对 `vector<int>` 进行降序排列，跟普通的一样：

```c++
#include <vector>

bool compareDescending(int a, int b) {
    return a > b;
}

int main() {

    std::sort(vec.begin(), vec.end(), compareDescending);
}
```

#### 对数组之间进行排序

比如，如果想要按照数组元素个数对数组排序，并且两个数组的元素个数相等的时候数组元素按照字典序排序（字典序就是当两个数组元素个数相同的时候，前 k - 1 个元素相等，如果第 k 个元素 a[k]  < b[k]，则数组 a 排序在 b 前面）

```cpp
vector<vector<int>> result; //一堆待排序的数组

//自定义排序规则
bool cmp(const vector<int> &a, const vector<int> &b){
	//先保证个数小的在前
	if(a.size() ！= b.size()) return a.size() < b.size();
	else return a < b;//个数相等的时候保证字典序
}

sort(result.begin(), result.end(), cmp);


```

#### 使用 sort 函数来对结构体进行排序

```c
#include <iostream>
#include <algorithm>
#include <vector>
using namespace std;

// 学生结构体
struct Student {
    string name;
    int id;
    double gpa;
};

// 按GPA降序排序
bool compareByGPA(const Student& a, const Student& b) {
    return a.gpa > b.gpa; // 降序排序
}

// 按姓名升序排序
bool compareByName(const Student& a, const Student& b) {
    return a.name < b.name;
}

// 多级排序：GPA相同时按ID升序
bool multiCompare(const Student& a, const Student& b) {
    if (a.gpa != b.gpa)
        return a.gpa > b.gpa;
    return a.id < b.id;
}

int main() {
    vector<Student> students = {
        {"Alice", 101, 3.8},
        {"Bob", 102, 3.9},
        {"Charlie", 103, 3.8},
        {"David", 104, 3.95}
    };

    // 按GPA降序排序
    sort(students.begin(), students.end(), compareByGPA);
    
    cout << "按GPA降序排序:" << endl;
    for (const auto& s : students) {
        cout << s.name << " (" << s.id << "): " << s.gpa << endl;
    }

    // 多级排序
    sort(students.begin(), students.end(), multiCompare);
    
    cout << "\n多级排序(GPA降序，相同则ID升序):" << endl;
    for (const auto& s : students) {
        cout << s.name << " (" << s.id << "): " << s.gpa << endl;
    }

    return 0;
}
```
#### 关于 cmp 函数

总的来说，cmp 的写法是，对于相邻两个元素，如果满足排序之后的数组相邻元素之间的关系，则返回 true，否则返回 false


### CPP 中的循环变量回收问题

#### 普通变量的回收

| 变量类型        | 生命周期         | 回收机制       | 风险提示           |
| ----------- | ------------ | ---------- | -------------- |
| 基本类型 (int 等) | 每次迭代结束       | 栈内存立即回收    | 无风险            |
| 对象类型        | 每次迭代结束       | 析构函数调用+栈回收 | 注意析构函数副作用      |
| 原始指针        | 每次迭代结束（指针本身） | 栈回收（指针变量）  | **堆内存泄漏**（高风险） |
| 智能指针        | 每次迭代结束       | 自动释放管理的内存  | 无风险            |
基本变量和对象类型是指在循环中定义的 int，double, string 之类的，一次循环结束的时候其会自动回收，下一次循环或者跳出循环这个变量就不能再使用了，比如：

```cpp
for (int i = 0; i < 5; ++i) {
    int temp = i * 10;      // 基本类型
    std::string s = "test"; // 对象类型
    
    // 每次迭代结束时：
    // 1. s的析构函数会被调用（释放字符串内存）
    // 2. temp和s的栈内存会被回收
}
```

指针类型的话，如果是普通的指针，其与基本变量是一致的，指针变量本身会被销毁，但是指针变量指向的 new 语句的内存不会被销毁：

```cpp
while(p && p->next){

        ListNode* temp = new ListNode(p->val);//temp指针变量每次循环都会重新创建
        //但是new的内存空间不会被回收，temp是这块内存空间地址
        //后面的语句是让这个内存空间的next指针指向上一个内存空间
        //这些内存空间以及各自的关系不会在循环结束后发生改变，改变以及销毁的只是存放这个内存空间地址的容器temp指针

        temp->next = pre;

        pre = temp;

        p = p->next;

    }
```

#### 循环内部向 vector 添加元素的问题

（1）如果在循环外部创建了 vector，然后在循环内部创建了临时变量 temp，并将 temp 加入到 vector 中，那么实际上退出循环之后 temp 变量确实会回收，但是 vector 中的数据仍然有效

（2）vector 对象本身在栈上，但是 vector 内部的数据实际上在堆上

```cpp
#include <iostream>
#include <vector>
#include <string>

// 定义学生结构体
struct Student {
    std::string name;
    int chineseScore;
    int mathScore;

    // 构造函数
    Student(std::string n, int c, int m) : name(n), chineseScore(c), mathScore(m) {
        std::cout << "构造函数被调用，学生：" << name << std::endl;
    }

    // 拷贝构造函数
    Student(const Student& other) : name(other.name), chineseScore(other.chineseScore), mathScore(other.mathScore) {
        std::cout << "拷贝构造函数被调用，创建了 " << name << " 的副本" << std::endl;
    }
};

int main() {
    std::vector<Student> students; // 在main函数作用域内定义vector
    int n = 2; // 假设有2个学生

    for (int i = 0; i < n; i++) {
        // 以下三个变量在每次循环内部定义，是局部变量
        std::string tempName;
        int tempChineseScore;
        int tempMathScore;

        // 模拟输入数据
        if (i == 0) {
            tempName = "张三";
            tempChineseScore = 90;
            tempMathScore = 85;
        } else {
            tempName = "李四";
            tempChineseScore = 95;
            tempMathScore = 88;
        }

        // 在循环内部创建结构体变量 tempStu
        Student tempStu(tempName, tempChineseScore, tempMathScore);

        // 将 tempStu 加入 vector
        students.push_back(tempStu);

        std::cout << "即将结束本次循环，tempStu 即将被销毁..." << std::endl;
```

### C++中的函数参数回收问题

C++在一个函数中，创建的局部变量会被回收，其地址也将不复存在，比如：

但是如果一个函数 new 了一个对象，那说明这个对象是在堆上，那么当函数结束的时候这个对象同样不会被销毁，只是指向这个对象的指针是临时变量，存储这个对象的地址，它在函数调用结束的时候会被销毁：


#### 函数中对全局数组 vector 的修改问题

vector 是一个全局数组，假设在一个函数中对其进行下面两类修改：

**第一类：**

```cpp
#include <vector>
using namespace std;

vector<int> nodes; // 全局vector

void addToNodes() {
    int a = 42; // 局部变量（临时变量）
    nodes.push_back(a); // 关键操作
    // 函数结束 → a被销毁
}

int main() {
    addToNodes();
    // 这里nodes仍然包含42
}
```

这里 nodes 中会保留 42，这是因为 push_back (a) 的本质是将 a 的具体数值赋值一份到 nodes 所在的内存空间中，当函数调用结束，nodes 不会被销毁，所以此时 nodes 中仍然保留 42 这个数值，这个数值是一个 int 类型的有意义的变量，可以被继续使用

**第二类**

```cpp
vector<int*> ptrNodes; // 指针向量

void badAdd() {
    int a = 42; // 局部变量
    ptrNodes.push_back(&a); // 存储局部变量的地址
} // a被销毁，ptrNodes[0]成为悬空指针

int main() {
    badAdd();
    cout << *ptrNodes[0]; // 未定义行为! 可能崩溃或输出错误值
}
```

这里其实 a 的地址还是会保留在 nodes 中，因为 a 的地址被复制了嘛，但是 a 变量本身在函数结束之后就被销毁了，这个地址就没有意义了，可能会被 OS 放入其他的数据，此时 nodes 中如果继续保留这个无意义的地址，那就是悬挂指针了，容易出错

**第三类**

```cpp
std::vector<TreeNode*> nodes;  // 全局结果集
int height;                     // 全局树高度

// 修复后的递归函数
void dfsl(TreeNode* root, int h) {
    if (!root) return;  // 空节点处理
    
    // 到达目标层：保存并停止递归
    if (h == height - 1) {
        nodes.push_back(root);
        return;  // ★ 关键修复：保存后立即返回 ★
    }
    
    // 递归子节点
    if (root->left) dfsl(root->left, h + 1);
    if (root->right) dfsl(root->right, h + 1);
}
```

这个代码的含义是将树的某一层的结点放入到全局数组 nodes 中

在这个函数中，root 是指向 TreeNode 的指针，其存储结点的地址，root 是一个函数局部变量，是一个指针变量，它在函数调用结束之后就会被销毁，但是 root 的内容是堆上的结点的地址，这个地址是始终有意义的，它被复制了一份到 nodes 中，函数结束但是堆的内容不变，所以 nodes 中的这份地址，即结点的地址，也可以说是结点的指针，仍然是有意义的，仍然可以通过 nodes[i]->val 来访问这个结点的 val 内容，此时 nodes[i]就是在堆上的结点的地址，也是指向结点的指针

这里的修改 nodes 的本质其实和第一类修改是一样的，nodes 中传入的始终是一个函数结束之后仍然有意义的数据

### C++中的内存释放与悬挂指针

==delete 的用法==

delete 后面跟的应该是一个内存的地址，用于释放这块内存，将内存还给 OS

（1）delete 释放单个对象的内存

```cpp

// 创建单个对象
MyClass* obj = new MyClass(); 
// 释放对象
delete obj;       // 正确用法
obj = nullptr;    // 推荐：避免悬挂指针

TreeNode* lchild = new TreeNode();
root->left = lchild;//将lchild指向的内存地址赋给root->left这个指针，此时lchild和root->left其实是指向同一块内存区域

delete lchild;//或者这里用delete root->left
root->left = nullptr;
lchild = nullptr;
```

（2）delete 释放多个对象的内存

```cpp
// 创建对象数组
MyClass* arr = new MyClass[10]; 

// 释放数组
delete[] arr;     // 注意 [] 符号
arr = nullptr;

int* numbers = new int[100];
delete[] numbers;  // 即使基本类型也需要 delete[]
numbers = nullptr;
```

==悬挂指针==

当使用 delete 释放某一块的内存之后，这块内存被交给 OS 可以被重新分配，但是，之前指向这块内存的指针的值仍然是这块内存的地址，相当于这个指针仍然指向这块内存，这个就是悬挂指针

由于这个指针不为空，所以其实它也可以被访问，但是访问或者修改它指向的内容就会出错，最好的方法是在用 delete 释放这块内存之后将指向这块内存的指针置空

#### 自定义元素优先队列

`priority_queue` 中的元素 T 必须支持可比较，如果是自定义结构，需要单独写一个比较类

```cpp
#include <queue>
using namespace std;

struct Node {
    int x, y;
    // 不重载 <
};

// 自定义比较类（仿函数）
struct CompareNode {
// 这里a和b分别表示左右两个元素
 // 这里与sort中的cmp的逻辑刚好是反过来的，最小堆是从右到左递减，从最右边取出最小元素，保证左边元素比右边大
 // cmp的从小到大排序是从右到左递减，保证左边元素比右边小

    bool operator() (const Node& a, const Node& b) {
        // 返回 true 表示 a 的优先级 **低于** b（即 b 应该先出队）
        // 例如：按 x 从小到大出队（最小堆）
        return a.x > b.x;
        // 若想按 x 从大到小出队（最大堆），则写 a.x < b.x
    }
};

int main() {
    // 模板参数：元素类型, 底层容器类型, 比较类型
    priority_queue<Node, vector<Node>, CompareNode> pq;
    pq.push({1, 2});
    pq.push({3, 4});
    // 此时 top 是 {1, 2}
    return 0;
}
```

**（7）一个细节，初始化列表方式初始化结构体的顺序问题**

```cpp
struct Example {
    int a;
    int b;
    
    // 注意：初始化列表中，b 写在 a 前面
    Example(int value) : b(value), a(b) { // 存在风险！
    }
};
```

上述代码中虽然初始化列表中是先初始化 b 再初始化 a，但是编译器会始终按照结构体中的声明顺序进行初始化，因此编译器仍然会先初始化 a，a 变成一个随机值，再初始化 b，这样就会导致 a 的值出错了

正确的写法是要保证变量声明顺序与初始化列表顺序一致：

```cpp
struct Example {
    int b; // 让被依赖的成员先声明
    int a;
    
    Example(int value) : b(value), a(b) { // 现在安全了：b先初始化，a再用b初始化
    }
};
```

（9）vector 的 push_back 扩容机制

#### memset 函数

```cpp
memset(a, 0, sizeof(a));
```

（2）`memset(a, -1, sizeof(a))`，初始化-1
（3）`memset(a, 0x3f, sizeof(a))`，初始化一个尽可能大的数

### C++的动态分配内存

在 C++ 中，动态内存分配允许程序在运行时（而非编译时）请求内存。这是通过 `new` 和 `delete` 运算符实现的。以下是动态内存分配的核心用法和最佳实践：

#### ​单个对象​​

```
// 分配单个 int
int* pInt = new int;       
*pInt = 42;

// 分配并初始化
double* pDouble = new double(3.14); 

// 释放内存
delete pInt;     
delete pDouble;
```

#### ​​对象数组​​

```
// 分配 10 个 int 的数组
int* arr = new int[10];     

// 初始化数组
for (int i = 0; i < 10; ++i) {
    arr[i] = i * 10;
}

// 释放数组内存
delete[] arr;  // 必须使用 delete[]
```



#### ​​动态分配类对象​​

```
class MyClass {
public:
    MyClass() { std::cout << "构造\n"; }
    ~MyClass() { std::cout << "析构\n"; }
    void show() { std::cout << "方法调用\n"; }
};

// 动态创建对象
MyClass* obj = new MyClass(); 

// 使用对象
obj->show();                  

// 释放对象
delete obj;                   
```

> ​**​输出​**​：  
> 构造  
> 方法调用  
> 析构

```
// 分配缓冲区
char* buffer = new char[100]; 

// 安全复制
strncpy(buffer, "Hello", 99); 
buffer[99] = '\0'; // 确保终止
```

#### 一些注意的问题​

1. ​**​配对使用​**​：每个 `new` 对应一个 `delete`，`new[]` 对应 `delete[]`
    
    ```
    int* p = new int;     → delete p;
    int* arr = new int[5]; → delete[] arr;
    ```
    
2. ​**​避免裸指针​**​：优先使用智能指针（`unique_ptr`, `shared_ptr`）
    
3. ​**​RAII 原则​**​：通过构造函数分配，析构函数释放
    
    ```
    class ResourceHolder {
        int* data;
    public:
        ResourceHolder(size_t size) : data(new int[size]) {}
        ~ResourceHolder() { delete[] data; }
    };
    ```
    
4. ​**​预防内存泄漏​**​：
    
    ```
    // 错误示例
    void leak() {
        int* p = new int[10];
        return; // 忘记 delete[] → 内存泄漏
    }
    ```
    
5. ​**​避免悬空指针​**​：
    
    ```
    int* p = new int(10);
    delete p;
    // p = nullptr; // 安全做法
    *p = 20; // 危险！悬空指针
    ```

## 二分法

### 整数二分模板

（1）找右侧性质的左端点，check 函数满足右侧性质

```cpp
bool check(int mid){
}
int bsearch(int l, int r, int t){
    while(l < r){
    	int mid = l + r >> 1;
        if(check(mid)) r = mid;
    	else l = mid + 1;//mid不满足右侧性质，那么显然mid指向的是左边性质区域，我们应该向右缩小区域
    }
    return l;
}
```

（2）找左侧性质的右端点，check 函数满足左侧性质

```cpp
bool check(int mid){
}
int bsearch(int l, int r, int t){
	while(l < r){
		int mid = l + r + 1 >> 1;
		if(check(mid)) l = mid;
		else r = mid - 1//不满足左侧性质，那么此时mid肯定指向右侧性质，所以我们应该将区域往左缩小
	}
	return l;
}
```

这样记忆：
（1）找左边区间右端点则 check 函数必须满足左侧性质；找右侧区间左端点，check 函数必须满足左侧性质，这里的满足性质指的是 check 函数中 mid 满足某侧性质后返回 ture，满足左侧性质就是 mid 满足左侧性质后返回 ture
（2）check 函数满足的是哪边的性质，那么满足 check 函数更改的就是哪边的端点；这时根据代码意思写出 if 和 else 两个语句即可
（3）mid = l + r + 1 >> 1 和某个区间 - 1 是绑定的，mid = l + r >> 1 与+1 是绑定的，先写出 check 函数，然后判断区域应该往哪里缩小，写出 else 后面的语句，然后再写 mid 应该如何改变

### 整数二分模板注意事项

（1）如果整个序列中没有右侧性质元素（比如数组 `1 4 5 5 7`，右侧性质为>= 8），此时使用找右侧性质左端点的模板返回的是元素 7 的下标，即 4；同理，如果整个序列中没有左侧性质（左侧性质定义为 < 0.5 ），此时使用找左侧性质右端点的模板返回的下标是元素 1 的下标，即 0

### 浮点数二分模板

（1）浮点数二分将整个区间分成两个部分，并且只有一个分界点，无论是找左区间右端点还是右区间左端点，这两种写法结果是一样的
（2）check 函数满足右侧性质，则修改右端点为 mid，满足左侧性质，则修改左端点为 mid，这个逻辑与整数二分是一样的
（3）由于 l 和 r 都是 double，因此两者只会无限接近，不可能相等，所以当两者差值小于某个 err（定为 1 e-9）的时候就认为相等，找到了分界点，浮点数二分不可能像整数二分那样准确找到分界点，只能无限逼近

```cpp

//第一种写法
bool check(double index){
	....
}

int bsearch(double l, double r){
	while(abs(l - r) < err){
		double mid = (l + r) / 2;
		if(check(mid)) r = mid;//满足右侧性质
		else l = mid;
	}
}

//第二种写法
bool check(double index){
	....
}

int bsearch(double l, double r){
	while(abs(l - r) < err){
		double mid = (l + r) / 2;
		if(check(mid)) l = mid;//满足左侧性质
		else r = mid;
	}
	return l
}
```

#### next 数组的求法（DP 思想）

`next[i]` 表示模式串（待匹配的串，非主串，短的那个）前缀与后缀（不包括模式串本身）相等的最大长度

比如下面 `next[10] = 3`，表示模式串中 `p[0~10]` 的前缀与后缀相等的最大长度
![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20260224202710.png)

下面来推导它的递推方程

`next[i]` 所表示的集合，其实就是 `p[0~i]` 的所有前缀和后缀相等的长度，当然在这个例子中集合元素只有一个

下面的例子中 `next[4]` 所对应的集合如下图所示：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20260224211031.png)


当然，这里的 `next[4]` 是前缀和后缀相等的最大值，这里就是 4

第一条性质：
**对于 `p[0~i]`，它的任意一个前缀和后缀相等的情况，前缀和后缀各自去掉最末尾的字符之后，就是 `p[0~i-1]` 的前缀和后缀相等的情况**，比如下图：

![](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20260224211031.png)
对于 `p[0~4]` 中前 4 个字符与后 4 个字符相等的情况（红色），前缀去掉末尾字符 `p[3]`，留下 `p[0~2]`，后缀去掉末尾字符 `p[4]` 留下 `p[1~3]`，两者各自去掉最末尾的字符之后，分别是 `p[0~3]` 的前缀和后缀相等的情况（绿色所示）

因此从直观的角度 `next[i]`， `p[0~i]` 前缀与后缀相等的最大长度，它肯定是由 `next[k](k < i)` 推导而来

![](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20260224211031.png)

根据这个性质，我们可以换一个说法，得到第二个性质：

**对于 `p[0~i]` 的所有前缀和后缀相等的情况，它都是由 `p[0~i-1]` 的前缀和后缀相等的情况的基础上，前缀加上自己后一个字符，后缀加上自己后一个字符变换而来**

比如上图中 `p[0~4]`，它的一个前缀和后缀相等的情况 `p[0~3] = p[1~4]`，这个就是由 `p[0~3]` 中的 `p[0~2] = p[1~3]` 前缀与后缀相等情况，然后前缀 `p[0~2]` 加上自己的后一个字符 `p[3]`，以及后缀 `p[1~3]` 加上自己的后一个字符 `p[4]` 变换而来

因此我们想要求 `next[i]`，只要遍历 `p[0~i-1]` 的所有前缀与后缀相等的情况，然后加上各自的后一个字符，看是否满足前缀等于后缀，然后这里面取大就行了

这里递推的时候有一个小技巧，我们先从 `p[0~i-1]` 最大的开始，验证它的前缀和后缀加上各自后面一个字符之后是否相等；如果不行，再验证次大的前缀和后缀是否相等：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20260224210435.png)

上图这里我们要求 `next[13]` 的时候，先看 `p[0~12]` 前缀与后缀相等最大的情况，也就是 `next[12]`，这里 `next[12] = 5`，而 5 恰好是 `p[0~12]` 的前缀与后缀相等最大的情况中前缀的后一个字符，**这是又一个性质，即 `next[i] = now` 那么 `p[now]` 就是 `p[0~i]` 前缀与后缀相等最大的情况中前缀的后一个字符**

这里验证了 `p[5] != p[13]`，不行，所以接着开始寻找 `p[0~12]` 前缀与后缀相等的次大情况，`p[0~12]` 前缀与后缀相等的次大情况，它对应的前缀长度和后缀长度，一定小于 `p[0~12]` 前缀与后缀相等的最大情况（红色框所示），所以这个次大情况的前缀一定是左边红色框 `p[0~4]` 的前缀，次大情况的后缀一定是右边 `p[8~12]` 的后缀，而 `p[0~4]` 与 `p[8~12]` 是相等的，是 `p[0~12]` 前缀后缀相等的最大情况，所以 `p[0~12]` 的次大情况，其实就等价于 `p[0~4]` 的前缀与后缀相等的最大情况，这样就形成了一个递归关系了

整理一下：

（1）我们要求 `next[13]`，即 `p[0~13]` 的前缀和后缀相等的最大情况的长度，由于 `p[0~13]` 的所有前缀和后缀相等情况都是由 `p[0~12]` 的前缀和后缀相等的情况 + 各自后面一个字符得到，所以就等价于找 `p[0~12]` 的所有前缀和后缀相等的情况，然后验证他们各自加上自己后面一个字符是否相等取大
（2）我们从大到小遍历 `p[0~12]` 的所有前缀和后缀相等的情况，最大的情况各自加上自己后面字符之后不相等，所以后面考察次大的情况
（3）`p[0~12]` 的所有前缀和后缀相等次大的情况，可以转换成上图两个红框，左边红色框 `p[0~4]` 的前缀与右边红色框 `p[8~12]` 的后缀相等的最大情况，而由于这两个红框实际上是 `p[0~12]` 前缀与后缀相等的最大情况，所以是相等的，从而转换成 `p[0~4]` 的前缀和后缀相等的最大情况，也就是 `p[0~12]` 的所有前缀和后缀相等次大的情况的长度，实际上就是 `next[4]`，我们再验证这个时候次大的前缀和后缀加上各自的后一个字符是否相等，如果还不相等，那就考察 `p[0~12]` 的次次大长度
（4）这个次次大情况，可以进一步转换成左右两个红框的前缀和后缀相等的次大情况，从而转换成左边红框的次大情况，也就是 `p[0~4]` 的次大情况，按照从 `p[0~12]` 找次大情况的相同的思路来找 `p[0~4]` 的次大情况，这就是递归关系了
（4）这样，我们在利用 `next[k](k < i)` 进行递推得到 `next[i]` 的时候，就形成了一个递归递推关系

（5）在这个递归递推关系中，有下面的下标关系

求 `next[i]`，先考察 `p[0~i-1]` 的最大的前缀和后缀相等的情况，即 `next[i-1]`，假如 `next[i-1] = now`，那么这个 `p[now]` 刚好就是 `p[0~i-1]` 的前缀的后一个字符，此时验证 `p[now]` 是否等于 `p[i]` 即可

如果 `p[now] != p[i]`，那么下一步就是找 `p[0~i-1]` 的前缀与后缀相等的次大情况，这个次大情况，实际上就是 `p[0~i-1]` 的前缀与后缀相等的最大情况的前缀字符串中，前缀和后缀相等的最大情况， `p[0~i-1]` 的前缀与后缀相等的最大情况的前缀字符串长度是 `now`，所以最大情况的前缀字符串中前缀和后缀相等的最大情况长度实际上就是 ` next[now-1]`，假设 `next[now-1] = now'`，这个 `p[now']` 就是次大情况的前缀的后一个字符，我们验证 `p[now']` 与 `p[i]` 是否相等即可；如果不相等，下一步就是看最大情况的前缀字符串中前缀和后缀相等的次大情况，进一步递归，那就是 `next[now'-1]`，继续验证即可

```cpp
class Solution {

public:

    int strStr(string s, string p) {
        int n = s.size(), m = p.size();
        if(m == 0) return 0;
        // 将字符串从下标1开始，方便后续计算
        s = " " + s;
        p = " " + p;

        // next数组也从下标1开始，next[i]表示p[1~i]前缀与后缀相等的最大长度
        vector<int> next(m + 1);
        //预处理next数组
        // next[j]表示p[1~j]前缀与后缀相等的最大长度
        // 由于下标是从1开始的，因此p[j + 1]才是前缀与后缀相等情况下的时候前缀的后一个字符
        for(int i = 2, j = 0; i <= m; i++){

            // 这里的j在循环的过程中始终保证了是next[i-1]的前缀与后缀相等情况下的最长长度
            // 因此求next[i]的时候p[j + 1]就是前缀的后一个字符
            while(j && p[i] != p[j + 1]) j = next[j];
            // 在循环过程中当j = 0退出循环的时候说明p[i-1]所有的前缀与后缀相等的情况都不能加上各自后面一个字符转换到p[i]前缀与后缀相等
            // 因此此时要看下p[1]与p[i]的相等情况
            // 如果p[1]与p[i]相等，说明next[i] = 1
            // 否则说明p[1~i]并没有前缀与后缀相等的情况，此时next[i] = 0
            if(p[i] == p[j + 1]) j++;
            next[i] = j;
        }
        
 	   int i = 1, j = 1;
        while(i <= n && j <= m){
            if(s[i] == p[j]){
                i ++;
                j ++;
            }else{
                // 如果是needle的第一个字符都不匹配，则i必须同时后移，并保持j不变
                if(j == 1){
                    i ++;
                // 其他的情况不匹配对j利用next数组进行移动
                // 此时p[1~j-1]是匹配完全的
                // 将j移动到p[1~j-1]前缀和后缀相等情况的后一个字符
                }else j = next[j-1] + 1;
            }
        }

        // 如果是needle移动完了，此时肯定匹配完全
        if(j > m) return i - m - 1;//注意下标是从1开始，需要-1变换到从0开始
        return -1;

    }

};


```

（1）`next` 数组从 1 开始，在目标串和模式串中都加上前置空格，让字符从 1 开始
（2）`next[1] = 0`，然后从下标 2 开始构造 next 数组，next 数组是根据模式串（短的那个）来构造的
（3）构造 next 数组的时候基本框架是 dp
（4）第一层 for 循环，j 总是在刚进入求 `next[i]` 的 for 循环的时候表示 ` next[i-1]` 的数值，j + 1 是 `p[1~i-1]` 前缀与后缀相等情况的下一个字符
（5）while 循环用来递归遍历 `next[i-1]` 中前缀与后缀相等的情况，递归的终点是 j = 0，表示 `p[1~i-1]` 中所有前缀与后缀相等的情况下，各自加上后面一个一个字符也不构成 `p[1~i]` 的前缀与后缀
（6）j = 0 退出之后要查看 `p[j + 1]`（`p[0]`）和 `next[i]` 是否相等，`p[1~i]` 前缀与后缀相等的情况，前缀和后缀的长度是 1 需要特判

### 筛质数

即快速筛出 2 ~ n 中的质数

如果一个数 n是合数，那么它一定有 2 ~ n-1 中的某个质因子，反过来，如果一个数 n 不是合数（质数），那么它一定没有 2 ~ n - 1 中的某个质因子

基本思想是，对 2 ~ n 中的每一个数进行遍历，假设遍历到 i，并且当 i 是质数的时候才筛后面的数，只有后面的数是 i 的倍数都被筛掉，这样的时间复杂度近似是 On 的

```cpp
 void get_prime(int n)
 {
     //从2到最后的那个数进行枚举
     for(int i = 2; i <= n; i ++)
     {
         //如果这个数没有被前面的数筛过，说明就是一个质数
         if(!st[i]) 
         {
             prime[cnt ++] = i;
             //再将剩下的数中所有是i（质数）的倍数的数删掉
             for(int j = i + i; j <= n; j += i) st[j] = true;
         }
        
     }
 }
```

### 分解质因数

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20260105175216.png)

找到 n 的每个质因数以及它的幂的基本思路就是从小到大枚举 2 ~ $\sqrt{ n }$，枚举到 i 的时候比如上图的 2，就用 2 反复去除 360，一直到无法整除，360/2 = 180；180 / 2 = 90； 90  / 2= 45，45 无法整除 2，所以 2 这个因子就是 3 次幂，然后 45 肯定是 $3^{2} * 5$，然后继续从 3 开始枚举，得到 3 是因子并且是 2 次，数变成 5，然后从 4 开始枚举，然后从 5 开始，得到 5 是因子，并且是 1 次

这里之所以是 $\sqrt{ n }$，是因为数 n 不可能有 2 个以上超过 $\sqrt{ n }$ 的因子，而数 n 本身就是自己的因子，所以 $\sqrt{ n } \sim n - 1$ 中不可能有数 n 的因子了

```cpp
 {

     //最后n一定是等于1退出循环
     //只有当n包含大于sqrt(n)的质因子，我们从前往后将小于原来的sqrt(n)的质因子剔除完了最后留下的就是大于原来sqrt(n)的这个数本身
     //注意此处带等号，i是可以等于n / i的，比如：9 = 3 * 3
     for(int i = 2; i <= n / i; i ++)
     {
         //如果i是n的约数
         if(n % i == 0)
         {
             //开始求i的次数
             int s = 0;

             {
                 n /= i;
                 s ++;
             }

     }

     //如果不为1，那么n就是它最后的那个大于原来的sqrt(n)的质因子
     if(n > 1) printf("%d %d\n", n, 1);
     puts("");
 }
```

### 求子集

求子集的基本思路是对于 n 个空位，每个空位选对应的数，或者不选对应的数，然后递归进入下一个空位，到最后将所有空位的数组合起来输出即可

```cpp
#include<bits/stdc++.h>
using namespace std;
int n;

vector<vector<int>> res;

vector<int> temp;

//子集的每个元素选，或者不选，然后自定义数组之间排序输出
bool cmp(vector<int> a, vector<int> b){
    if(a.size() < b.size()) return true;
    else if(a.size() == b.size()){
        for(int i = 0; i < a.size(); i ++){
            if(a[i] < b[i]) return true;
            else if(a[i] > b[i]) return false;//这里必须加上a[i] > b[i]的比较，因为如果不加上并不会返回flase,而是进入下一次循环
        }
    }else return false;
    return false;
}

void dfs(int level){
    if(level == n + 1){
        res.push_back(temp);
        return;//注意这里要加上返回return
    }
    temp.push_back(level);
    dfs(level + 1);
    temp.pop_back();
    dfs(level + 1);
}

  
int main(){
    cin >> n;
    dfs(1);
    cout << endl;
    sort(res.begin(), res.end(), cmp);
    for(int i = 0; i < res.size(); i ++)
        for(int j = 0; j < res[i].size(); j ++)
            {
                if(j != res[i].size() - 1) cout << res[i][j] << " ";
                else cout << res[i][j] << endl;
            }

    return 0;

}
```


### 求组和（选或者不选思路）

基本思想过程和求子集是完全一样的，实际上就是将子集中含有 k 个数的筛出来，而且，按照这个过程，这些 k 个数的组合天然就是数组字典序的，不用自定义排序

```cpp
#include <cstdio>
#include <vector>
using namespace std;

vector<vector<int> > result;
vector<int> temp;
int n, k;

void DFS(int idx) {
    //当temp中有k个数的时候，就是一种组合
    if (temp.size() == k) {
        result.push_back(temp);
        return;
    }
    //候选数不能越界
    if (idx == n + 1) {
        return;
    }
    //仍然是针对集合中的每个元素选，或者不选
    temp.push_back(idx);
    DFS(idx + 1);
    temp.pop_back();
    DFS(idx + 1);
}

int main() {
    scanf("%d%d", &n, &k);
    DFS(1);
    for (int i = 0; i < result.size(); i++) {
        for (int j = 0; j < result[i].size(); j++) {
            printf("%d", result[i][j]);
            printf(j + 1 < result[i].size() ? " " : "\n");
        }
    }
    return 0;
}
```

### 搜索回溯的时间复杂度

有一个简易的公式就是叶结点个数乘搜索路径长度

比如全排列算法中，叶结点的个数是 `n!` 个，从根结点搜索到叶结点的路径长度是 n，所以复杂度就是 `O(n*n!)`

比如 N 皇后问题中，按照每一行应该放什么列的思想，叶结点的上限是 $O(n!)$ 个，在到达每个叶结点的路径中间的结点中，比如到达第 i 行的时候，此时需要枚举所有的列，如果在枚举所有的列的过程中利用的是遍历前面 1~i 行来判断当前列是否可行，那么路径中间结点找到一个合适的列的复杂度就是 $O(n^{2})$， 到达叶结点的代价就是 n^3，总的复杂度就是 $O(n^3 n!)$；如果用的是 O (1) 判断第 i 行的某一列是否可行，那么到达叶结点的路径中的某个结点枚举所有的列的复杂度是 O(n)，判断可行是 O(1)，则到达叶结点的总复杂度就是 O (n^2)，总的复杂度就是 $O(n^{2}n!)$

### `Dijkstra` 最短路径性质

（1）假如利用 Dijkstra 算法得到了从源点到汇点的最短路径长度是 s，并且这个路径有多条，那么对于任意一条最短路径，比如路径 A，这条路径上的任意一个顶点 V，这个顶点 V 按照这条路径到达源点 S 的距离也一定是最短的

假如不是最短，那么这个点 V 一定可以通过另外一条路径到达源点，这样就与路径 A 是最短路径矛盾了

（2）`Dijkstra` 是一种思想，每次找到一个距离源点最近的顶点 V加入到集合 S 之后，此时顶点 V 到源点的最短路径必然已经确定，不仅是距离确定，路径所经过的顶点也确定，即顶点 V 到源点的最短路径上的顶点一定由当前集合 S 中的顶点构成，不可能包含后续加入集合 S 中的顶点

假如包含后续假如集合 S 的顶点 U，那么此时 U 到 S 的距离实际上小于 V 到集合 S 的距离，那么此时应该选择的是顶点 U，而不是顶点 V，所以矛盾

### Bellman-ford 算法

（1）这个算法的本质是动态规划，`dist[i]` 表示从起点到顶点 i 的最短路径（这里不用知道 dp 原理）
（2）这个算法由两层循环构成，外层循环 k 次表示 `dist[i]` 是经过不超过 (<=) k 条边从源点到达顶点 i 的最短距离；当然如果题目要求最多经过不超过 k 个顶点的话，外层循环得进行 k + 1 次；内层循环是遍历所有的边对这些边进行松弛操作，具体来说，对于边 u->v，假如 dist[v] < dist[u] + w，则将 dist[v]更新为 dist[u] + w，这里更新边的时候 dist[v]一定是上一轮的结果，但是 dist[u]则不一定，所以得用一个 backup 数组来保存上一轮的结果，假如 `dist[v] < backup[u] + w` 其实等价于 `backup[v] < backup[u] + w` 则将 dist[v]更新为 `backup[u] + w`
（3）在没有负环的情况下（可能有正环），从顶点到源点，只要最短路径存在，最大经过就是 n - 1 条边，所以外层循环 n - 1 次求得的 `dist[i]` 就是源点到顶点 i 的最短距离；实际上如果没有负环的情况下，外层循环大于 n - 1 次也无所谓，求得的结果是一样的
（4）在存在负环的情况下，这个算法仍然可以求得结果，只要控制外层循环即可，外层循环 n - 1 次求得的 `dist[i]` 表示经过不超过 n - 1 条边，从源点到顶点 i 的最短距离，当然如果顶点 i 在负环上面的话，从源点到顶点 i 的距离可能会更小，但是经过的边的个数一定会超过 n - 1
（5）在松弛的时候不能用本轮松弛的结果，得记录保存上一轮的结果

```cpp
#include<iostream>
#include<algorithm>
#include<stdio.h>
#include<vector>
#include<cstring>
using namespace std;

struct Edge{
	int v, w;
	Edge(int _v, int _w) : v(_v), w(_w) {
	}
};

int n, m;
vector<Edge> G[1010];

int main(){
	cin >> n >> m;
	for(int i = 0; i < m; i ++){
		int s, t, v;
		cin >> s >> t >> v;
		G[s].push_back(Edge(t, v));
	}
	int src, dst, k;
	cin >> src >> dst >> k;
	
	
	int dist[n + 1];
	int backup[n + 1];
	
	memset(dist, 0x3f, sizeof(dist));
	
	dist[src] = 0;
	
	//这里是经过不超过k个顶点，所以外层得循环k + 1次
	for(int i = 1; i <= k + 1; i ++){
		memcpy(backup, dist, sizeof(dist));
		//遍历所有的边，对所有的边进行松弛
		for(int j = 1; j < n; j ++){
			for(int l = 0; l < G[j].size(); l ++){
				int v = G[j][l].v;
				int w = G[j][l].w;
				//这里松弛的时候是固定操作，记住即可
				if(dist[v] > backup[j] + w) dist[v] = backup[j] + w;
			}
		}
	}
	
	if(dist[dst] > 0x3f3f3f3f/2) cout << "unreachable";
	else cout << dist[dst];
	
	return 0;
}
```

### spfa 算法

这个算法其实是 bellman-ford 算法的优化版，基本思想是 dp ，但是 bellman-ford 算法的优势在于可以处理有限制（经过不超过 k 条边的最短路径情况）条件下的最短路径

`dist[i]` 表示源点到顶点的最短距离，也就是，所有从源点到顶点 i 的路径中，最短的那条长度就是 `dist[i]` 了

它的递推关系是，对于所有的顶点 `u1 ->w1 i, u2 ->w2 i, u3 ->w3 i...`，这里的 w 是边的权值；只要求出了 `dist[u1], dist[u2], dist[u3]...`，实际上 `dist[i]` 就是这些取小的结果：

$$
dist[i] = min(dist[u_{1}] + w_{1}, dist[u_{2}]+w_{2}, dist[u_{3}] + w_{3})
$$

初试化就是源点的距离是 0，即 `dist[1] = 0`

**递推顺序是按照一个类似广度优先搜索的顺序（只是类似，不是真实的广搜）进行递推，需要用到一个队列进行辅助**，这里 spfa 算法的难点就是递推顺序了

（0）设置 `dist[1] = 0` 并加入顶点 1 到队列中
（1）每次从队列中取出一个顶点 u，都会对它的所有邻接顶点 v，即 u -> v，进行松弛更新 `dist[v] = min(dist[v], dist[u] + w[u->v])`；当 `dist[v]` 被更新了之后，如果 v 不在队列中，需要将其加入到队列，如果 v 已经在队列中，则不进行处理
（2）对于任意一个顶点 u，只要它的 `dist[u]` 被更新了，u 就应该被重新加入到队列，当然如果它已经在队列中则不重复加入队列

这样做的目的是保证某个顶点 `dist[u]` 只要被更新，就会将顶点 u 重新加入队列（已经在队列中不重复假如），只要 u 在队列中，一定会用这个更新过的 `dist[u]` 去松弛所有的 u->v临界点 v，即进行 `dist[v] = min(dist[v], dist[u] + w[u->v])`；也就是说，只要某个顶点 `dist[u]` 被更新了，就一定会利用队列对 u 的所有邻接点 v 的 `dist[v]` 进行松弛更新；这样当 `dist[u]` 被更新到最小值的时候，就一定会利用这个最小值 `dist[u]` 对 u 的临界点 v 进行 ` dist[v] = min(dist[v], dist[u] + w[u->v]) ` 松弛更新

因此对于任意的顶点 v，假如存在关系 ui -> v，在整个算法的松弛过程中，即整个算法过程对 `dist[v]` 进行 `dist[v] = min(dist[ui] + w, dist[v])` 的操作中，一定会有某些操作是 `dist[ui]` 最小的时候对 `dist[v]` 执行的松弛操作，这样就满足 dp 的递推关系了

至于 `dist[u]` 是否一定会被更新到最小值，可以用结构归纳法证明

对于顶点 u 的所有前驱，ui，假设所有的 `dist[ui]` 都被更新到了最小值，那么他们被更新之后，利用队列一定会对顶点 u 进行松弛，按照 `dist[u]` 的递推关系，此时 `dist[u]` 也会被松弛到最小，所以 `dist[u]` 一定会被更新的最小值；当然这里的归纳奠基是 `dist[1] = 0`，即源点是最小值

```cpp
#include<iostream>
#include<algorithm>
#include<stdio.h>
#include<vector>
#include<queue>
#include<cstring>

using namespace std;

  
  

struct Edge{
    int v, w;
    Edge(int _v, int _w) : v(_v), w(_w) {
    }
};

  

int n, m;

  

vector<Edge> G[1010];

int dist[1010];
bool st[1010];

  

int main(){

    cin >> n >> m;

    for(int i = 0; i < m; i ++){

        int s, t, v;

        cin >> s >> t >> v;

        G[s].push_back(Edge(t, v));

    }

    memset(dist, 0x3f, sizeof(dist));

    dist[1] = 0;

    queue<int> q;

    q.push(1);

    st[1] = true;

    while(q.size()){

        int u = q.front();

        q.pop();

        st[u] = false;

        for(int i = 0; i < G[u].size(); i ++){
            int v = G[u][i].v;
            int w = G[u][i].w;
            if(dist[v] > dist[u] + w){
                dist[v] = dist[u] + w;
                // 只要顶点v被重新松弛，就将其重新加入队列，当然如果本来就在队列则不用处理
                if(st[v] == false){
                    q.push(v);
                    st[v] = true;
                }
            }
        }
    }

    if(dist[n] > 0x3f3f3f3f/2) cout << "unconnected";
    else cout << dist[n];
    return 0;

}
```

==一个数据结构==

`p[i] = k`，表示结点 i 所在的集合的树的中，i 的父节点是 k，当 `p[i] = i` 的时候，说明这个结点是这个集合的根结点

==`find(a)`函数==

```cpp
int find(int x){
    if(p[x] != x) p[x] = find(p[x]);
    return p[x];
}
```

这个函数的作用是找结点 x 所在的集合的根结点，并一层层返回，将路径上的所有结点的父节点全部置为根结点

==算法基本过程==

**（1）初始化**

```cpp
for(int i = 1; i <= n; i ++) p[i] = i;
```

初始 n 个结点作为 n 个独立的集合

**（2）构造关系**

```cpp
    for(int i = 1; i <= m; i ++){
        int a, b;
        scanf("%d%d", &a, &b);
        p[find(a)] = find(b);
    }
```

这里 a b 表示 a 和 b 属于同一个集合（也是一般题目中给出的条件），这里的做法是让 a 所属的集合的根结点指向 b 所属的集合的根结点，注意不能是 `p[a] = find(b)`，因为如果初始情况下，同时给出了 a c 和 a b，你执行了这些代码之后只能保证 a b 属于同一个集合，c b 无法表示属于同一个集合，所以只能是 `p[find(a)] = find(c)`，开始先将 a 的根结点指向 c，即将 a 挂到 c 上，然后是 `p[find(a)] = find(b)`，这里是将 c 挂到 b 上了

**（3）查找关系 or 数所有集合的个数**

判断两个定点是否属于同一个集合，用 `find(a) == find(b)` 即可

数所有集合的个数，那就是遍历所有的顶点，将 `find (i)` 加入到 `unordered_set<int>` 中就可以了

并且查找的次数越多，往后的 `find(i)` 速度就越快，最后会保证一个集合的所有顶点全部直接挂在一个根结点上：

### 在数组上进行建树过程

即题目按照结点编号顺序给出一个树的结构，我们需要构建这棵树

建树的基本思想就是创建一个结点数组，当作整个树结点的存储空间，将结点的编号当作结点在这个空间的地址，即在结点数组中的下标即可，父子结点关系通过每个结点本身的数据结构来记录

（1）创建一个新的结构体
（2）结构体数组当作所有树结点的空间，结点编号就是结点地址，同时也是结点在数组中的元素下标
（3）通过每个结点结构体内部的 left 和 right 来记录整个树的结点之间父子关系

```cpp
struct TreeNode{
	int left, right
}Tree[MAXSIZE];

//Tree[MAXSIZE]就是整个树结点数组，每个树结点的left和right就是结点在数组中的下标，同时也是结点的编号
```

这种建树方式与完全二叉树数组形式树结构是不一样的
（1）两者相同之处在于结点编号同样都是结点在数组中的下标
（2）不同之处在于这种建树方式，父子结点关系通过一个新的结构确定，上文代码所示，而完全二叉树方式的树结构，父子结点关系通过数组本身的下标关系确定，即编号 i 的左儿子必须是 2 * i，编号 i 的右儿子必须是 2 * i + 1
（3）这种建树方式数组只是起到一个提供地址空间的作用，具体的父子结点关系通过结构体中的 left, right 数值确定，比如编号 1 的结点左儿子和右儿子可以是编号 2 和 5，遍历的时候直接按照编号 1 结点的结构体记录的 left 和 right 数值进行遍历即可；但是在完全二叉树数组形式的树结构中编号 1 的左儿子必须是 2，右儿子必须是 3，遍历的时候必须通过数组本身的结构来遍历

```cpp
#include <cstdio>
#include <vector>
using namespace std;

const int MAXN = 50;

struct Node {
    int l, r; // 左子节点和右子节点编号
} nodes[MAXN];

vector<int> pre; // 存储先序遍历结果

void preOrder(int root) {
    if (root == -1) { // 如果当前节点为空，直接返回
        return;
    }
    pre.push_back(root); // 访问当前节点
    preOrder(nodes[root].l); // 递归访问左子树
    preOrder(nodes[root].r); // 递归访问右子树
}

int main() {
    int n;
    scanf("%d", &n); // 读取节点个数
    for (int i = 0; i < n; i++) {
        scanf("%d%d", &nodes[i].l, &nodes[i].r); // 读取每个节点的左子节点和右子节点编号
    }
    preOrder(0); // 从根节点开始进行先序遍历
    for (int i = 0; i < (int)pre.size(); i++) {
        printf("%d", pre[i]); // 输出先序遍历结果
        if (i < (int)pre.size() - 1) {
            printf(" "); // 确保行末没有多余空格
        }
    }
    return 0;
}
```

### 判断二叉树是完全二叉树的方法

用 BFS 层序遍历，将整个二叉树当成一个满二叉树遍历，即空结点也当作一个结点放入队列，空结点的左右儿子也是空结点，这样一个满二叉树由空结点和非空结点组成，BFS 层序遍历的话就是从左到右，从上到下

如果遍历到了空结点，根据这个满二叉树的结构，如果是完全二叉树的话，那么后续遍历就不能出现非空结点，一直将整个满二叉树遍历完全；如果遍历的时候空结点在非空前面，那么就不是完全二叉树了

有一个规律是，一旦遍历到了空结点，那么如果是非完全二叉树的话，这个空结点的当前层或者下一层一定会出现非空结点，因此遍历完这个空结点这一层之后，完全可以保证队列中空结点后面会有一个非空结点，这样你一定可以遍历一个非空结点，所以遍历到空结点的时候可以不用把空结点的左右儿子放入队列，直接往后遍历即可，如果后面全是空结点，那当然就是完全二叉树，如果出现了非空结点，那就不是了


```cpp
bool isCompleteTree(TreeNode* root) {
    queue<TreeNode*> q;               // 用于层序遍历
    q.push(root);                     // 入队根节点

    bool foundNull = false;           // 是否已遇到空节点

    while (!q.empty()) {
        TreeNode* node = q.front();   // 取队头
        q.pop();                      // 出队

        if (node == nullptr) {        // 遇到空节点
            foundNull = true;         // 设置标记
        } else {
            if (foundNull) {          // 若之前遇到空节点
                return false;         // 再遇非空则非完全二叉树
            }
            q.push(node->left);       // 左孩子入队
            q.push(node->right);      // 右孩子入队
        }
    }

    return true;                      // 完全二叉树
}
```

#### 排列组合总和问题

排列组合总和问题，实际上就是考虑顺序的情况下的完全背包问题：

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20260206191636.png)
![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20260206191649.png)

它的处理思路是设 `dp[i]` 表示前 n 个元素排列组合的和达到 i 的方案个数，其中每个元素的可选个数无限，并且考虑顺序

那么这些方案可以分为下面几类：
（1）以 `nums[n-1]` 结尾的排列组合的和达到 i 的方案，其个数就是 `dp[i-nums[n-1]]`
（2）以 `nums[n-2]` 结尾的排列组合的和达到 i 的方案，其个数就是 `dp[i-nums[n-2]]`
...
（n）以 `nums[0]` 结尾的排列组合的和达到 i 的方案，其个数就是 `dp[i-nums[0]]`

`dp[i]` 就是将上面的所有方案数加起来即可

实际上就是问 nums 数组中的数据的排列组合总和为 target 的方案数是多少

### spfa 判断负环

（1）增加一个数组 `cnt[i]`，它表示从源点到顶点 i 所经过的边的个数
（2）对于边 u -> v，当利用 `dist[u]` 来更新 `dist[v]` 的时候，如果 `dist[v]` 被更新，说明 v 应该从源点到 u 的路径再到 v，所以此时 `cnt[v] = cnt[u] + 1`
（3）在有负环的情况下，会存在某个点，从源点到这个点经过的边的个数 > n（因为负环图会始终转圈更新 `dist`）
（4）需要增加一个虚拟源点，保证整个图是可达的（只用判断负环的情况下需要增加虚拟源点，如果同时还要求到源点的距离，则不能加上虚拟源点）
