### sort 函数

#### 普通的升序排序

sort 函数是 C++中的函数

==对 vector 进行升序的操作是 :==

```cpp
vector<int> a;
sort(a.begin(), a.end());
```

上面的 a.begin () 表示指向 a 的第一个元素的指针；a.end () 是指向最后一个元素的后一个位置的指针, sort 函数的括号中对元素是左闭右开的

==对普通数组 a[]进行升序排序是：==

```cpp
int a[n];
sort(a, a + n);
```

#### 降序排序

如果想要降序操作还得加上一个 cmp 函数：

```cpp
bool cmp(int &x, int &y) {
   return x > y;
}

int main(){
	int a[n];
	
	sort(a, a + n, cmp);//此时降序排列
}
```

这里 cmp 函数的含义就是保证前后两个元素 x, y 满足 cmp 函数中为 ture 的规则

如果想要对 `vector<int>` 进行降序排列，跟普通的一样：

```c++
#include <vector>
#include <algorithm>

// 自定义比较函数
bool compareDescending(int a, int b) {
    return a > b;
}

int main() {
    std::vector<int> vec = {3, 1, 4, 1, 5, 9, 2, 6};
    std::sort(vec.begin(), vec.end(), compareDescending);
}
```

#### 对数组之间进行排序

比如，如果想要按照数组元素个数对数组排序，并且两个数组的元素个数相等的时候数组元素按照字典序排序（字典序就是当两个数组元素个数相同的时候，前 k - 1 个元素相等，如果第 k 个元素 a[k]  < b[k]，则数组 a 排序在 b 前面）

```cpp
vector<vector<int>> result; //一堆待排序的数组

//自定义排序规则
bool cmp(const vector<int> &a, const vector<int> &b){
	//先保证个数小的在前
	if(a.size() ！= b.size()) return a.size() < b.size();
	else return a < b;//个数相等的时候保证字典序
}

sort(result.begin(), result.end(), cmp);


```

#### 使用 sort 函数来对结构体进行排序

```c
#include <iostream>
#include <algorithm>
#include <vector>
using namespace std;

// 学生结构体
struct Student {
    string name;
    int id;
    double gpa;
};

// 按GPA降序排序
bool compareByGPA(const Student& a, const Student& b) {
    return a.gpa > b.gpa; // 降序排序
}

// 按姓名升序排序
bool compareByName(const Student& a, const Student& b) {
    return a.name < b.name;
}

// 多级排序：GPA相同时按ID升序
bool multiCompare(const Student& a, const Student& b) {
    if (a.gpa != b.gpa)
        return a.gpa > b.gpa;
    return a.id < b.id;
}

int main() {
    vector<Student> students = {
        {"Alice", 101, 3.8},
        {"Bob", 102, 3.9},
        {"Charlie", 103, 3.8},
        {"David", 104, 3.95}
    };

    // 按GPA降序排序
    sort(students.begin(), students.end(), compareByGPA);
    
    cout << "按GPA降序排序:" << endl;
    for (const auto& s : students) {
        cout << s.name << " (" << s.id << "): " << s.gpa << endl;
    }

    // 多级排序
    sort(students.begin(), students.end(), multiCompare);
    
    cout << "\n多级排序(GPA降序，相同则ID升序):" << endl;
    for (const auto& s : students) {
        cout << s.name << " (" << s.id << "): " << s.gpa << endl;
    }

    return 0;
}
```
#### 关于 cmp 函数

总的来说，cmp 的写法是，对于相邻两个元素，如果满足排序之后的数组相邻元素之间的关系，则返回 true，否则返回 false


### CPP 中的循环变量回收问题

#### 普通变量的回收

| 变量类型        | 生命周期         | 回收机制       | 风险提示           |
| ----------- | ------------ | ---------- | -------------- |
| 基本类型 (int 等) | 每次迭代结束       | 栈内存立即回收    | 无风险            |
| 对象类型        | 每次迭代结束       | 析构函数调用+栈回收 | 注意析构函数副作用      |
| 原始指针        | 每次迭代结束（指针本身） | 栈回收（指针变量）  | **堆内存泄漏**（高风险） |
| 智能指针        | 每次迭代结束       | 自动释放管理的内存  | 无风险            |
基本变量和对象类型是指在循环中定义的 int，double, string 之类的，一次循环结束的时候其会自动回收，下一次循环或者跳出循环这个变量就不能再使用了，比如：

```cpp
for (int i = 0; i < 5; ++i) {
    int temp = i * 10;      // 基本类型
    std::string s = "test"; // 对象类型
    
    // 每次迭代结束时：
    // 1. s的析构函数会被调用（释放字符串内存）
    // 2. temp和s的栈内存会被回收
}
```

指针类型的话，如果是普通的指针，其与基本变量是一致的，指针变量本身会被销毁，但是指针变量指向的 new 语句的内存不会被销毁：

```cpp
while(p && p->next){

        ListNode* temp = new ListNode(p->val);//temp指针变量每次循环都会重新创建
        //但是new的内存空间不会被回收，temp是这块内存空间地址
        //后面的语句是让这个内存空间的next指针指向上一个内存空间
        //这些内存空间以及各自的关系不会在循环结束后发生改变，改变以及销毁的只是存放这个内存空间地址的容器temp指针

        temp->next = pre;

        pre = temp;

        p = p->next;

    }
```

### C++中的函数参数回收问题

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250721153243.png)

C++在一个函数中，创建的局部变量会被回收，其地址也将不复存在，比如：
```cpp
void example() {
    int a = 10;           // 局部变量（栈）
    TreeNode localNode;   // 局部对象（栈）
} // 函数结束 → a和localNode自动销毁
```

但是如果一个函数 new 了一个对象，那说明这个对象是在堆上，那么当函数结束的时候这个对象同样不会被销毁，只是指向这个对象的指针是临时变量，存储这个对象的地址，它在函数调用结束的时候会被销毁：

```cpp
void example() {
    TreeNode* heapNode = new TreeNode();  // 堆分配
    nodes.push_back(heapNode);
} // heapNode指针销毁 → 但堆内存依然存在！
```

#### 函数中对全局数组 vector 的修改问题

vector 是一个全局数组，假设在一个函数中对其进行下面两类修改：

**第一类：**

```cpp
#include <vector>
using namespace std;

vector<int> nodes; // 全局vector

void addToNodes() {
    int a = 42; // 局部变量（临时变量）
    nodes.push_back(a); // 关键操作
    // 函数结束 → a被销毁
}

int main() {
    addToNodes();
    // 这里nodes仍然包含42
}
```

这里 nodes 中会保留 42，这是因为 push_back (a) 的本质是将 a 的具体数值赋值一份到 nodes 所在的内存空间中，当函数调用结束，nodes 不会被销毁，所以此时 nodes 中仍然保留 42 这个数值，这个数值是一个 int 类型的有意义的变量，可以被继续使用

**第二类**

```cpp
vector<int*> ptrNodes; // 指针向量

void badAdd() {
    int a = 42; // 局部变量
    ptrNodes.push_back(&a); // 存储局部变量的地址
} // a被销毁，ptrNodes[0]成为悬空指针

int main() {
    badAdd();
    cout << *ptrNodes[0]; // 未定义行为! 可能崩溃或输出错误值
}
```

这里其实 a 的地址还是会保留在 nodes 中，因为 a 的地址被复制了嘛，但是 a 变量本身在函数结束之后就被销毁了，这个地址就没有意义了，可能会被 OS 放入其他的数据，此时 nodes 中如果继续保留这个无意义的地址，那就是悬挂指针了，容易出错

**第三类**

```cpp
std::vector<TreeNode*> nodes;  // 全局结果集
int height;                     // 全局树高度

// 修复后的递归函数
void dfsl(TreeNode* root, int h) {
    if (!root) return;  // 空节点处理
    
    // 到达目标层：保存并停止递归
    if (h == height - 1) {
        nodes.push_back(root);
        return;  // ★ 关键修复：保存后立即返回 ★
    }
    
    // 递归子节点
    if (root->left) dfsl(root->left, h + 1);
    if (root->right) dfsl(root->right, h + 1);
}
```

这个代码的含义是将树的某一层的结点放入到全局数组 nodes 中

在这个函数中，root 是指向 TreeNode 的指针，其存储结点的地址，root 是一个函数局部变量，是一个指针变量，它在函数调用结束之后就会被销毁，但是 root 的内容是堆上的结点的地址，这个地址是始终有意义的，它被复制了一份到 nodes 中，函数结束但是堆的内容不变，所以 nodes 中的这份地址，即结点的地址，也可以说是结点的指针，仍然是有意义的，仍然可以通过 nodes[i]->val 来访问这个结点的 val 内容，此时 nodes[i]就是在堆上的结点的地址，也是指向结点的指针

这里的修改 nodes 的本质其实和第一类修改是一样的，nodes 中传入的始终是一个函数结束之后仍然有意义的数据
### C ++中的数组传参和二维数组传参

#### int a[]\[n]二维数组传参

这里的列必须是常量，是一个具体常数 3，或者 4；或者是一个 const int n；不能是 int n

```cpp
void func(int a[][3], int rows) { // 必须指定列数（此处为3）
    for (int i = 0; i < rows; ++i) {
        for (int j = 0; j < 3; ++j) {
            cout << a[i][j] << " ";
        }
    }
}

int main() {
    int arr[2][3] = {{1,2,3}, {4,5,6}};
    func(arr, 2); // 传递数组名和行数
}
```

这种形式的传参二维数组的每一行的列数是固定的，所以编译器会进行检查，因此列数必须是一个常量，这种二维数组的初始化时候就是普通的初始化

#### **`vector<vector<int>>` 二维数组传参**

下面是一个使用 `std::vector<std::vector<int>>` 容器进行二维数组传参的完整示例：
```cpp
#include <iostream>
#include <vector>

// 1. 按值传递（会创建副本，适用于需要修改副本的场景）
void printByValue(std::vector<std::vector<int>> matrix) {
    std::cout << "按值传递:\n";
    for (const auto& row : matrix) {
        for (int num : row) {
            std::cout << num << " ";
        }
        std::cout << "\n";
    }
    matrix[0][0] = 100; // 修改不影响原始数据
}

// 2. 按常量引用传递（推荐，避免拷贝，只读访问）
void printByConstRef(const std::vector<std::vector<int>>& matrix) {
    std::cout << "\n按常量引用传递:\n";
    for (const auto& row : matrix) {
        for (int num : row) {
            std::cout << num << " ";
        }
        std::cout << "\n";
    }
}

// 3. 按引用传递（可修改原始数据）
void modifyMatrix(std::vector<std::vector<int>>& matrix) {
    std::cout << "\n按引用传递（修改前）:\n";
    for (const auto& row : matrix) {
        for (int num : row) {
            std::cout << num << " ";
        }
        std::cout << "\n";
    }
    
    // 修改原始数据
    for (auto& row : matrix) {
        for (int& num : row) {
            num *= 2; // 每个元素乘以2
        }
    }
}

int main() {
    // 创建二维vector
    std::vector<std::vector<int>> matrix = {
        {1, 2, 3},
        {4, 5, 6},
        {7, 8, 9}
    };

    // 1. 按值传递调用
    printByValue(matrix);
    
    // 2. 按常量引用传递调用
    printByConstRef(matrix);
    
    // 3. 按引用传递调用（会修改原始数据）
    modifyMatrix(matrix);
    
    // 显示修改后的结果
    std::cout << "\n修改后的原始矩阵:\n";
    printByConstRef(matrix);

    return 0;
}
```

| **传递方式**         | **语法**                              | **特点**                              | **适用场景**    |
| ---------------- | ----------------------------------- | ----------------------------------- | ----------- |
| **按值传递**         | `vector<vector<int>> matrix`        | 创建完整副本，修改不影响原始数据，但可能有性能开销（拷贝整个二维数组） | 需要独立修改副本的场景 |
| **按常量引用传递** (推荐) | `const vector<vector<int>>& matrix` | 无拷贝开销，只读访问，安全高效                     | 只读取数据不修改的场景 |
| **按引用传递**        | `vector<vector<int>>& matrix`       | 无拷贝开销，可直接修改原始数据                     | 需要修改原始数据的场景 |

### C++中的内存释放与悬挂指针

==delete 的用法==

delete 后面跟的应该是一个内存的地址，用于释放这块内存，将内存还给 OS

（1）delete 释放单个对象的内存

```cpp

// 创建单个对象
MyClass* obj = new MyClass(); 
// 释放对象
delete obj;       // 正确用法
obj = nullptr;    // 推荐：避免悬挂指针

TreeNode* lchild = new TreeNode();
root->left = lchild;//将lchild指向的内存地址赋给root->left这个指针，此时lchild和root->left其实是指向同一块内存区域

delete lchild;//或者这里用delete root->left
root->left = nullptr;
lchild = nullptr;
```

（2）delete 释放多个对象的内存

```cpp
// 创建对象数组
MyClass* arr = new MyClass[10]; 

// 释放数组
delete[] arr;     // 注意 [] 符号
arr = nullptr;

int* numbers = new int[100];
delete[] numbers;  // 即使基本类型也需要 delete[]
numbers = nullptr;
```

==悬挂指针==

当使用 delete 释放某一块的内存之后，这块内存被交给 OS 可以被重新分配，但是，之前指向这块内存的指针的值仍然是这块内存的地址，相当于这个指针仍然指向这块内存，这个就是悬挂指针

由于这个指针不为空，所以其实它也可以被访问，但是访问或者修改它指向的内容就会出错，最好的方法是在用 delete 释放这块内存之后将指向这块内存的指针置空

###  `unordered_map`

```cpp

#include <unordered_map>
#include <string>

    // 初始化
    std::unordered_map<std::string, int> age_map = {{"Alice", 25}, {"Bob", 30}};
```

```cpp
    int x, y;

    Point(const Point &other) : x(other.x), y(other.y) {}

    void print() { 
        cout << "(" << x << ", " << y << ")" << endl; 
    }
};

int main() {
    Point p1;        // 调用默认构造函数 -> (0, 0)
    Point p2(3, 4);  // 调用带参构造函数 -> (3, 4)
    Point p3 = p2;   // 调用拷贝构造函数 -> (3, 4)

    p2.print();
    p3.print();
    
    return 0;
}
```

**（7）一个细节，初始化列表方式初始化结构体的顺序问题**

```cpp
struct Example {
    int a;
    int b;
    
    // 注意：初始化列表中，b 写在 a 前面
    Example(int value) : b(value), a(b) { // 存在风险！
    }
};
```

上述代码中虽然初始化列表中是先初始化 b 再初始化 a，但是编译器会始终按照结构体中的声明顺序进行初始化，因此编译器仍然会先初始化 a，a 变成一个随机值，再初始化 b，这样就会导致 a 的值出错了

正确的写法是要保证变量声明顺序与初始化列表顺序一致：

```cpp
struct Example {
    int b; // 让被依赖的成员先声明
    int a;
    
    Example(int value) : b(value), a(b) { // 现在安全了：b先初始化，a再用b初始化
    }
};
```

### 数组初始化

#### memset 函数

`memset (*p, value, size)` 函数用于将指针指向的地方连续 size 个字节初始化为 value

用 memset 初始化一个 int[]数组为 0 的操作为：

```cpp
memset(a, 0, sizeof(a));
```

这里只能用 memset 初始化为数值 0，用其他数值初始化数组 a 最好是循环一遍，因为 memset 是逐个字节的操作

（1）`memset(a, 0, sizeof(a))`，初始化 0
（2）`memset(a, -1, sizeof(a))`，初始化-1
（3）`memset(a, 0x3f, sizeof(a))`，初始化一个尽可能大的数

### 整数二分模板

（1）找右侧性质的左端点，check 函数满足右侧性质

```cpp
bool check(int mid){
}
int bsearch(int l, int r, int t){
    while(l < r){
    	int mid = l + r >> 1;
        if(check(mid)) r = mid;
    	else l = mid + 1;//mid不满足右侧性质，那么显然mid指向的是左边性质区域，我们应该向右缩小区域
    }
    return l;
}
```

（2）找左侧性质的右端点，check 函数满足左侧性质

```cpp
bool check(int mid){
}
int bsearch(int l, int r, int t){
	while(l < r){
		int mid = l + r + 1 >> 1;
		if(check(mid)) l = mid;
		else r = mid - 1//不满足左侧性质，那么此时mid肯定指向右侧性质，所以我们应该将区域往左缩小
	}
	return l;
}
```

这样记忆：
（1）找左边区间右端点则 check 函数必须满足左侧性质；找右侧区间左端点，check 函数必须满足左侧性质，这里的满足性质指的是 check 函数中 mid 满足某侧性质后返回 ture，满足左侧性质就是 mid 满足左侧性质后返回 ture
（2）check 函数满足的是哪边的性质，那么满足 check 函数更改的就是哪边的端点；这时根据代码意思写出 if 和 else 两个语句即可
（3）mid = l + r + 1 >> 1 和某个区间 - 1 是绑定的，mid = l + r >> 1 与+1 是绑定的，先写出 check 函数，然后判断区域应该往哪里缩小，写出 else 后面的语句，然后再写 mid 应该如何改变

### 整数二分模板注意事项

（1）如果整个序列中没有右侧性质元素（比如数组 `1 4 5 5 7`，右侧性质为>= 8），此时使用找右侧性质左端点的模板返回的是元素 7 的下标，即 4；同理，如果整个序列中没有左侧性质（左侧性质定义为 < 0.5 ），此时使用找左侧性质右端点的模板返回的下标是元素 1 的下标，即 0

### 浮点数二分模板

（1）浮点数二分将整个区间分成两个部分，并且只有一个分界点，无论是找左区间右端点还是右区间左端点，这两种写法结果是一样的
（2）check 函数满足右侧性质，则修改右端点为 mid，满足左侧性质，则修改左端点为 mid，这个逻辑与整数二分是一样的
（3）由于 l 和 r 都是 double，因此两者只会无限接近，不可能相等，所以当两者差值小于某个 err（定为 1 e-9）的时候就认为相等，找到了分界点，浮点数二分不可能像整数二分那样准确找到分界点，只能无限逼近

```cpp

}

		double mid = (l + r) / 2;

		else l = mid;
	}
}
```

### 筛质数

即快速筛出 2 ~ n 中的质数

如果一个数 n是合数，那么它一定有 2 ~ n-1 中的某个质因子，反过来，如果一个数 n 不是合数（质数），那么它一定没有 2 ~ n - 1 中的某个质因子

基本思想是，对 2 ~ n 中的每一个数进行遍历，假设遍历到 i，并且当 i 是质数的时候才筛后面的数，只有后面的数是 i 的倍数都被筛掉，这样的时间复杂度近似是 On 的

```cpp
 void get_prime(int n)
 {
     //从2到最后的那个数进行枚举
     for(int i = 2; i <= n; i ++)
     {
         //如果这个数没有被前面的数筛过，说明就是一个质数
         if(!st[i]) 
         {
             prime[cnt ++] = i;
             //再将剩下的数中所有是i（质数）的倍数的数删掉
             for(int j = i + i; j <= n; j += i) st[j] = true;
         }
        
     }
 }
```

### 分解质因数

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20260105175216.png)

找到 n 的每个质因数以及它的幂的基本思路就是从小到大枚举 2 ~ $\sqrt{ n }$，枚举到 i 的时候比如上图的 2，就用 2 反复去除 360，一直到无法整除，360/2 = 180；180 / 2 = 90； 90  / 2= 45，45 无法整除 2，所以 2 这个因子就是 3 次幂，然后 45 肯定是 $3^{2} * 5$，然后继续从 3 开始枚举，得到 3 是因子并且是 2 次，数变成 5，然后从 4 开始枚举，然后从 5 开始，得到 5 是因子，并且是 1 次

这里之所以是 $\sqrt{ n }$，是因为数 n 不可能有 2 个以上超过 $\sqrt{ n }$ 的因子，而数 n 本身就是自己的因子，所以 $\sqrt{ n } \sim n - 1$ 中不可能有数 n 的因子了

```cpp
 void divide(int n)
 {
     //从小到大先将小于等于sqrt(n)的质因子枚举完
     //对于不含大于sqrt(n)质因子的数，我们从前往后遍历小于sqrt(n)的质因子
     //最后n一定是等于1退出循环
     //只有当n包含大于sqrt(n)的质因子，我们从前往后将小于原来的sqrt(n)的质因子剔除完了最后留下的就是大于原来sqrt(n)的这个数本身
     //注意此处带等号，i是可以等于n / i的，比如：9 = 3 * 3
     for(int i = 2; i <= n / i; i ++)
     {
         //如果i是n的约数
         if(n % i == 0)
         {
             //开始求i的次数
             int s = 0;
             while(n % i == 0)
             {
                 n /= i;
                 s ++;
             }
             printf("%d %d\n", i, s);
         }
     }
     
     //如果没有大于原来sqrt(n)的的质因子，那么n最后一定会为1
     //如果不为1，那么n就是它最后的那个大于原来的sqrt(n)的质因子
     if(n > 1) printf("%d %d\n", n, 1);
     puts("");
 }
```

### 一个用来知道 BFS 遍历到树的哪一层的技巧

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250704210412.png)

这道题目关键在于两点：

（1）得剔除掉不必要的结点，不让他们加入到队列中，避免复杂度爆炸
（2）剔除结点接入到队列中的时候，层序遍历就不是一个完整的树，此时不能通过结点计数取 2 的对数来确定当前结点的高度，而是在 `while(q.size())` 循环内部的刚开始加上一个 `cnt = q.size()`，这个 cnt 就表示当前层的结点个数，然后在 while 循环内部再加上一个 for 循环用于遍历当前层的结点，这个 for 循环中加入的结点一定是下一层的结点，并且 for 循环会剔除当前层的结点，这样你下次再进入 while 循环的时候得到的 q.size () 就一定是下一层的所有结点个数了
（3）根据（2）这样 while 每次循环都是一层层的遍历结点，于是可以根据 while 循环的次数来判断层序遍历的层数了

```cpp
int h = 0;
while(q.size()){

	//for循环用来遍历当前层的所有结点并将他们全部剔除
	//同时在for循环中加入下一层的结点

	for(int i = 0; i < cnt; i ++){
		int temp = q.front();
		q.pop();
		q.push(leftchild);
		q.push(rightchild);
	}
	//for循环结束之后当前层的结点就完全被剔除了，此时q中就只有下一层的结点了
	//再进入while循环的时候cnt就是下一层结点的个数了
}
```


### 求子集以及 $C_{n}^{k}$ 种组合方法

**求子集**

求子集的基本思路是对于 n 个空位，每个空位选对应的数，或者不选对应的数，然后递归进入下一个空位，到最后将所有空位的数组合起来输出即可

```cpp
//子集的每个元素选，或者不选，然后自定义数组之间排序输出
bool cmp(vector<int> a, vector<int> b){
    if(a.size() < b.size()) return true;
    else if(a.size() == b.size()){
        for(int i = 0; i < a.size(); i ++){
            if(a[i] < b[i]) return true;
            else if(a[i] > b[i]) return false;//这里必须加上a[i] > b[i]的比较，因为如果不加上并不会返回flase,而是进入下一次循环
        }
    }else return false;
    return false;
}

void dfs(int level){
    if(level == n + 1){
        res.push_back(temp);
        return;//注意这里要加上返回return
    }
    temp.push_back(level);
    dfs(level + 1);
    temp.pop_back();
    dfs(level + 1);
}

  
int main(){
    cin >> n;
    dfs(1);
    cout << endl;
    sort(res.begin(), res.end(), cmp);
    for(int i = 0; i < res.size(); i ++)
        for(int j = 0; j < res[i].size(); j ++)
            {
                if(j != res[i].size() - 1) cout << res[i][j] << " ";
                else cout << res[i][j] << endl;
            }

    return 0;

}
```

**求 $C_{n}^{k}$种数的组合

基本思想过程和求子集是完全一样的，实际上就是将子集中含有 k 个数筛出来，而且，按照这个过程，这些 k 个数的组合天然就是数组字典序的，不用自定义排序

```cpp
#include <cstdio>
#include <vector>
using namespace std;

vector<vector<int> > result;
vector<int> temp;
int n, k;

void DFS(int idx) {
    //当temp中有k个数的时候，就是一种组合
    if (temp.size() == k) {
        result.push_back(temp);
        return;
    }
    //候选数不能越界
    if (idx == n + 1) {
        return;
    }
    //仍然是针对集合中的每个元素选，或者不选
    temp.push_back(idx);
    DFS(idx + 1);
    temp.pop_back();
    DFS(idx + 1);
}

int main() {
    scanf("%d%d", &n, &k);
    DFS(1);
    for (int i = 0; i < result.size(); i++) {
        for (int j = 0; j < result[i].size(); j++) {
            printf("%d", result[i][j]);
            printf(j + 1 < result[i].size() ? " " : "\n");
        }
    }
    return 0;
}
```

## 并查集

==一个数据结构==

`p[i] = k`，表示结点 i 所在的集合的树的中，i 的父节点是 k，当 `p[i] = i` 的时候，说明这个结点是这个集合的根结点

==`find(a)`函数==

```cpp
int find(int x){
    if(p[x] != x) p[x] = find(p[x]);
    return p[x];
}
```

这个函数的作用是找结点 x 所在的集合的根结点，并一层层返回，将路径上的所有结点的父节点全部置为根结点

==算法基本过程==

**（1）初始化**

```cpp
for(int i = 1; i <= n; i ++) p[i] = i;
```

初始 n 个结点作为 n 个独立的集合

**（2）构造关系**

```cpp
    for(int i = 1; i <= m; i ++){
        int a, b;
        scanf("%d%d", &a, &b);
        p[find(a)] = find(b);
    }
```

这里 a b 表示 a 和 b 属于同一个集合（也是一般题目中给出的条件），这里的做法是让 a 所属的集合的根结点指向 b 所属的集合的根结点，注意不能是 `p[a] = find(b)`，因为如果初始情况下，同时给出了 a c 和 a b，你执行了这些代码之后只能保证 a b 属于同一个集合，c b 无法表示属于同一个集合，所以只能是 `p[find(a)] = find(c)`，开始先将 a 的根结点指向 c，即将 a 挂到 c 上，然后是 `p[find(a)] = find(b)`，这里是将 c 挂到 b 上了

**（3）查找关系 or 数所有集合的个数**

判断两个定点是否属于同一个集合，用 `find(a) == find(b)` 即可

数所有集合的个数，那就是遍历所有的顶点，将 `find (i)` 加入到 `unordered_set<int>` 中就可以了

并且查找的次数越多，往后的 `find(i)` 速度就越快，最后会保证一个集合的所有顶点全部直接挂在一个根结点上：

### 在数组上进行建树过程

即题目按照结点编号顺序给出一个树的结构，我们需要构建这棵树

建树的基本思想就是创建一个结点数组，当作整个树结点的存储空间，将结点的编号当作结点在这个空间的地址，即在结点数组中的下标即可，父子结点关系通过每个结点本身的数据结构来记录

（1）创建一个新的结构体
（2）结构体数组当作所有树结点的空间，结点编号就是结点地址，同时也是结点在数组中的元素下标
（3）通过每个结点结构体内部的 left 和 right 来记录整个树的结点之间父子关系

```cpp
struct TreeNode{
	int left, right
}Tree[MAXSIZE];

//Tree[MAXSIZE]就是整个树结点数组，每个树结点的left和right就是结点在数组中的下标，同时也是结点的编号
```

这种建树方式与完全二叉树数组形式树结构是不一样的
（1）两者相同之处在于结点编号同样都是结点在数组中的下标
（2）不同之处在于这种建树方式，父子结点关系通过一个新的结构确定，上文代码所示，而完全二叉树方式的树结构，父子结点关系通过数组本身的下标关系确定，即编号 i 的左儿子必须是 2 * i，编号 i 的右儿子必须是 2 * i + 1
（3）这种建树方式数组只是起到一个提供地址空间的作用，具体的父子结点关系通过结构体中的 left, right 数值确定，比如编号 1 的结点左儿子和右儿子可以是编号 2 和 5，遍历的时候直接按照编号 1 结点的结构体记录的 left 和 right 数值进行遍历即可；但是在完全二叉树数组形式的树结构中编号 1 的左儿子必须是 2，右儿子必须是 3，遍历的时候必须通过数组本身的结构来遍历

```cpp
#include <cstdio>
#include <vector>
using namespace std;

const int MAXN = 50;

struct Node {
    int l, r; // 左子节点和右子节点编号
} nodes[MAXN];

vector<int> pre; // 存储先序遍历结果

void preOrder(int root) {
    if (root == -1) { // 如果当前节点为空，直接返回
        return;
    }
    pre.push_back(root); // 访问当前节点
    preOrder(nodes[root].l); // 递归访问左子树
    preOrder(nodes[root].r); // 递归访问右子树
}

int main() {
    int n;
    scanf("%d", &n); // 读取节点个数
    for (int i = 0; i < n; i++) {
        scanf("%d%d", &nodes[i].l, &nodes[i].r); // 读取每个节点的左子节点和右子节点编号
    }
    preOrder(0); // 从根节点开始进行先序遍历
    for (int i = 0; i < (int)pre.size(); i++) {
        printf("%d", pre[i]); // 输出先序遍历结果
        if (i < (int)pre.size() - 1) {
            printf(" "); // 确保行末没有多余空格
        }
    }
    return 0;
}
```

### 判断二叉树是完全二叉树的方法

用 BFS 层序遍历，将整个二叉树当成一个满二叉树遍历，即空结点也当作一个结点放入队列，空结点的左右儿子也是空结点，这样一个满二叉树由空结点和非空结点组成，BFS 层序遍历的话就是从左到右，从上到下

如果遍历到了空结点，根据这个满二叉树的结构，如果是完全二叉树的话，那么后续遍历就不能出现非空结点，一直将整个满二叉树遍历完全；如果遍历的时候空结点在非空前面，那么就不是完全二叉树了

有一个规律是，一旦遍历到了空结点，那么如果是非完全二叉树的话，这个空结点的当前层或者下一层一定会出现非空结点，因此遍历完这个空结点这一层之后，完全可以保证队列中空结点后面会有一个非空结点，这样你一定可以遍历一个非空结点，所以遍历到空结点的时候可以不用把空结点的左右儿子放入队列，直接往后遍历即可，如果后面全是空结点，那当然就是完全二叉树，如果出现了非空结点，那就不是了


```cpp
bool isCompleteTree(TreeNode* root) {
    queue<TreeNode*> q;               // 用于层序遍历
    q.push(root);                     // 入队根节点

    bool foundNull = false;           // 是否已遇到空节点

    while (!q.empty()) {
        TreeNode* node = q.front();   // 取队头
        q.pop();                      // 出队

        if (node == nullptr) {        // 遇到空节点
            foundNull = true;         // 设置标记
        } else {
            if (foundNull) {          // 若之前遇到空节点
                return false;         // 再遇非空则非完全二叉树
            }
            q.push(node->left);       // 左孩子入队
            q.push(node->right);      // 右孩子入队
        }
    }

    return true;                      // 完全二叉树
}
```
