# 基本语法

### sort 函数

#### 普通的升序排序

sort 函数是 C++中的函数

==对 vector 进行升序的操作是 :==

```cpp
vector<int> a;
sort(a.begin(), a.end());
```

上面的 a.begin () 表示指向 a 的第一个元素的指针；a.end () 是指向最后一个元素的后一个位置的指针, sort 函数的括号中对元素是左闭右开的

==对普通数组 a[]进行升序排序是：==

```cpp
int a[n];
sort(a, a + n);
```

#### 降序排序

如果想要降序操作还得加上一个 cmp 函数：

```cpp
bool cmp(int &x, int &y) {
   return x > y;
}

int main(){
	int a[n];
	
	sort(a, a + n, cmp);//此时降序排列
}
```

这里 cmp 函数的含义就是保证前后两个元素 x, y 满足 cmp 函数中为 ture 的规则

如果想要对 `vector<int>` 进行降序排列，跟普通的一样：

```c++
#include <vector>
#include <algorithm>

// 自定义比较函数
bool compareDescending(int a, int b) {
    return a > b;
}

int main() {
    std::vector<int> vec = {3, 1, 4, 1, 5, 9, 2, 6};
    std::sort(vec.begin(), vec.end(), compareDescending);
}
```

#### 对数组之间进行排序

比如，如果想要按照数组元素个数对数组排序，并且两个数组的元素个数相等的时候数组元素按照字典序排序（字典序就是当两个数组元素个数相同的时候，前 k - 1 个元素相等，如果第 k 个元素 a[k]  < b[k]，则数组 a 排序在 b 前面）

```cpp
vector<vector<int>> result; //一堆待排序的数组

//自定义排序规则
bool cmp(const vector<int> &a, const vector<int> &b){
	//先保证个数小的在前
	if(a.size() ！= b.size()) return a.size() < b.size();
	else return a < b;//个数相等的时候保证字典序
}

sort(result.begin(), result.end(), cmp);


```

#### 使用 sort 函数来对结构体进行排序

```c
#include <iostream>
#include <algorithm>
#include <vector>
using namespace std;

// 学生结构体
struct Student {
    string name;
    int id;
    double gpa;
};

// 按GPA降序排序
bool compareByGPA(const Student& a, const Student& b) {
    return a.gpa > b.gpa; // 降序排序
}

// 按姓名升序排序
bool compareByName(const Student& a, const Student& b) {
    return a.name < b.name;
}

// 多级排序：GPA相同时按ID升序
bool multiCompare(const Student& a, const Student& b) {
    if (a.gpa != b.gpa)
        return a.gpa > b.gpa;
    return a.id < b.id;
}

int main() {
    vector<Student> students = {
        {"Alice", 101, 3.8},
        {"Bob", 102, 3.9},
        {"Charlie", 103, 3.8},
        {"David", 104, 3.95}
    };

    // 按GPA降序排序
    sort(students.begin(), students.end(), compareByGPA);
    
    cout << "按GPA降序排序:" << endl;
    for (const auto& s : students) {
        cout << s.name << " (" << s.id << "): " << s.gpa << endl;
    }

    // 多级排序
    sort(students.begin(), students.end(), multiCompare);
    
    cout << "\n多级排序(GPA降序，相同则ID升序):" << endl;
    for (const auto& s : students) {
        cout << s.name << " (" << s.id << "): " << s.gpa << endl;
    }

    return 0;
}
```
#### 关于 cmp 函数

总的来说，cmp 的写法是，对于相邻两个元素，如果满足排序之后的数组相邻元素之间的关系，则返回 true，否则返回 false


### CPP 中的循环变量回收问题

#### 普通变量的回收

| 变量类型        | 生命周期         | 回收机制       | 风险提示           |
| ----------- | ------------ | ---------- | -------------- |
| 基本类型 (int 等) | 每次迭代结束       | 栈内存立即回收    | 无风险            |
| 对象类型        | 每次迭代结束       | 析构函数调用+栈回收 | 注意析构函数副作用      |
| 原始指针        | 每次迭代结束（指针本身） | 栈回收（指针变量）  | **堆内存泄漏**（高风险） |
| 智能指针        | 每次迭代结束       | 自动释放管理的内存  | 无风险            |
基本变量和对象类型是指在循环中定义的 int，double, string 之类的，一次循环结束的时候其会自动回收，下一次循环或者跳出循环这个变量就不能再使用了，比如：

```cpp
for (int i = 0; i < 5; ++i) {
    int temp = i * 10;      // 基本类型
    std::string s = "test"; // 对象类型
    
    // 每次迭代结束时：
    // 1. s的析构函数会被调用（释放字符串内存）
    // 2. temp和s的栈内存会被回收
}
```

指针类型的话，如果是普通的指针，其与基本变量是一致的，指针变量本身会被销毁，但是指针变量指向的 new 语句的内存不会被销毁：

```cpp
while(p && p->next){

        ListNode* temp = new ListNode(p->val);//temp指针变量每次循环都会重新创建
        //但是new的内存空间不会被回收，temp是这块内存空间地址
        //后面的语句是让这个内存空间的next指针指向上一个内存空间
        //这些内存空间以及各自的关系不会在循环结束后发生改变，改变以及销毁的只是存放这个内存空间地址的容器temp指针

        temp->next = pre;

        pre = temp;

        p = p->next;

    }
```

```cpp
            tempName = "李四";

        students.push_back(tempStu);
```

### C++中的函数参数回收问题

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250721153243.png)

C++在一个函数中，创建的局部变量会被回收，其地址也将不复存在，比如：
```cpp
void example() {
    int a = 10;           // 局部变量（栈）
    TreeNode localNode;   // 局部对象（栈）
} // 函数结束 → a和localNode自动销毁
```

但是如果一个函数 new 了一个对象，那说明这个对象是在堆上，那么当函数结束的时候这个对象同样不会被销毁，只是指向这个对象的指针是临时变量，存储这个对象的地址，它在函数调用结束的时候会被销毁：

```cpp
void example() {
    TreeNode* heapNode = new TreeNode();  // 堆分配
    nodes.push_back(heapNode);
} // heapNode指针销毁 → 但堆内存依然存在！
```

#### 函数中对全局数组 vector 的修改问题

vector 是一个全局数组，假设在一个函数中对其进行下面两类修改：

**第一类：**

```cpp
#include <vector>
using namespace std;

vector<int> nodes; // 全局vector

void addToNodes() {
    int a = 42; // 局部变量（临时变量）
    nodes.push_back(a); // 关键操作
    // 函数结束 → a被销毁
}

int main() {
    addToNodes();
    // 这里nodes仍然包含42
}
```

这里 nodes 中会保留 42，这是因为 push_back (a) 的本质是将 a 的具体数值赋值一份到 nodes 所在的内存空间中，当函数调用结束，nodes 不会被销毁，所以此时 nodes 中仍然保留 42 这个数值，这个数值是一个 int 类型的有意义的变量，可以被继续使用

**第二类**

```cpp
vector<int*> ptrNodes; // 指针向量

void badAdd() {
    int a = 42; // 局部变量
    ptrNodes.push_back(&a); // 存储局部变量的地址
} // a被销毁，ptrNodes[0]成为悬空指针

int main() {
    badAdd();
    cout << *ptrNodes[0]; // 未定义行为! 可能崩溃或输出错误值
}
```

这里其实 a 的地址还是会保留在 nodes 中，因为 a 的地址被复制了嘛，但是 a 变量本身在函数结束之后就被销毁了，这个地址就没有意义了，可能会被 OS 放入其他的数据，此时 nodes 中如果继续保留这个无意义的地址，那就是悬挂指针了，容易出错

**第三类**

```cpp
std::vector<TreeNode*> nodes;  // 全局结果集
int height;                     // 全局树高度

// 修复后的递归函数
void dfsl(TreeNode* root, int h) {
    if (!root) return;  // 空节点处理
    
    // 到达目标层：保存并停止递归
    if (h == height - 1) {
        nodes.push_back(root);
        return;  // ★ 关键修复：保存后立即返回 ★
    }
    
    // 递归子节点
    if (root->left) dfsl(root->left, h + 1);
    if (root->right) dfsl(root->right, h + 1);
}
```

这个代码的含义是将树的某一层的结点放入到全局数组 nodes 中

在这个函数中，root 是指向 TreeNode 的指针，其存储结点的地址，root 是一个函数局部变量，是一个指针变量，它在函数调用结束之后就会被销毁，但是 root 的内容是堆上的结点的地址，这个地址是始终有意义的，它被复制了一份到 nodes 中，函数结束但是堆的内容不变，所以 nodes 中的这份地址，即结点的地址，也可以说是结点的指针，仍然是有意义的，仍然可以通过 nodes[i]->val 来访问这个结点的 val 内容，此时 nodes[i]就是在堆上的结点的地址，也是指向结点的指针

这里的修改 nodes 的本质其实和第一类修改是一样的，nodes 中传入的始终是一个函数结束之后仍然有意义的数据
### C ++中的数组传参和二维数组传参

#### int a[]\[n]二维数组传参

这里的列必须是常量，是一个具体常数 3，或者 4；或者是一个 const int n；不能是 int n

```cpp
void func(int a[][3], int rows) { // 必须指定列数（此处为3）
    for (int i = 0; i < rows; ++i) {
        for (int j = 0; j < 3; ++j) {
            cout << a[i][j] << " ";
        }
    }
}

int main() {
    int arr[2][3] = {{1,2,3}, {4,5,6}};
    func(arr, 2); // 传递数组名和行数
}
```

这种形式的传参二维数组的每一行的列数是固定的，所以编译器会进行检查，因此列数必须是一个常量，这种二维数组的初始化时候就是普通的初始化

#### **`vector<vector<int>>` 二维数组传参**

下面是一个使用 `std::vector<std::vector<int>>` 容器进行二维数组传参的完整示例：
```cpp
#include <iostream>
#include <vector>

// 1. 按值传递（会创建副本，适用于需要修改副本的场景）
void printByValue(std::vector<std::vector<int>> matrix) {
    std::cout << "按值传递:\n";
    for (const auto& row : matrix) {
        for (int num : row) {
            std::cout << num << " ";
        }
        std::cout << "\n";
    }
    matrix[0][0] = 100; // 修改不影响原始数据
}

// 2. 按常量引用传递（推荐，避免拷贝，只读访问）
void printByConstRef(const std::vector<std::vector<int>>& matrix) {
    std::cout << "\n按常量引用传递:\n";
    for (const auto& row : matrix) {
        for (int num : row) {
            std::cout << num << " ";
        }
        std::cout << "\n";
    }
}

// 3. 按引用传递（可修改原始数据）
void modifyMatrix(std::vector<std::vector<int>>& matrix) {
    std::cout << "\n按引用传递（修改前）:\n";
    for (const auto& row : matrix) {
        for (int num : row) {
            std::cout << num << " ";
        }
        std::cout << "\n";
    }
    
    // 修改原始数据
    for (auto& row : matrix) {
        for (int& num : row) {
            num *= 2; // 每个元素乘以2
        }
    }
}

int main() {
    // 创建二维vector
    std::vector<std::vector<int>> matrix = {
        {1, 2, 3},
        {4, 5, 6},
        {7, 8, 9}
    };

    // 1. 按值传递调用
    printByValue(matrix);
    
    // 2. 按常量引用传递调用
    printByConstRef(matrix);
    
    // 3. 按引用传递调用（会修改原始数据）
    modifyMatrix(matrix);
    
    // 显示修改后的结果
    std::cout << "\n修改后的原始矩阵:\n";
    printByConstRef(matrix);

    return 0;
}
```

| ---------------- | ----------------------------------- | ----------------------------------- | ----------- |

| **按引用传递**        | `vector<vector<int>>& matrix`       | 无拷贝开销，可直接修改原始数据                     | 需要修改原始数据的场景 |

### C++中的内存释放与悬挂指针

==delete 的用法==

delete 后面跟的应该是一个内存的地址，用于释放这块内存，将内存还给 OS

（1）delete 释放单个对象的内存

```cpp

// 创建单个对象
MyClass* obj = new MyClass(); 
// 释放对象
delete obj;       // 正确用法
obj = nullptr;    // 推荐：避免悬挂指针

TreeNode* lchild = new TreeNode();
root->left = lchild;//将lchild指向的内存地址赋给root->left这个指针，此时lchild和root->left其实是指向同一块内存区域

delete lchild;//或者这里用delete root->left
root->left = nullptr;
lchild = nullptr;
```

（2）delete 释放多个对象的内存

```cpp
// 创建对象数组
MyClass* arr = new MyClass[10]; 

// 释放数组
delete[] arr;     // 注意 [] 符号
arr = nullptr;

int* numbers = new int[100];
delete[] numbers;  // 即使基本类型也需要 delete[]
numbers = nullptr;
```

==悬挂指针==

当使用 delete 释放某一块的内存之后，这块内存被交给 OS 可以被重新分配，但是，之前指向这块内存的指针的值仍然是这块内存的地址，相当于这个指针仍然指向这块内存，这个就是悬挂指针

由于这个指针不为空，所以其实它也可以被访问，但是访问或者修改它指向的内容就会出错，最好的方法是在用 delete 释放这块内存之后将指向这块内存的指针置空

#### C++结构体构造函数

**（1）编译器会自带一个构造函数，称为默认构造函数，初始化的时候会导致结构体内部的值不确定**

```cpp
struct Student {
    int id;
    char gender;

    Student stu; // 使用编译器生成的默认构造函数，id和gender值不确定
    return 0;

```

**（2）可以自己手动定义默认构造函数，这样在初始化的时候可以将结构体内部数值初始化为默认构造函数中的值**

```cpp
struct Student {
    int id;
    char gender;
    Student() { // 手动定义默认构造函数
        id = 0;
        gender = '\0'; // 或其它你希望的默认值
    }
};
```

**（3）带参构造函数，用于在创建对象的时候赋给自己希望的值**

```cpp
struct Student {
    int id;
    char gender;
    // 带参数的构造函数
    Student(int _id, char _gender) {
        id = _id;
        gender = _gender;
    }
};

//简洁写法
struct Student {
    int id;
    char gender;
    Student(int _id, char _gender) : id(_id), gender(_gender) {}
};

//使用方式
Student stu1(10086, 'M'); // 直接初始化
Student stu2 = Student(10087, 'F'); // 显式调用构造函数
```

如果自己显示定义了带参构造函数，那么在结构体初始化的时候必须按照带参的方式声明结构体，如果仅仅是 `Student stu` 这种声明，则会出错

**（4）构造函数重载**

可以同时定义 `Student()`、`Student(int _id)` 和 `Student(int _id, char _gender)`，此时仅仅是 `Student stu` 这种声明，则不会出错，比如：

```cpp
struct ListNode{
	int val;

```

**（5）拷贝构造函数**

拷贝构造函数用于构造函数的参数是另一个结构体，它的参数必须是对结构体的引用，一般就是 `const Student&`：

```cpp
struct Student {
    int id;
    char gender;
    // 拷贝构造函数
    Student(const Student &other) {
        id = other.id;
        gender = other.gender;
    }
};
```

结构体的拷贝构造函数只有在下面的情况下才会调用：

```cpp
Student s1;           // 调用普通构造函数
Student s2 = s1;      // 调用拷贝构造函数（初始化）
Student s3(s1);       // 调用拷贝构造函数（初始化）

//对两个已经声明的构造体s1, s2
s1 = s2;//这里并不会调用拷贝构造函数，而是运算符=重载
```


**（6）一个简单的例子**

```cpp
#include <iostream>
using namespace std;

struct Point {
    int x, y;
    
    // 默认构造函数
    Point() : x(0), y(0) {} 
    
    // 带参数的构造函数
    Point(int _x, int _y) : x(_x), y(_y) {}
    
    // 拷贝构造函数
    Point(const Point &other) : x(other.x), y(other.y) {}

    Point p3 = p2;   // 调用拷贝构造函数 -> (3, 4)
    
    p1.print();
    p2.print();
    p3.print();
    
    return 0;
}
```

**（7）一个细节，初始化列表方式初始化结构体的顺序问题**

```cpp
struct Example {
    int a;
    int b;
    
    // 注意：初始化列表中，b 写在 a 前面
    Example(int value) : b(value), a(b) { // 存在风险！
    }
};
```

上述代码中虽然初始化列表中是先初始化 b 再初始化 a，但是编译器会始终按照结构体中的声明顺序进行初始化，因此编译器仍然会先初始化 a，a 变成一个随机值，再初始化 b，这样就会导致 a 的值出错了

正确的写法是要保证变量声明顺序与初始化列表顺序一致：

```cpp
struct Example {
    int b; // 让被依赖的成员先声明
    int a;
    
    Example(int value) : b(value), a(b) { // 现在安全了：b先初始化，a再用b初始化
    }
};
```

#### memset 函数

`memset (*p, value, size)` 函数用于将指针指向的地方连续 size 个字节初始化为 value

用 memset 初始化一个 int[]数组为 0 的操作为：

```cpp
memset(a, 0, sizeof(a));
```

这里只能用 memset 初始化为数值 0，用其他数值初始化数组 a 最好是循环一遍，因为 memset 是逐个字节的操作

### C++的动态分配内存

在 C++ 中，动态内存分配允许程序在运行时（而非编译时）请求内存。这是通过 `new` 和 `delete` 运算符实现的。以下是动态内存分配的核心用法和最佳实践：

#### ​单个对象​​

```
// 分配单个 int
int* pInt = new int;       
*pInt = 42;

// 分配并初始化
double* pDouble = new double(3.14); 

// 释放内存
delete pInt;     
delete pDouble;
```

#### ​​对象数组​​

```
// 分配 10 个 int 的数组
int* arr = new int[10];     

// 初始化数组
for (int i = 0; i < 10; ++i) {
    arr[i] = i * 10;
}

// 释放数组内存
delete[] arr;  // 必须使用 delete[]
```



#### ​​动态分配类对象​​

```
class MyClass {
public:
    MyClass() { std::cout << "构造\n"; }
    ~MyClass() { std::cout << "析构\n"; }
    void show() { std::cout << "方法调用\n"; }
};

// 动态创建对象
MyClass* obj = new MyClass(); 

// 使用对象
obj->show();                  

// 释放对象
delete obj;                   
```

> ​**​输出​**​：  
> 构造  
> 方法调用  
> 析构

#### ​​动态字符串​​

```
// 分配缓冲区
char* buffer = new char[100]; 

// 安全复制
strncpy(buffer, "Hello", 99); 
buffer[99] = '\0'; // 确保终止

std::cout << buffer;

delete[] buffer;
```

#### 一些注意的问题​

1. ​**​配对使用​**​：每个 `new` 对应一个 `delete`，`new[]` 对应 `delete[]`
    
    ```
    int* p = new int;     → delete p;
    int* arr = new int[5]; → delete[] arr;
    ```
    
2. ​**​避免裸指针​**​：优先使用智能指针（`unique_ptr`, `shared_ptr`）
    
3. ​**​RAII 原则​**​：通过构造函数分配，析构函数释放
    
    ```
    class ResourceHolder {
        int* data;
    public:
        ResourceHolder(size_t size) : data(new int[size]) {}
        ~ResourceHolder() { delete[] data; }
    };
    ```
    
4. ​**​预防内存泄漏​**​：
    
    ```
    // 错误示例
    void leak() {
        int* p = new int[10];
        return; // 忘记 delete[] → 内存泄漏
    }
    ```
    
5. ​**​避免悬空指针​**​：
    
    ```
    int* p = new int(10);
    delete p;
    // p = nullptr; // 安全做法
    *p = 20; // 危险！悬空指针
    ```

（1）得剔除掉不必要的结点，不让他们加入到队列中，避免复杂度爆炸
（2）剔除结点接入到队列中的时候，层序遍历就不是一个完整的树，此时不能通过结点计数取 2 的对数来确定当前结点的高度，而是在 `while(q.size())` 循环内部的刚开始加上一个 `cnt = q.size()`，这个 cnt 就表示当前层的结点个数，然后在 while 循环内部再加上一个 for 循环用于遍历当前层的结点，这个 for 循环中加入的结点一定是下一层的结点，并且 for 循环会剔除当前层的结点，这样你下次再进入 while 循环的时候得到的 q.size () 就一定是下一层的所有结点个数了
（3）根据（2）这样 while 每次循环都是一层层的遍历结点，于是可以根据 while 循环的次数来判断层序遍历的层数了

```cpp
int h = 0;
while(q.size()){
	int cnt = q.size();//这里的q.size()必须写在外边不能放在循环中
	h ++;//每进入while循环一次h ++ ，表示树的高度++，根结点是第一层
	//for循环用来遍历当前层的所有结点并将他们全部剔除
	//同时在for循环中加入下一层的结点

	for(int i = 0; i < cnt; i ++){
		int temp = q.front();
		q.pop();
		q.push(leftchild);
		q.push(rightchild);
	}
	//for循环结束之后当前层的结点就完全被剔除了，此时q中就只有下一层的结点了
	//再进入while循环的时候cnt就是下一层结点的个数了
}
```

### 判断二叉树是完全二叉树的方法

用 BFS 层序遍历，将整个二叉树当成一个满二叉树遍历，即空结点也当作一个结点放入队列，空结点的左右儿子也是空结点，这样一个满二叉树由空结点和非空结点组成，BFS 层序遍历的话就是从左到右，从上到下

如果遍历到了空结点，根据这个满二叉树的结构，如果是完全二叉树的话，那么后续遍历就不能出现非空结点，一直将整个满二叉树遍历完全；如果遍历的时候空结点在非空前面，那么就不是完全二叉树了

有一个规律是，一旦遍历到了空结点，那么如果是非完全二叉树的话，这个空结点的当前层或者下一层一定会出现非空结点，因此遍历完这个空结点这一层之后，完全可以保证队列中空结点后面会有一个非空结点，这样你一定可以遍历一个非空结点，所以遍历到空结点的时候可以不用把空结点的左右儿子放入队列，直接往后遍历即可，如果后面全是空结点，那当然就是完全二叉树，如果出现了非空结点，那就不是了


```cpp
bool isCompleteTree(TreeNode* root) {
    queue<TreeNode*> q;               // 用于层序遍历
    q.push(root);                     // 入队根节点

    bool foundNull = false;           // 是否已遇到空节点

    while (!q.empty()) {
        TreeNode* node = q.front();   // 取队头
        q.pop();                      // 出队

        if (node == nullptr) {        // 遇到空节点
            foundNull = true;         // 设置标记
        } else {
            if (foundNull) {          // 若之前遇到空节点
                return false;         // 再遇非空则非完全二叉树
            }
            q.push(node->left);       // 左孩子入队
            q.push(node->right);      // 右孩子入队
        }
    }

    return true;                      // 完全二叉树
}
```

### 一个基于数组的邻接表建图方法

==基本数据结构==

```cpp
 int h[N], e[N], ne[N], idx;
 //h[N]是每个单链表的头指针，指向每个单链表的第一个结点,h[i]是结点i的链表头指针
 //e[N]是链表的结点元素,e[i]的i是结点地址
 //ne[N]是链表的结点的指针，其指向对应单链表的下一个结点,ne[i]的i是结点地址，跟e[i]成对出现
 //e[N]和ne[N]通过下标联系起来，下标相同的e[]和ne[]属于同一个结点，下标就是结点的地址
 //需要注意的是，e[]和ne[]被切分成了多个链表
 //idx表示用到了哪个空闲结点，idx用来模拟结点的地址
```

==初始化==

```cpp
 memset(h, -1, sizeof h);
 //将所有邻接表的头指针指向-1，即空集
```

==插入一条边的操作==

```cpp
 void add(int a, int b)
 {
     e[idx] = b;//b作为结点元素
     ne[idx] = h[a];//b对应的结点插入到a结点的单链表中，我们用对应的图结点元素来索引对应的头指针
     h[a] = idx;//插入到头部，头指针指向b结点对应的地址
     idx ++;//空闲指针指向下一个空闲结点的地址，指向下一个待分配的结点
 }
```


==dfs 遍历==

```cpp
 //由于遍历只遍历一次，用bool数组来记录哪些点已经被遍历过
 bool st[N];
 
 //dfs(i)的i是结点编号​
 void dfs(int u)
 {
     st[u] = true;//标记一下这个点已经被搜过了
     
     //遍历这个结点的所有出边，类似于深度优先搜索中的遍历所有的分支
     //这里的i是定点u的临界链表的所有结点地址
     for(i = h[u]; i != -1; i = ne[i])
     {
         int j = e[i];//记录链表里的结点对应图中的编号是多少,根据地址i取出这个结点对应的定点编号
         if(!st[j]) dfs(j);//如果没有被搜过就一直搜下去
         
         //因为只是单纯的遍历，所以搜完后回溯不需要再回到什么初始状态
     }
 }
```


### 关于有向图和无向图的区别

无向图其实是特殊的有向图，即带有一个小环的有向图，比如对于邻接矩阵来说无向图的存储就是 `G[i][j] = G[j][i] = w` 是一个带有小环的无向图

所以那些只要能够处理有向图中带有环的算法都可以处理无向图数据

比如 Dijkstra 和 Floyd，他们两个可以处理有向图中带有正环的问题，所以也可以处理无向图的问题


## 并查集

==一个数据结构==

`p[i] = k`，表示结点 i 所在的集合的树的中，i 的父节点是 k，当 `p[i] = i` 的时候，说明这个结点是这个集合的根结点

==`find(a)`函数==

```cpp
int find(int x){
    if(p[x] != x) p[x] = find(p[x]);
    return p[x];
}
```

这个函数的作用是找结点 x 所在的集合的根结点，并一层层返回，将路径上的所有结点的父节点全部置为根结点

==算法基本过程==

**（1）初始化**

```cpp
for(int i = 1; i <= n; i ++) p[i] = i;
```

初始 n 个结点作为 n 个独立的集合

**（2）构造关系**

```cpp
    for(int i = 1; i <= m; i ++){
        int a, b;
        scanf("%d%d", &a, &b);
        p[find(a)] = find(b);
    }
```

这里 a b 表示 a 和 b 属于同一个集合（也是一般题目中给出的条件），这里的做法是让 a 所属的集合的根结点指向 b 所属的集合的根结点，注意不能是 `p[a] = find(b)`，因为如果初始情况下，同时给出了 a c 和 a b，你执行了这些代码之后只能保证 a b 属于同一个集合，c b 无法表示属于同一个集合，所以只能是 `p[find(a)] = find(c)`，开始先将 a 的根结点指向 c，即将 a 挂到 c 上，然后是 `p[find(a)] = find(b)`，这里是将 c 挂到 b 上了

**（3）查找关系 or 数所有集合的个数**

判断两个定点是否属于同一个集合，用 `find(a) == find(b)` 即可

数所有集合的个数，那就是遍历所有的顶点，将 `find (i)` 加入到 `unordered_set<int>` 中就可以了

并且查找的次数越多，往后的 `find(i)` 速度就越快，最后会保证一个集合的所有顶点全部直接挂在一个根结点上：

## 贪心

### 1

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250609154649.png)

这里保证数组 a 是从小到大排列，b 是从大到小排列
![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250609154918.png)

这种情况下 a 和 b 的元素逐个相加

（1）如果此时满足逐个相加 <= x，那么可以推出有这样一个排列成立

（2）如果此时不满足逐个相加 <= x，假设此时 ai + bi > x，即不存在一个 bi 与 ai 配对的排列满足题意

那么此时，如果将 bi 往前换，那么 ai 前面一定有一个 ak 配对 bk >= bi 要被换到后面与 ai 以及后面 aj 配对，显然此时 bk 都大于等于 bi 了而 ai + bi > x，那么 bk 往后面配对的时候也一定有 bk + a (i ~ j) > x，所以不存在一个 bi 与 ai 之前的元素配对的排列满足题意

如果将 bi 往后换，那 ai 后面一个要有一个 aj 与 bi 对应，但是 ai + bi > x，那显然 aj >= ai 也满足 aj + bi > x，所以不存在一个 bi 与 ai 之后的元素配对的排列满足题意

所以在这种情况下只要逐个相加有不满足的元素对，那么就不可能通过调整，使得 b 的一个排列与 a 逐个相加成立了，也就不存在一个排列满足题意

所以可以通过判断数组 a 是从小到大排列，b 是从大到小排列，逐个元素配对来等价判断是否有一个 b 的排列满足题意


### 2

![image.png](https://typora-1310242472.cos.ap-nanjing.myqcloud.com/typora_img/20250618154500.png)

如果可以通过调整变成互不相同的数，那么这些数一定可以形成一个严格递增的序列

于是我们可以先对数组从小到大排序，对于排序之后的数组，如果有一个策略使得其可以严格递增，那就等价于原数组有一个调整策略符合题意（因为排序之后元素本身没有变化，对排序之后的每个元素的调整可以直接放到原数组对应元素的调整，并且严格递增了，当然互不相同）；同样如果排序之后的数组不存在一个策略满足严格递增，那么原数组也没有一个策略满足题意了

**即对排序之后的数组进行调整得到一个严格递增的序列与原数组调整使得各个数互不相同具有等价性**

这里的策略是，对于相邻的两个元素 a[i]和 a[i + 1]，设 a[i]调整之后的数值是 last 且没有与前面的数发生冲突；那么 a[i + 1]就在 a[i + 1] - 1, a[i + 1], a[i + 1] + 1 这三个数中选择一个满足大于 last 的最小的数；这样可以留给后面的数的调整空间尽可能的大

如果按照这种策略调整完了之后，数组是严格递增的，那么对这些数在原数组中对应位置进行同样的调整，那当然就存在一个策略满足了题意；

下面来说明如果这种策略失败，那也不存在一个别的策略将排序之后的数组调整成严格递增，既然排序之后的序列没有一个策略将其调整成严格递增的，那这些数就不能调整成严格递增的序列，那原来的数组就不可能经过调整后重新排列获得一个递增的排列（有点小问题，不过就这样吧，不纠结了）

下面来证明当这种策略失败之后，没有别的策略可以将其调整成严格递增的

这种策略失败的情况是，a[i]调整为 last 的时候没有冲突，但是对于a[i + 1]，其可能调整的数值a[i + 1] - 1, a[i + 1], a[i + 1] + 1 都小于上一个数 a[i]的调整数值 last，那么这个时候，只可能有 a[i] = a[i + 1]才会出现这种情况，并且 last = a[i] + 1 = a[i + 1] + 1（因为如果 a[i] < a[i + 1]，那么 last 最大也才是 a[i] + 1 = a[i + 1]，a[i+ 1] 完全可以调整为 a[i + 1] + 1 来保证没有冲突）

那么对于 a[0] <= a[1] <= a[2] <= ... <= a[i] = a[i + 1]，假设还有一个别的调整策略使得冲突没有发生，也就是还有一个别的调整策略使得可以调整成严格递增的序列，那么此时对于 a[0] ~ a[i - 1]这些数，假设 a[k]是第一个与原策略调整之后不一样的数，原策略 a[k] = M 1, 新策略 a[k] = M 2，并且原策略 a[k-1] = N，由于 a[k]的调整只能是 a[k] - 1, a[k] a[k] + 1 三种可能，原策略调整为 M 1 保证了严格递增且M 1 的含义是三种可能中第一个大于 a[k-1] = N 的数，那么新策略必须保证 M 2 > M 1

也就是说，这个新策略与原策略相比，第一个不同的数 a[k]经过调整后必然是大于原策略的，那么a[k]后面的数，经过新策略的调整也必然不会比原策略小；因此对于 a[i]其经过新策略调整的数值有 last >= a[i] + 1，所以 last 还是 a[i] + 1，此时 a[i + 1]还是无法调整，出现矛盾

简而言之，就是如果原策略调整失败，那么新策略为了保证严格单增进行调整的时候会导致原来的数往大了调整，这会导致 a[i]还是会调整成 last，a[i + 1]仍然会调整失败，所以原策略调整失败之后不存在一个别的策略可以调整成功

所以原贪心策略将排序之后的数字调整成严格递增的序列具有等价性，这个策略可以，那就可以看，这个策略不行，那就不行

于是就可以通过对排序之后的数组使用这个策略来判断原来的数组是否有一个策略调整成互不相同的了
